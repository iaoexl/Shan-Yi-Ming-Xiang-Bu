# 食饵系统知识库

## README · 导览

> 本知识库以五部道教服食与本草文献——《云笈七签·方药部》《抱朴子内篇·仙药篇》《神农本草经》《食疗本草》《黄帝九鼎神丹经诀》——为骨架，将原本按书分列的读书笔记重组为按主题贯通的食饵研究体系：从文献谱系、本草三品、仙药服食、食疗日用、辟谷服气、丹经炼服，到禁忌边界与整理方法。所述内容属传统饮食与药物文化研究，不作"功效/灵验"的真实性宣称。

### README_1 材料来源与本书定位

本库主源为「读书笔记」五册：《云笈七签·方药部》《抱朴子内篇·仙药篇》《神农本草经》《食疗本草》《黄帝九鼎神丹经诀》；辅源为同名五册「书籍」原文（必要时用于补全）。五书分属不同文类，彼此构成互补而非重复：

1. 《神农本草经》为本草体例母本，以"物"为条、以"三品"分等，是后世一切药目的格式源头。
2. 《抱朴子内篇·仙药篇》为仙药名物志兼操作手册，以"物性"为轴，重名实、产地、采制与隐秘。
3. 《食疗本草》为唐代食疗专书，以"食"为用，把厨房经验系统化，重心在宜忌。
4. 《云笈七签·方药部》为道教类书之一门，以"法"为轴，把诸家异说并列收编，价值在存异而非裁断。
5. 《黄帝九鼎神丹经诀》为早期外丹丹经，以"炼服次第"为轴，文本分层（经诀图录），价值在火候与"候"的方法论。

五书合观，恰好覆盖"吃什么—是什么—怎么处置—有什么忌—另有几种说法"这一食饵知识的完整环路。本库不按书罗列，而按主题打散重组，以便横向对照。

### README_3 几种进入方式

1. **按主题贯通**：从板块1入门，先弄清五书"各回答什么问题"，再顺板块2→4展开，适合系统研究者。
2. **按问题检索**：有具体食物或药材疑问，直奔板块4（食疗）与板块7（禁忌边界），适合日常对照。
3. **按方法检索**：想学如何读古籍、做笔记、做验证，看板块8，适合文献整理者。
4. **按源流检索**：想理解类书体例与丹经文本分层，看板块1与板块6，适合目录学与道教文献方向。

### README_4 核心心法

1. **名实先于功效**：先辨"这是什么、出哪里、怎么认"，再问"有何用"；无法辨识者不碰、不采、不服。
2. **异说并列而不裁断**：类书与方术文本多存矛盾，读其"并存"而非求其"统一"；编者的并置不等于历史的关联。
3. **传统主张与现代认知严格分栏**：凡"久服轻身""通神延年"类表述，记其原意与语境，不作安全或疗效结论，不反推出现代用法。

### README_5 易被忽略的前提

1. **古书多不载剂量、不载疗程、不载失败案例**：空白与缺字段本身就是信息，不能把"未写主治"读作"没有作用"。
2. **"仙药""上品"是古代用途/风险分层**：不等于现代安全等级或疗效判定；"上品"未必无毒，"下品"未必皆毒。
3. **矿物药、丹药、毒烈药在今日多属受管控或高风险类别**：古籍记载不构成可照做的依据，更不可据以在家试制或服食。

> 食饵之学的真正收益，不在于记住某一味药的"奇效"，而在于获得一套对待珍贵之物与古老知识的清醒态度：先辨名实、再查来路、明其制法、知其失效条件、识其禁忌人群——凡说不清这些的，无论多神秘、多珍贵、多号称有效，都当止于文献，不下手。

## 板块0 · 学习路径和建议

### 0_1 学习路径（分阶段）

本库建议分四阶段推进，先立框架，再入细节，最后归方法。

**第1阶段 · 文献谱系与体例（板块1）**。先弄清五书是什么文类、彼此如何分工。重点建立"类书录异说、本草立格式、仙药考名实、食疗重宜忌、丹经讲次第"的分别，避免把五书读成同一套体系。

**第2阶段 · 本草与仙药基础（板块2、板块3）**。先读《神农本草经》的三品框架与条文六部件，掌握本草"信息压缩格式"；再读《抱朴子·仙药篇》的仙药双重判准与物性分类，理解"识物—知性—知法—知节—知界"的线索。两书一为总集母本、一为名物专论，互为表里。

**第3阶段 · 食疗与服食话语（板块4、板块5）**。进入《食疗本草》的厨房视角，把握"主某病—忌某物"的宜忌结构；再读《云笈七签·方药部》的辟谷、服食、存思符咒，理解道教内部"减食—以气代食—身心复归"的多种路线。

**第4阶段 · 丹经与综合边界（板块6、板块7、板块8）**。读《九鼎神丹经诀》的炼服次第与火候方法论；回到板块7统合"传统主张 vs 现代认知"的边界；最后以板块8的整理方法收束，把阅读成果落成可复核的卡片。

### 0_2 使用建议与边界声明

使用建议：

1. 本库为文献与文化研究的整理产物，适合作为"读什么、怎么读、如何不误用"的导航，不适合作为任何饮食或医疗方案。
2. 凡涉及具体药材、食物、丹方，请始终以现行药典、医师与药师意见为准，不以古书替代诊疗。
3. 引述古书时，养成"原文—理解—证据等级"三栏分记的习惯，不把传闻、转述与亲见混写。
4. 跨书对照同一物或同一法时，重点看它在各书被放在什么位置、以什么口气说；位置与口气的差别，往往比结论本身更能说明问题。

边界声明（必读）：

> 本知识库为道教服食文化与本草文献整理，所述服食/食疗内容属传统饮食与药物文化研究范畴，不作"功效/灵验"的真实性宣称，不构成营养或医疗建议；涉及药材服用须在合格中医师/药师指导下进行，切勿自行服食丹药或药材。

## 板块1 · 食饵文献源流与目录学谱系

### 1_1 五书定位与相互分工

同一支"食饵"知识，五书以三种不同"轴"组织，回答三种不同问题：

| 书 | 以何为轴 | 回答的问题 | 体例特征 |
| --- | --- | --- | --- |
| 神农本草经 | 物 | 这味药是什么、怎么记 | 条文体，六字段，三品分等 |
| 抱朴子·仙药篇 | 物性 | 这物怎么认、怎么采制、怎么服 | 名物志＋操作手册 |
| 食疗本草 | 食 | 今天买回的东西能做什么、忌什么 | 条目体，"主某病—忌某物" |
| 云笈七签·方药部 | 法 | 古人对这件事有几种说法 | 类书体，异说并列 |
| 九鼎神丹经诀 | 炼服次第 | 一炉丹如何配、何时起止、服后如何自验 | 问答丹诀，经诀图录分层 |

关键判句（《云笈七签》读书笔记原意重述）：一部说某物可久服，不等于另两部同意；一部说某法可行，不等于它给出了做法。对读的正确用法是拿同一物或同一法做线索，看它在五本书里各被置于何地、以何种口气言说。

### 1_2 《云笈七签》的类书体例与"方药部"取材

《云笈七签》为北宋张君房奉敕编纂的道教类书，一百二十二卷，把道藏经典按门类重排。"方药部"专收服药、辟谷、疗病、炼养诸家文字，其价值不在自成一说，而在"保存异说、暴露矛盾"。

类书体例的三件事：分类（安放名目）、摘录（整篇照录不改原意）、标注（标原书与卷次）。第四件常被忽略的是"不改"——编者不为原文加按语、不作辨正，只在门目标题上体现取舍。因此读者看到的每一条，观点都属于被引者，编者只负责安放。

方药部的骨架可还原为六门，按"人之所为"划分：

```text
方药部分类骨架（依条目大势归纳）

┌────────┬──────────────┬──────────────────┬──────────────┐
│ 门     │ 核心问题     │ 代表主张         │ 与他门交叉   │
├────────┼──────────────┼──────────────────┼──────────────┤
│ 辟谷   │ 能不能不吃谷 │ 断谷、却谷、餐霞 │ 与服气、疗病│
│ 食疗   │ 吃了什么才好 │ 主五谷、忌某物   │ 与疗病同源   │
│ 服食   │ 以何代食     │ 食气、餐霞、服气 │ 与辟谷、炼养│
│ 炼养   │ 怎么炼       │ 还丹、内炼       │ 与服食、存思│
│ 疗病   │ 病了怎么办   │ 服、敷、熨、祝由 │ 与食疗、符箓│
│ 符与诀 │ 如何持守驱治 │ 符箓、存思、禁咒 │ 贯穿各门    │
└────────┴──────────────┴──────────────────┴──────────────┘
读法：把"服食"读成"吃药"是最常见的错误；
      交叉处正是矛盾最多、最值得细读的地方
```

分类的代价是"整体性被切碎"：一家完整说法被拆进不同门，原本自成一体的实践（如辟谷须配合导引）被拆成两处。读类书最好手边备一张"出处还原表"，把每条材料还原到原书、原门、原语境，再看编者把它挪到了哪里——凡编者挪动位置处，往往是他下判断处。

### 1_3 本草学的体例母本：《神农本草经》的字段革命

《神农本草经》成书于汉代，作者不详，为多人经验累积、编纂综合而定稿，原书早佚，今存辑复本。其历史价值一半在收录的经验，一半在发明的体例：它用统一格式换取内容中立，用放弃论证换取条目可比。

全书条目大致六字段：药名（正名+异名）、性味（味+气）、主治（病名或功用并列）、产地、采制、久服（收尾语）。这个格式被后世《本草经集注》《新修本草》《证类本草》《本草纲目》一路沿用，条目数从三百六十五膨胀到近两千，但"药名—性味—主治—产地—采制—久服"的字段顺序几乎原封不动。今日中药说明书的骨架仍可追溯至此。

"神农"为托名，是把知识权威追溯到最古源头的一种背书方式，应理解为"本草这一门知识的总集"，而非具体作者。

### 1_4 从药到食：食疗书的唐代转向与丹经的文本分层

《食疗本草》把书名里的"疗"字推到最前，把稻麦果蔬、禽畜鱼介、蜜酒酱醋一并纳入可医用范围。这一立场转变的技术含义是：**药物需要炮制、剂量、疗程，食物只需要方法、时机与禁忌**。故其条目几乎不写剂量，代之以一套没有数字的剂量语言——以"空腹/饭后"定时，以"多食/少食/久食"定量，以"与某物同食"定搭配。

《九鼎神丹经诀》则呈现另一种文本分层：经（问答叙事、讲原理）、诀（短句禁诫、制度性留白）、图（鼎形炉位等空间坐标，常传抄散失）、录（名目性味禁忌的档案）。四层质地不同、可信度与读法不同：经可作思想史，诀可作技术史，图可作图像史，录可作名物名录；混读则会出现"拿一句诀当药理、拿一条录当结论"的错位。

### 1_5 自检问题

1. 能否不翻书说出五书各自"以何为轴"、各回答哪一类问题？
2. 能否解释"类书实录异说"与"专论自成一说"对读者意味着什么差别？
3. 遇到一条方药部材料，能否先判断"这是谁家之言"而非"这是本书主张"？

## 板块2 · 本草三品与上品长生

### 2_1 三品分类的依据：用途与风险的分层

三品是《神农本草经》最外层的框架，其坐标由序录本经一句点明："养命应天，以置上药；养性益气，以置中药；折病败毒，以置下药。"三品**不是**按疗效强弱、贵贱或毒性划分，而是按**服用的目的与风险层次**分：

- 上品：养命应天，作用和缓，可久服而不致伤。
- 中品：养性益气，作用略强，可酌情久服但非无条件。
- 下品：折病败毒，作用峻烈，多有毒烈，用于攻伐而非久养。

全书载药三百六十五种（取年度节律之数），上品一百二十、中品一百二十、下品一百二十五。上中品偏多，说明编纂重心在"可久服、可日常用"；下品略多却未压倒，说明攻伐毒烈药被列出却未被当作主体。

三品与"有毒/无毒"是**正交的两个维度**：三品按用途分，有毒无毒按风险标。个别上品（如矿物药）在现代毒理学意义上风险明确，个别下品（如附子、乌头）在现代仍是可控合法药材。故"上品=安全""下品=有毒"均为误读。

### 2_2 条文六部件与"久服"句的读法

单条结构稳定，可析为六部件：药名（正名+异名）、性味（味+气）、主治（病名/功用并列）、产地、采制、久服（收尾语）。统一字段使三百六十五味可横向排比、交叉检索，但代价是炮制火候、用量常被压扁，性味与主治的因果关系通常不写。

"久服轻身""久服令人不忘"一类收尾语是最需警惕的表述，理由有三：其一，它描述的是长期服用的**目标**，不是长期服用的**安全证明**；其二，它隐含"吃→久→身轻健"的未经检验的因果假设；其三，它在文献流变中极易被夸饰。本库对所有久服句统一处理：记录原意、标注语境，并明确其不构成安全或疗效结论。

### 2_3 上品：养命与药食同源的古今分际

上品共一百二十种，内分玉石、草、人三部。玉石部知识含量最高（丹砂、雄黄、雌黄、硫黄、磁石、云母、石英、钟乳等），但矿物药在现代毒理学上风险明确，本经列其为上品反映的是当时矿物学与象征体系，不反映现代判断。草部是重心（人参、甘草、术、地黄、薯蓣、薏苡、枸杞、菊花、麦冬、茯苓等），多数延续至今且为高频常用药。

上品主治句排列有固定顺序：先脏腑（补五脏、补中益气），次神志（安精神、定魂魄），次具体症状（止惊悸、除邪气），末感官智识（明目、益智）。这一顺序透露当时的效用分类逻辑。

"上品"与今日"药食同源"名录名字大量重合（山药、大枣、薏苡、枸杞、菊花、茯苓、甘草等），但依据不同：本经"可久服"依据古代观察与理论框架，不记剂量上限与不良反应；现代名录依据食用历史、安全性评估与法规程序，且附使用条件与不适人群。重合只说明"越是打算长期入口者越应选自平淡温和日常之品"这一直觉古今一致，绝不意味着它可以治病或人人适宜、多多益善。

### 2_4 中品与下品：从补到通、从养到攻

中品一百二十种，承担"从保养走向调理、从久服无碍走向明确针对"的过渡。其条目主治项更多、分科更细（头目、咽喉、胸膈、心腹、腰膝等），功效动词密集出现"散、利、通、化、消、降、逐"等方向性语汇，性味偏性（苦寒、辛温）开始明显——"有偏才有用"的传统命题在此显现。久服语重心由"保养"滑向"持续改善某种具体状况"。

下品一百二十五种，全书中唯一以"攻"为定位的层级（"折病败毒"）。多为作用峻猛之品：巴豆、大戟、甘遂、芫花、商陆；温燥毒性植物如附子、乌头、蜀椒；以及毒性矿物。它们现代多属法定药材，但普遍严格管控、限定剂量、需炮制、需医师辨证。读下品应把它视为"高风险工具清单"而非"可选项清单"。

中品到下品的移动，同时是治法的移动：上品说"补"，中品说"和/通"，下品说"攻"。

### 2_5 序录本经：四气五味、君臣佐使、七情和合

序录本经为全书总纲，内容可归四组：药有阴阳；药有酸咸甘苦辛五味与寒热温凉四气；方有君、臣、佐、使；药有单行、相须、相使、相畏、相恶、相反、相杀（七情）。

四气五味是药性坐标系：

```text
四气五味对应表（据序录本经精神，兼列现代可核要点）

┌────┬──────────────┬────────────────┬──────────────────┐
│ 味 │ 传统作用趋向  │ 传统脏腑归属    │ 现代可核成分倾向  │
├────┼──────────────┼────────────────┼──────────────────┤
│ 辛 │ 能散、能润    │ 肺、大肠        │ 多含挥发油/辛辣物 │
│ 甘 │ 能补、能和、缓│ 脾、胃          │ 多含糖类、多糖    │
│ 酸 │ 能收、能涩    │ 肝、胆          │ 多含有机酸、鞣质  │
│ 苦 │ 能泄、能燥、坚│ 心、小肠        │ 多含苦味苷、生物碱│
│ 咸 │ 能下、能软    │ 肾、大肠        │ 多含无机盐        │
└────┴──────────────┴────────────────┴──────────────────┘
传统"脏腑归属"与"现代成分倾向"属两套体系，可作理解古方思路的参考，
不可互相替代
```

七情和合是"合方"的检查清单：单行（独用）、相须（同类互增）、相使（一主一辅）、相畏（一药毒被另一药抑）、相恶（一药减另一药功）、相反（同用生毒害）、相杀（一药消另一药毒）。它对应现代药物相互作用与配伍禁忌的朴素版本，但不能替代现代审查，尤其当所服还含西药时，跨体系风险评估须由医师药师完成。

现代定位：四气五味与七情是历史上形成的、相当系统的经验分类工具，其真正价值在"怎么用"层面（寒热搭配、辛散甘补等确有长期经验积累），而不在作为现代药理学的替代物。性味与现代生理机制不构成同构关系。

## 板块3 · 仙药体系：名实、物性与服食

### 3_1 仙药的双重判准与隐秘性

《抱朴子内篇·仙药篇》为东晋葛洪所撰《抱朴子》卷四，在全书以"理"为纲的格局中，是唯独以"物"为纲的一篇，承担把"理"与"物"接起来的那段——神仙须有物质基础，而物质须落实为可辨认、可采制、可服食的具体之物。

"仙药"首先是一个**关于知识**的定义：世上本有一类东西，因其名不被世人所识、用不被世人所知，才被称作仙药；一旦被命名、被广泛使用，它便不再是仙药。葛洪开卷即言"天下多同名异实之药，庸人不知而宝之，此仙药之所以难成也"，把"不知"与"误宝"视为同一类错误的两面。

仙药须同时满足两重判准：

```text
仙药篇的双重判准（据原书主张整理）

  判准A：名实判准          判准B：久服判准
  ┌──────────────┐    ┌──────────────┐
  │ 世人不识其名  │    │ 久服而无害    │
  │ 传之则失其灵  │    │ 不立见其效    │
  │ 需自辨自采自制│    │ 需长期小量隐秘│
  └──────┬───────┘    └──────┬───────┘
         └────────┬───────────┘
                  ▼
      凡广为人知且立见其效之物，必非仙药
```

这一判准有实际排除功能：凡被炒得沸沸扬扬、功效保证明确、到处有售、服后立刻见效者，按葛洪标准几乎必然不是仙药。

"服之勿使人知"在原卷不是神秘主义口号，而有三重实际考虑：其一安全（毒烈之物旁人效法易误用过量）；其二防祸（服食成仙者易招求贷陷害）；其三学理（"仙药"定义本含"人不知"，公开服用等于公开否认其所服）。其直接后果是**不可证伪**——成功归隐秘之益，失败归德行时机采法。故读法上应作明确切分：**把"怎么做"当知识学，把"成了吗"当信仰看**。

仙药的价值序列（丹砂→黄金→白银→诸芝→五玉→云母、雄黄→松柏脂、茯苓、地黄、麦冬等）按稀缺、难遇、转化可能排列，越靠前越难得、越被认为近"不朽"之质、也因此往往毒性越大；这与本草三品"越上越平和无毒"的安全逻辑不同，是追求奇效的稀缺逻辑。两条线并存，读时需分清哪句出自哪条逻辑。

### 3_2 矿物药：丹砂、雄黄雌黄、硫黄磁石云母

仙药序列以矿物居首，丹砂（天然硫化汞、辰砂）被视为诸石之首。"丹"在此双关：既为颜色之丹（赤），又为炼化之丹（入炉）。书载其色赤、产石穴、煅后转色，并有"研之有声"（响砂）的实用辨伪经验，与现代矿物学的硬度、解理、结晶习性可对上。

雄黄、雌黄成对出现，按颜色作正反分类（雄赤雌黄），燃烧有异臭熔融，现代对应砷硫化物（As2S2/As2S3），含砷意味着急慢性中毒风险俱在。硫黄（单质硫）现代知其成分，古代对其"解一切毒"与"服之易病"的自相矛盾记载，反映对其燥烈性的朴素认识。磁石（磁铁矿Fe3O4）"吸铁"，其"研末水飞"的水飞法是标准矿物药粉碎分离工艺，至今中药炮制仍用。云母记其层状解理、透明片状与"服之不饥"的传说层。

矿物类条目的正确读法：**价值在"辨"不在"服"**——学会用颜色、硬度、结晶、气味、燃烧表现区分近似物，是可迁移的物性知识；把古书服用法落到自身，则是把知识用在了最不该用的地方。

### 3_3 芝草、日常草木与动物杂物

芝草类是《仙药篇》最大的一类，"五芝七芝"多以赤紫青白黄五色为纲。"芝"在古代文献里不总等于今日餐桌蘑菇，多指被赋予神圣意义的草木或菌类实体，形态描述奇异、多"状如""大如"而非确定种名。其价值不在物种鉴定（基本无法完成），而在保存了一份"古人以何物为贵"的清单——形状（圆盖）、颜色（赤紫为贵）、环境（五岳深山）、年份（久生者贵）的评价体系，是文化史一手材料。

日常草木的仙化同样值得注意：松叶、柏叶（常绿四时不凋，被读为寿）、茱萸（辟邪逐寒）、菖蒲、远志、麦冬、菊花等，在与当时通行本草共用同一批药名，只改写了用途。现代部分确有合法药材对应（松柏提取物、菖蒲挥发油、吴茱萸生物碱），但研究指向特定成分、剂量、适应证，与"久服成仙"无对应关系；"久服安全"必须由毒理与长期安全性数据支撑，不能由"古人说能久服"反推。

动物与杂物类：蜂蜜（果糖葡萄糖、高糖低水分不易腐败，现代知其抑菌机制）、龟蛇（长寿象征，"食龟得寿"属以形补形类比，现代无法支持，且龟甲鳖甲蛇类多属受保护）、麻黄（现代药理最充分，麻黄碱类用于平喘升压，副作用谱明确）、桑黄（民间"抗癌"自采成风，基原混乱，各地"桑黄"实为多种真菌统称）、菖蒲（石菖蒲/水菖蒲基原须分清）。本类最杂：既有可对应药材者，也有纯传说层，须逐条落实界线。

### 3_4 择地择时与炮制：早期标准操作规程

《仙药篇》残留下来的是一份结构完整的前现代制药规范，骨架与现代工艺规程要素一一对应：原药材鉴别（名与形）、产地确认、采收时点控制、粗加工（水飞、煅）、精制（煮、渍、烘）、稳定性处理（阴干、密封）、成品判据（色、味、声响、手感）、贮藏条件、禁忌（人群、时令、同服）。

- **择地**：含产地层级（道地）、生境条件（深山阴地、石穴，现代可对应光照湿度基质宿主）、洁净避讳（避开人烟污秽，生态保护意义上正面，但"以童男女采集"等仪式绑定部分当剥离）。
- **择时**：按月、按节气、按日夜时辰。前两者与现代药用植物采收学吻合度高（根秋冬采、果实成熟采、叶花未开或初开采）；日夜时辰更多可理解为"避高温避日晒"的保鲜考虑。
- **炮制**：煅（改晶型、易粉碎、降部分毒）、水飞（沉降分离取细粉）、煮渍（去毒去腥）、阴干密封（防潮防氧化防霉变，对应现代稳定性原则）。书中"须在阴地干燥，不可见日"可解释为避光解氧化。

方法论要义：**药物知识的成熟标志不是药效传说，而是流程标准化**。读此卷最好当"药工手册"而非"仙书"——带走"怎么认、何时采、怎么制、怎么判坏、何种条件失效"的清单，不带走"服几天成仙"。

剂型与送服（丸、散、酒渍、作饵）承担补白功能：丸缓图、散易行、酒渍温通、作饵可久备。其文献特征极鲜明——记得清"做成什么样"，记得含糊"吃多少、吃多久"，这种空白本身即数据：凡原书不记用量疗程者，证据等级应下调一级。

### 3_5 服食禁忌与原著的风险三层

《仙药篇》在用量上相当保守：反复出现"勿多服""少服""久服乃效""服之当断酒肉五辛"等限定语，对应现代的剂量窗、蓄积效应、疗程限制。原著对风险的处理特点是**不掩饰失败与危险**：

```text
仙药篇风险表述三层次（意译归纳）

  层次一 · 物本身风险：「此物有毒，服之宜少，不宜多」→ 剂量、蓄积毒性
  层次二 · 人的风险：「体虚者、年少者、患某病者不可服」→ 特殊人群、病证禁忌
  层次三 · 知识风险：「或云有之，未得其真」→ 物之真伪、信源可靠性
```

三层合为"低承诺、高约束"的表述方式——说得越肯定，约束反而越多，恰与广告式宣传逻辑相反。凡把不确定性藏起来的文本值得警惕，把"未得其真"写在正文里的文本反而相对可靠。

"久服乃效"的双重含义须分辨：药理上缓慢起效确需足够暴露时间；方术语境里还含"渐进修炼、断酒肉五辛以免药力被夺"。"断酒肉五辛"在现代能找到温和对应（某些药物与酒精或高刺激食物存在相互作用），但不能推广为"服药须长期斋戒"；若需用药，应由医师给具体饮食与相互作用建议。

## 板块4 · 食疗体系：以食为药

### 4_1 唐代食疗的立场：从药到食的转向

《食疗本草》为唐代孟诜撰、张鼎增补，三卷，原书早佚，今存辑佚本（敦煌残卷存部分条文）。它针对的是已成型的唐代日常饮食状况：丰盛与节制并存、新物不断入馔、信息渠道有限、生食熟食鲜储并存。其出现的必然性在于——物产跨地域流通不受经验约束，而关于"这东西是什么、能不能吃、跟什么不能一起吃"的经验未被系统整理。

从《神农本草经》到《食疗本草》有根本立场转变：本经主角是"草"是药，框架是"以药治疾"；食疗书把"疗"字推前，把稻麦果蔬、禽畜鱼介置于主体，按食物自然门类编排。隐含主张是"厨房是一间诊室，灶台是一张药方"——这一主张今日仍有力量，但须用现代营养与医学重新校准，而非照单全收。

成书有两层文本须分辨：孟诜原撰多以物名起、接"主某病/味某性某"，是物志写法；张鼎增补多以"治/疗/又方"起，是方书写法，偶见"捣筛""和丸""以酒下"等剂型语。引到增补方时，应说明这是后世增补方，而非唐代食疗原貌。原书早佚、辑本互异，宜作一批唐代饮食经验的集合，遇异文并列存疑而非替它挑一。

### 4_2 分类框架与"主某病"句法

分类依食物自然属性（谷、菜、果、禽兽虫鱼、及蜜酒酱醋调味加工品、少量矿物），而非按功效或贵贱。这透露三件事：把"吃的东西"当作整体世界来认识；分类本身就是打破饮食习俗神秘性的第一步；它保留了本草学格式（仍有药名、产地、采制、功用），是在既有本草体例内作题材转换。

条目典型骨架：名（一物一名或一名数物）→产（出某州某地者佳）→性（味某性某/有毒）→主（主某病症，可并列多项）→制（生食/熟食/炙/煮/酿酒）→忌（忌某物/与某物同食令人某症/不可多食）。

条文信息可归四类，可信度递减：

1. **可观察描述**（产地、形态、色气味、采收、加工）——最可靠，今日仍可核对。
2. **经验性功效对应**（"主某病"）——可靠性差异大，部分为长期观察，部分为民间传说。
3. **推理性/象征性对应**（以形以色以性类推）——最需警惕，现代无任何支持。
4. **禁忌语**（"与某物同食令人某症""不可多食"）——最有价值，多记录"出过事"或广泛警示，现代往往能找到部分机制（胃肠刺激、酶与营养素互作、食物本身毒性或变质）。

"主某病"句混有三种性质：症状指向（主腹中冷痛、小便数，近主诉层）、功能指向（令人不饥、耐寒暑、利小便，近功能变化）、体质倾向指向（养脾、润肠、暖胃，须放进脏腑理论框架）。三者可靠性递减，症状指向多来自观察，体质指向更多来自理论建构。

原书部类更细（玉石、草、木、果、菜、米谷、兽、禽、虫鱼诸部），笔记所讲"五类"是餐桌归并。草部并入菜类（黄精、枸杞、薯蓣等"药食之间"者被淡化）；木部几乎消失（茯苓、茱萸、五加只在禁忌处顺带）；**玉石部最须单列**——丹砂、钟乳、云母、石英被收进讲吃的书，反映唐代服食之风与本草传统交叠，绝非可当饭吃；今读只当药物史材料，不给出任何配比或自制指引。

### 4_3 谷菜、果实、禽兽虫鱼的分门读法

**谷菜**：粳米（甘温、养脾胃，现代对应淀粉构成与升糖特征，"勿多"是笼统告诫，现代给具体总能量与精制碳水建议）；粗杂粮（黍稷粟、薏苡、麦大麦）保留更多膳食纤维B族矿物质、升糖更低，古代"宜杂宜粗"的直觉与现代同向，但粗杂粮植酸影响矿物质吸收这一点古书没有。薏苡是本书与现代药学对应最好的一味（利水渗湿健脾，薏苡多糖等研究），但细胞/动物层面研究不等于与"治湿痹"整体证候同构。薯蓣（山药）作为药食同源品种，古籍定位与现代高度一致；萝卜（莱菔/莱菔子消食下气，"解酒"现代未确证）；胡瓜（黄瓜）"多食伤脾"在现代框架不成立，属古代不适经验不宜照搬。

**果实与种实**：核果类果肉与核仁分开记载，且核仁往往已是药——**桃杏仁含苦杏仁苷，体内可代谢产生氰化物，现代有严格限量与炮制规范，苦杏仁不能当坚果大量食用，儿童尤防误食**；梅（乌梅收敛，未熟梅含较多有机酸单宁，空腹大量刺激胃，与古忌高度吻合）；柿含鞣酸，与高蛋白/空腹/富铁同食可引起胃柿石或影响铁吸收，古人"勿与高蛋白同食、勿空腹多食"在现代有机制支持，是宜忌条目中印证最强的一类；葡萄（葡萄酒多饮伤身，与现代酒精无安全阈值共识同向）；枇杷（止咳化痰类中成药与食疗方向一致）。

**禽兽虫鱼**：肉类常拆肉骨血脏胆分别入条（一物多条的密集分布）。猪肉（猪肝补铁维A有依据，但内脏检疫卫生古书不提）、羊肉（血红素铁锌B族，虚劳羸瘦者宜之与现代补铁思路近，但"忌食与某同食"多无确证机制）；鹿茸、熊胆记述详尽却引出现代最该补的一层——**野生鹿类、熊均属保护动物，合法来源极受限，古代记载说明曾被如何使用，不构成今天获取或使用的许可**。家禽蛋分全蛋/蛋白/蛋黄/蛋壳各有主治，现代对应最清（蛋白质、磷脂、微生物与新鲜度要求），"发物"概念宽泛，现代更精准做法是按具体诊断与过敏史建议，而非笼统忌口名单。水产（鲤利水、鳖软坚、蟹多条禁忌）现代三层可对应：过敏（甲壳类常见致敏原）、变质致病菌与寄生虫（不新鲜/生食醉制风险最现实）、嘌呤（痛风高尿酸需限食），"发物"在古代多以笼统表述覆盖。

### 4_4 宜忌体系：机制型与象征型禁忌

《食疗本草》最值得重视的是功效之后的禁忌，顺序反映清醒思路：食物的作用与限度是同一事两面。禁忌写法约五类：同物相忌（某物与某物同食令人某症）、性味相碍（性寒者不可多食、虚寒忌之）、时令禁忌（非其时不利）、加工生熟（生食令人某症、须炙过）、性状来源（腐败杀人、采时须某时）。

古忌绝大多数可重述为四类现代语言：食物本身风险、搭配导致胃肠负担、变质与卫生、过敏与个体差异。其中"变质与卫生"古人认识有时比功效条目更准确。

搭配禁忌须分两类处理：

```text
搭配禁忌两类对照

┌────────────┬──────────────────────┬──────────────────┐
│ 类型       │ 表现                 │ 现代对应         │
├────────────┼──────────────────────┼──────────────────┤
│ 机制型     │ 鞣酸+蛋白胃部不适   │ 柿/浓茶+高蛋白  │
│            │ 有机酸刺激胃黏膜     │ 山楂/梅/未熟果  │
│            │ 组胺释放皮疹风团     │ 不新鲜鱼类      │
│            │ 微生物与寄生虫       │ 生食/保存不当   │
├────────────┼──────────────────────┼──────────────────┤
│ 象征型     │ 颜色/名称/形态相近相忌│ 形类推，无支持  │
└────────────┴──────────────────────┴──────────────────┘
```

正确态度：机制型认真对待并细化（新鲜度、过敏史、个体胃肠状况）；象征型作为文化现象记录，不必遵守也不必由嘲笑。真正安全底线不依赖这类条目——不新鲜不吃、发芽要小心、生熟要得当、来源要合法、过敏要避开，五条已覆盖绝大部分风险。

硬性底线（现代仍绝对成立）：发芽（豆类薯类发芽含天然有毒物质，发芽马铃薯龙葵素升高）、腐败（"肉腐食之杀人"对应微生物致病，李斯特建立细菌理论前人类已用"闻着不对就别吃"保命数千年）、未熟（抗营养因子/毒素需充分加热）、来源不明（野生/保护/农残）。

### 4_5 加工与生熟：炙煮蒸酿的现代对应

加工方式（生食、熟食、炙、煮、蒸、焙、糟、酒渍、蜜渍、研末作膏）不是可有可无细节，而是疗效与安全的一部分：

- **炙焙**：脱水抑菌、改变成分，但过度高温产生氧化产物与杂环胺。
- **煮**：最普遍也最关安全，杀灭病原、破坏不耐热电毒素、糊化淀粉；但煮不透是"未熟/发芽"禁忌核心机制之一，且某些毒素耐热（木薯生氰苷、苦楝素）煮后仍需特殊处理。
- **蒸**：更好保留风味与水溶性营养，同样糊化灭菌。
- **酿酒酒渍**：酒作提取与送服媒介，现代确有药食两用传统；但边界必须写清——乙醇无安全摄入阈值，孕妇、未成年人、肝病胰病者、服头孢类/部分镇静药/抗凝药者均应严格避免，"以酒为引"不能作为今日饮酒养生依据。
- **作膏作酱研末**：决定保存期限与有效成分溶出，粉剂与汤剂溶出吸收不同，现代药理学有明确对应。

家庭食疗若要落为可用参考，核心原则是**一次只改一个变量**并记录背景（同时吃什么药、近期作息情绪）、观察指标须可数可分级（如夜间咳醒次数、大便性状）、把原书禁忌语抄全、任何持续或加重不适即停手就医。家庭记录不是临床证据，无法排除自然病程、安慰剂、季节干扰，至多支持"值得试/不必再试"的低强度结论。

## 板块5 · 辟谷服气与存思符咒

### 5_1 辟谷三词：断谷、却谷、餐霞

方药部"辟谷"门下，"断谷""却谷""餐霞"常被混用，实指不同主张：

- **断谷**（减与止）：渐进减少乃至断绝谷物，较温和一路主张先减半、次减半、久则自轻；激烈一路直陈不食五谷专饮水果菜；还有一路强调"断谷须有法"，须配合行气导引静坐，否则气力不继。
- **却谷**（换）：以他物代谷，书常举矿石、松叶、露水之类；这类记载可能指向古人对矿物性质的真实观察，也可能是象征写法，或早已失传的口耳之传，宜作"古代如何想象以非谷物为食"的记录，成分存疑不辨。
- **餐霞**（升）：不以常规食物为对象，以传说中清精之气为养，与服气、存思、内景相通，更接近信仰与象征，宜作身心修养的想象来理解，而非饮食史材料。

三者是主张差别而非程度差别：断谷派信五谷为浊为累，却谷派信问题在食物种类不在食物本身，餐霞派已转入象征信仰。这一分辨可避免把象征说法误读为具体饮食建议。

**复食**是诸家反复叮嘱、今人最易忽略的一环：断谷既久胃气已弱，不可骤进谷食，须以稀软之物渐次引入；各家的日数与次序并不相同，本库不转写这些次序，但"渐"字一致。现代对应明确：连续多日明显减少进食后，代谢与电解质状态已改变，突然大量进食可引起严重代谢紊乱，须在医疗监督下进行；出现头晕、心悸、乏力、意识不清须立即就医。断谷与复食都不是可照古书自行尝试的事。

### 5_2 服食炼养三路线：食气、辟谷服气、还丹

- **食气**：以气代食的主张，论证方式是本体论式而非营养学式——既然"气"是生命根本，"食"只是气的粗重形态，故不必执着食物形质。强度不一：弱版"少食养气"属节食养生，强版"完全不食五谷亦可"属宗教实践。
- **辟谷服气**：把断谷与食气合成一路，同时处理"减谷食"与"补气"，常含整套做法描述（如何行气、导引、守、维持），把信仰推到可传授方法；其自我约束是强调循序渐进、不可勉强。
- **还丹炼养**：在类书里被安置于接近养生的位置，语汇围绕"还/复/返"的复归意象（耗散者复还其本、昏蔽者复其明），描述的是身心状态的复归而非物质转化。读此类须避免用外丹物质语言硬套——"丹"在此更接近"所成之果"语义场；且还丹与服气相邻却未必同源，一家兼引数法多反映编纂汇合而非历史自然演化。

├────────┼──────────┼──────────┼──────────┼──────────────┤
│ 主张   │ 谷为浊为累│ 气为本末 │ 身心复归 │ 传统理论文化  │

### 5_3 存思与符咒：方药部的交界地带

方药部收进符与存思，并非分类不严谨，而是道门内部这几类做法共用一套身体观：身体内部有可主宰的通道与可感知层次，意志可作用于其上；符箓、禁咒、祝由把主宰媒介从内在观想换成外在书写与仪式。符箓之学在传承上与炼养辟谷多有关联，师承交叉、术语互借，故被放进方药部反映的是实务关联而非教理归类。

存思进入方药条目有三方式：作为治法补充（服汤后行存思助药力行）、作为服食条件（不先存思则服之无功）、作为独立养护（每日定时自我调节，比后世宣传更朴素日常）。

符可理解为"随身方"：书于纸帛或刻于金属砖石，佩戴、持诵、或水浸而服，用途辟邪治病护身；与方书的差别在——方记录物质与组合，符记录的是书写行为本身所承载的效力，效力来自书写规则、书写者资格、书写状态与被写对象（神名印信）。故符书里处处是名讳、笔画、次第、颜色材质规定，这些不是装饰而是效力链条环节，符是一套与书写制度深度绑定的技术文本。

判断一个动作归属何处，看语汇重心：落在物质与作息上归辟谷食疗，落在观想守一上归存思，落在书写仪轨上归符箓；三者共享同一身体观（身内有序、意志可作用其上），这是门类无法彻底隔开它们的根本原因。

## 板块6 · 九鼎神丹：丹经的炼服记载

### 6_1 四层文本与"九鼎"辨析

《九鼎神丹经诀》为单卷丹经，托名黄帝，作者不详，中古以降师徒口传抄本流传。书名四字各有所指："黄帝"托名（话语权）、"九鼎"器象兼数目承诺、"神丹"目标物、"经诀"体裁（经偏原理、诀偏窍门）。

前文已析其四层文本（1_4）。此处补"九鼎"辨析：原典讲鼎多讲作用与象征，几乎不逐一列"鼎有九部位主某事"的对应系统；逐位对应式解释（九脏、九曜、九宫、九穴）主要出自后起注家与丹家著述。辨别办法是看它是否使用原典不曾有的术语体系（脏腑名、星次名成体系出现，几乎可断为后起）。

**"九鼎"指九个丹，不是九个鼎位**。传统九丹依次为丹华、神符、神丹、还丹、饵丹、炼丹、柔丹、伏丹、寒丹（各本次序用字略异）。其命名依成品样子与用法（华取色泽、符取征信、饵取服食、柔伏取性状、寒取药性之偏），而非依原料——印证原典重心在成品可辨识特征，不在配方公开。九丹自一至九由浅入深，前丹为后丹基础，故反复强调不可躐等，次第是全书技术骨架。

必须划线：丹名可列，做法不能转写。九丹用药、火候、合和原属诀层与师承，本库只作名目与结构说明，不给任何配比、用量、加热时长或自制指引；矿物丹类在现代毒理上多有明确风险，古载不构成安全结论，更不可在家尝试。

### 6_2 丹诀分解：药物配伍与君臣佐使之变形

本书谈药谈"类"不谈"两"，只作结构描述不作配方转写。药物语言按维度铺开：来源（矿物草木金属动物）、作用（主/辅/使）、状态（生用/煅制/阴干）、禁忌（畏/忌/不可同用）。反复"异名并列"——同一物连写数别名（道教内名、世俗方名、传说产地），是知识传递的对冲策略，别名当索引键而非重复。

君臣佐使进入丹经发生三变形：处方之"病"不再是病而是"道"，君臣分工变为"合和"；常把"意/心"置于君位（心为君、意火为使），身体被编入配伍框架；君臣关系从固定变动态，依"证"而异。故不能把本草君臣佐使原样搬来解读丹方——丹经配伍带强烈象征，其"佐"有时指调匀火候、斋戒或择日。

"合和"一语双关：字面上混合得匀，义理上身心与天地相和。丹家认为药性间有相性，相合则成丹、相戾则败，故"配伍"在此是避开冲突的排除法，最费笔墨的往往不是"加什么"而是"不同用"。

### 6_3 火候："候"的可判断指标与心身对应

火候是技术内容重心。文火（柔缓可久持）、武火（骤强短促用于收束），习惯"文火起、武火收、和火过渡"，关键在文与武的分配顺序与时长比。须强调：本书谈火候常讲"意火"而非炉火——文火对应心静息微、武火对应一意专注，炉火比喻为说明注意力如何在长时段保持稳定。

"候"是全书最核心也最难的字，意为由现象显示时机已到，不由人定。判据三类：色（鼎内药色变化）、声（鼎内响动）、形（药之聚散湿润）；另有"觉"（操作者体感）。三类合为巧妙机制：时机不由人定而由过程给征兆，人须持续观察即时响应——把"不可控"转成"可辨识"，使操作可传授，其价值远大于任何数字。

│ 书中语汇│ 语义方向     │ 现代对读         │
├────────┼──────────────┼──────────────────┤
│ 文火   │ 柔缓可久持   │ 低强度长时维持  │

火候处完成最漂亮的概念位移：从"按时"转到"候时"。按时是钟表问题（失败归因工具），候时是判断问题（失败归因观察者）。这解释了为何反复要求择静斋戒避人——所有干扰破坏"候"的能力，火候由此从技术难度变为德行要求。其可迁移价值：任何需长期精确观察的工作（修复、观测、训练、写作），判断时刻到没到不由自己定、由现象定，且判断者状态本身就是变量。

### 6_4 择地择时斋戒与服食验证

择地含三类条件：物理（安静背阳通风有水源）、卫生（洁净少人畜无秽浊）、心理（能久处不烦、久坐不思杂事）——心理条件被写得与物理条件同等重要，说明编者知长时专注状态本身是变量。其中"结界禁约"类宗教语言（不许喧哗、妇女临、杂人入）可还原为操作管理原则：不受干扰、场地有序、防污染与泄密。

择时含择日（节气月相时辰吉日，偏象征与规避）与择时（日内起火收火段落，偏过程连续掌控），前者少后者多；同一书不同抄本宜忌表可能矛盾，宜作"择时方法论示例"而非可照用通书。

斋戒承担三项：身体准备（饮食清淡节饮）、心理准备（禁杂念妄语）、制度准备（沐浴更衣焚香）。它把高度依赖注意力稳定的长时任务用外部规则固定——与现代管理学的清洁环境、标准化流程、明确暂停交接重合。

服食与验证是全书最易失真部分。原典末段语汇转为"应/验/效/久则/弥佳"，倾向列举身体感受（神清、气顺、思虑定、夜寐安）与延年。必须严格分辨：这些是"作者主张"还是"作者记录的结果"？从文本形态看更接近主张——无时间点、无人数、无失败样本、无观察方法，只有一个通顺因果叙述。效验叙述可拆四段式：起因句（久服久炼后）、条件句（斋戒择时心诚）、效验清单、扩展句（延年益智通神）。其修辞功能是把效验放在充分长因果链末端，使前面困难禁忌显得必要；与本草"久服轻身"、方书"主治"同为"用漫长时间跨度兑换强效果断言"的技术。

可把效验转写为可讨论形式：抽可观测项（静坐杂念减少、睡眠中断次数、任务耗时变化）与不可观测项（通神、延年、形解），后者只作宗教经验记载。凡遇肯定性陈述，先按主张处理，是对待丹经的基本纪律。

**不可复制性**须诚实说明：古代丹家条件（洁净专用丹室、可控稳定炉具、师徒在场即时判断、长期时间投入）今人大多不具备，任何"以身试法"的模仿既不可取也不必要。读它的正确方式是读其知识组织方式。

### 6_5 自检问题

1. 能否分辨"九鼎"原典层（鼎为容受密闭之器/收摄之象）与后世附会层（九配九脏九曜），并说明九丹指九个丹而非九个鼎位？
2. 面对一条火候句，能否先判它说炉火还是意火，并指出"候"由色声形觉哪类判据定时机？
3. 能否把一段效验叙述拆成起因/条件/清单/扩展四段，并标出它是"作者主张"而非"记录结果"？

## 板块7 · 服食禁忌、风险与现代认知边界

### 7_1 传统主张与现代认知的分离原则

五书合观，凡功效与灵验主张皆应归入三层之一：

1. **可验证**：物性鉴别（色硬光泽断面气味燃烧反应）、炮制工艺（煅水飞煮渍阴干密封，部分被现代药典吸收为法定法）、采收理论（按季节部位物候，现代可用成分周期波动部分解释）、道地与产地概念（同名异物制度化回应）。
2. **部分可验证**：某些主治与现代病证有较清对应（如"主咳逆上气"与止咳降逆）、某些成分类研究有方向对应；但整体证候概念不等于现代病名。
3. **不可验证**：一切"成仙/轻身/延年/通神明/役使鬼神"功效，一切以类比（食龟增寿）推出的补益逻辑，一切依赖特定天象时辰仪式或不可言说之秘的操作。

实用判据：**这个主张能不能写成一句可设计对照试验的话？** 能，则值得找证据；不能（如"服之使人不老"），归入信仰层标注即可。

### 7_2 有毒无毒与剂量：古今尺度落差

古代"毒"概念比现代宽：既指今日毒性，也指药性峻烈、偏性强、可能引发剧烈反应；"无毒"更接近"按常规用法不致伤人"的判断，观察尺度远小于现代毒理学。故本经标"无毒"不能推断现代安全，"标有毒"在现代仍可能是可控合法药材（附子乌头）。三品是用途轴，有毒无毒是风险轴，二者正交——"上品=安全""下品=有毒"均误。

毒烈药（下品）与现代认知的四重距离：

```text
毒烈药：古记载与现代要求四项对照

┌────────┬──────────────┬──────────────────┐
│ 项目   │ 传统记载     │ 现代要求         │
├────────┼──────────────┼──────────────────┤
│ 剂量   │ 多省略/少许  │ 法定限量个体化  │
│ 炮制   │ 简记如"去皮"│ 法定方法与程度  │
│ 煎法   │ 偶有"久煎"  │ 明确煎煮时间    │
│ 人群   │ 一句"孕妇忌"│ 分人群禁忌替代  │
└────────┴──────────────┴──────────────────┘
```

脱离剂量的古载几乎不能直接转为方案；省略炮制的古方今照做风险高；"久煎"对含乌头碱类是现代明确减毒要求；孕妇等特需人群古书仅一句，缺剂量条件替代。

### 7_3 矿物、丹药与毒烈药：不可照做的红线

红线（所有板块通用）：本库不提供任何矿物药或丹药的配比、温度、时长、器具或自制操作指引。涉及朱砂（硫化汞）、雄黄雌黄（砷化物）、硫黄、磁石、云母，以及九鼎神丹经诀所载矿物金属类物质，在现代毒理上多有已知风险（重金属与砷硫化物对肝肾神经的累积损害、炮制不合格致游离态毒性增加、来源不明药材的农残微生物污染）。最现实的一项风险是：**把古代记载当成现行用药依据而延误正规诊疗**。

### 7_4 野生动物与来源合法性

鹿茸、熊胆、野生甲鱼、龟蛇、部分芝菌，在古代记载详尽却不代表今日可获取使用。野生鹿类、熊均属保护动物，合法来源极受限，多地区流通受严格管制甚至禁止；龟甲鳖甲蛇类多属受保护。历史记载说明"曾被如何使用"，不构成采集、购买、使用的许可，来源合法性须先行确认。古代书里当然没有这条，但使用者今天必须知道。

### 7_5 立即可做动作 / 自我核查清单

可立即执行的核查（限文献与信息核验，不涉及任何制备服用）：

1. 取五味常食（粳米、鸡蛋、梨、枣、羊肉），各填三栏：书中主治、书中忌讳、现代安全要点。
2. 抽三味下品药（附子、半夏、蜀椒），列出其古"有毒"标注与现代限量/炮制/特需人群的对应，体认古今尺度落差。
3. 遇市面"古方/本草/食疗"产品宣称，用三问筛选：对应哪条原文？原文说"主某表现"还是"治某病"？宣称功效在现代药典或药理有无对应？任一答不上，归入宣传层。
4. 凡涉及矿物丹药或野生动物的条目，在卡片注明"历史记载不构成采集/使用许可"。

## 板块8 · 知识整理与读法方法论

### 8_1 两套分栏：原文、理解、证据

整理五书的核心纪律是把"原文所说""我的理解""凭什么可信"三栏分开，不混写。混写是最易产生自我说服的方式。

```text
仙药/本草条目三栏记录卡（可直接套用）

┌────────────┬────────────────────────┬────────────┐
│ 原文所述   │ 我的理解与疑问         │ 证据标注   │
├────────────┼────────────────────────┼────────────┤
│ 名/异称    │ 与今日同名物是否同一？ │ 可验证    │
│ 产地       │ 今日是否仍产？生态？  │ 可验证    │
│ 形态特征   │ 可作实物鉴别依据？    │ 可验证    │
│ 采时       │ 与现代采收理论吻合？  │ 部分可验  │
│ 炮制       │ 原理能否理化说明？    │ 部分可验  │
│ 功效主张   │ 能否写成可检验命题？  │ 不可验证  │
│ 禁忌       │ 与现代禁忌方向一致？  │ 部分可验  │
│ 叙事成分   │ 传说/亲见/转引？      │ 需溯源    │
└────────────┴────────────────────────┴────────────┘
```

另设"药性记录卡"标准格式：传统主张栏（性味主治原句、产地采制、久服语、品级）与现代认知栏（药典功能主治、主要成分、药理方向、主要风险）分列，可验证性单列，安全标注（含毒性成分/需炮制/特需人群/受保护来源）单列。填卡纪律：传统主张栏只填原文不加己话；现代认知栏注明来源与查证状态，未查证写"待查"不填推测。

### 8_2 笔记方法场景

**场景一 · 通读批注**：每册只标记号建立形状——品级/毒否/久服语型（神农），或门类/禁忌强度（食疗），或层属/关键语（丹经）。三遍得全书分布图，比逐条细读更立整体感。

**场景二 · 精读摘录**：选一部门类逐条填卡，原文与理解分行（原句入引号、己话在引号外），绝不混写；禁忌语完整抄下不作缩写。

**场景三 · 配伍/对照**：同证异品横比（如咳嗽在三品各取若干条比性味主治），自然显出三品=治法谱系；或把同一物在五书的位置并排，看其被置于何地、以何口气言说。

**场景四 · 复盘对照**：季度回看卡片集，统计三件事——标"可验证"且真查证过的有几条；标"不可验证"中后来在别处见到的同源说法；这些说法里有多少被现代营销改写成"古方秘传"。长期做对"古方"类宣传形成稳定判断力。

### 8_3 实用验证：失败判别与自检

通用失败判别（任一出现即未通过）：

- 把托名当作者、把辑佚本当定本、把增补方当原貌。
- 把"久服轻身""通神延年"当安全或疗效结论引用。
- 把"上品=安全""下品=有毒"，或古"无毒"当现代无害。
- 未核实基原即按古描述自行采认/采服；按"主咳嗽"直接对译现代病名并建议用药。
- 笔记出现可照做配比/温度/时长/自制流程；或把"主某病"改写成"治某病"。
- 缺"古代记载不等于现代安全结论"与"遵医嘱"两处声明。

跨书一页自检清单（读罢五书应能自答）：

1. 五书各以何为轴、各回答哪类问题？
2. 三品划分依据为何不等于毒性分级？
3. 一条本草条文含哪六部件、最易被忽略哪两项？
4. 仙药两重判准与"服之勿使人知"三重考虑各是什么？
5. 食疗"主某病"句混含症状/功能/体质哪三类、"忌讳"为何更可信？
6. 辟谷三词主张差别、复食为何更需医疗关注？
7. 丹经"候"由哪类判据定时机、九丹指九个丹还是九个鼎位？
8. 为何"可验证"不等于"有效"、古载不构成今用依据？

若八问有两问以上答不上，建议回板块1、板块2、板块4、板块6 各重读一遍。

### 8_4 收束与方法论要义

五书合观，真正可带走的不是任何一味药的"奇效"，而是一套对待珍贵之物与古老知识的态度：先辨名实、再查来路、明其制法、知其失效条件、识其禁忌人群——凡说不清这些的，无论多神秘、多珍贵、多号称有效，都止于文献，不下手。

本库所引剂量、时长、配伍均属古代记载且原书多不载剂量，任何据以自行操作均缺乏安全依据。古代记载不等于现代安全结论；本库不构成医疗或用药建议；涉及药材服用须在合格中医师/药师指导下进行，切勿自行服食丹药或药材；出现不适立即停止并就医。
