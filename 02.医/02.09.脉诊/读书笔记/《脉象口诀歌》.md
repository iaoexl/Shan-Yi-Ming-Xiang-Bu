## 板块1 · 前言：为什么歌诀难学，又非学不可

《濒湖脉学》成书于明嘉靖四十三年（1564），是李时珍晚年撷取乃父李言闻《四诊发明》精华、参合诸家脉论编成的一部"脉学速记手册"。全书约万余字，分前后两部分：**前一部分**以"体状诗—相类诗—主病诗"三段式，系统论述浮、沉、迟、数、滑、涩、虚、实、长、短、洪、微、紧、缓、芤、弦、革、牢、濡、弱、散、细、伏、动、促、结、代共 **27 种脉象**；**后一部分**《四言举要》，则是李言闻在宋人崔嘉彦《脉诀》基础上删补而成，总述脉理、诊法、五脏平脉、妇人小儿脉法及真脏绝脉。

二十七脉的阴阳属性，原书分列如下（这是全书的"索引"，先记阴阳，再记体状，才不会乱）：

- **阳脉（8）**：浮、数、实、长、洪、紧、动、促
- **阴脉（15）**：沉、迟、涩、虚、短、微、缓、革、濡、弱、散、细、伏、结、代
- **阳中阴（3）**：滑、芤、弦
- **阴中阳（1）**：牢

**本书最核心的一句话，恰恰写在序里，而不是正文：**

> "世之医病两家，咸以脉为首务，不知脉乃四诊之末，谓之巧者尔。上士欲会其全，非备四诊不可。"

这句话决定了我们读歌诀的正确姿态：**歌诀是入门的梯子，不是断病的判据**。脉象是四诊之末，是高阶技巧，离开了望、闻、问，单凭一部脉下结论，正是李时珍批评的"俗子杜撰脉诀"一路。全书以歌诀写脉，本质是让学者"指下有循"——把抽象脉理翻译成手指可以复现的触觉，而不是让人对着韵文猜病。

本文不做原文的复述与堆砌，而是按"**结构重排 → 原文精读 → 类脉鉴别 → 分部落地 → 训练方案**"五步重构，把歌诀变成可以实际练习的读法。

## 板块2 · 先立骨架：浮沉迟数是"脉之纲领"

《濒湖脉学》虽列 27 脉，但李时珍本人明确说"**浮沉迟数，脉之纲领**"。后世"**浮沉分表里，迟数辨寒热，有力无力定虚实**"这一句总纲，正是由此化出。也就是说，27 脉其实是用四个维度层层细分出来的：

| 纲领 | 辨的是什么 | 核心提问 |
| --- | --- | --- |
| 浮 / 沉 | 病位深浅 | 轻按即得，还是重按始得？ |
| 迟 / 数 | 病性寒热 | 一息几至？慢于四至还是快于五至？ |
| 有 力 / 无 力 | 邪正虚实 | 按下去是充实，还是豁空？ |
| 形 / 势 / 律 | 气血津液状态 | 宽窄、滑涩、长短、节律是否整齐？ |

其余23 脉，都是在"某个位 +某个速 +某个力"的基础上，再叠加**脉形**（洪、细、长、短）、**脉势**（滑、涩、弦、紧）、**节律**（促、结、代、动）的变化。所以实操上，**初学者绝不该 27脉齐头并进，而应先把浮沉迟数有力无力这"五母脉"练成条件反射**，再逐个叠加。这是本文给出的最重要的学习建议。

### 2_1 平脉：先认"正常"，才有资格认"病"

> "春弦、夏洪、秋毛、冬石"——四时平脉，本是常识。

正常脉象（平脉）的标准是：**不浮不沉、不快不慢、不大不小、从容和缓、节律均匀**。换算成现代计数，约为 **一息 4～5 至，每分钟 60～90 次**。原书还特别强调 **尺脉沉取有力** 是肾气未衰的标志——这比"脉跳得多快"更值得初学者留意。

实操提醒：晨起未饮食、未活动时诊脉最准；诊室要安静，患者先休息片刻。临床上常见的"数脉"，一半其实是刚爬完楼、刚吵完架、刚喝完咖啡。**未经静息确认的脉，不作数**。每手诊察不少于 1 分钟，3 分钟左右为宜。

## 板块3 · 六纲精读：浮沉迟数 + 滑涩 + 弦紧

下文选取八对最常用、也最容易混淆的脉象，按"**原文 → 拆解 → 鉴别 → 落地**"四层解读。原文照录《濒湖脉学》歌诀，拆解部分才是本文的加工。

### 3_1 浮脉：举之有余，按之不足

**【体状诗】**

> 浮脉惟从肉上行，如循榆荚似毛轻。

三秋得令知无恙，久病逢之却可惊。

**【相类诗】**

> 浮如木在水中浮，浮大中空乃是芤。

拍拍而浮是洪脉，来时虽盛去悠悠。
浮脉轻平似捻葱，虚来迟大豁然空。
浮而柔细方为濡，散似杨花无定踪。

**【主病诗】**

> 浮脉为阳表病居，迟风数热紧寒拘。

浮而有力多风热，无力而浮是血虚。
寸浮头痛眩生风，或有风痰聚在胸。
关上土衰兼木旺，尺中溲便不流通。

**原文拆解：**

"举之有余，按之不足"八个字是全脉学最要紧的定义之一。浮脉的位置在**肌肉表层**，轻手（举法）即得，重按（按法）反见衰减，但不空——这是与芤、散的根本区别。

**三个极易被误读的点：**

1. **"三秋得令知无恙"**——秋季脉象本就该微浮（肺脉当令，其气清肃在上），此时见浮是**四时平脉**，不是病。同样，春季微弦、夏季微洪、冬季微沉，都是生理状态。**脱离季节谈脉象，十有八九是错的。**
2. **"久病逢之却可惊"**——久病之人正气已衰，脉应沉细，若反见浮大，多为**虚阳外浮**，是阳气欲脱的危象，绝非"表证"。这就是中医最讲究的"**脉证顺逆**"：新病浮为顺，久病浮为逆。
3. **"迟风数热紧寒拘"**——这是一组"脉中套脉"：浮而兼迟（浮迟）多风寒，浮而兼数（浮数）多风热，浮而兼紧（浮紧）多风寒束表。可见**单凭一个"浮"字断不了病，必须再看兼脉**。

**分部落地（寸关尺怎么用）：**

| 部位 | 浮脉所主 | 对应信号 |
| --- | --- | --- |
| 寸（上焦） | 头痛、眩晕、风痰 | 外感初起、风痰聚胸 |
| 关（中焦） | 土衰木旺 | 脾胃虚弱、肝气偏亢 |
| 尺（下焦） | 溲便不通 | 小便、大便传导失司 |

左寸候心、左关候肝、左尺候肾；右寸候肺、右关候脾胃、右尺候肾（命门）。**寸口分部的本质是"候脏腑之气"，不是"某脏的脉真的从这里过"**，这一点从一开始就要摆正，否则越学越迷信。

**浮脉家族速记（相类诗的核心）：**

```plain
浮 + 大中空   = 芤（如按葱管，失血）
浮 + 来盛去衰 = 洪（波涛汹涌，热盛）
浮 + 迟大空虚 = 虚（举大按松，气血两虚）
浮 + 柔细     = 濡（水面浮绵，湿困、自汗）
浮 + 散漫无根 = 散（杨花无定，元气离散，危）

```

### 3_2 沉脉：重手按至筋骨乃得

**【体状诗】**

> 水行润下脉来沉，筋骨之间软滑匀。

女子寸兮男子尺，四时如此号为平。

**【相类诗】**

> 沉帮筋骨自调匀，伏则推筋着骨寻。

沉细如绵真弱脉，弦长实大是牢形。

**【主病诗】**

> 沉潜水蓄阴经病，数热迟寒滑有痰。

无力而沉虚与气，沉而有力积并寒。
寸沉痰郁水停胸，关主中寒痛不通。
尺部浊遗并泻痢，肾虚腰及下元痌。

**原文拆解：**

沉脉的取法是"**重手按至筋骨**"，它主**里证、阴经病**。关键在于**沉 + 兼脉**的配伍逻辑：

- 沉而**数** → 里热；沉而**迟** → 里寒；沉而**滑** → 痰饮、水蓄
- 沉而**无力** → 虚、气虚；沉而**有力** → 积滞、寒凝

**这一段是全书的"辨证模板"**：同一个位（沉），配上不同的速（迟/数）、势（滑）、力（有力/无力），主病完全不同。学会这套组合法，27 脉其实只有一套逻辑。

**被忽略的干货："女子寸兮男子尺，四时如此号为平"**——女子尺脉宜沉、男子寸脉宜沉，本是生理差异。古人对男女脉位有专门论述，**用同一把尺子量所有人，反而会把平脉判成病脉**。这是临床极易踩的坑。

**分部落地：**

| 部位 | 沉脉所主 |
| --- | --- |
| 寸 | 痰郁、水停胸膈 |
| 关 | 中焦寒凝、腹痛 |
| 尺 | 下元虚寒、遗浊、泻痢、腰痛 |

### 3_3 迟脉与缓脉：慢，但慢得不一样

**【体状诗】**

> 迟来一息至惟三，阳不胜阴气血寒。

但把浮沉分表里，消阴须益火之原。

**【相类诗】**

> 脉来三至号为迟，小快于迟作缓持。

迟细而难知是涩，浮而迟大以虚推。

**【主病诗】**

> 迟司脏病或多痰，沉痼癥瘕仔细看。

有力而迟为冷痛，迟而无力定虚寒。
寸迟必是上焦寒，关主中寒痛不堪。
尺是肾虚腰脚重，溲便不禁疝牵丸。

**原文拆解：**

**一息三至（约 <60 次/分）为迟**。迟主寒，但"有力/无力"立刻分出两条路：迟而有力 = 实寒（冷痛）；迟而无力 = 虚寒（阳气衰）。这又是"有力无力定虚实"的标准应用。

**相类诗里藏着一个高价值辨析：迟 vs 缓。**

> "小快于迟作缓持"——比迟脉稍微快一点，就是缓脉（一息四至）。

- **迟**：去而不至、往来不前，脉形**蹇涩呆滞**，主寒、主脏病
- **缓**：从容和缓、来去舒缓**流畅**，本是**平脉**，也可主湿、脾虚

**这是临床最容易混的一对**：都"偏慢"，但迟是病态的滞，缓是生理的从容。**诀窍是感受"来去的流畅度"，不是数秒表**。同理，软弱、微涩也都是靠"流畅度 + 力度 + 清晰度"三维度区分（见后文类脉表）。

### 3_4 数脉：一息六至，但儿童不算病

**【体状诗】**

> 数脉息间常六至，阴微阳盛必狂烦。

浮沉表里分虚实，惟有儿童作吉看。

**【主病诗】**

> 数脉为阳热可知，只将君相火来医。

实宜凉泻虚温补，肺病秋深却畏之。
寸数咽喉口舌疮，吐红咳嗽肺生疡。
当关胃火并肝火，尺属滋阴降火汤。

**原文拆解：**

**一息六至（约 >90 次/分）为数**，主热。同样要分虚实：数而有力 = 实火（宜凉泻），数而无力 = 虚火（宜温补）。

两句极易被现代读者误读的话：

1. **"惟有儿童作吉看"**——小儿呼吸快、脉率本就高于成人，**小儿一息六至是正常现象**，不能套用成人标准判为"数脉主热"。年龄校正，是脉诊的前提。
2. **"肺病秋深却畏之"**——肺病本已伤阴，若在秋燥之时再见数脉，是**热灼阴液、病情进逼**的凶象。这是"脉与时节、宿病合参"的高级用法，提示我们：**脉象的吉凶是"相对"的，同一个数脉，放在不同人身上含义相反**。

**分部落地：**

| 部位 | 数脉所主 |
| --- | --- |
| 寸 | 咽喉、口舌疮、咯血、咳嗽（上焦热） |
| 关 | 胃火、肝火 |
| 尺 | 阴虚火旺（滋降为治） |

### 3_5 滑脉与涩脉：一对相反相成的"流利度"

**【滑脉·体状诗】**

> 滑脉如珠替替然，往来流利却还前。

莫将滑数为同类，数脉惟看至数间。

**【滑脉·主病诗】**

> 滑脉为阳元气衰，痰生百病食生灾。

上为吐逆下蓄血，女脉调时定有胎。
寸滑膈痰生呕吐，吞酸舌强或咳嗽。
当关宿食肝脾热，渴痢淋看尺部。

**【涩脉·体状诗】**

> 细迟短涩往来难，散止依稀应指间。

如雨沾沙容易散，病蚕食叶慢而艰。

**【涩脉·主病诗】**

> 涩缘血少或伤精，反胃亡阳汗雨淋。

寒湿入营为血痹，女人非孕即无经。
寸涩心虚痛对胸，胃虚胁胀察关中。
尺为精血俱伤候，肠结溲淋或下红。

**原文拆解：**

**这是全书最精彩的一组对照，也是最容易被误读的一组。**

**滑脉的"如珠替替然"**，说的是**往来流利的"形与势"**——像珠子在盘子里滚动，指下圆滑顺畅。它**不要求脉率快**。涩脉的"细迟短涩往来难"，说的恰恰是**不流利**——像轻刀刮竹、雨滴沾沙、病蚕食叶。两者是对"**血流顺畅度**"这同一个维度的正反两极。

**关键辨析："莫将滑数为同类"**

滑脉与数脉都属阳、常被误认成一对，但李时珍特意用"**数脉惟看至数间**"划清界限：**滑看流利度，数看至数（频率）**。因此临床上存在：

- **滑而不数**（迟滑）——有痰湿、食积，脉不快但流利
- **数而不滑**（涩数）——有热但津液已伤、血流艰涩
- **既滑且数**（滑数）——痰火、湿热，最常见

**反过来，"滑脉主痰、主食、主妊娠"也必须加条件**：青壮年气血充盛时可见生理性滑脉；孕妇见滑，要结合停经、体征才可断胎。把"滑脉 = 怀孕"当成公式，是江湖脉诊的最大误区。**"女脉调时定有胎"的"调"字才是重点——脉息调和、三部均匀，才是妊娠之象，单凭一个"滑"不够。**

**分部落地：**

| 部位 | 滑 | 涩 |
| --- | --- | --- |
| 寸 | 膈痰、呕吐、吞酸 | 心虚、胸痛 |
| 关 | 宿食、肝脾热 | 胃虚、胁胀 |
| 尺 | 渴、痢、淋 | 精血俱伤、肠结、溲淋、下血 |

### 3_6 弦脉与紧脉：都"紧绷"，绷得不一样

**【弦脉】**

> 弦而有力，如按琴弦，端直以长。——主肝胆、痛证、痰饮。

**【紧脉·体状诗】**

> 举如转索切如绳，脉象因之得紧名。

总是寒邪来作寇，内为腹痛外身疼。

**【主病诗】**

> 紧为诸痛主于寒，喘咳风痫吐冷痰。

浮紧表寒须发越，紧沉温散自然安。
寸紧人迎气口分，当关心腹痛沉沉。
尺中有紧为阴冷，定是奔豚与疝疼。

**原文拆解：**

弦与紧是**全书中最难用文字说清、却最值得练出指感的一对**。原书对弦脉的核心描述是"**端直以长**"——脉气紧张、挺然指下，像按在琴弦上，且**直而长，超过本部**。紧脉则是"**举如转索切如绳**"——脉势绷急弹指，像按在绷紧、甚至转动的绳索上。

**实操鉴别（三维度）：**

| 维度 | 弦脉 | 紧脉 |
| --- | --- | --- |
| 脉形宽度 | 较宽，可兼滑大 | 紧束而窄 |
| 紧张性质 | 端直而长，弹性感 | 绞绳转索，弹回感 |
| 可兼之象 | 可兼滑、大 | 难兼滑、大 |
| 主病倾向 | 肝郁、肝胆、痰饮、高血压 | 实寒、诸痛、外感寒邪 |

再补一对延伸：**弦与长**也易混。"**长类于弦而盛于弦，弦脉带急，长脉带缓**"——长脉是超过本位、如循长竿，长而不急；弦脉虽长但脉气紧张。**带急的是弦，带缓的是长。**

**分部落地（紧脉）：**

| 部位 | 紧脉所主 |
| --- | --- |
| 寸 | 表寒（浮紧）、人迎/气口分辨外感内伤 |
| 关 | 心腹疼痛 |
| 尺 | 下焦阴冷、奔豚、疝痛 |

**现代拓展（仅供参考，不作诊断）：** 弦脉常见于肝阳上亢、高血压病、胆囊炎胁痛、长期情绪压抑者；紧脉多见于风寒外束、剧痛、寒凝腹痛。**但脉象只能提示方向，必须配合血压、影像、化验，绝不能凭脉"确诊"某病。**

### 3_7 虚脉与实脉：有力无力的两极

**【虚脉·体状诗】**

> 举之迟大按之松，脉状无涯类谷空。

莫把芤虚为一例，芤来浮大似慈葱。

**【主病诗】**

> 脉虚身热为伤暑，自汗怔忡惊悸多。

发热阴虚须早治，养营益气莫蹉跎。

**【实脉·体状诗】**

> 浮沉皆得大而长，应指无虚愊愊强。

热蕴三焦成壮火，通肠发汗始安康。

**【主病诗】**

> 实脉为阳火郁成，发狂谵语吐频频。

或为阳毒或伤食，大便不通或气疼。

**原文拆解：**

虚脉是"**三部举之无力、按之豁空**"，涵盖气血两虚；实脉是"**三部举按皆有力、应指愊愊**"，主邪气亢盛、正邪相搏。

**一句辨析警句："莫把芤虚为一例"**——芤脉浮大中空（如按葱管），虚脉迟大按之空，二者都"空"，但**芤浮而芤，主失血亡津；虚无固定浮位，主气血两虚**。临床上失血初期见芤，久病气血亏见虚，不可混称。

**虚脉主病诗的现代转译：**"脉虚身热为伤暑"——暑邪伤气，气伤则身热而脉反虚（不洪不数），这是典型的**"脉证不符"**：热证却不见数脉，反而虚弱。此时若误当实热清泻，必致虚脱。**遇到"症状很重、脉象很弱"的情况，先怀疑脉证不符，这是保命级的经验。**

### 3_8 结脉、代脉、促脉：节律里的生死线

> 促脉：数而时一止，**止无定数**——阳盛实热、痰食停滞，亦见于脏气衰败。

结脉：缓而时一止，**止无定数**——阴盛气结、寒痰血瘀。
代脉：脉来一止，**止有定数、良久方还**——脏气衰微（孕妇见之可为胎象）。

**鉴别口诀：**"**结缓促数止无定，代歇有常命鲜回**"。

**这是全书最具临床风险的一组，实操时必须严肃对待：**

- 发现"间歇"，第一件事是**计时**：规律停顿（如每 5 跳一停）多为代，不规则停顿多为促、结。
- **绝对不要仅凭"脉有歇止"下预后判断**。情绪激动、惊恐、跌打损伤、妊娠都可出现暂年代脉。**任何节律异常，都应以心电图等现代检查确认，脉诊只作线索。**
- 促与结的区别在"至数"（促数结缓），代与二者的区别在"规律性"（代有规律）。三者的鉴别**靠计数，不靠感觉**。

## 板块4 · 类脉鉴别：全书的难点，做成对照表

李时珍写"相类诗"的用意，是承认了一个残酷事实：**脉象差异极其细微，"心中了了，指下难明"**。与其死记 27 个孤立定义，不如把 10 组高频混淆脉做成对比卡，练的时候成对出现。

| 相类组 | 共性 | 鉴别要点（一句话版） |
| --- | --- | --- |
| 浮 · 芤 | 脉位皆浅 | 浮按之不空；芤浮大中空、如按葱管 |
| 浮 · 洪 | 轻取即得 | 浮中等力度；洪来盛去衰、满指如波涛 |
| 浮 · 虚 · 散 | 均表浅无力 | 虚迟大按之豁空；散浮散无根、漫无定踪 |
| 沉 · 伏 | 重按方得 | 伏更深，需"推筋着骨"始得 |
| 沉 · 弱 | 皆沉 | 弱必沉细而无力；沉可兼大、兼数 |
| 迟 · 缓 | 脉率偏慢 | 迟蹇涩呆滞；缓和从容流畅（本是平脉） |
| 滑 · 数 | 均属阳 | 滑看流利度；数看至数（频率） |
| 弦 · 紧 | 脉管紧张 | 弦端直而长、如琴弦；紧绷急弹指、如转索 |
| 弦 · 长 | 脉体偏长 | 长超过本位而带缓；弦长而带急 |
| 微 · 涩 | 均细小 | 微若有若无、按之欲绝；涩往来艰涩但清晰可辨 |
| 软（濡）· 弱 | 均柔软无力 | 濡浮细而软；弱沉细而软（脉位相反） |
| 促 · 结 · 代 | 均有歇止 | 促数止无定数；结缓止无定数；代止有定数 |

**对照表的使用方法：** 不要把表背下来，而是**每次切脉时只问一个问题——"它更像左边还是更像右边？"** 把 27 选 1 的难题，降维成 10 次二选一，这正是"相类诗"的设计初衷。

## 板块5 · 寸关尺与举按寻：让歌诀落到手指上

原文的分部诗（寸/关/尺各一句）如果不配合诊法，永远是纸上文字。本节补齐实操链条。

### 5_1 布指：先定"关"，再定"寸尺"

1. **体位**：患者正坐或仰卧，前臂自然伸展，**腕与心脏同一水平**，掌心向上。环境安静，患者先休息。
2. **中指定关**：医者中指按在掌后高骨（桡骨茎突）内侧动脉处——此为"关"。
3. **食指定寸、无名指定尺**：以中指为基准，食指在关前（腕侧）为寸，无名指在关后（肘侧）为尺。
4. **布指疏密**：三指呈弓形、指端平齐，指目（指腹与指尖交界的棱起处）贴合脉体，与皮肤约呈 45°。身高臂长者布指宜疏，矮小者宜密。**小儿寸口短，用"一指定关法"，以拇指统按三部。**
5. **左右手都查**：医者通常以左手切患者右手、右手切患者左手。左右寸关尺脏腑分配不同（左心肝肾、右肺脾命门），**只把一只手等于只读半本书**。

### 5_2 指力：举、按、寻三层取脉

这是把"分部诗"变成可操作动作的关键：

- **举（浮取）**：轻按于皮肤，感知脉位深浅——答"浮还是沉"
- **按（沉取）**：重按至筋骨，感知脉力与根——答"有力还是无力、有无根"
- **寻（中取 + 推寻）**：指力由轻到重、由重到轻，左右前后推寻，寻找脉动最清晰的特征点——答"宽窄、滑涩、弦紧"

配合 **总按**（三指同力，看整体）与 **单按**（一指独取一部，看局部），形成完整信息。

**实操口诀（直接对应分部诗）：**

> 先总按，定整体浮沉迟数有力无力；

再单按寸关尺，问三个问题——
"寸部有没有异常？关部有没有异常？尺部有没有异常？"
最后举按寻，把每部的深浅、力度、流利度补细。

### 5_3 三部九候的现代意义

原书与《内经》所说的"三部九候"本是遍诊法，后世简化为独取寸口。**今天更值得继承的是它的思路：分层次、分部位、多维度采集信号**，而不是迷信某一种取脉位置。寸口诊法的合理性在于桡动脉位置表浅、易于标准化，但它的信息量天然有限——这恰恰是李时珍强调"四诊合参"的底层原因。

## 板块6 · 实操训练：把歌诀练成条件反射

以下方案按 4 周设计，每天 15～20 分钟，**建议在有资质中医师带教下、于自身或健康同伴身上练习**。自学脉诊只能用于体会手感，不能用于自我诊断或指导用药。

### 6_1 第一周：只练"五母脉"

目标：闭眼能分出浮/沉、迟/数、有力/无力。

- 每天先用**举按寻**在自己寸口反复切换，刻意体会"轻按即得（浮）"与"重按始得（沉）"的临界点
- 静息 5 分钟后**默数一息脉次**，记录早晚各一次，建立自己的基线
- 对比运动后（数、洪）与休息后（缓、平）的差异——**这是体会"脉随气变"最快的方式**
- 周末用"总按 + 单按"分别体会寸关尺的力度差异

### 6_2 第二周：成对辨析（对照第三节表格）

每周攻 3 组，顺序建议：**浮/芤 → 滑/数 → 弦/紧**。

方法：**预设特征法**——先用表格把"芤是浮大中空"这类要点在指下"找一遍"，再闭眼复现。每一组都问一个二选一问题，不许给模糊答案。

### 6_3 第三周：分部 + 兼脉

- 把每部常见脉象写成小卡：寸—浮/数/滑，关—弦/实/沉，尺—沉/细/弱
- 练习"**脉中套脉**"的表述：不单说"弦脉"，而说"**左关弦而有力，兼略数**"——把位、速、力、形四要素一次说全
- 对应原文主病诗，只做"方向性联想"，不下诊断

### 6_4 第四周：节律专项（结促代）

- **以秒表 + 计数替代感觉**：连续计数 100 次搏动，标记停顿位置
- 明确"止无定数 / 止有定数"的统计定义
- **出现任何明显节律异常，停止练习、转做心电图检查**——这一条不可省略

### 6_5 自检清单（每周自评一次）

- [ ] 能否在 10 秒内说出浮/沉/迟/数/滑/涩/弦/紧八脉的核心体状？
- [ ] 能否在指下区分"流利（滑）"与"频率快（数）"？
- [ ] 能否说清弦与紧的至少 2 个差异点？
- [ ] 是否养成"**先定浮沉迟数，再定有力无力，最后定形与律**"的固定顺序？
- [ ] 是否每次记录都注明**静息状态、体位、时间、左右手**？（缺任何一项，记录不可比）

## 板块7 · 读书方法复盘：四条原则

**1. 先总纲后枝叶。** 浮沉迟数是纲，其余是目。纲不立，目必乱。

**2. 以"相类诗"为正文，而非附录。** 27 脉中真正独立的"体状"只有十来种，其余差异全在相类诗里。会读相类诗，才算真正读了这本书。

**3. 永远带着"兼脉"意识。** 原文主病诗里大量"浮而有力""沉而数""迟而无力"的写法，提示**真实脉象几乎都是复合的**。单脉是教材概念，兼脉才是临床常态。

**4. 脉诊的上限由四诊决定。** 李时珍在序中直言"脉乃四诊之末"。脉象可以提示方向、判断进退（如**脉由浮转沉 = 邪气由表入里；由数转缓 = 热邪消退；由虚转实 = 正气渐复**），但**不能替代问诊、望舌、体征与现代检查**。尤其是节律异常、危脉（雀啄、屋漏、釜沸、解索等真脏脉），必须以现代医学手段确认。

## 板块8 · 结语：歌诀的真正价值

《濒湖脉学》用了上万个字、二十七组歌诀，想说的事其实只有一件：**把"指下难明"的脉，翻译成可以复现的触觉动作**。浮如木浮、芤如葱管、涩如刮竹、弦如琴弦——每一个比喻都是一份"操作说明"。

所以它最忌讳两种读法：一是把歌诀当咒语背，背得烂熟却从未在腕上找过一次；二是把脉象当仪器，幻想凭一部脉断尽全身病。前者是"心中不了了"，后者是"忘了脉乃四诊之末"。

真正的学习路径始终是：**先认平脉 → 再辨纲领 → 再攻类脉 → 再练分部 → 最后四诊合参**。歌诀是起点，不是终点；指下分明之后，最终要回到"人"——回到症状、体质、季节、情志，以及现代医学的客观证据上。这大概正是这部五百年前的"速记手册"，今天仍然站得住的原因。

## 板块9 · 附：二十七脉速记卡（一体状 + 一主病，两行成诵）

1. **浮**：如榆荚毛轻飘，表证风邪血虚招
2. **沉**：行筋骨按方得，里证寒凝水积迫
3. **迟**：一息三至阳不足，寒证冷痛虚寒伏
4. **数**：息间六至阴不足，热证实火虚火分
5. **滑**：如珠替替往来利，痰食妊娠元气疲
6. **涩**：如刮竹来往来难，血少伤精血瘀干
7. **虚**：迟大按之豁然空，气血两伤自汗逢
8. **实**：浮沉有力大而长，火郁积滞实证殃
9. **长**：迢迢过本位，气盛阳和热势深
10. **短**：两头缩缩短，气郁血涩痞痛缠
11. **洪**：来盛去衰如波澜，热盛壮汗阴液残
12. **微**：欲绝有如无，气血大虚阳欲孤
13. **紧**：转索切绳绷急弹，寒证诸痛喘咳寒
14. **缓**：四至柳梢柔，湿证脾虚平人亦可求
15. **芤**：中空如葱管，失血吐衄崩漏满
16. **弦**：端直而长如弓弦，肝郁痰饮痛疟牵
17. **革**：芤弦相合如鼓皮，虚寒失血半产多
18. **牢**：沉实弦长坚，里寒积滞腹心煎
19. **濡**：浮细软如絮，湿困脾虚自汗俱
20. **弱**：沉细按乃得，阳虚精亏气血竭
21. **散**：浮大无定踪，元气涣散汗出凶
22. **细**：如线应指清，气血不足湿邪停
23. **伏**：推筋着骨寻，闭郁厥逆积滞深
24. **动**：摇摇豆形团，痛惊妊娠男子崩
25. **促**：数止无定数，热盛瘀痰脏气枯
26. **结**：缓止无定数，寒凝气结瘀血阻
27. **代**：止有定数期，脏气衰微元气离

## 板块10 · 案例拆解：歌诀背熟了，指下还是分不清

（虚构教学案例，不对应真实人物）一位自学者把二十七脉歌诀背得滚瓜烂熟，临到给家人摸脉，仍分不出迟与缓。

口诀给的是"文字坐标"，指下要的是"肌肉记忆"。数息之间，迟脉一息三至、缓脉一息四至而脉体松弛——差别在节律与紧张度，这两样只能靠反复对比练出来。背得再熟，不落在指上，仍是别人的经验。

**落点**：脉学没有"读懂"这一说，只有"摸到"。每天五分钟，连续三个月，胜过背十遍口诀。
