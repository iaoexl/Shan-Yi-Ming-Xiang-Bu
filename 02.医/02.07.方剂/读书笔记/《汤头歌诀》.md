## 板块1 · 先破题：这本书到底在读什么

《汤头歌诀》为清代汪昂（字讱庵，安徽休宁人）所撰，刊于清康熙三十三年（1694 年）。汪昂先习儒，后转医学，一生志在「去粗取精、由博返约」，另著《本草备要》《医方集解》《素问灵枢类纂约注》，皆为浅近实用的入门经典。

书名中「汤头」二字，就是「方剂的套路、规格」——前人制方，某方某药各有成规，加减虽有变通，治法不逾正则。全书选录常用方剂 300余首，编为约 200首方歌，分为 **20 类**，每方以七言歌诀概括**方名、药味、功效、主治、加减、剂量、剂型**，并附简要注释，通俗易懂。刊行之后「风行久矣，初学医者每手置一编，熟诵而心记之」，被后世与《药性赋》等并尊为「中医四小经典」之一。

### 1_1 常见的三种误读

| 误读 | 真实情形 | 本书的立场 |
| --- | --- | --- |
| 它是「方剂学教材」 | 它是**方剂启蒙书**，成书早于现代学科体系 | 当索引与骨架，不当全部知识 |
| 背熟歌诀就能开方 | 歌诀只给「方剂轮廓」，不给「病机判断」 | 歌诀是钥匙，**辨证才是锁孔** |
| 是过时的古文 | 其分类逻辑与配伍范式至今仍是《方剂学》教材的底层结构 | 它是活的思维工具，而非文物 |

### 1_2 一个必须建立的元认知

歌诀压缩的是「**方证对应**」——方剂的适用边界被押成了韵。学习的第一原则应是：

> **先解其义，后诵其文。** 把方歌当顺口溜死背，就是「小和尚念经，有口无心」；真正要到病人身上发挥作用、自己组方，必须先把配伍逻辑拆开。

### 2_2 暗线：一套完整的治法哲学（这才是精华）

目录顺序并非随意排列，而是沿一条清晰的治病逻辑展开：

```plain
扶正（补益之剂）
   ↓ 邪之所凑，其气必虚 → 首列补益，四君子汤为代表
祛邪（发表 / 攻里 / 涌吐）
   ↓ 汗、吐、下——给邪气三条出路
调和（和解 / 表里 / 消补 / 理气 / 理血）
   ↓ 既不能纯补、也不能猛攻时，用"和法"调到平和
分治六淫（祛风 / 祛寒 / 祛暑 / 利湿 / 润燥 / 泻火）
   ↓ 针对风、寒、暑、湿、燥、火等单一病邪专项处理
收尾（除痰 / 收涩 / 杀虫 / 痈疡 / 经产）
   ↓ 特殊病机与专科场景

```

由此可推出**三个深层结论**，远比"记住分类"有用：

1. **补益居首 ≠ 补药优先**，而是承认"正气存内，邪不可干"是治病的地基。
2. **汗吐下三法并列**，说明祛邪的核心是"给邪以出路"，而不是一味对抗。
3. **和解、表里、消补、理气、理血都可归入"和法"**——它们是同一思路在不同病位的展开，这也是全书最容易被忽略的统一结构。

### 2_3 方剂家族：比分类更高效的记忆单位

汪昂善用「附方」表明方剂演化关系，**同一基础方可加减出整族方剂**。掌握家族树，记忆量呈指数级下降：

- **四君子汤（补气基础方）**：四君子 → 加半夏、陈皮 = 六君子（祛痰补气）→ 去半夏 = 异功散 → 再加木香、砂仁 = 香砂六君子（温胃散寒）
- **六味地黄丸（补肾基础方）**：六味 → 加知母、黄柏 = 知柏地黄丸（阴虚火旺）→ 加枸杞子、菊花 = 杞菊地黄丸（养肝明目）→ 加五味子 = 都气丸（纳气喘）
- **四物汤（补血基础方）**：四物 → 合四君子 = 八珍汤 → 再加黄芪、肉桂 = 十全大补汤 → 加志、陈、味、姜、枣 = 人参养荣汤
- **理中汤（温中基础方）**：理中 → 加附子 = 附子理中汤（扶阳）

> **实操结论**：与其逐首死背 200 方歌，不如**先立 15 个"基础方"节点，再沿加减关系生长出全树**。

## 板块3 · 原文重点解析：从「文字」到「方义」的四层拆法

以开篇第一方**四君子汤**示范标准拆解流程，后文所有方剂皆可用此模板处理。

### 3_1 案例：四君子汤

> **原文歌诀**：四君子汤中和义，参术茯苓甘草比；益以夏陈名六君，祛痰补气阳虚饵；除却半夏名异功，或加香砂胃寒使。

**第一层 · 释文**：参（人参）、术（白术）、茯苓、甘草四味等量相比，药性平和，符合"君子致中和"之意；加半夏、陈皮为六君子汤，主治痰湿兼气虚；去半夏为异功散；再加木香、砂仁，治胃寒气滞。

**第二层 · 组方（君臣佐使）**：人参为君补气，白术为臣健脾燥湿，茯苓为佐渗湿，炙甘草为使调和——**四味构成"补气—健脾—去湿—和中"的完整闭环**，正是后世补气方的母版。

**第三层 · 病机**：脾胃气虚 → 气短乏力、食少便溏。此方治在"中焦气化"，而非单纯补营养。

**第四层 · 延伸（方证边界）**：

- **适用**：脾胃气虚、虚寒体质；
- **慎用**：湿热内蕴、实热证者；
- **关键鉴别**：同样是"虚"，气虚用四君子，血虚用四物，气血两虚用八珍——**辨的是"虚在哪一经"，不是"人虚不虚"**。

### 3_2 拆解模板（建议抄录，每学一方填一份）

```plain
「1」 原文歌诀 → 「2」 组成 + 剂量比例 → 「3」 君臣佐使
        ↓
「4」 主治证候 + 辨证要点（舌、脉、典型症状）
        ↓
「5」 核心配伍逻辑（哪两味药是"药对"，为什么）
        ↓
「6」 加减 / 附方关系（它在哪个家族树上）
        ↓
「7」 禁忌与鉴别（和哪个相似方最容易混）

```

## 板块4 · 核心名方精讲：高频 + 高结构价值

下面挑选**临床高频、且配伍结构典型**的方剂，按"歌诀—方义—要点"压缩呈现。每首都附**辨证要点**与**易错鉴别**，这是原文里没有、但临证最要紧的部分。

### 4_1 发表之剂（解表）

**麻黄汤**（辛温解表峻剂）

> 麻黄汤中用桂枝，杏仁甘草四般施；发热恶寒头项痛，伤寒服此汗淋漓。

- 组成：麻黄、桂枝、杏仁、甘草。
- 方义：麻黄发汗宣肺为君，桂枝助汗为臣，杏仁降肺平喘为佐，甘草缓麻桂之峻为使。**麻桂相须、麻杏相使**是核心结构。
- **辨证要点**：恶寒发热、无汗而喘、脉浮紧——关键词是「无汗」。
- **鉴别**：麻黄汤（无汗而喘）vs 桂枝汤（有汗恶风），一字之差，一散一收，**错用麻黄汤于表虚自汗者，发汗太过亡阳**。

**桂枝汤**（调和营卫法之祖）

> 桂枝汤治太阳风，芍药甘草姜枣同；桂麻相合名各半，太阳如疟此为功。

- 组成：桂枝、芍药、炙甘草、生姜、大枣。
- **核心结构**：桂枝配芍药，等量（1:1），一散一收、一治卫强一治营弱，寓含三意——营卫同治、相辅相成、相制相成。
- **辨证要点**：发热、汗出、恶风、脉浮缓。
- **服法细节（最易被忽略）**：服后**啜热稀粥**以助汗源，温覆取"遍身漐漐微似有汗"，**不可令如水流漓**；中病即止，不必尽剂。
- **禁忌**：表虚自汗、血虚、阴虚者，麻黄汤禁用——而桂枝汤恰恰是给"表虚有汗"准备的。

**九味羌活汤**（分经论治代表）

> 九味羌活防风苍，辛芷芎草芩地黄；发汗祛湿兼清热，分经论治变通良。

- 要点：解表 + 祛湿 + 清热三法合一，**"分经论治"**是其区别于麻黄、桂枝二方的标志——表里兼顾，用于外感风寒湿邪、内有蕴热。

**银翘散 / 桑菊饮**（辛凉解表两兄弟）

> 银翘散主上焦疴，竹叶荆牛豉薄荷，甘桔芦根凉解法，清疏风热煮无过。

桑菊饮中桔杏翘，芦根甘草薄荷饶，清疏肺卫轻宣剂，风温咳嗽服之消。

- **鉴别**：银翘散（辛凉**平**剂，风热表证为主，咽痛发热突出）vs 桑菊饮（辛凉**轻**剂，偏于**咳嗽**）。**临床选型的关键是"以热为主还是以咳为主"**。

### 4_2 补益之剂（扶正）

**补中益气汤**（升阳举陷代表）

> 补中益气芪术陈，升柴参草当归身；虚劳内伤功独擅，亦治阳虚外感因。

- 组成：黄芪、白术、陈皮、升麻、柴胡、人参、甘草、当归。
- 方义：黄芪、人参补气为君，**升麻、柴胡升阳举陷**是全方灵魂——补中有升，故能治"中气下陷"之脱肛、久泻、内脏下垂。
- **辨证要点**：劳倦内伤、少气乏力、气虚发热（甘温除热）。
- **鉴别**：补中益气汤（补气 + 升提）vs 归脾汤（补气 + 养血安神）vs 四君子汤（纯补气）——三者差在"要不要升、要不要养心脾"。

**六味地黄丸**（三阴并补范式）

> 六味地黄益肾肝，茱薯丹泽地苓专；更加知柏成八味，阴虚火旺可煎餐。

- 组成：熟地、山茱萸、山药、泽泻、茯苓、牡丹皮（"三补三泻"）。
- **核心结构**：补药用量重（地八山山四），泻药用量轻（丹苓泽泻三），体现"**补中寓泻、开泻通补**"，而非一味堆补。
- **注意**：感冒发热时暂停；长期调养方，非一日之功。

**生脉散**（气阴两伤急救方）

> 生脉麦味与人参，保肺清心治暑淫；气少汗多兼口渴，病危脉绝急煎斟。

- 组成：麦冬、五味子、人参。**急救场景指征**：气少汗多、口渴、脉绝。

### 4_3 和解与表里之剂

**小柴胡汤**（和法总方）

> 小柴胡汤和解供，半夏人参甘草从；更用黄芩加姜枣，少阳百病此为宗。

- 组成：柴胡、黄芩、半夏、人参、甘草、生姜、大枣。
- 方义：柴胡升散、黄芩苦降，**一升一降、一寒一温且消且补**，正是"和法"的活标本。
- **辨证要点（少阳四大症）**：往来寒热、胸胁苦满、默默不欲饮食、心烦喜呕，口苦咽干目眩，脉弦。
- **警示**：为处方药，须专业医师辨证，**不建议自行配制**。

**大柴胡汤 / 防风通圣散**（表里双解代表）

> 大柴胡汤用大黄，枳实芩夏白芍将；煎加姜枣表兼里，妙法内攻并外攘。

- 适用：少阳阳明同病，**外有表证、里有里实**，需"内攻外攘"同时下手。

### 4_4 攻里、祛湿、泻火、理血

**大承气汤**（峻下热结代表）

> 大承气汤用芒硝，枳实厚朴大黄饶；救阴泻热功偏擅，急下阳明有数条。

- **辨证要点（痞、满、燥、实四症）**：阳明腑实证，热结便秘、腹满拒按。
- **注意**：攻下峻剂，**中病即止，老人、体弱、孕妇慎用**。

**五苓散**（利水第一方）

> 五苓散治太阳腑，白术泽泻猪苓茯；桂枝化气兼解表，小便通利水饮逐。

- 方义：桂枝温通助气化，是"利水 + 解表"双解结构。主治蓄水证、水湿内停、痰饮（小便不利、水肿、烦渴欲饮、水入即吐）。

**龙胆泻肝汤**（清利肝胆湿热）

> 龙胆泻肝栀芩柴，生地车前泽泻偕；木通甘草当归合，肝经湿热效力杰。

- 要点：**"泻中有补、利中有滋"**——用当归、生地护阴，防苦寒伤正。主治肝胆湿热下注（阴肿、淋浊、带下、口苦尿赤）。

**血府逐瘀汤**（活血化瘀行气）

> 血府当归生地桃，红花枳壳膝芎饶；柴胡赤芍甘桔梗，血化下行不作劳。

- **辨证要点（血瘀关键指征）**：刺痛有定处、舌暗红或有瘀斑瘀点、脉涩，**入暮潮热、急躁易怒**。
- 现代多用于冠心病心绞痛、血栓闭塞性脉管炎、脑震荡后遗症等属"瘀阻气滞"者。

**二陈汤 / 平胃散 / 保和丸**（痰湿食积三阶梯）

> 二陈汤用半夏陈，苓草梅姜一并存；燥湿化痰兼理气，湿痰为患此方珍。

平胃散用朴陈皮，苍术甘草姜枣齐；燥湿运脾除胀满，湿滞中焦此方宜。
保和山楂莱菔曲，夏陈茯苓连翘取；炊饼为丸白汤下，消食和胃食积去。

- **鉴别阶梯**：**湿痰内停 → 二陈汤（化痰）**；**湿滞脾胃、胀满 → 平胃散（燥湿运脾）**；**食积停滞 → 保和丸（消食和胃）**。三者病位都在中焦，差别在"痰 / 湿 / 食"。

## 板块5 · 可落地的实操系统：把笔记变成能力

### 5_1 五步学习法（按此执行，100 天可通读全书）

**第一步 · 选对版本，别一上来啃古文**
直接用线装原文易劝退。建议选**带白话注释 + 方解 + 现代应用**的版本（如《汤头歌诀白话解》《图解汤头歌诀》），需满足三点：术语有解释（如"太阳风"即风寒表虚有汗）、药味有对应（甘桔陈苓 → 甘草、桔梗、陈皮、茯苓）、**禁忌有提醒**（如麻黄汤风热、老人、小儿慎用）。

**第二步 · 按功效分块，每日定量**
每天 **2～3 首**（而非贪多到 5 首），按 20 类顺序推进，每首按第三节的「四层拆法」走一遍。**重点方剂须烂熟于心**：麻黄汤、桂枝汤、白虎汤、四君子汤、四物汤等。

**第三步 · 分类对比，构建网络**
把相似方并排记。例如治"眩晕"：风晕、火晕、痰晕、虚晕各有对应方。**本书给出的天然对比组**：

| 对比维度 | 方剂对 | 关键差异 |
| --- | --- | --- |
| 无汗 vs 有汗 | 麻黄汤 / 桂枝汤 | 汗孔开闭、麻桂 vs 桂芍 |
| 气虚 vs 血虚 | 四君子汤 / 四物汤 | 补气 vs 养血 |
| 辛凉平 vs 轻 | 银翘散 / 桑菊饮 | 热重 vs 咳重 |
| 湿热 vs 瘀血 | 龙胆泻肝汤 / 血府逐瘀汤 | 肝胆湿热 vs 胸中血瘀 |
| 补气 vs 升提 vs 养心脾 | 四君子 / 补中益气 / 归脾 | 纯补 / 补+升 / 补+养血安神 |

**第四步 · 溯源经典，理解加减**
《汤头歌诀》是提炼，方剂的原始面貌在《伤寒论》《金匮要略》《温病条辨》等。学到一处附方（如六君子、知柏地黄丸），务必回到主方看加减逻辑——**这正是在学"如何自己组方"**。

**第五步 · 临床反刍，从案中印证**
随师临证时，把看到的病证与脑中歌诀对应：见"外感自汗恶风"即唤起桂枝汤，思考为何用桂芍一散一收。名家经验一致认为：**背诵是建立中医直觉与快速反应的基石，这种"临床手感"是检索替代不了的**。

### 5_2 三类强化工具（可直接复制使用）

**「1」 对比鉴别卡（正面方名 + 组成，背面主治 + 要点）**
按第四步的对比组制作，专攻"最易混的 20 组"，考前/临证前快速过一遍。

**「2」 方剂家族树笔记**
以 4.2 节的四个家族为起点，把 20 类中所有"附方"关系画出。**掌握 15 个基础方 ≈ 覆盖全书半数方剂**。

**「3」 场景—方对应表（最贴近实战）**
把日常 / 临证场景直接映射到方剂，形成条件反射：

| 场景信号 | 对应方 | 出处关联 |
| --- | --- | --- |
| 恶寒、无汗、脉浮紧 | 麻黄汤 | 发表之剂 |
| 发热、自汗、恶风 | 桂枝汤 | 发表之剂 |
| 往来寒热、胸胁苦满 | 小柴胡汤 | 和解之剂 |
| 食少便溏、气短乏力 | 四君子汤 | 补益之剂 |
| 腰膝酸软、盗汗耳鸣 | 六味地黄丸 | 补益之剂 |
| 刺痛有定处、舌暗瘀斑 | 血府逐瘀汤 | 理血之剂 |
| 咳喘痰稀、舌苔白滑 | 小青龙汤 | 发表之剂 |

### 5_3 进阶：从"背方"到"组方"

真正的能力分水岭，在于**理解君臣佐使的配伍规律**，而非记住药味。可重点玩味三组经典药对：

- **桂枝 + 芍药**（一散一收，调和营卫）——桂枝汤灵魂
- **麻黄 + 杏仁**（一宣一降，平喘）——麻黄汤灵魂
- **熟地 + 泽泻 / 山萸 + 丹皮 / 山药 + 茯苓**（三补三泻，开泻通补）——六味地黄丸灵魂

掌握药对逻辑后，**面对活的疾病，可在主方骨架上做精准加减**，而不再是"方证死套"。

## 板块6 · 现代应用的三条红线（务必遵守）

1. **辨证永远先于选方**。同一"感冒"，风寒用麻黄汤类、风热用银翘散类，**银翘散若误用于风寒、麻黄汤误用于风热，皆会加重病情**。歌诀里的"主治"是线索，不是自动匹配的按钮。
2. **方是死的，病是活的**。连建伟教授批评"光背几个汤头像小和尚念经"，段富津教授则强调"医者书不熟则理不明，临证游移，漫无定见"。**背诵是手段，明理才是目的**。
3. **安全边界不可逾越**：
    - 麻黄汤类发汗峻剂，**表虚自汗、血虚、阴虚者禁用，中病即止**；
    - 小柴胡汤等须专业医师辨证，**不建议自行抓药煎服**；
    - 补益方（如六味地黄丸）**感冒发热期间暂停**；
    - 孕妇、老人、体弱者使用攻下、发汗、破血类方剂须格外谨慎。
    - **涉及具体诊疗，务必线下就医，本书笔记不可替代医生判断。**

## 板块7 · 延伸拓展：让笔记"长出"更多体系

汪昂《汤头歌诀》并非孤立存在，可与以下材料构成**三层知识网**：

- **同作者体系**：《本草备要》（药）→《汤头歌诀》（方）→《医方集解》（方解）→《素问灵枢类纂约注》（理）——汪昂一生"由博返约"的四部曲。**学《汤头》遇到不懂的药性，直接查《本草备要》；遇到不懂的方义，查《医方集解》**，这是最原汁原味的配套路径。
- **启蒙双璧**：《汤头歌诀》+《药性赋》。前者记方、后者记药，陈文伯、周信有、段富津等名家皆以二书为启蒙。
- **现代方剂学教材**：高等医学院校《方剂学》篇末多附方歌，可与本书对照——**教材补"病机与循证"，本书供"记忆与框架"**，二者不可偏废。
- **当索引用**：全书 20 类 + 附方体系，本身就是一张**中医方剂全景地图**，适合在做病例分析时快速检索候选方。

## 板块9 · 案例拆解：背了方歌，却把君臣弄反

（虚构教学案例，不对应真实人物）一位自学者能背三百首方歌，替家人治外感时照歌诀抓药，剂量平均分配，服后无效。

方歌给的是"有哪几味"，不给"谁为君、谁为臣、比例多少"。同一组药，君臣易位就是另一张方——桂枝汤与桂枝加桂汤只差一味剂量，主治便从调和营卫转为降冲逆。

**落点**：方歌是索引，剂量是内容。背方不记比例，等于只记住了药名清单。
