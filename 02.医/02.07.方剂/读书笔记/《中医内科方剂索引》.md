## 板块1 · 本书（索引）在学什么：三层方根体系

读《中医内科方剂索引》最容易被"按笔画罗列"的形式带偏。真正要建立的，是**三层方根**的认知骨架：

**第一层 · 基础方（药出有理）**
一个治法的最小完整单元，是后续所有加减的"种子"：

- 外感风寒表实 → **麻黄汤**
- 外感风寒表虚 → **桂枝汤**
- 表邪未解、邪热壅肺之喘咳 → **麻杏石甘汤**
- 伤寒少阳证 → **小柴胡汤**
- 阳明气分热盛 → **白虎汤**
- 疏肝理脾 → **四逆散**
- 阳明腑实证 → **大承气汤**
- 中焦脾胃虚寒 → **理中丸**
- 脾胃气虚 → **四君子汤**
- 补血调经 → **四物汤**
- 补气生血 → **当归补血汤**
- 肝肾阴虚 → **六味地黄丸**
- 燥湿化痰 → **二陈汤**
- 湿滞脾胃 → **平胃散**
- 温阳利水 → **真武汤**

**第二层 · 代表方（治出有法）**
在基础方上体现明确治法取向：

- 疏肝健脾 → **逍遥散**
- 寒热平调、辛开苦降 → **半夏泻心汤**
- 补气升阳、甘温除热 → **补中益气汤**
- 气血痰火湿食"六郁" → **越鞠丸**
- 益气活血 → **补阳还五汤**
- 清宣凉燥 → **杏苏散**
- 中阳不足痰饮 → **苓桂术甘汤**

**第三层 · 常用方（方出有名）**
直接对应内科常见证型的"一线方"：

- 外寒内饮喘咳 → **小青龙汤**
- 风热表证 → **银翘散**
- 风热犯肺咳嗽 → **桑菊饮**
- 肝脾不和痛泻 → **痛泻要方**
- 热病后期气阴两伤 → **竹叶石膏汤**
- 肝胆实火上炎 → **龙胆泻肝汤**
- 肺热喘咳 → **泻白散**
- 胃火牙痛 → **清胃散**
- 胃热阴虚牙痛 → **玉女煎**
- 阴虚火旺盗汗 → **当归六黄汤**
- 血虚温经散寒 → **当归四逆汤**
- 调和阴阳、柔肝理脾 → **小建中汤**
- 脾虚湿盛泄泻 → **参苓白术散**
- 气阴两虚 → **生脉散**
- 表虚自汗 → **玉屏风散**
- 脾虚肝郁湿浊下注 → **完带汤**
- 心脾气血两虚 → **归脾汤**
- 阴虚肝郁胁痛 → **一贯煎**
- 补肾助阳 → **肾气丸**
- 命门火衰五更泻 → **四神丸**
- 心肾阴血亏虚神志不安 → **天王补心丹**
- 痰气互结梅核气 → **半夏厚朴汤**
- 上实下虚咳喘 → **苏子降气汤**
- 胃虚痰阻气逆 → **旋覆代赭汤**
- 胃虚有热呃逆 → **橘皮竹茹汤**
- 外感风邪头痛 → **川芎茶调散**
- 风痰阻络 → **牵正散**
- 风疹湿疹 → **消风散**

>  读书法：不要按笔画死记，要把每一个方"挂"到这三层中的某一层。看到一个新方，先问三句话——它**继承自哪个基础方**？它**突出哪种治法**？它**主治哪种内科证型**？

## 板块2 · 方剂学的几条"源代码"：配伍规律提炼

索引背后的真正干货，是方剂与方剂之间的**配伍语法**。掌握这几条，比背 300 个方歌更有效。

### 2_1 辛开苦降 —— 调和寒热的核心语法

**半夏泻心汤**是典型：半夏、干姜（辛开）+ 黄芩、黄连（苦降）+ 人参甘草大枣（补泻兼施）。
这一语法可迁移到：

- **左金丸**（黄连+吴茱萸）
- **半夏泻心汤**类方：生姜泻心汤、甘草泻心汤、黄连汤

>  临床识别点：心下痞、呕而肠鸣、冷热错杂——第一时间想到辛开苦降。

### 2_2 甘温除热 —— 气虚发热的独特解法

**补中益气汤**重用黄芪、人参、白术、炙甘草甘温益气，配升麻柴胡升阳举陷。
适用于：气虚感冒、气虚发热、内脏下垂、久泻脱肛。

>  易错：气虚发热**忌**用寒凉直折，越清越虚。

### 2_3 培土生金 —— 从脾胃治肺的桥梁

**参苓白术散**健脾渗湿之外，桔梗载药上行、兼保肺，是"培土生金"的典范。
适用于：肺脾气阴耗伤之久咳、肺痨缓解期。

### 2_4 通因通用 / 塞因塞用 —— 反治法的两个经典场景

- **大承气汤**治热结旁流（通因通用）—— 表面下利，实为热结旁流，峻下热结
- **脾虚腹胀用健脾法**（塞因塞用）—— 真虚假实之腹胀

### 2_5 治痰先治气，治风先治血

- **二陈汤**用橘红理气，杜绝生痰之源
- **参苏饮**用陈皮、木香、枳壳，理气化痰兼顾
- **大秦艽汤、消风散、独活寄生汤**均配伍当归、地黄、芍药、川芎等养血药

>  这两条是内科选方的"隐性坐标轴"：看到痰证先想气，看到风证先想血。

### 2_6 分经论治与去性取用

- **九味羌活汤**：细辛、白芷、川芎、羌活、苍术构成"分经论治"基本结构
- **银翘散**：荆芥穗、淡豆豉虽辛温，配入辛凉方中增强透表，是"去性取用"

## 板块3 · 内科常见病证 · 辨证选方闭环

下面把索引中的方剂放回内科临床场景，每条都形成「主症 → 证型 → 治法 → 选方 → 鉴别/加减」的完整链条。

### 3_1  肺系病证

#### 3_1_1 感冒

| 证型 | 主症抓手 | 治法 | 首选方 | 鉴别要点 |
| --- | --- | --- | --- | --- |
| 风寒束表 | 恶寒重、无汗、流清涕 | 辛温解表 | **荆防达表汤 / 荆防败毒散** | 后方兼祛湿，适于时行感冒风寒夹湿 |
| 风热犯表 | 发热重、咽痛、涕黄 | 辛凉解表 | **银翘散 / 葱豉桔梗汤** | 银翘散清热解毒力强；葱豉桔梗汤重在清宣 |
| 暑湿伤表 | 身热汗少、头重肢困、胸闷 | 清暑祛湿 | **新加香薷饮** | 夏月专用 |
| 气虚感冒 | 气短、脉弱、恶寒发热 | 益气解表 | **参苏饮** | 化痰与理气兼顾，寓"治痰先治气" |
| 阴虚感冒 | 头痛身热、微恶风寒、汗少、舌红 | 滋阴解表 | **加减葳蕤汤** | 体虚感冒，咽干口燥 |

#### 3_1_2 咳嗽

- **风寒袭肺** → 三拗汤、止嗽散（前方宣肺散寒为主，后方疏风润肺，用于迁延不愈）
- **风热犯肺** → 桑菊饮（辛凉轻剂，杏仁苦降+桔梗辛散，宣降肺气）
- **风燥伤肺** → 桑杏汤（温燥）；杏苏散（凉燥）
- **痰湿蕴肺** → 二陈平胃散合三子养亲汤（前者重点在胃，痰多脘痞；后者重点在肺，痰涌气急）
- **痰热郁肺** → 清金化痰汤
- **肝火犯肺** → 黛蛤散合加减泻白散
- **肺阴亏耗** → 沙参麦冬汤

#### 3_1_3 哮病 / 喘证

- **冷哮** → 射干麻黄汤、小青龙汤（前者长于降逆平哮，表证不著；后者解表散寒力强，表寒里饮）
- **热哮** → 定喘汤、越婢加半夏汤
- **虚哮** → 平喘固本汤
- **肺肾两虚** → 生脉地黄汤合金水六君煎
- **表寒肺热喘** → 麻杏石甘汤
- **痰热郁肺喘** → 桑白皮汤
- **肾虚不纳** → 金匮肾气丸合参蛤散（前者偏温阳，后者长于益气，喘重势急用参蛤散）

#### 3_1_4 肺痈（分期选方）

1. 初期 → 银翘散
2. 成痈期 → 千金苇茎汤合如金解毒散
3. 溃脓期 → 加味桔梗汤
4. 恢复期 → 沙参清肺汤或桔梗杏仁煎

## 板块4 · 方证对应的"抓手"：抓主证而非病名

经方派的核心心法：**辨症精细与方剂特性高度契合，而非简单病名对应**。

几条最实用的"方证抓手"：

- **桂枝汤** → 发热恶风、汗出、脉浮缓（太阳中风）
- **麻黄汤** → 恶寒无汗、发热身痛、脉浮紧（太阳伤寒）
- **白虎汤** → 高热大汗、口渴喜冷饮、脉洪大（阳明经热，**无便秘**）
- **大承气汤** → 潮热谵语、腹满痛拒按、便秘（阳明腑实，**痞满燥实**）
- **小柴胡汤** → 寒热往来、胸胁苦满、口苦咽干（少阳枢机不利）
- **理中汤** → 腹满时痛、腹泻清稀、手足不温（太阴虚寒）
- **四逆汤** → 四肢厥冷、下利清谷、脉微细（少阴阳衰）
- **乌梅丸** → 消渴、气上撞心、饥不欲食（厥阴寒热错杂）

>  临床警句：**抓主证，不抓病名**。同样是"头痛"，风寒用川芎茶调散，肝阳上亢用天麻钩藤饮，瘀血用通窍活血汤——病名相同，方若差之毫厘，效则谬以千里。

### 5_4 模块 D：多方合用治法总结（考试高频）

- **五积散**：汗、温、消、补四法同施，治寒、湿、气、血、痰五积
- **温经汤**：温、清、消、补四法并用，兼顾寒、热、瘀、虚
- **清燥救肺汤**：宣、润、清、降、补五法并用
- **防风通圣散**：表里气血三焦通治，汗、下、清、利并行
- **三仁汤**：宣上、畅中、渗下，分消三焦湿热

### 5_5 模块 E：治则治法警句

- **壮水之主，以制阳光** → 六味地黄丸
- **益火之源，以消阴翳** → 肾气丸
- **治上焦如羽，非轻莫举** → 银翘散
- **治痰先治气，气顺则痰消**
- **治风先治血，血行风自灭**
- **急则治其标，缓则治其本**
- **塞因塞用**（治真虚假实）；**通因通用**（治真实假虚）

## 板块6 · 读书法建议：把索引"用活"的三步

1. **第一步 · 挂层**：每遇到一个方，先判断它属于基础方 / 代表方 / 常用方的哪一层，找出它的"方根"。
2. **第二步 · 抓证**：背方不背方歌背"抓手"——这个方对应的 2-3 个不可替代的主症是什么？
3. **第三步 · 串联**：把基础方 → 代表方 → 常用方串成一条"治法演进链"。例如：
    - 四君子汤（补气基础）→ 六君子汤（+化痰）→ 香砂六君子汤（+行气）
    - 二陈汤（燥湿化痰基础）→ 温胆汤（+清热）→ 黄连温胆汤（+泻火）

>  这种"方根树"的记忆法，比单纯背方剂组成效率高 3 倍以上，且不易混淆。

## 板块9 · 案例拆解：从方名倒推病的一次误选

（虚构教学案例，不对应真实人物）一位中年男性胃脘胀满、食后加重，自学者翻开索引，看到"保和丸"三字下写着"食积"，便照方抓药。两周不效，胀满反增，且添乏力、便溏。

问题出在顺序：他先看方名，再找病名，最后才想起问证。若按索引的正确用法，第一步该是定证型——胀满而喜按、食少便溏、舌淡，属脾虚不运，食积只是结果；此时该查的是健脾消导一类，而非单纯消食。

**落点**：索引是"证型→方"的单向检索表，不是"症状→方名"的联想词典。倒着用，越查越偏。
