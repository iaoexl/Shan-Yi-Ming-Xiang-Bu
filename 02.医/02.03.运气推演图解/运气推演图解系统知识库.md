# 运气推演图解系统知识库

## README · 导览

> 本库以《玄珠密语》《元和纪用经》《运气易览》三书读书笔记为主、参校书籍原文与参考知识库，将"运气推演"的图表化方法、逐年推步、脉应气、天符岁会与纪年用药，重组成一套可手算、可填图、可复盘的图解知识系统。它不追求逐本罗列，而是按主题把三书打散、互为注脚，使读者先有地图、再钻地形。

### README_1 三书角色速览

- **《玄珠密语》（秘）**：题托唐代王冰，为七篇之后的"第一层发挥"。重心在把标准推演落为可上手的"脉应气""运藏相应""天符岁会细辨"，但传本杂、多占候附会，须分层看待。其价值在"方法"而非"断言"。
- **《元和纪用经》（用）**：唐代运气方学先声，主张"医历合一"。以"纪"（推算）与"用"（针药）二字为眼目，把六十年运气翻译成可排进日历的针药宜忌，并以"上中下"三元结构给出逐年司天定味与宜用之品。
- **《运气易览》（图）**：明代汪机所辑三卷通俗图解本。以"运气诸图""甲子逐年运气表"把七篇算法可视化，并附"愚按"点明哪些宜活看，是入门运气推演最宜先读的一本。

### README_3 几种进入方式

1. **图解入门式**：先读板块2、板块3、板块4，照图把任意一年干支推一遍，建立"先图后文"的手感，再回头看板块1的源流定位。
2. **问题驱动式**：带着"某年司天在泉怎么排、客主加临怎么填"去板块3、板块4查流程与示例，缺哪步补哪步。
3. **分层研读式**：从板块5、板块6入手，先把《玄珠密语》的"可验/存疑/附会"三档纪律立住，再用板块9的研判框架读其余二书。
4. **应用落式**：从板块7的纪年用药与板块9的个人逐年对照档案做起，把推算结果排进自己的日历与宜避清单。

### README_4 心法

1. **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉皆可逐字复核，但对具体年份气候与疫病的"预测"属传统经验范畴，只能当倾向假设，须用当年实际气象物候校正。
2. **图是地图，不是地形**：《运气易览》之"图"是把七篇原理画出来，权威在上游七篇；会填图不等于已穷其理，结论仍须综合活看，不可执一。
3. **方法可用，断言待验**：托名秘本之可贵在"怎么把气挂到脉上、藏上"，不在"某运必主某病"；凡直断先视为"原文所述、待验"。

### README_5 易被忽略的前提

1. **运气落在"医"不在"命"**：它看的是"那一年天地之气偏哪一边、人易得哪一类病"，不涉个人吉凶祸福；一旦滑向个人命理，推演便失去可讨论的基础。
2. **太过不及只是全年基调**：实际气化还要看司天在泉、主客加临与主客气的交织，单凭岁运一端下断语是常见误用。
3. **传本与校勘差异**：《玄珠密语》传本繁简悬殊，《运气易览》图版漫漶会直接影响推演，读前须记清所用何本、卷数，遇图缺宁参考通行本补全，不凭空猜测。

## 板块0 · 学习路径和建议

### 0_1 学习路径（分阶段）

#### 0_1_1 阅读顺序

第1步，先立"图解"底座：读《运气易览》的运气诸图与甲子逐年表，把"天干化运、地支司天、客主加临"的版式看熟，再读汪机"愚按"，建立先图后文的秩序。

第2步，进"发挥"层：读《玄珠密语》的脉应气、运藏相应、天符岁会细辨，重点体会它怎样把七篇框架挂到脉上与藏上，同时用"分层阅读"纪律隔离占候附会。

第3步，落到"施用"层：读《元和纪用经》的纪年与针药、司天定味，把前两步推得的格局翻译回日历与宜避清单。

第4步，做完整推演：自取一真实干支年，走完板块4的推演 SOP，再与甲子表、脉气对照、纪年宜避三项互相印证，形成可累积的个人档案。

#### 0_1_2 前置基础

「1」七篇大论的岁运、主客运气、司天在泉概念，是读懂三书"纪"的前提，可先温习《素问》运气七篇，免得在推算环节卡壳。

「2」基本干支与六十甲子：至少能背十天干、十二地支及其阴阳，明白两两相配成一轮循环，这是进入一切运气推演的门槛。

「3」基本脉法与藏象常识（浮沉迟数弦缓滑涩、寸关尺、五脏配五行），便于理解《玄珠密语》"脉应气""运藏相应"的可验部分。

#### 0_1_3 重点条目

"纪用"二字是《元和纪用经》的眼目：纪为推算、用为施行，二者相须。"脉应气"是《玄珠密语》的眼目：把无形之"气"转成可摸可记之"脉"。"客主加临"是《运气易览》的试金石：能否填对六步加临图，是是否读懂图解本的标志。三者分别对应"用、秘、图"三种读法，宜并观而不偏废。

### 0_2 使用建议与边界声明

#### 0_2_1 读法纪律

以"图"为纲、以"按语"为眼，把《运气易览》当作七篇的带批注说明书而非独立体系。读《玄珠密语》边读边给每条打"可验 / 存疑 / 附会"三档，三栏分开、互不污染。读《元和纪用经》重在"能够排进自己的日历去试"，而不在熟读条文、背诵歌诀，每读一条即自问"我今年处在哪一运、哪一气，这条于我何用"。

#### 0_2_2 边界声明

本知识库为中医运气学文献与文化整理，不构成现代医学诊断、治疗或用药建议；运气推演与养生须在合格中医师指导下参考，切勿据此自行诊断、用药或施针；急重症请及时就医。两条具体边界先立住：

- **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉都可逐字复核，但它在具体年份气候与疫病上的"预测"属传统经验范畴，现代统计验证结果并不一致，只能当倾向假设，须用当年实际气象物候校正。
- **不可替代诊疗**：凡涉用药、针刺与防疫措施，一律以正规医疗与公共卫生指引为准；本库所引"某气主某病""某运主某藏"皆传统主张，只作学习与对照。

## 板块1 · 运气推演图解总论

### 1_1 三书分工：秘 · 用 · 图

三书虽同出七篇框架，却在"怎么让运气落地"上各取一角：

- **玄珠重"秘"**：把七篇口诀化、把推演挂到脉与藏上，是最早的"临床化翻译"，但裹着秘传口吻与占候杂质。
- **纪用重"用"**：最早提出"医历合一"的日程化，把运气翻译成可排日历的针药宜忌，是运气方学的先声。
- **易览重"图"**：把七篇算式画成图、列成甲子表，并加按语纠偏，是最宜入门的图解阶梯。

四者（玄珠、纪用、圣济、易览）分别从原理幽深、用方结合、官方集成、图解通俗不同角度发力，而《运气易览》最宜入门，其短处恰在"图"字——易查却不自动带来原理深度，需自觉回到七篇补足。

### 1_2 图解的核心价值

七篇大论把运气框架讲得周全，却"只搭台、少唱戏"——怎么落到脉上、藏上、逐年对照上，语焉不详。《玄珠密语》替这台子唱戏，《元和纪用经》替它排日程，《运气易览》替它画地图。图解的意义在于把隐性推导显性化：原本要在脑中绕几圈的客主加临，一旦落到六步表格，冲突与顺承便一目了然；原本抽象的"气"，一旦接回节气月令，便有了时间坐标，"择时"二字才落到可查的日程。

### 1_3 源流坐标：七篇 → 玄珠 → 纪用 → 易览

把三书放回运气学史链条：上接《素问》运气七篇这座框架之塔（王冰补注为关键节点），中经《玄珠密语》的口诀化发挥与《元和纪用经》的针药时令落地，下启宋代《圣济总录》的官方运气方集成，再经明代《运气易览》图表通俗化，终由明清《运气商》《运气辩》对机械套用展开批判。理解这条"经典 → 密语 → 纪用 → 方 → 图 → 商"的链，便知三书贵在"开创其法"而非"完备其文"，读时宜取大义、不必求全。

### 1_4 四大误区与边界前提

1. **把运气当"中医算命"**：运气的落点是气候与发病的趋势提示，不是个人吉凶祸福；一旦把年干支当成个人命运密码，后续推演会滑向不可验证的方向。
2. **机械套用某年某气**：同一甲子年份南北地域、海拔、微气候差异巨大，原典本身也强调不可拘泥数字，须以当年实际气象物候校正；格局是"倾向假设"而非必然结论。
3. **只背表不推演**：会背口诀不算会，能对着任意年干支独立推一遍、再核对一遍，才算真正掌握；规则的复用能力比记忆本身更重要。
4. **把附会当真理或把可验一并丢弃**：托名秘本的占候灾异与可验算法常混在一起，须分层剥离，既不奉占候为推演真理，也不因托名而丢掉脉应气这类可验观察。

## 板块2 · 基础算具：干支甲子与口诀图

### 2_1 天干化五运口诀

岁运由年干决定，歌诀可压缩为一表（阳干为太过、阴干为不及）：

```
天干化五运（岁运）：
  甲己 -> 土   乙庚 -> 金   丙辛 -> 水
  丁壬 -> 木   戊癸 -> 火
  阳干(甲丙戊庚壬)为太过，阴干(乙丁己辛癸)为不及
```

白话释义：岁运即"当年为主的那一行气"，阳干之年该行本气有余（太过），阴干之年本气不足（不及）。两张口诀（天干化运、地支司天）覆盖了年度推演一半的信息量，是性价比最高的一周基本功。

### 2_2 地支司天在泉口诀

客气之大体由年支决定，司天统上半年、在泉统下半年：

```
地支司天（简括）：
  子午 -> 少阴君火司天，阳明燥金在泉
  丑未 -> 太阴湿土司天，太阳寒水在泉
  寅申 -> 少阳相火司天，厥阴风木在泉
  卯酉 -> 阳明燥金司天，少阴君火在泉
  辰戌 -> 太阳寒水司天，太阴湿土在泉
  巳亥 -> 厥阴风木司天，少阳相火在泉
```

白话释义：年支定"司天"何气行令于上、统三之气以降的上半年；其对面之"在泉"行令于下、统终之气以降的下半年。这是排客气六步的锚点。

### 2_3 六十甲子与阴阳配对

天干十、地支十二，天干每转六轮（6×10=60）、地支每转五轮（5×12=60）重新重合，乃六十甲子循环之根。配对合法性判定：

```
天干阴阳：甲丙戊庚壬为阳，乙丁己辛癸为阴（序号奇为阳、偶为阴）
地支阴阳：子寅辰午申戌为阳，丑卯巳未酉亥为阴
配对法则：奇配奇、偶配偶——如"甲子""乙丑"合法，"甲丑"（阳干配阴支）不合法
```

记忆窍门：每旬十天、逢癸换旬，六十组自然分六旬；熟练后不必背全表，给出干支即能推断其在六十甲子中的大致位置与阴阳。

### 2_4 主气六步次序歌诀

主气年年固定，显"常"，是客气叠加比对之底图：

```
主气六步（由初气到终气，固定不变）：
  初气 风木 → 二气 君火 → 三气 相火 → 四气 湿土 → 五气 燥金 → 终气 寒水
```

白话释义：主气依五行相生与三阴三阳常序排定，象征一年气候的常轨；客气依岁支而变、显"变"，二者相加才构成某年实际的气候倾向。

## 板块3 · 主客运气与客气司天在泉推算图

### 3_1 岁运太过不及

```
年干 -> 天干化运得"岁运五行"
     -> 阳干则"太过"（本气有余、本藏实而乘其所胜）
     -> 阴干则"不及"（本气不足、所不胜乘侮而乱）
例：甲（阳）己化土 -> 土运；甲为阳 -> 土运太过
    乙（阴）庚化金 -> 金运；乙为阴 -> 金运不及
```

白话释义：太过者本藏气实，如木运太过则肝实而脾（所胜）受克；不及者本藏气虚，如土运不及则脾虚而风木（所不胜）乘之。掌握此组术语，方能读懂"某运太过/不及—某藏虚/实"的大量条目；但乘侮只是倾向，临床仍需结合体质、地域、脉证。

### 3_2 司天在泉定位

```
取年支 -> 查 2_2 口诀得：
     司天 = 上半年行令之气（定三之气）
     在泉 = 下半年行令之气（定终之气）
例：子年 -> 少阴君火司天、阳明燥金在泉
```

白话释义：司天、在泉是客气六步的两枚锚。司天既主上半年气化，传统认为其脉象多应于寸部；在泉主下半年气化，多应于尺部，为"脉应气"提供一层空间化的落点。

### 3_3 客主加临填图

主气六步固定，客气六步由司天、在泉推出：司天定三之气、在泉定终之气，其余按三阴三阳由阴入阳之常序顺推补满六步。以子午年为例填出：

```
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： 太阳寒水 厥阴风木 少阴君火 太阴湿土 少阳相火 阳明燥金
       （司天=少阴君火定三气，在泉=阳明燥金定终气，余顺推）
标注： 主客同气=相得；主客异气=相争(易偏)；相争处宜回看"愚按"
```

填图口诀（逆推其余四步）：以司天为三气、在泉为终气为锚，按"厥阴→少阴→太阴→少阳→阳明→太阳"的客气常序，由三气向前补初、二气，由终气向前补四、五气。

### 3_4 相得相争与活看

```
主客同气  -> 相得（气化协调，偏性小）
主客异气  -> 相争（气机交争，易见偏盛偏衰，须活看）
```

白话释义：汪机"愚按"反复提醒"大率如此，不可执一"——相争之年正该活看，不能见相争就断为灾。图能帮你查，但查到的不是铁律，而是参考模型；地域、时差、人体差异都会让同一年甲子呈现不同结果。

## 板块4 · 年度推演流程图解（完整 SOP）

### 4_1 五步推演流程

下图为任意干支年走通一次年度格局的总流程，把板块2、板块3 的零件串成一面完整的墙：

```
取年干支
   │
   ├─ 第1步 查岁运：天干化运 + 阳干太过/阴干不及
   │
   ├─ 第2步 查司天在泉：地支化气（定三气、终气）
   │
   ├─ 第3步 排客气六步：以司天在泉为锚，顺三阴三阳补满六步
   │
   ├─ 第4步 客主加临比对：标"相得/相争"，回查"愚按"活看处
   │
   └─ 第5步 得本年气候倾向(常+变) -> 写推演理由 -> 对照实际气候 -> 记偏差复盘
```

### 4_2 甲子年完整示例

下面以甲子年走一遍流程（仅以干支演示算法，不写具体公元年号）：

```
第1步 取年干支：甲 子
第2步 查岁运：甲己化土，甲为阳干 -> 土运太过
第3步 查司天在泉：子午少阴君火司天 -> 司天=少阴君火
                          在泉=阳明燥金
第4步 排客气六步：以司天(三气)定少阴君火、在泉(终气)定阳明燥金为锚，
        按三阴三阳常序逆推其余四气：
        初气=太阳寒水 二气=厥阴风木 三气=少阴君火(司天位)
        四气=太阴湿土 五气=少阳相火 终气=阳明燥金(在泉位)
第5步 与主气加临比对：上半年君火司天与主气相争(三气主相火、客君火，近同),
        其余步逐一标相得/相争，回查"愚按"。
结论：土运太过之年，传统认为湿气偏盛，宜结合司天在泉综合判断，
      不可单看岁运一端。
```

### 4_3 逐年表查法

拿到任一年干支，按下列流程即可在甲子表中查得本年格局（甲子逐年运气表是手算对照的金标准，推得对不对翻到对应干支那一栏便知）：

```
取年干支 -> 查岁运(天干化运,太过/不及)
        -> 查司天在泉(地支化气)
        -> 查客主加临(填入 3_3 六步图)
        -> 得本年气候倾向(常+变) -> 与甲子表对应栏核对
```

### 4_4 复盘校正循环

推演不是"查表得结论"的静态知识，而是"按规则推演、再按现实校正"的动态方法：

```
排一张盘 ──► 写一段推演理由 ──► 对照实际气候 ──► 记一条偏差 ──┐
   ▲                                                              │
   └────────────────────── 下周重排优先修正此类错误 ◄──────────┘
```

实操节奏：每周挑一个年干支（虚拟年份同样有效），排出岁运、司天在泉、主客；写三到五句推演理由说明"为何这样判"；对照该年真实气候与物候（气象记录、地方志），找出至少一条与推演不符之处；把偏差写进错题本。写下来的错下次能改，只在脑子里过的错下次照错。

> 立即可做：取你出生的年干支，走完 4_1 五步，把结果抄进 3_3 的六步图，再与《运气易览》甲子表核对一次。

## 板块5 · 玄珠密语：脉应气与运藏相应图

### 5_1 运藏对应表

五运直连五藏，岁运太过则本藏实、不及则本藏虚，乘侮随之：

```
五运 → 五藏 对应表（太过则本藏实、不及则本藏虚，乘侮随之）
------------------------------------------------------------
岁运   天干    太过(太X·本藏实)        不及(少X·本藏虚)
木     丁壬    肝实、风盛、脾受克        肝虚、燥金乘之
火     戊癸    心实、热盛、肺受克        心虚、寒水乘之
土     甲己    脾实、湿盛、肾受克        脾虚、风木乘之
金     乙庚    肺实、燥盛、肝受克        肺虚、火热乘之
水     丙辛    肾实、寒盛、心受克        肾虚、湿土乘之
------------------------------------------------------------
用法：先由年干定岁运与太过/不及，再查本行得"本藏虚实"，
      并留意"所胜受克、所不胜乘之"的继发态势。
```

白话释义："运藏相应"是运气与藏象病证的直连通路。须守住"倾向"二字：原文常以"某运必主某藏病"的直断口吻，我们当还原为"某运偏盛，相应藏易受牵动"，避免机械套用到具体病人。

### 5_2 脉气对照图（逐年实测模板）

把无形之"气"转成可摸可记之"脉"，是《玄珠密语》最值得逐年实测的部分：

```
年份：____    岁运：____(太过/不及)    司天：____    在泉：____
------------------------------------------------------------
书中预言脉象：____（如：风木司天，脉当弦；在泉寒水，冬脉当沉）
------------------------------------------------------------
当年实测（分四季填）：
  春：____    夏：____    秋：____    冬：____
------------------------------------------------------------
吻合度：  □ 全符   □ 部分   □ 不符
若不符： 回查"运之太少"或"气之标本"，并记录可能的
         地域、体质干扰因素，不作硬判。
```

白话释义："应"是倾向性而非必然性。风木之气偏盛则脉多见弦象，只是多见之倾向，须留出个体差异与地域气候的余地；临床仍须由合格医师据证施行，不可据文自行针治。

### 5_3 司天在泉与脉象部位

```
司天（上半年气化） -> 多应于寸部
在泉（下半年气化） -> 多应于尺部
```

白话释义：本书把时间（上下半年）与空间（寸尺部位）叠进脉诊，是相对七篇的新加细处。验证时须分上下半年分别记录，方能看清"司天—在泉"是否真有部位差异。

### 5_4 分层阅读三档

托名秘本最忌"全信"或"全否"两端。凡读一条，先归位再判断：

```
【可验算法层】                【托名附会层】
 脉应气（逐年实测）            占候祥异（星变/物异/灾言）
 运藏相应（太过不及虚实）      吉凶硬断言（某运必主某灾）
 天符岁会格局判定             "秘授不可疑"的神秘包装
------------------------------------------------------------
读法：可验层 -> 纳入对照、逐年验证
      附会层 -> 仅作文献现象存档，不作推算与预测依据
      介于其间者单开"存疑层"，标"待对勘"，三栏分开、互不污染。
```

> 立即可做：取《玄珠密语》任意一条"某运必某病"的直断，按上图归到三档之一并写理由。

## 板块6 · 天符岁会格局细辨图

### 6_1 五类特殊格局判定

七篇已列天符、岁会、同天符、同岁会、太乙天符诸格，《玄珠密语》在其上补列更多年份组合与气候病候倾向。格局判定本身（五行相合关系）来自七篇、可验可核：

```
格局      判定条件（五行相合）              示例思路
天符      岁运干 与 司天支 五行同          岁运土、司天湿土
岁会      岁运 与 岁支 五行同              岁运木、年支寅卯

太乙天符  岁运、司天、岁支 三者五行皆同    气专而盛，重点防范
```

### 6_2 太乙天符重点防范

太乙天符为岁运、司天、岁支三者五行皆同，气化专一而盛，传统视为重点防范之年。其"重点防范"是格局层面的倾向提示，不等于必然多灾，仍须结合当年实际气候与个体体质活看。

### 6_3 细辨加料的甄别

```
细辨加料（本书所补，须甄别）：
  · 同格之年附加的"主某灾某病"断言 -> 多属附会层，存疑存档
  · 格局本身（五行相合判定）        -> 属可验层，按年核查
```

白话释义：天符岁会细辨把七篇偏原理的格局，转译成"某年某格、易见某气某病"的实用查表，方便按年检索、按格备防；但细化的同时夹带了更多托名附益断言。格局可验、加料待验，是读此部分的基本分寸。

## 板块7 · 纪年用药与三元定味图

### 7_1 三元结构：上 · 中 · 下

《元和纪用经》以"上中下"三元对应"司天 · 岁运 · 在泉"，把一年气化切成三层可操作的用药框架。原典句式如：

> "己巳 己亥：上厥陰辛涼 中土運甘和 下少陽咸寒。"

白话释义："上"指司天之气所宜之味，"中"指当年岁运所宜之和味，"下"指在泉之气所宜之味。原典又强调"必先胃主，必先榮衛"——胃为生之原、荣卫为气之主，气化推算与针药施用都须以顾护脾胃荣卫为前提，不知胃主荣卫则不可语奉生之宜。

### 7_2 六气司天治味总纲

原典对六气司天各立治味，是"司天定味"的枢纽（以咸酸苦辛甘调其上、以对应味调其下）：

```
厥陰風木：辛涼為治（以辛調上，以咸調下）
少陰君火：咸寒為治（以咸調上，以酸調下）
太陰濕土：苦熱為治（苦溫兼化，上下調和）
少陽相火：咸寒為治（以咸調上，以辛調下）
陽明燥金：苦溫為治（以苦調上，以咸調下）
太陽寒水：苦熱為治（以苦治上，以甘兼苦治下）
```

白话释义：它不另立一套药性，而是借既有的五味阴阳，按当年气化偏性做加减取舍，使同一类药在不同年份各有当用与当避。如太阴湿土司天之年，以苦熱平淫濕、宜散邪濕，正是运气方剂学"逐年据气立方"的雏形。

### 7_3 各司天宜用之品举例

原典于每一司天下列"皆歲主所宜，隨證命方"之品，并定君臣佐使："倍多主病者為君，君以定名；倍少者佐君為臣，不倍者應臣為使。"略举数端：

- **厥陰司天**（風火同德）：宜車前子、雞肶胵、地骨皮、澤瀉、丹參、牡丹、戎鹽之類，寒補者倍之。
- **少陰司天**（寒交暑、熱加燥）：宜地黃、白芍藥、羚羊角、白僵蠶、羌活、獨活、決明子之類，咸寒者倍之。
- **太陰司天**（陰專其政，平淫濕）：宜術、麻黃、附子、牡荊實、熟艾葉、獨活、柴胡、芍藥、乾姜、桂之類，苦熱者倍之。
- **少陽司天**（風熱參布）：宜羚羊角、石膏、白薇、車前子、澤瀉、白僵蠶、旋覆花、牡蠣、人參之類，咸寒者倍之。
- **陽明司天**（陽專其令）：宜知母、桑根白皮、槐實、竹葉、升麻、柴胡、黃芩、芍藥、天門冬、菊花之類，溫者倍之。
- **太陽司天**（寒臨太虛）：宜萆薢、蛇床子、繼斷、澤蘭、艾葉、何首烏、術、遠志、附子、當歸、姜桂之類，苦熱者倍之。

白话释义：所列皆为"岁主所宜"的候选之品，须"隨證命方"而非刻板套用；"倍之"是按当年气运偏性调整用量轻重的古法。

### 7_4 客主胜复与用寒远寒

原典明文："六氣用藥……或逆、或從……用寒遠寒，寒無犯寒也；用熱遠熱，熱無犯熱也。從者養和，逆者生病。"又立客主相胜之则：

```
主勝為逆，客勝為從；
客勝則瀉客補主，主勝則瀉主補客；
主客之部各六十一，居無常所，隨歲遷移。
```

白话释义：客气胜则泻客而补主、从其为顺；主气胜则泻主而补客。又有"用寒远寒、用热远热"——当令之气属寒则用药避寒、属热则避热，以免以水济水、以火助火。原典复论"从本、从标、从中"：少阳太阴从本，少阴太阳从本从标，厥阴阳明从乎中，是治病气化枢要。

### 7_5 用药自检

> 立即可做：取本年干支，按 7_1 三元结构填出"上/中/下"三味，再据 7_2 总纲核对该司天治味，列一张"宜用之品 / 当避之性"速查卡，贴于药箱旁（只记避什么、不记治什么，避免与医师处方混淆）。

## 板块9 · 分层研判与研读路径

### 9_1 三书研读次序

推荐一条"由图入、由秘辨、由用落"的路线：先以《运气易览》打图（最通俗、最少占候），再以《玄珠密语》看发挥（立分层纪律），后以《元和纪用经》落实针药时令（把格局翻成日历宜避）；全程上接《素问》七篇以为原理总根。读此数书，正好与"秘—用—方—图—商"的完整光谱相合，运气学说便不再是孤本秘谈，而是一部有源有流、有立有破的学问。

### 9_2 分层研判纪律

1. **可验 / 存疑 / 附会三档隔离**：脉应气、运藏相应、天符岁会格局属可验层，纳入逐年验证；占候祥异、吉凶硬断言属附会层，仅作文献现象存档；弱关联的"疑似经验"单开存疑层，标待对勘。
2. **算得准的是规则，算不准的是气候**：推演规则可精确复现，但对气候与疫病的预测效力属传统经验范畴，只能当倾向假设。
3. **不谈个人吉凶**：运气看"那年天地之气偏哪边、人易得哪类病"，不涉个人祸福；滑向命理便失去可讨论基础。
4. **不替代诊疗与公卫指引**：凡涉用药、针刺、防疫，以正规医疗与公共卫生指引为准，运气仅作"因时制宜"的辅助维度。

### 9_3 个人逐年对照档案法

把推算排进日常记录，运气才真正活起来。四类轻量场景可择一或并用，核心是"每年一表、每季一核"：

1. **日历标注**：年初标岁运、司天在泉，每月记一体感关键词，半年回看自身节律与年气是否合拍。
2. **针药对照卡**：把"某气→宜某味、避某味"列成速查卡贴厨房或药箱旁，只记避什么不记治什么。
3. **禁忌清单**：按"运太过之年忌助本气、司天所胜之年忌逆其性"汇总"避什么"，边界最清楚。
4. **季度复盘**：每季末逐栏标"吻合/不符/存疑"，年终汇总吻合度，作为来年读法调整依据。
