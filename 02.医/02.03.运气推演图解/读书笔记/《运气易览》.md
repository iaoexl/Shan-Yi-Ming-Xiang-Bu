# 《运气易览》

## README · 导览

### README_1 书目速览

- **书目信息**：明代汪机（号石山）所辑，三卷，又名《运气易览》。书名"易览"取"容易阅览"之意，是运气学史上最著名的"图表化、通俗化"入门读本，常被后学作为接触五运六气的第一本实操手册。
- **成书背景**：运气七篇古奥难读，托名之作又杂出纷纭，明代医界亟需一部能把算式"画出来、列成表"的阶梯书。汪机遂删繁就简、绘图立表，让学医者不必深通训诂也能照图推演，是运气"教科书化"的关键一步。
- **核心主旨**：以大量图表（运气诸图、甲子逐年运气表、客主加临图）把七篇算法"可视化"，并附"愚按"按语，点明哪些格局可验、哪些宜活看，使复杂的气化推演变得可查、可对、可练。
- **与五运六气关系**：它处在七篇原著与后世学习者之间，是一座"翻译器"与"带批注的说明书"，今天多数人初学运气实际都经由这类书间接理解七篇，而非直啃古文。
- **阅读价值**：最适合作为"第一本运气实操手册"；其图表法天然便于做笔记、绘图与自测，也最利于在脑中建立"先图后文"的学习秩序。

## 板块0 · 学习路径和建议

> 导语：任何一本工具书的读法，都应由"怎么用"反推"怎么读"。《运气易览》既然定位为图表化上手本，最讲效率的读法便是以图领文、以按语点睛，先搭框架后填细节，再借手算把别人的表变成自己的手感。

---

### 0_1 学习路径

#### 0_1_1 阅读顺序

第1步，先翻全书图表。运气类书最忌一上来就逐句啃文言，而《易览》的图本身就是浓缩的算法，看图识框架比读正文快得多，先把"运气诸图"和"甲子表"的版式看熟。

第2步，读汪机按语（常标"愚按"）。这些是编者替读者做的"去伪存真"判断，指明哪些格局宜活看、哪些不可执一，是全书最珍贵的部分，宜与正文同等重视甚至优先细读。

第3步，照书中"推运示例"自己手算一遍，再与原表逐格对勘。只有亲手推过一次，才知道图表的每一栏从何而来，也才能把"易看"转化为"真懂"。

#### 0_1_2 前置基础

「1」干支与六十甲子：至少要能背出十天干、十二地支及其阴阳属性，明白六十甲子如何两两相配成一轮循环，这是进入一切运气推演的门槛。

「2」七篇基本术语：天元纪、五运行、至真要等篇的核心名词（岁运、司天、在泉、主客加临）需有粗浅概念，不懂处宜回查同辑的七篇笔记，但不必先求通篇精读。

#### 0_1_3 重点条目

「1」运气诸图：把"五运／六气／客主加临"画成可查之图，是全书骨架，读时宜先认图后读说明。

「2」甲子运气表：六十年逐年速查的"运气年历"，给出每岁岁运、司天在泉、主客等项，是手算练习的最佳对照样本。

「3」汪机"活看"提醒：反复出现的按语，反对机械套用，是防止把工具书当"算命书"的关键护栏。

---

### 0_2 使用建议与边界声明

#### 0_2_1 读法纪律

以"图"为纲、以"按语"为眼，始终遵循先图后文，把本书当作"七篇的带批注说明书"而非另一套独立体系。遇到与原文或他书说法相左处，先查是图版脱落还是编者取舍，再决定取舍，不要凭印象改动。

#### 0_2_2 边界声明

运气可以算，结论却只是倾向。两条边界先立住：

- **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉都可逐字复核，但它对具体年份气候与疫病的"预测"属传统经验范畴，现代统计验证结果并不一致，只能当倾向假设，须用当年实际气象物候校正。
- **不可替代诊疗**：凡涉用药、针刺与防疫措施，一律以正规医疗与公共卫生指引为准；本册的"某气主某病"皆传统主张，只作学习与对照。

## 板块1 · 作者、年代与版本源流

> 导语：一本书的脾性往往由作者的身份与成书处境决定。汪机既是一线临床家，又是文献整理者，这种"临床—文献"的双重眼光，恰好解释了《易览》何以能既通俗又不浮浅。

### 1_1 作者汪机

汪机为明代新安医家，号石山，在明代医林中与诸多名家并峙，以临床功力深厚、又留心典籍整理著称。他留下的著述多带"把难题讲明白"的倾向，《运气易览》正是其"把古奥运气讲清楚"的教科书尝试。与传统注家不同，汪机并不刻意炫博，而是把力气花在"让人会算"上，这使他编的书天然带工具书气质。

### 1_2 成书年代

本书成于明代。彼时运气学已积累千年注本，从王冰补七篇到宋代官修集成，材料极丰却也极杂，初学者往往望而却步。明代医界一方面沿袭运气为科举与临证参考的传统，另一方面又迫切需要一个"能快速上手"的简本，本书即在这种"千年注本亟须通俗化"的语境中应运而生的图解教材。

### 1_3 版本流传

《运气易览》三卷本多见于明代以来的医学丛书中，因通俗实用而翻刻颇多。读此类书有个特殊麻烦：图版是否清晰完整，直接决定能否照图推演，故择本时以校刊精善者为宜，并留意是否有图缺、图倒、墨漫之处。若所得本子图版漫漶，宁可参考通行整理本补全图示，也不要凭空猜测图中栏目。

### 1_4 书名寓意与定位

"易览"二字既是招牌也是承诺：编者自认做的是"降低门槛"的活，而非"另立门户"的活。理解了这一点，便能摆正态度——它是地图而非地形，是索引而非原典，宜拿它入门、不宜拿它独断。这种自觉的工具书定位，恰恰是它流传数百年的根本原因。

## 板块2 · 核心主旨与内容梳理

> 导语：若用一句话概括《易览》的功劳，那就是"把算法画出来"。它几乎不发明新理论，而是把七篇里散落的算式，重组成可查、可填、可练的图与表，并辅以编者按语校正偏差。

### 2_1 图表化：把算法画出来

这是全书最大的贡献。七篇中分散的"天干化运、地支司天、主客加临"等规则，被汪机系统作成系列图，学习者照图推演即可，不必逐字啃古奥文言。图的作用不只是"好看"，更在于把隐性推导显性化：原本要在脑中绕几圈的客主加临，一旦落到六步表格里，冲突与顺承便一目了然。

### 2_2 逐年甲子运气表

本书给出六十年逐年"岁运、司天在泉、主客"的速查表，相当于一本"运气年历"。这张表至今仍是手算练习的最佳对照样本：当你自己推完某年格局，翻表一核便知哪一步出错。它把"六十年一大循环"压缩成可翻页查阅的清单，使运气学第一次真正具备"工具书"的便利。

### 2_3 汪机按语：可验与宜活看

书中"愚按"多处提醒：运气"大率如此，不可执一"。这是早期对"机械运气论"的自觉纠偏——汪机承认格局有常，却也强调地域、时差、人体差异会让同一年甲子呈现不同结果。读本书最该带走的，正是这种"信而不迷"的态度：图能帮你查，但查到的不是铁律，而是参考模型。

### 2_4 通俗化定位

《易览》并不发明新算法，它做的是"转译＋校对"：把七篇的文言算式译成图和表，再用按语校出易错与易偏之处。认清这一点，就能把它当"七篇的带批注说明书"来用，而不是误以为它自成一派。凡遇书中结论，宜记得其上源在七篇，本书只是让上源更易抵达。

### 2_5 内容板块构成

全书以"图—表—按"三段式展开：先列运气诸图定框架，再附甲子逐年表供查检，最后以按语贯穿始终点出活看之处。这种编排本身就是一种教学法——先给骨架，再填血肉，随时提点陷阱，非常符合初学者的认知节奏，也为后世同类入门书立了范式。

## 板块3 · 关键概念与术语体系

> 导语：工欲善其事，先要认得工具的名字。《易览》自有一套围绕"图"与"表"形成的术语，抓住这几个枢纽词，整本书的脉络便握在手里。

### 3_1 运气诸图

指书中把算法可视化的图集，是全书骨架。它把"五运如何化、六气如何司天在泉、主客如何加临"等抽象规则，落实为可照填的栏目与可对照的方位。读图时先认清图分几栏、每栏对应哪项推导，再动手填，方能避免"看着热闹、算时懵懂"。

### 3_2 甲子运气表

即六十年逐年速查表，是手算对照的金标准。每岁固定给出岁运（太过或不及）、司天在泉、主客等项，相当于把六十年气化总格局预先排好。它既是查询工具，也是检验工具：你推得对不对，翻到对应干支那一栏便知。

### 3_3 愚按

汪机按语的标识，书中多处以"愚按"起头，专门标示"可验"或"宜活看"。这是全书的"书眼"，因为图与表只负责"怎么算"，而按语负责"算出来怎么看"。忽略按语，等于只拿到了地图却没听向导的提醒，极易把参考当定论。

### 3_4 易览定位

"易看"二字点明其教科书属性：先图后文、由浅入深、可查可对。它不要求读者先有深厚训诂功力，而是假设读者"想会算"，从而提供一条最短路径。这个定位提醒我们：它的目标是让人"上手"，而非让人"穷理"，二者不可混为一谈。

### 3_5 客主加临

本书反复演练的核心术语，指"主气"与"客气"在一年六步中叠加比对。主气年年固定、显"常"；客气随岁支而变、显"变"，二者相加才构成某年实际的气候倾向。能否填对加临图，是检验是否读懂《易览》的试金石。

## 板块4 · 推演演示（含 ASCII 图）

> 导语：这一板块把前面讲过的"图与表"真正用起来。下面用几张 ASCII 图还原书中的查检逻辑，并以一个具体干支年做完整推演，读者可照此自行替换年份练习。

### 4_1 五运与六气基础歌诀图

书中把天干化运、地支司天编成可诵之诀，便于记诵。其要旨以 ASCII 呈现如下：

```
天干化五运（岁运）：
  甲己 -> 土   乙庚 -> 金   丙辛 -> 水
  丁壬 -> 木   戊癸 -> 火
  阳干(甲丙戊庚壬)为太过，阴干(乙丁己辛癸)为不及

地支司天（简括）：
  子午 -> 少阴君火司天，阳明燥金在泉
  丑未 -> 太阴湿土司天，太阳寒水在泉
  寅申 -> 少阳相火司天，厥阴风木在泉
  卯酉 -> 阳明燥金司天，少阴君火在泉
  辰戌 -> 太阳寒水司天，太阴湿土在泉
  巳亥 -> 厥阴风木司天，少阳相火在泉
```

### 4_2 客主加临填图

主气六步固定，客气六步由司天、在泉推出（司天定三之气，在泉定终之气，其余顺三阴三阳相生推排）。原书图式可改进为如下可填格式：

```
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： ____     ____     ____     ____     ____     ____
(客气由司天在泉推：司天定三气，在泉定终气，余顺推)
标注： 主客同气=相得；主客异气=相争(易偏); 相争处宜回看"愚按"
```

### 4_3 逐年表查法

拿到任一年干支，按下面流程即可在甲子表中查得本年格局：

```
取年干支 -> 查岁运(天干化运,太过/不及)
        -> 查司天在泉(地支化气)
        -> 查客主加临(填入上图六步)
        -> 得本年气候倾向(常+变)
```

### 4_4 完整推演示例（以"甲子年"为教学样本）

下面用甲子年走一遍流程，读者可换任意干支自行演练。注意此处不写具体公元年号，仅以干支演示算法。

```
第1步 取年干支：甲 子
第2步 查岁运：甲己化土，甲为阳干 -> 土运太过
第3步 查司天在泉：子午少阴君火司天 -> 司天=少阴君火
                          在泉=阳明燥金
第4步 排客气六步：以司天(三气)定少阴君火、在泉(终气)定阳明燥金为锚，
        按三阴三阳由阴入阳的常序逆推其余四气：
        初气=太阳寒水 二气=厥阴风木 三气=少阴君火(司天位)
        四气=太阴湿土 五气=少阳相火 终气=阳明燥金(在泉位)
第5步 与主气加临比对，标记相得/相争，回查"愚按"活看之处
结论：土运太过之年，传统认为湿气偏盛，宜结合司天在泉综合判断，
      不可单看岁运一端。
```

此例说明：《易览》的价值不在替你下结论，而在给你一套"填得对、查得清"的流程，结论仍须综合活看。

## 板块5 · 与七篇及他书的承启异同

> 导语：一本入门书的位置，要看它"承接了谁、启发了谁、又与同侪有何不同"。《易览》的独特性，恰恰在它把"图"做到了极致，而这一点要与七篇及其他运气专书对照才显出来。

### 5_1 上承七篇

全书算法皆出《素问》运气七篇，汪机并未另起炉灶，只做"可视化＋按语"两件事。七篇给出原理与格局，本书把原理画成图、把格局列成表，是七篇与后世读者之间的转译层。认清这一层，便不会把《易览》误读为独立理论源，它的权威始终来自上游七篇。

### 5_2 下启普及

作为最通俗的运气读本，它长期是后世学堂与自学者入门的"第一站"。其"活看"按语所体现的审慎态度，也直接影响了后世批判派，例如《运气商》等专论对机械套用的反思，与汪机"不可执一"的精神一脉相承。可以说，没有这类图解阶梯，运气学很难从"专家之学"走向"可传之艺"。

### 5_3 异同要点

历来把七篇推向可学可用的书中，各有侧重：玄珠"秘"、纪用"用"、圣济"方"、易览"图"。四者分别从原理幽深、用方结合、官方集成、图解通俗不同角度发力，而《易览》最宜入门。它的短板也正在"图"字上——易查却不自动带来原理深度，需读者自觉回到七篇补足。

### 5_4 与官修集成的区别

宋代《圣济总录》以官方之力首卷载六十年运气图并附方药，是"方—图"并重的集成；而《易览》是私人医家编的"纯教学本"，重心只在让人会算，不负担方药汇辑。两者都含运气图，但一个是临床资源库，一个是学习脚手架，用途不同，不可互相替代。

## 板块6 · 案例佐证

> 导语：下面这则小故事专用于说明《易览》"图表化查检"的读法。故事紧扣"先图后文、照图填运"的方法，不依赖他书套路，意在让读者体会工具书该怎样用。

（虚构教学案例，不对应真实人物）

阿岚刚接触五运六气，被"客主加临"六个步骤绕得头晕，背了三天仍分不清司天定的是哪一气、在泉又管哪一步。她的老师没有让她继续死记，而是递来一本《运气易览》，翻开那张客主加临图说："你别背，照图来。先把今年的年支告诉我。"

阿岚报出当年的地支，老师教她依书中"地支化气"一栏查司天在泉：司天定三之气，在泉定终之气，其余按三阴三阳顺序顺推。阿岚把六步客气逐一填进图里，再与主气一行对照，发现上半年君火司天与主气相争，那一格明显"打架"。她正要惊慌，老师指了指图旁汪机的"愚按"——原文所述"大率如此，不可执一"，意思是冲突年份正该活看，不能见相争就断为灾。

阿岚忽然松了口气，说："这书像给七篇配了张地图，我以前是直接想钻进地形里，所以迷路。"老师笑答："对，易览就是地图，七篇是地形。先有地图，才走得进地形，还不至于困在半山。"后来阿岚养成了习惯：每学一本新的运气书，都先画一张"它在七篇体系中的位置图"，标清它上承哪篇、下启什么、自己属于图还是方还是秘——这套法子，正是从《易览》学的。

此故事说明：本书最宜作"图解上手本"，核心价值在"先图后文、照图查检"，用熟了，复杂推导也能变成可操作的填表游戏。

## 板块7 · 笔记方法与多场景记录

> 导语：工具书最怕"读过即忘"，而《易览》偏偏最宜用"动手"的方式留下记忆。下面按几种常见学习场景，给出可落地的笔记方法。

### 7_1 描图笔记场景

把书中关键图（客主加临图、甲子表局部）手抄或重绘一遍。绘图的过程本身就是记忆：手画六步栏目时，你被迫想清每一栏的来源与顺序，比单纯看一遍印象深得多。建议用活页纸，留出空白栏位，方便日后填不同年份。

### 7_2 按语摘录场景

专设一页收录"愚按"类活看提醒，作为"防机械套用"的警示栏。每摘一条，用自己的话写一句"它提醒我别怎样"，例如"别因岁运太过就断全年偏盛"。这页日后翻查，比回翻原书更快。

### 7_3 手算自测场景

最扎实的读法，是每年初动手把当年运气完整算一遍，再与《运气易览》书后甲子运气表逐格核对。具体做法：第1步，列出本年干支，先推岁运（天干化运：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火）与太过不及；第2步，定司天在泉（地支寻司天：子午少阴君火、丑未太阴湿土、寅申少阳相火、卯酉阳明燥金、辰戌太阳寒水、巳亥厥阴风木）；第3步，排主气客气并做客主加临；第4步，把四步结果与书中对应那一格对照。凡是算出来和书表不一致的地方，就是你的薄弱点——回头重推一遍，通常能发现是某一步口诀记串了。坚持数年，你会自然积累出一本"逐年对照簿"，既练出了手感，也留下一份可回溯的练习档案，日后翻查某年气化极其方便。

### 7_4 体系定位场景

每学一本他书（玄珠、纪用、圣济、运气商等），都画一张"它在七篇体系中的位置图"，标清其侧重（秘／用／方／图／商）。这种练习训练全局观，避免把任一书当成运气学的全部。

### 7_5 歌诀抄诵场景

《运气易览》里天干化运、地支司天、主气次序等，都有便于记诵的歌诀，把它们单独抄在小卡片上，利用通勤或碎片时间反复诵记，是性价比很高的巩固手段。建议的节奏是：第1步，先背诀——歌诀本质上是推演图的压缩版，把"甲己化土乙庚金"这类句子念熟；第2步，再填图——合上卡片，在空白的运气图里凭记忆把对应内容填回去，填不出的就是没背牢处；第3步，后查表——回到书后甲子表核验，确认自己填的与表一致。这三步"背诀→填图→查表"层层互相加固，记诵效率明显高于孤立地硬背条文。卡片可按"天干卷""地支卷""主气卷"分袋收纳，每月抽测一袋，长期下来基本能做到看到任意干支便脱口报出岁运与司天。

## 板块8 · 实用验证与自测

> 导语：有没有读懂《易览》，不靠感想，靠能不能独立推对。下面给出可立即操作的自我检验流程与题目，建议先动手再对答案。

### 8_1 客主加临自测

```
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： ____     ____     ____     ____     ____     ____
操作：
  第1步 取年支 -> 查司天(定三气)、在泉(定终气)
  第2步 余四步按 厥阴->少阴->太阴->少阳->阳明->太阳 顺推填入
  第3步 填完核对《易览》甲子表，不一致则回查"地支->司天"一步
```

### 8_2 五运速查自测

```
取年干 -> 依"甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火"定岁运
       -> 依阳干太过、阴干不及判盛衰
       -> 与甲子表该年岁运栏对照
例：年干为"丙"，丙辛化水，丙为阳干 -> 水运太过，核对表栏是否一致。
```

### 8_3 自测题

「1」由任意给定年支，推司天在泉，并完整填出客气六步。

「2」列出汪机"活看"提醒的要点，并各写一句你自己的理解。

「3」为什么说《易览》是"七篇的说明书"而非独立体系？请用自己的话说明。

「4」取一个你熟悉的干支年，走完板块4的"逐年表查法"五步，把结果写下来并与甲子表核对。

## 板块9 · 现代意义、研究与延伸阅读

> 导语：一部明代图解教材，今天是否还有价值？答案是肯定的，但价值不在"预测"，而在"教学法"与"批判性态度"两方面，这恰是当代读任何模型都该具备的素养。

### 9_1 现代视角

"可视化教学"在《易览》里已运用得相当成熟：把抽象推导变成可填图表，本质就是今天的"降门槛设计"。其"活看"按语所体现的批判性——承认模型有常亦有变——恰是今天对待任何统计或气象模型都该有的态度。传统认为运气可示气候—疾病的大趋势，但原文所述也反复提醒不可执一，这种平衡立场经得起时间检验。

### 9_2 边界与提醒

图表是简化模型，实际气候与健康的关联复杂得多，受地域、海拔、微气候与个体差异层层影响。宜把《易览》当作学习工具与传统医学参考模型，而非预测吉凶或疾病的工具。近几十年的研究对运气是否具备稳定预测力仍有分歧，因此凡涉推演结论，都应标注"参考模型、勿机械套用"。

### 9_3 延伸阅读

上接《素问·运气七篇大论》为原理总根；平行可读《玄珠密语》（重原理）、《元和纪用经》（重用方）、《圣济总录》（官方集成与运气方）；入门收尾宜读《运气商》与《运气辩》，以补足批判性与适用边界。读此数书，正好与《易览》的"图"形成"秘—用—方—图—商"的完整光谱。

### 9_4 研究线索

若想进一步验证，可沿两条线：一条是"制表练习线"，自绘近若干年的甲子运气格局表，训练推演手感；另一条是"回溯验证线"，把历史疫病或气候异常高发年份与当年运气格局对照，体会"大率如此"在统计上的强弱。两条线都宜保持审慎，把《易览》当作方法入口，而非结论来源。
