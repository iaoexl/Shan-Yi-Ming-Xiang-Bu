# 针灸系统知识库

## README · 导览

> 本知识库以《奇经八脉考》《针灸甲乙经》《针邪密要》《铜人针灸经》《鬼门十三针》五部读书笔记为主源，并交叉印证《中医系统知识库》"经络与奇经""针灸与艾灸"相关条目，将五书打散重组为主题板块，提供一套可推演、可落地的针灸文献与操作框架。它不逐本罗列，而是回答三件事：经络腧穴的底层规则是什么、古人如何用针、什么情况绝对不能动针。

### README_1 本知识库的范围与五源

1. 主源（必读、优先）：读书笔记《奇经八脉考》《针灸甲乙经》《针邪密要》《铜人针灸经》《鬼门十三针》五册。
2. 辅源（选读、补全）：同名书籍版原文；其中《针灸甲乙经》书籍版篇幅较大，凡笔记已足者不重入，仅在必要时以检索补全细节。
3. 参考源（交叉印证）：中医系统知识库"板块3·经络与奇经""板块11·针灸与艾灸"条目，抽取五输配五行、子母补泻、居家温补灸表等作补充，不照搬全文。

内容重心在"框架、规则与边界"：经络方向、五输与交会穴、奇经八脉、腧穴定位与刺灸剂量、补泻与得气、治神、特定针法文献、安全红线。具体操作（针刺、艾灸、放血等）只作文献与识别层面的梳理，施行交专业医师。

### README_3 几种进入方式

1. 框架优先者：先读板块 2、3，立住"经络方向—奇经蓄溢"两套坐标，再进板块 4、5 学定位与补泻。
2. 文献优先者：从板块 1（源流谱系）入手，看清五书各自的定位与衔接，再展开专论。
3. 安全优先者：直接进板块 8（红线与禁忌），把"什么不能碰"刻进脑子，再回头读技术板块。
4. 自修保健者：只读板块 4（取穴与穴位身份证）、板块 6（治神内核）、板块 8（居家安全区），并严格限定在按揉与温和艾灸范围。

### README_4 心法 · 核心方法

1. 方向先于位置：十二经流向记错，迎随补泻全反；先记"手三阴从胸走手、足三阳从头走足"这条底层设定，再谈取穴。
2. 穴位不是点，是"姿势下的坐标"：体位一变，位置就偏；取穴永远走"骨度—标志—指寸—按压验证"四步。
3. 先辨虚实，再谈手法：补泻的方向判断（顺逆经、先后补泻）是主变量，复杂手法是次变量；虚补母、实泻子，且先补后泻为铁律。

### README_5 易被忽略的前提

1. 得气不等于痛：酸麻胀重为有效针感，锐痛、触电样放射、无法忍受是误伤或危险信号，须立即调整。
2. "奇经"是备用坐标系而非第一选择：常规脏腑辨证已穷尽仍兜不住时，才转向八脉；不可一上手就八脉，那是捷径也是歧路。
3. 古籍剂量不可直接套用：宋制 1 寸约今 3.1cm、教材约 3.33cm，"分""呼""壮"是比例与计数，始终以现代安全上限为准。

> 归根结底，针灸教的是一套可被观察、被重复、被验证的动作纪律：位置定准、方向辨清、虚实分明、神气调和、危险规避。这套纪律，才是真正可以带进临床与日常的东西。

## 板块0 · 学习路径和建议

### 0_1 学习路径

五书在"针灸专科类"中的位置一致：须先有理论与辨证根基，再谈经络腧穴与针法。建议衔接顺序：

1. 医学三字经、医学源流论——建立医学史与范式认知。
2. 素问、灵枢选读——理论根基（藏象、经络、运气）。
3. 神农本草经 + 药性赋 + 汤头歌诀——药性与方剂口诀，互为索引。
4. 伤寒论、金匮要略——辨证论治的实战主干。
5. 温热论、温病条辨——补上温病一支。
6. 景岳全书、血证论、类证治裁——各家学说与专科深入。

五书各自的读法侧重：

- 《针灸甲乙经》：当"说明书"读，按"穴位身份证"格式记穴（归经、定位、主治、刺法），再读补泻与治神；定位与手法属操作范围，自学只做识别与禁忌判断。
- 《铜人针灸经》：当"取穴校准器"读，先明体位再定穴；理论去《甲乙经》，校准看这本。
- 《奇经八脉考》：当"备用坐标系"读，十二经治不效、久病入络时才启用；先记蓄溢功能，再看病案。
- 《针邪密要》：剥离仪式层，只看进针前状态管理与医患信任如何建立；符咒部分只作史料。
- 《鬼门十三针》：当史料与治神极端个案读，具体操作不进入自学范围，红线比穴位更须牢记。

### 0_2 使用建议与边界声明

使用建议：

- 取穴按"骨度分寸 → 体表标志 → 指寸辅助 → 按压验证"四步，缺一不离手。
- 把"禁针""忌灸"单抄一份贴针包、灸盒；把"取穴姿势"一栏强制填进每穴笔记。
- 与《铜人针灸经》对读《甲乙经》：一个给文字标准，一个给图示传统，合起来才是完整取穴体系。
- 先辨虚实再谈手法；虚补母、实泻子，严格先补后泻。

边界声明：

本知识库为中医针灸文献与文化整理，不构成现代医学诊断、治疗或针灸操作指导；针灸、艾灸、放血等属医疗行为，须在合格中医师/针灸师授权与操作下进行，切勿自行施针；急重症请及时就医。

具体守则：凡属急症重症、孕产哺育、婴幼儿与高龄体弱，或涉及深部要害穴、风险部位，一律交专业医师，不以本库内容自行处理；针刺、艾灸治疗性操作及方药使用，必须就医由专业中医师辨证施治；居家仅可在安全区内做穴位按揉与温和艾灸，且孕妇、出血倾向、皮肤破损者慎用或禁用。

## 板块1 · 针灸文献源流与体系定位

### 1_1 五书定位与性质

| 书目 | 作者/时代 | 性质与定位 | 体量 |
| --- | --- | --- | --- |
| 《针灸甲乙经》 | 晋·皇甫谧（约 260 年） | 现存最早针灸学专著，将《素问》《灵枢》《明堂孔穴》"事类相从"，厘定腧穴、补泻与禁忌 | 十二卷，厘定 349 穴 |
| 《铜人针灸经》 | 宋·王惟一系统（今传七卷本为元明析出，不著撰人） | 穴位坐标 + 刺灸剂量 + 操作禁忌的国家标准手册，图示传统代表 | 七卷，配铜人模型 |
| 《奇经八脉考》 | 明·李时珍（1578 年） | 首次系统考订奇经八脉循行、病候与治法，补十二正经之缺 | 一卷 |
| 《针邪密要》 | 明·佚名（存于《针灸大成》卷九） | 论治神与针前准备，非腧穴书；祝由外衣下的治神操作规程 | 一篇 |
| 《鬼门十三针》 | 明·佚名（旧题孙思邈，实见于《针灸大成》等） | 专治癫狂痫一类神志病的十三穴组方文献，宜作史料与安全案例读 | 一篇（歌诀体） |

五书关系：《甲乙经》立"操作规范"，《铜人经》立"取穴校准"，二者是标准的一体两面；《奇经八脉考》补"十二经之外的蓄溢系统"；《针邪密要》管"进针之前"，《鬼门十三针》（十三鬼穴）管"神志病的极端配穴"——后二者同属治神一脉，合读才完整。

### 1_2 从晋到宋明的传承谱系

```plain
皇甫谧《针灸甲乙经》(282 年)
    │
    ├─→ 唐代太医署 → 定为针灸科必修教材
    ├─→ 孙思邈《千金方》→ 针灸部分直接取材；十三鬼穴首见《备急千金要方》
    ├─→ 王惟一《铜人腧穴针灸图经》(1026 年) → 以《甲乙经》卷三为基础扩充，铸铜人两具
    ├─→ 王执中《针灸资生经》→ 遵循本书编次
    ├─→ 杨继洲《针灸大成》(1601 年) → 集大成；收入《针邪秘要》《十三鬼穴歌》
    └─→ 现代国家标准 361 穴 → 框架源自《甲乙经》
```

一个东西用了约 1700 年未被淘汰，靠的不是神秘主义，而是"可执行、可验证、可传承"的硬核内容。日本早在 701 年《大宝律令》即列其为医者必读；2003 年中日韩商定以《甲乙经》为底本制定国际针灸穴位标准。

### 1_3 版本与读法坐标

- 《铜人针灸经》七卷本是元代书商从《太平圣惠方》卷九九《针经》析出，属"图经"的实用摘录；真正的源头是北宋天圣年间王惟一奉诏所撰《铜人腧穴针灸图经》。四库本"不著撰人名氏，虽冠铜人之名，实与铜人无涉"——读它守住底线：它是王惟一书系的下游实用本，价值在"可照搬"，不在"原创性"。
- 遇"前顶，甄权《针经》云一寸，今依《素问》一寸五分为定"一类校语，不要跳过——那是古人替你做过的一次循证审查。
- 《针邪密要》通行本署"杨继洲著"，但现存最早木刻本《卫生针灸玄机秘要》已佚，今本为杨继洲底稿 + 靳贤补辑重编 + 后世翻刻的三层叠加；人卫版校勘记指出"念咒"段部分版本并入"书符"段，今传"八步"整齐结构很可能经后世整理强化，条目数不重要，漏斗结构才重要。

自检问题：拿到一本针灸书，先问三句——它解决的是"标准、校准、还是坐标系"中的哪一层？它属于"原文、实用摘录、还是后世发挥"？我读它是为了立框架、学手法、还是查某病证？答不清，就容易把史料当手册、把摘录当原典。

## 板块2 · 经络总论：方向与五输

### 2_1 十二经：一条必须先记住的方向规则

《铜人针灸经》里有一条底层设定，必须先看懂：

> 手三阳之脉从手至头，手三阴之脉从手至胸；足三阳之脉从足至头，足三阴之脉从足至胸。是谓日夜循环，阴阳会合。

```plain
                     头（诸阳之会）
                           ▲
        手三阳 ↑            │            ↑ 足三阳
                           │
    手 ───────────────────────────────────→ 足
                           │
        手三阴 ↓            │            ↓ 足三阴
                           ▼
                     胸（阴之所聚）
```

- 阴经向心、阳经离心（头为诸阳之会，胸为阴之所聚）。
- 方向错了，后面迎随补泻全部反着做。
- 临床隐藏红利：四肢末端穴位的作用域可覆盖远端脏腑。井穴在指（趾）端而能治五脏满闷，原理就在此处——经气由此出入，是流量最大的"关卡"。

### 2_2 五输穴：经络上最高频的操作接口

> 所出为井，所流为荥，所注为俞，所过为原，所行为经，所入为合。

以肺经为例：井少商 → 荥鱼际 → 输太渊 → 经经渠 → 合尺泽。

一个高频记忆错误：很多人把列缺当成肺经原穴——错。列缺是络穴，肺经的原穴是太渊。规律是：阴经"以输代原"，输穴即原穴（太渊既是肺经输穴也是原穴）；阳经在输穴之后另有独立原穴（如大肠经输穴是三间，原穴却是合谷）。这也是阴经五输为"井荥输经合"五个、阳经为"井荥输原经合"六个的原因。

五输主病（可直接做成卡片贴工作台）：

| 穴类 | 主治 | 典型穴 | 适用场景 |
| --- | --- | --- | --- |
| 井 | 心下满（满闷）、急救醒神 | 少商、隐白 | 急救、神志、五脏满闷 |
| 荥 | 身热 | 鱼际、内庭 | 热证、红肿热痛 |
| 输（俞） | 体重节痛 | 太渊、太白、中渚、足临泣 | 关节痛、软组织病——最高频 |
| 经 | 喘咳寒热 | 经渠、昆仑、复溜 | 外感、咳喘 |
| 合 | 逆气而泄 | 尺泽、阴陵泉、足三里 | 腑病、泄利、气机上逆 |

气血在五输中的流注意象：井（源头初出）→ 荥（小流）→ 输（灌注）→ 经（畅行）→ 合（汇入），从指趾末端流向肘膝关节。病愈深者，取穴愈下（合穴治脏腑）；病在表浅者，取穴愈上（井荥治热、治神）。

### 2_3 五输配五行与子母补泻

《难经》第六十二至六十八难专论俞穴，提出"井主心下满、荥主身热、俞主体重节痛、经主喘咳寒热、合主逆气而泄"的应用纲领，并把五输配五行：

- 阴经：井木、荥火、俞土、经金、合水。
- 阳经：井金、荥水、俞木、经火、合土。

由此推出"补母泻子"针法（第六十九、七十五难）：虚则补其母，实则泻其子。例：肺（属金）虚证 → 补其母（土）→ 取肺经属土的穴（太渊）；肝（属木）实证 → 泻其子（火）→ 取肝经属火的穴（行间）。它把"补泻"从手法层面推进到选穴层面——同样是补，选哪个穴本身就有补泻方向。

记忆窍门：五行相生"木生火、火生土、土生金、金生水、水生木"。生我者为母，我生者为子。"东方实、西方虚，泻南方、补北方"即肝（木）实肺（金）虚，泻心（火，木之子）、补肾（水，木之母），是同一套逻辑的临床展开。

### 2_4 原穴、络穴与八脉交会穴

- 原穴是脏腑原气驻留之处，十二经各一过之，适用范围远宽于井荥俞经合。口诀："五脏有疾，当取之十二原"（《灵枢·九针十二原》）。
- 络穴沟通表里两经（如列缺为肺经络穴，亦通任脉）。
- 八脉交会穴是奇经八脉与十二正经的交接"接口"，是板块 3 的核心工具（见 3_3）。

立即可做动作：默写出井、荥、输、经、合各自主治（心下满 / 身热 / 体重节痛 / 喘咳寒热 / 逆气而泄），并说出"为什么四肢末端井穴能治远端脏腑病"。

## 板块3 · 奇经八脉：备用坐标系

### 3_1 沟渠与湖泽：八脉的蓄溢模型

《奇经八脉考》全书最有解释力的一句话在总说，李时珍引扁鹊《难经》之喻：

> 正经犹夫沟渠，奇经犹夫湖泽。正经之脉隆盛，则溢于奇经。

| 概念 | 对应物 | 功能 |
| --- | --- | --- |
| 十二正经 | 沟渠（主干河道） | 如环无端的常规气血循环 |
| 奇经八脉 | 湖泽（蓄水池） | 收容"流溢之气"，蓄溢调节 |
| 奇经为病 | 湖泽淤塞或决口 | 溢则妄行，虚则失守 |

临床含义极关键：正经的病是"河道堵了"，奇经的病是"水库出了问题"——溢、蓄、摄、固的功能失常。因此，所有反复发作、久治不愈、越补越漏的慢性病（崩漏、遗精、久泻、内伤发热、痿证），当常规辨证无效时，思维就该转向奇经。这是全书留给临床的第一条金钥匙。

《难经》第二十三至二十九难是这一理论的先导："人脉隆盛，入于八脉而不环周，故十二经亦不能拘之"，正是"沟渠湖泽"之喻的先声。

### 3_2 八脉空间坐标系与分脉病机要点

李时珍给八脉建立了一个覆盖全身的调控网：

| 脉 | 方位 | 功能定位 |
| --- | --- | --- |
| 阳维 | 表（乾） | 维系一身之表（卫分） |
| 阴维 | 里（坤） | 维系一身之里（营分） |
| 阳跷 | 左右之阳（东） | 主肢体左右之阳 |
| 阴跷 | 左右之阴（西） | 主肢体左右之阴 |
| 督脉 | 身后之阳（北） | 阳脉之海 |
| 任脉 / 冲脉 | 身前之阴（南） | 阴脉之海 / 十二经之海 |
| 带脉 | 横向约束（六合） | 总束诸脉 |

一个颠覆性结构安排：全书排列顺序为阴维、阳维、阴跷、阳跷、冲、任、督、带，把"二维"推到最前。这不是编排癖好，而是李时珍的核心判断——二维主一身表里，是营卫的维系者；抓住二维，就抓住八脉总纲。

分脉病机要点（用自己的话归纳）：

- 阴维、阳维（总纲）：阳维为病苦寒热（表），阴维为病苦心痛（里）。李时珍大幅扩充《难经》："阳维起于诸阳之会，由外踝上行于卫分；阴维起于诸阴之交，由内踝上行于营分，所以为一身之纲维也。"阳维寒热按所兼经脉选方（太阳有汗桂枝、无汗麻黄、少阳小柴胡、虚弱黄芪建中）；阴维心痛按三阴与寒热分格（寒痛四逆/当归四逆/理中，热痛金铃散/失笑散，营血内伤四物/养营）。关键鉴别：暴痛无热、久痛无寒；按之少止者为虚，不可近按者为实。
- 阴跷、阳跷（左右）："阴跷为病，阳缓而阴急；阳跷为病，阴缓而阳急"——一侧拘急、对侧松弛，是肢体不对称病变（偏瘫、面瘫、痉挛、足内外翻）的专属病机。申脉主昼发、照海主夜发，把发作时间作辨证开关；照海别名"漏阴"，主咽喉干痛、失眠、癫痫夜发、月经不调。
- 冲、任、督（腹背三脉同源于胞中）：冲为血海/十二经之海，病则"逆气里急"；任主胞胎/阴脉之海，病则"男子内结七疝，女子带下瘕聚"；督为阳脉之海，病则"从少腹上冲心而痛、不得前后"。三者同出于胞中，故月经病、崩漏、不孕、产后病调冲任；久病阳虚、痿躄、腰脊强痛温督；生殖内分泌整体失调冲任督同调。叶天士"通补奇经"以鹿茸壮督阳、鹿角霜通督气、鹿角胶补肾脉血为经典结构。
- 带脉（唯一横向）："带之为病，腹满，腰溶溶如坐水中"——腰部像泡冷水般松软沉重无力，是"总束诸脉"失职。对应腰腹脂肪异常堆积、内脏下垂、脱肛、疝气、带下、腰腹松弛。带脉穴、五枢、维道、足临泣（通带脉）为常用。

### 3_3 八脉交会穴落地

八脉除任、督有专属穴位外，其余六脉穴位全部交会于十二正经。李时珍逐条列出交会穴，本质是给八脉装上"可操作接口"。八脉交会穴总表：

| 穴 | 通于 | 穴 | 通于 |
| --- | --- | --- | --- |
| 公孙 | 冲脉 | 内关 | 阴维 |
| 足临泣 | 带脉 | 外关 | 阳维 |
| 后溪 | 督脉 | 申脉 | 阳跷 |
| 列缺 | 任脉 | 照海 | 阴跷 |

歌诀："公孙冲脉胃心胸，内关阴维下总同；临泣胆经连带脉，阳维目锐外关逢；后溪督脉内眦颈，申脉阳跷络亦通；列缺任脉行肺系，阴跷照海膈喉咙。"配对使用是灵魂：公孙+内关、足临泣+外关、后溪+申脉、列缺+照海，四对组合覆盖绝大部分奇经病证。例：内关别名即"阴维"，文献直称"八法有名阴维穴，腹中之疾永安康"，与阴维辨证完全对应。

日常按揉参考（非针刺）：内关拇指和缓按揉每穴 2~3 分钟；晕车恶心可薄姜片贴敷内关。针刺须专业医师操作。

### 3_4 气口九道脉：奇经专属脉诊

《奇经八脉考》末篇"气口九道脉"是李时珍最原创的贡献。他指出后世只传寸关尺"三部"，而《脉经·手检图》"九道"已失传，导致奇经无脉诊依据；他重绘"气口九道图"复原定位。《四库提要》特褒其"创为气口九道脉图，畅发内经之旨而详其诊法，尤能阐前人未泄之秘"。

操作核心：把寸口脉视为一个面而非一条线。纵向为前（寸）、中（关）、后（尺）；横向为内（尺侧推按）、外（桡侧推按）、中央直（正中平取）；组合成九道。最值钱处是"左右弹"与"斜至"——脉气不在正中而在边缘来回弹动，或呈斜线从尺部走向寸部。

奇经脉象对照（临床速查）：

| 脉 | 脉象特征 | 主病 |
| --- | --- | --- |
| 任脉 | 前部横于寸口，丸丸（圆滑如珠横亘） | 少腹痛、逆气抢心 |
| 督脉 | 三部俱浮，直上直下 | 腰脊强痛、癫、痫 |
| 冲脉 | 三部俱牢（坚实），直上直下 | 逆气里急、寒疝、绝孕 |
| 阳跷 | 前部左右弹 | 腰背痛、癫痫僵仆、偏枯 |
| 带脉 | 中部左右弹 | 少腹痛引命门、月经不调、失精 |
| 阴跷 | 后部左右弹 | 癫痫寒热、漏下不止 |
| 阳维 | 从少阴斜至太阳 | 颠仆、失音、痹痒 |
| 阴维 | 从少阳斜至厥阴 | 癫痫、汗出恶风 |

辨证捷径：寸口三部俱浮/俱牢 + 脊强先想督冲；寸口横丸 + 少腹逆气先想任；前/中/后"左右弹"分应阳跷、带、阴跷；脉象呈斜线（尺→寸）为维脉。这是疑难杂症中极低成本的诊断入口。须注意：原图已佚（今本多标"图缺"），且九道诊法后世未见专门研究，宜作历史文献与方法学启示，不宜径作今日可复现的客观诊断标准。

### 3_5 通补奇经与八脉隶于肝肾

李时珍未系统展开，但埋下伏笔；后世叶天士发展为完整理论：

- "八脉隶于肝肾"：肝血肾精灌养奇经，肝肾虚损必累及奇经。
- "冲脉隶于阳明"：阳明（脾胃）久虚、脉不固摄则崩漏。
- 治则："奇经为病，通因一法，为古圣贤之定例"——实证宜通，虚证亦必佐通，因"经络之病，非通不能入脉"。

叶天士通补奇经用药范式（延伸干货）：任脉用龟板（滋阴填任）、督脉用鹿角/鹿茸（温阳壮督）、冲脉用紫石英（重镇降逆）、带脉用当归（宣补），久病损及八脉则用紫河车、坎炁、阿胶、淡菜、动物脊髓等血肉有情之品。

铁律：必须是"久病、大病、诸虚劳损、下元衰惫"的虚证且属"下损"，才上通补；实证（六淫、痰瘀、跌扑）用苦辛芳香宣通（鹿角、小茴、当归、泽兰、桂枝、琥珀、香附等）。虚实用反，祸不旋踵。

自检：给出"半年反复崩漏、三种常规辨证都只取效一时、越补越烦"，说出该转向哪套坐标系及理由（答：转向冲任督带奇经，因"越补越漏"是固摄失司、湖泽决口之象，层次错了再细的辨证也白费）。

## 板块4 · 腧穴定位与刺灸剂量规范

### 4_1 穴位的"完整身份证"

《甲乙经》卷三对每个穴位记录格式高度统一。以天突为例："天突，一名玉户，在颈结喉下二寸，中央宛宛中，阴维、任脉之会，低头取之。刺入一寸，留七呼，灸三壮。"

```plain
穴名（含别名）│ 精确位置 │ 取穴姿势 │ 归经/交会 │ 针刺深度 │ 留针时长 │ 艾灸壮数 │ 主治 │ 禁忌
```

信息密度要点："低头取之"——体位是关键操作前提，歪个头位置就变；"刺入一寸"——精确到分的深度；"留七呼"——"呼"是计息单位（一呼一吸），规定留针时长；"灸三壮"——"壮"指每燃一艾炷为一壮，规定灸量。今天的针灸教学单位换了（毫米），但"身份证格式"一个字没变。初学者可拿书里任意一穴，对照自身位置逐条验证——这是最快的"穴位定位肌肉记忆"训练法。

两个沿用至今的分类逻辑：头面躯干按部位排（从头到脚分区）、四肢按经脉排（从阴到阳、从肘到手/膝到足）。这套"分部+分经"双轨制至今仍是针灸教材编排方式。

### 4_2 取穴四法：骨度、标志、指寸、按压验证

《铜人针灸经》把取穴拆成可执行的四步，优先级如下：

第1步，骨度分寸（首选标准，优先于指寸）：以患者自身身体为基准。高频段须背：

| 部位 | 起止点 | 折量寸 |
| --- | --- | --- |
| 头部 | 前发际正中→后发际正中 | 12 寸 |
| 胸部 | 天突→胸剑联合（歧骨） | 9 寸 |
| 上腹部 | 胸剑联合→脐中 | 8 寸 |
| 下腹部 | 脐中→耻骨联合上缘 | 5 寸 |
| 上臂 | 腋前/后纹头→肘横纹 | 9 寸 |
| 前臂 | 肘横纹→腕横纹 | 12 寸 |
| 大腿（内侧） | 耻骨联合上缘→股骨内上髁上缘 | 18 寸 |
| 小腿（内侧） | 胫骨内侧髁→内踝尖 | 13 寸 |

第2步，体表标志法（古籍最常用）：大量"低头取之""仰头取之""开口有孔""合口有孔，张口即闭"即活动标志。例如下关"合口有孔，张口即闭"，用"咬紧牙关"找比死算骨度快十倍。

第3步，手指同身寸法（辅助）：中指中节两侧横纹间距 = 1 寸（定横距）；拇指关节横宽 = 1 寸（定竖距）；"一夫法"（四指并拢）总宽 = 3 寸（定胸腹横向）。最重要的一条：四指并拢量胸腹横向距离，最不易错。

第4步，按压验证（最高级一步）：不用丈量，靠骨性突起、凹陷、皱纹、张口空陷直接定位，再叠加"先按后刺"——指压酸胀放散明显处即正穴。三法优先级：骨度分寸 → 体表标志 → 指寸辅助，最后一律用按压得气验证。

### 4_3 姿势即坐标：穴位是"姿势下的坐标"

《铜人针灸经》与夏竦序的核心论点其实是教学法："传心岂如会目，著辞不若案形"——口传心授不如看模型，文字描述不如对照实体。这解释了大量"取穴姿势"的篇幅（正坐、俯伏、挺腹地、端身、两手相重支额）。

实践含义：穴位不是一个坐标，而是一个"姿势下的坐标"。歪个头、挺个腹，位置就变。以膏肓俞为最精彩范例："令人正坐，曲脊伸两手，以臂着膝前……按之自觉牵引于肩中……多至五百壮。"一段包含全部密码：姿势 → 骨性标志 → 肋骨计数 → 按压验证（牵引于肩中是确诊信号）→ 灸量上限。现代人用"按之酸胀可向肩部放散"复刻这一验证环节。

背俞穴定位几乎全部靠"第几椎下 + 旁开 1.5 寸"，唯一须额外记住的锚点是"肾俞与脐平"——先摸肾俞（命门旁开 1.5 寸，约平脐），再上下数椎，比硬数第几胸椎可靠得多。

立即可做动作：取天枢（脐旁 2 寸），用一夫法量脐左右各三指宽核对；再取肾俞，先定位命门（与脐对）旁开确认。

### 4_4 刺灸剂量规范与现代换算

每穴固定四项缺一不可：穴名 + 定位 + 主治 + 针/灸剂量。剂量书写含三个维度：

- 深度用"分"（1 寸 = 10 分）。宋制 1 寸约今 3.1cm，现代教材约 3.33cm，二者不可直接套用——把"分"当比例而非绝对值，以教材现代安全上限为准。
- 留针用"呼"。一般穴 6~7 呼（约一分钟），少商等井穴 1 呼，环跳、内庭、公孙等 10~20 呼。原理是手三阴三阳"其气之来疾"故手经留针宜短，足经可稍长，是古人对不同经络气血运行速度的量化观察。
- 灸量用"壮"。一壮 = 一个艾炷燃尽。直接灸与艾条灸、温灸盒之间无简单换算，统一用"时间 + 皮肤反应"控制，不照搬"灸三百壮"。

《铜人经》灸法细则（提炼为可执行规范）：时间午后施灸优于清晨（清晨谷气未复易眩晕）；环境避风避湿避雷电阴雾；饮食忌过饱、大饥、饮酒、生冷硬物；情志忌思虑、忧愁、呼骂、叹息（气乱则灸效差）。核心不是迷信时辰，而是"气血稳定、环境可控时施灸，疗效与安全同步提升"。

### 4_5 禁针穴与忌灸穴清单

《甲乙经》用大段篇幅立"安全红线"，明确禁针者包括：神庭、上关、颅息、人迎、云门、脐中、伏兔、三阳络、复溜、承筋、然谷、乳中、鸠尾等。现代解读：绝大多数位于大血管旁（人迎、上关）、靠近重要脏器（脐中、鸠尾、云门、乳中）或深部有骨骼神经（伏兔、承筋、然谷）。

《铜人经》最易被忽视的安全清单：

- 囟会："八岁以上方可针，囟门未合若针，不幸令人死"——小儿前囟未闭禁针。
- 脑户、喑门（哑门）："灸令人失喑""入八分徐徐出之，不宜灸"——头项部穴位大多禁灸，以免伤髓。
- 天突："直横下，不得低手"——必须沿胸骨后缘向下斜刺，禁止向下直刺深刺，否则伤及纵隔与肺。
- 白环俞："针入八分……忌灸"；取穴须"挺腹地、端身、两手相重支额、纵气息、令肢肉俱缓"。

把"忌灸"单抄一份贴灸盒，价值超过读十遍正文。古人的"禁针"标准在现代解剖与针具改良后有所调整，但核心逻辑没变——"能杀生人，不起死人"，安全红线永远优先于任何"古籍说能扎你就扎"的迷思。

## 板块5 · 补泻手法与得气判定

### 5_1 先辨虚实，再谈手法

《灵枢》十六字总纲："凡用针者，虚则实之，满则泄之，宛陈则除之，邪胜则虚之。"《甲乙经》又给可操作的虚实辨别："虚者，脉大如其故而不坚也；实者，脉大如其故而益坚也。"——虚实不能靠"感觉"，要靠脉诊：虚证脉虽大但按之不坚实，实证脉大且按之实紧。

优先级铁律（出自《铜人经》）：

1. 先辨虚实，再谈手法——方向判断是主变量，复杂手法是次变量。
2. "当先补而后泻"是固定顺序，不可选——先泻后补会伤正。
3. "不虚不实，以经取之"指本经自病不中他邪，只在本经取穴调理，范围更窄、取穴更应聚焦，绝非"随便取穴"。

### 5_2 五种/三组补泻手法

《甲乙经》卷五系统整理补泻手法，可两两配对记忆：

| 手法 | 补法操作要义 | 泻法操作要义 | 一句话记忆 |
| --- | --- | --- | --- |
| 呼吸补泻 | 吸气进针出针，出针即按闭 | 吸气进针捻转，呼气慢出针 | 补随吸气收，泻借呼气散 |
| 徐疾补泻 | 慢进针、快出针（徐内疾出） | 快进针、慢出针（疾内徐出） | 补如春雨润物，泻如利刃出鞘 |
| 迎随补泻 | 针尖顺经气方向刺入（随而济之） | 针尖逆经气方向刺入（迎而夺之） | 补顺经行，泻逆经伐 |
| 开阖补泻 | 出针立刻按闭针孔（闭门留正） | 出针摇大针孔不按（开门泻邪） | 补是关门，泻是开门 |
| 留针补泻 | 得气后少动，静以久留 | 得气后持续行针，动以久留 | 补是耐心等，泻是持续推 |

最易踩的坑——迎随方向感：很多初学者搞反"顺逆"。记忆窍门："随"字本就提示方向——顺着经气走的方向。经气走向即板块 2 那条线：手三阴从胸到手、手三阳从手到头、足三阳从头到足、足三阴从足到胸。针尖顺着箭头刺即为补。

### 5_3 迎随：方向即补泻

《铜人经》："所谓迎随者，知荣卫之流行、经络之往来也，随其顺逆而取之……调气之方，必在阴阳者，知其表里，随其阴阳而调之。"可执行的规则：

- 补（顺经气走向）：针尖朝向源头方向，随而济之。
- 泻（逆经气走向）：针尖朝向末端方向，迎而夺之。

实操要点：进针前先用 3 秒想清"这条经经气往哪流"。这是最低成本、最高回报的动作——不必会复杂手法，方向对，基础提插已自带补泻倾向。

两组极具体化的细节（出自《铜人经》）："针阳者，卧针而刺之"——刺阳经斜卧进针以减少痛感与穿透；"刺阴者，先以左手捻按所针荥俞之处，候气散乃内针"——刺阴经先按揉使气散再进针，避免伤营血。这是"刺营无伤卫、刺卫无伤营"的具体化，也是全书最具可操作性的手法细节之一。

### 5_4 得气：唯一不能跳过的疗效判定

《铜人经》："入卫至营至病，得气，如鲔鱼食钓，即得其病气也……既引气，名一向无补，名之曰泻。"《灵枢》："气至而有效。"——针刺是否有效，不看扎得多准，看是否得气。

"如鱼吞钩饵"是全书最精准的临床描述：针下由空虚滑脱突然变得沉紧、涩滞、被吸住，即得气。双向指征：

- 患者侧：酸、麻、胀、重、凉、热、触电感、蚁走感，可向远端扩散。指趾末端多痛，四肢丰厚处多酸胀，腹部多沉压感，腰部多酸胀感。
- 医者侧：针下由轻松虚滑变为沉紧，如鱼吞钩饵；触摸穴周肌肉由松弛变紧张，或出现跳动、蠕动。

两个误判必须破除：

- "痛 = 得气" → 痛是刺中神经或筋膜牵拉，有效针感是酸麻胀重而非锐痛；触电样放射痛应立即调整针尖方向。
- "没感觉 = 没效果" → 部分人群（糖尿病、老年、长期服药者）感觉迟钝，应以医者侧沉紧手感为主要判据。

若双侧均不成立，按序排查：定位 → 深度 → 方向 → 手法 → 患者状态。其中"患者状态"一项常被遗漏却最常是主因——神未定，气不至。

### 5_5 因时刺：春夏秋冬与刺深

《铜人经》："春夏温必致一阴者，初下针沉之至肝肾之部，得气乃引持之阴也；秋冬寒必致一阳者，乃初内针浅而浮之至心肺之部，得气而内之阳也。"即在"刺浅刺深"规则之上，再加一个进针中途的得气步骤。

季节配穴（本书"因时刺"）："春刺井、夏刺荥、仲夏刺俞、秋刺经、冬刺合。"配合"春夏刺浅、秋冬刺深"，可合并为实用判断：病在表、时在春夏 → 浅刺 + 远端井荥；病在里、时在秋冬 → 深刺 + 合穴与原穴。

重要提醒：这里的"春夏秋冬"并非要求换季改方，而是调节刺深与选穴层级的思维方式——热病、急症、病位浅者天然"属春夏"；慢性病、病位深者天然"属秋冬"。把季节映射成病位深浅，这条规则全年可用。子午流注是迎随的时辰版（时辰为辅助，穴与病相宜优先），实证在气血流注本经的时辰取子穴（我生之穴）泻之，虚证取母穴（生我之穴）补之，平证取本穴或原穴。

立即可做动作：背下十二经流注方向（手三阳从手走头、手三阴从手走胸、足三阳从足走头、足三阴从足走胸），并默写五输主病卡（井主满、荥主热、俞主体重节痛、经主咳寒热、合主逆气泄）。

## 板块6 · 治神：针前状态管理

### 6_1 《针邪密要》的去魅：从祝由外衣到治神内核

《针邪密要》存于《针灸大成》卷九，是一篇被长期误读的文献。若把它当符咒文献，它荒谬；若把"病因模型"与"操作方法"剥离，它惊人地现代。原文标题用"密要"而非"秘要"，是沿用"不可轻传"的训诂义，不表示认同神秘化。

破题关键在于那句判断语："如此之类，乃飞虫精灵，妖孽狂鬼，百邪侵害也。"两种读法：字面读病因是鬼神；模型读病因是"神乱"——古人用"邪/鬼"指代无法用脏腑辨证单独解释的功能性紊乱。取模型读的理由有二：其一，全文没有一个治疗穴位，全部是"如何进入治疗"的准备动作；其二，紧接其后的《孙真人针十三鬼穴歌》才是取穴方案。《针邪秘要》与《十三鬼穴歌》是"术前总则 + 术中方案"的上下篇关系，合读才完整。

核心结论：这篇文章的核心不是"驱邪"，而是"治神"——在针落下之前，先把患者和医者的状态调到可治疗区间。

### 6_2 漏斗型操作规程

把原文的八条按操作对象重排，是一个清晰的漏斗：

```plain
        愉悦 ──► 关系层（医患双方）
      书符 念咒 ──► 预期层（建立框架）
      定神 ──► 状态层（各自安定）
      正色 ──► 行为层（医者专注）
      祷神 密言 ──► 注意层（指向针与穴）
      咒针 ──► 执行层（落针一刻）
```

每一层都在做同一件事：缩小自由度。关系层把"怀疑"缩为"信任"；预期层把"不可控恐惧"缩为"有框架期待"；状态层把"散乱"缩为"安定"；行为层把"多通道注意"缩为"单一任务"；注意层把"杂念"缩为"针尖"；执行层把"犹豫"缩为"一次到位"。

四条总开关："神不定勿刺，神已定可施。"两层含义：患者侧惊恐焦虑→交感兴奋→肌紧张→痛阈下降+得气困难+晕针风险；医者侧慌乱分心→手法变形→进针偏差→信任受损（反安慰剂）。古人早已把"医患共同调神"写进流程，只是被符咒外壳盖住。

### 6_3 可转化的动作：去超自然，留功能

原则：临床环境中去掉超自然成分，保留其心理学与生理学功能。

- "愉悦"→ 治神前评估（进针前 3 分钟）：总分 ≥ 7 才进入下一步；总分 < 4 暂停针刺转介或先心理疏导；单项 ≤ 2（尤指信任与意愿）不进针。原文"主恶砭石，不可以言治"即此义——知情同意不是文书，是治疗变量。
- "书符/念咒"→ 双通道暗示框架：视觉（消毒包、穴位图、处方单）+ 言语（固定三步口令）+ 触觉（先爪切按压定位）同时给出同一信号"安全、有序、正在治疗"。关键不在"符"而在"双通道一致性"。保留一项有益做法：令患者进针前主动说一句"我准备好了"，把被动接受转为自我承诺。
- "定神"→ 一呼吸三步口令（约 60 秒）：吸 4 秒松肩感受足底 → 停 2 秒命名当下感受 → 呼 6 秒把注意放向将针处，重复 3 轮。吸短呼长是副交感占优的呼吸模式；"命名"这步不可替代——给杂念一个去处比压制有效。医者须同步做同一呼吸。
- "正色/祷神"→ 90 秒静默锚定：闭眼 10 秒降杏仁核唤醒；默演一遍手法（进针角度、深度、得气后行针）以减少失误；爪切穴位 3 次配固定口令。"手如握虎，势若擒龙"正确读法是肌张力最佳区间——手指稳定、手腕松弛、前臂不僵。过度用力→肌震颤→进针抖动；完全放松→落空。
- "咒针"→ 进针量化动作：呵气一口（与患者呼气同步，温热与同步降低痛阈、增加可预测感）；默存心火烧过（定位三核对：穴名/深度/角度）；用力徐徐插入（穿皮 ≤ 0.1 秒快破皮，进深每毫米 ≥ 0.2 秒慢推进，遇阻力层先停 1 秒）。

### 6_4 得气的双边判据与"神未定气不至"

把"神"拆成五个可测变量：注意力（能否跟随三步口令）、情绪（HRV、皮电）、呼吸（频率、吸呼比）、肌张力（前臂/咬肌、出汗）、预期（信任评分）。

"得气"双语判定：患者侧酸麻胀重热凉循经感传，或蚁行水流感——有针感 ≠ 得气，完全无感须重审手法；医者侧针下沉紧涩"如鱼吞钩饵之浮沉"——手下沉紧是得气成立的必要旁证。若双侧均不成立，排查顺序中"患者状态"最常是主因：神未定，气不至。

反例（必须避免）："你别紧张""一点都不疼"这类否定式指令会反向激活被禁止的感受；替代说法："把注意力放在脚底""跟着我的呼吸数，数到三就结束"。

立即可做动作（非针刺、可自学）：进针前 30 秒只做"一呼吸三步"——吸 4 秒松肩、停 2 秒命名感受、呼 6 秒指向目标部位，体会手稳不稳；再读《素问·宝命全形论》"凡刺之真，必先治神"与《灵枢·九针十二原》"粗守形，上守神""气至而有效"，理解治神是针效的前提而非玄学。

## 板块7 · 特定针法与神志病文献

> 本章以"历史文献 / 文化传统"角度整理十三鬼穴与《鬼门十三针》。须严正声明：该组方涉及精神科传统针法，绝非现代精神科治疗手段；所列风府、会阴、舌下等穴风险明确，非专业者严禁自行操作，须在专业医师指导下于正规医疗机构进行，且不可替代规范的精神科诊断与治疗。

### 7_1 十三鬼穴的史料定位

古人对"查不出器质性病变、却把人折腾得不像人样"的病归因为"鬼神作祟"，十三处穴位通通冠以"鬼"字。"鬼"不是实指，而是古人认知边界的标签——当医学解释不了时，就说是鬼。其治疗对象对应今天：癫（抑郁、精神分裂谱系）、狂（躁狂、双相）、痫（癫痫）、以及癔症、惊恐障碍、重度失眠等。核心病机只有三字：痰、火、惊——痰浊蒙心则神不守舍，痰火扰心则狂躁不安，惊则气乱神散则昏厥失语。

孙思邈《孙真人针十三鬼穴歌》首见《备急千金要方·风癫第五》，原文极朴素："百邪颠狂所为病，针有十三穴须认。"它起源于战国扁鹊传说，经孙思邈记入，后由杨继洲《针灸大成》定型推广，到现代经历"去鬼名化"的安全改造——"鬼"字一直在，内涵一直在变：从对未知的恐惧，到对经络的精准把握，再到对安全边界的严肃划定。

### 7_2 原文拆解：顺序、深浅梯度、灵活增补

歌诀开篇定调："凡针之体先鬼宫，次针鬼信无不应。一一从头逐一求，男从左起女从右。"

- 顺序暗逻辑：鬼宫（人中）→ 鬼信（少商）→ 鬼垒（隐白）→ 鬼心（大陵）→ 鬼路（申脉）→ 鬼枕（风府）→ 鬼床（颊车）→ 鬼市（承浆）→ 鬼窟（劳宫）→ 鬼堂（上星）→ 鬼藏（会阴）→ 鬼臣（曲池）→ 鬼封（海泉）。遵循"先督后任、先上后下、先急救穴后远端穴"逻辑。
- 深浅梯度（非随意）：人中、少商、隐白、承浆入三分；大陵、风府、劳宫、上星、会阴入二分；大陵、颊车入五分；申脉、曲池用火针；海泉点刺出血。梯度暗含"由浅入深、由表及里"策略——急救要穴（人中）只刺三分因近延髓宜浅；远端泄热穴用火针力度最强；舌下出血为开窍泻热。
- 最被忽视的一句话："更加间使、后溪二穴尤妙。"间使（心包）、后溪（小肠/八脉交会）并非十三穴，却是孙思邈亲点"加分项"，提示以"宁心安神 + 通督醒脑"为核心组合。扁鹊更直白："未必须并针，止五六穴即可知矣。"——扎五六穴即见效，才是古人真实态度，非十三针必须全扎。

### 7_3 十三穴逐组拆解与"不必全扎"

前四针（救命优先序）：人中（鬼宫）醒脑开窍第一要穴，雀啄法至眼球湿润；少商（鬼信）肺经井穴点刺出血开泄肺热；隐白（鬼垒）脾经井穴统血健脾安神；大陵（鬼心）心包原穴清心泻火安神。铁律：开窍在前，清热在中，安神在后。

中五针（神志钢筋框架）：申脉（鬼路）通跷脉调睡眠节律治癫痫失眠；风府（鬼枕）督脉要穴近延髓醒脑通髓；颊车（鬼床）祛风清热开关；承浆（鬼市）调和任督；劳宫（鬼窟）清心泄火开窍。风府是全组危险系数最高者——深部紧贴延髓，必须朝下颌方向斜刺，深度超 1 寸即危险，古代"针要温"也是为降痛感减应激。

最后三针（能用不能滥用）：上星（鬼堂）清头散风；会阴（鬼藏）/玉门头（女）深部近直肠膀胱，现代临床基本禁用；海泉（鬼封，舌下系带）点刺出血操作不当易血肿感染，现代极少用。正因第 11、13 穴是最大"雷区"，现代中医院针灸科几乎弃用，改用曲泉（肝经，定惊安神）、大钟（肾经络穴，治痴呆狂躁）等安全穴替代。

### 7_4 现代安全替代与"去鬼名化"

| 传统穴 | 现代安全替代 | 替代逻辑 |
| --- | --- | --- |
| 鬼藏（会阴） | 曲泉（肝经，膝上方） | 清泄湿热，同样定惊安神 |
| 鬼藏（会阴） | 大钟（肾经，太溪下方） | 肾经络穴，专治痴呆狂躁、调肾宁神 |
| 鬼封（海泉） | 涌泉（足底前 1/3） | 肾经末穴，"引火归元"安神失眠 |

临床真正可落地的"拆阵打法"（仅作史料与思路参考，施行交医师）：开窍醒神阵（人中+少商+隐白，井穴刺血开泄气机）；拔毒定志阵（大陵+风府+申脉+劳宫，清火调律安神）；清阳降浊阵（颊车透地仓+承浆+上星+曲池，疏散面部郁闭、釜底抽薪）。但凡"全套照做"的读法，先怀疑它是不是把选择表当成了流程单——原文本就是辨证选用。

### 7_5 安全边界（最高优先级）

第1，非专业人士绝对禁止操作。风府、会阴、海泉深部紧贴延髓、脏器和大血管，误差 0.5 寸可造成不可逆损伤，须由持执业医师资格、有丰富针灸经验的专业医师操作。第2，必须排除器质性病因——精神症状首要有神经内科排除颅内肿瘤、出血、脑炎等，这是底线。第3，它不能替代正规治疗——现代临床只能作辅助手段，配合精神科药物、心理治疗、物理治疗综合进行；神化"包治百病"或"驱鬼"既是虚假宣传也涉嫌非法行医。慎用人群：孕妇（尤其会阴、曲池相关）、凝血障碍者、严重基础病、极度虚弱者、晕针史者；施针须专人陪护。

## 板块8 · 安全红线与禁忌体系

### 8_1 通用红线清单

| # | 红线 | 依据/后果 |
| --- | --- | --- |
| 1 | 无资质、非规范场所，不施针 | 针刺属侵入性医疗行为 |
| 2 | 疑似谵妄、中毒、器质性精神障碍者，先排除器质病因 | "见鬼神"可能是低血糖、感染、卒中首发表现 |
| 3 | 症状属精神专科范畴者，针刺不可替代规范诊断与治疗 | 可辅助调节睡眠焦虑与躯体化，非替代方案 |
| 4 | 风府、哑门等深部穴位，禁止自学自用 | 针尖越过硬脊膜可损伤延髓危及生命 |
| 5 | 会阴、舌下、乳突周围等区域，非专科场景不碰 | 出血、感染与解剖风险显著高于收益 |
| 6 | 患者恐惧明显时，宁可不针 | 反安慰剂可加重症状，且构成依从性失败 |

总原则：凡涉及神志异常、急重症、深部要害穴，一律交专业医师，不在家庭环境尝试。

### 8_2 最需警惕的风险部位

- 风府穴（鬼枕/鬼林）：CT 测量安全深度与体型相关（瘦/适中/胖均值约 27.7/30.8/33.4mm），超过约 1.5 寸（≈40mm）已进入危险区间；"四肢麻电感"是明确停止信号，出现即退针。方向以针尖朝鼻尖较安全，严禁针尖向上（朝枕骨大孔）深刺，亦禁用大幅度提插捻转。数据只说明风险量级，不能作为自学操作依据。
- 气胸：背、胸、锁骨上窝穴位过深刺破肺组织 → 胸闷、气短、胸痛。必须由正规医师操作，严禁深刺。
- 重要脏器与大血管：腹、颈、锁骨上窝须精准控制进针深度与角度，严禁盲目深刺。

得气与危险的界线：酸麻胀重 = 有效；剧烈锐痛、触电样放射、无法忍受 = 立即停止调整。

### 8_3 晕针：识别、处理、预防

| 阶段 | 要点 |
| --- | --- |
| 诱因 | 初诊紧张、体质虚弱、饥饿、过劳、酒后、手法过重 |
| 先兆 | 面色变化、额角微汗、言语应对迟滞 |
| 症状 | 头晕目眩恶心，重则面色苍白、冷汗、四肢厥冷、脉细数、晕厥 |
| 处理 | 立即停针、全部起出 → 平卧、头低脚高、松衣带、保暖 → 饮温水；重者点刺/指压水沟、合谷、足三里，必要时急救 |
| 预防 | 初诊取卧位、取穴宜少、刺激宜轻；饥饿疲劳者先进食休息；见先兆即点刺水沟、令其平卧 |

### 8_4 现代预诊清单（替代"人神禁忌"）

古籍"人神"日忌（子日在目、丑日在腰之类）属宋代避忌体系，现代无循证支持，不必逐日避忌；但"针灸前评估患者状态"本身完全成立——疲劳、醉酒、大怒、大汗、大泻、大出血后气血本虚，强刺易变。以下情况推迟或调整方案：

- 空腹 / 过饱 / 醉酒 / 大汗 / 大泻 / 大出血后。
- 极度疲劳、情绪剧烈波动、熬夜后。
- 妊娠（合谷、三阴交、至阴等诱发风险，需专科评估；腹部腰骶部禁针禁灸）。
- 凝血功能障碍、正在服用抗凝药。
- 皮肤破损、感染、肿瘤局部。
- 严重心脏病、植入起搏器者（电针慎用）。

《铜人经》原也强调针前状态："不用饱食，亦不用空肚……令坐息，安神定气……候气脉安定，乃可下针。"——这是预防晕针最有效、成本最低的手段。

### 8_5 两个剂量陷阱

第1，"壮"不等于"分钟"。一壮 = 一个艾炷燃尽，直接灸与艾条灸、温灸盒之间无简单换算，统一用"时间 + 皮肤反应"控制，不照搬"灸三百壮"。《铜人经》："日灸三壮，至百五壮罢，不宜多灸。须停十余日，然后更灸。若频灸，恐拔气大上，令人眼暗。"——灸量须渐进且间歇，连续大量灸会"拔气上冲"致头痛目暗（即现代"灸后上火"）；灸后可用三棱针点刺宣散防热邪上壅。

第2，"分"不等于现代寸。按宋制约 3.1cm、教材约 3.33cm 折算后再用，且始终以现代安全深度为上限。背部 0.5–0.8 寸、胸胁部斜刺 0.3–0.5 寸为参考上限。

居家安全区（温和艾灸可自用，且相对安全）：足三里（健脾强壮）、关元（培元温肾）、气海（益气助阳）、中脘（和胃）、神阙（隔盐/隔姜灸虚寒泻）、命门（温肾阳）、大椎（解表散寒）、三阴交（健脾养血，孕期慎用）。安全须知：孕妇腹部腰骶部禁灸，三阴交等孕期慎用；面部大血管处关节不宜直接瘢痕灸；糖尿病皮肤感觉迟钝者慎灸；实热证阴虚火旺者不宜温灸；每次每穴温和灸 10–15 分钟，皮肤温热潮红为度，不追求起泡；灸后保暖避风。

自检问题：列出三个自己或家人适合温和灸的穴位并说明为什么（须同时说明不属于实热/阴虚火旺）；再列出三种"今天绝对不扎"的情形（答：无资质、深部要害穴、急重症与器质性精神障碍未排除）。

### 9_1 分阶段学习路径

第一阶段（框架）：读板块 2、3 立"经络方向—奇经蓄溢"两套坐标；读板块 1 看清五书定位。输出：能默画十二经流向图与八脉坐标图。

第二阶段（标准）：读板块 4（取穴四法、穴位身份证、禁忌穴）、板块 5（补泻与得气）。输出：能做一张"穴位身份证卡"（定位含姿势、归经、穴性、主治、刺法、灸量、禁忌七栏），并把"取穴姿势"强制填栏。

第三阶段（内核）：读板块 6（治神）、板块 8（红线）。输出：能口述"进针前三分钟"流程与晕针处置，并列出个人居家安全区。

第四阶段（史料与批判）：读板块 7（十三鬼穴）只作史料与治神极端个案；做文献批判性阅读，区分原作者与后世发挥（如"八脉隶于肝肾"是叶天士发展非李时珍原文）。

不同读者精读路线：

- 初学者：先抄卷三腧穴，每天一穴"穴名→位置→刺入几分→灸几壮"，一周 20 个肌肉记忆级穴位；再读补泻手法各练五次（用合谷、内关等安全穴体会呼吸补泻节奏）；最后翻病证篇找最关心的一两类病看方案模板。
- 中西医骨科/全科医生：重点读经络循行与现代解剖对照，建立"经络 = 神经-血管-结缔组织束"的现代诠释框架，用于疼痛管理精准靶点。
- 中医专业学生：把相关书当《内经》的"操作注释本"读，两书对照，对内经理解质的飞跃。
- 自修保健者：只读取穴、治神内核、居家安全区，严格限定按揉与温和艾灸。

### 9_3 自检问题集（可立即做动作）

1. 方向测试：说出足三阳经走向（从足至头），并解释为何四肢末端井穴能治远端脏腑病（答：经气出入最大关卡，流量最大）。
2. 五输主病：默写井荥输经合主治（心下满/身热/体重节痛/喘咳寒热/逆气而泄）。
3. 奇经启用：给出"半年反复出血、三种常规辨证只取效一时、越补越烦"，说明转向哪套坐标系及理由（答：冲任督带奇经，固摄失司）。
4. 补泻方向：给出"久病乏力、喜按、脉沉细无力"，判补或泻并说出出针后是否按闭针孔（答：补，按闭）。
5. 得气判断：用自己的话解释得气，及日常按揉如何应用（答：酸麻胀重经气感应；按揉追求酸胀感而非随便蹭）。
6. 安全自查：列出三个适合温和灸的穴位并说明非实热/阴虚火旺；列出三种今天绝对不扎的情形。

立即可做动作（非针刺）：本周内用"骨度—标志—指寸—按压验证"四步，在自身标定内关、关元、三阴交、肾俞四处，并各按揉 2–3 分钟体会酸胀得气感；孕妇、出血倾向、皮肤破损者跳过。
