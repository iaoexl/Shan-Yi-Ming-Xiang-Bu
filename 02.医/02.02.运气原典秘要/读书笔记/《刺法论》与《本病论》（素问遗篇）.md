# 《刺法论》与《本病论》（素问遗篇）

## README · 导览

### README_1 书目速览

- **书目信息**：本书目所指为《素问》"遗篇"中的《刺法论》与《本病论》两篇，旧题出于《素问》亡佚之卷，专论疫病（五疫）的发生机制与针刺预防之法，后世多附于《素问》传本之后，与运气七篇大论并称运气学说的核心文献群。
- **成书背景**：两篇在唐代王冰整理《素问》时已称亡缺，今传文本一般认为在宋代方才补入或重辑，行文带有较浓的方技与禁咒色彩，是运气学说从"气化格局推演"走向"疫病专题"的晚出专论。
- **核心主旨**：以"气交失序"为总纲，系统论述五运乖违、六气不交如何酿成群体性疫疠（木火土金水五疫），并给出刺五脏之俞、避让毒气等具体操作，是古人从运气角度谈疫病预防的独特文本。
- **与五运六气关系**：它上承七篇大论的"胜复郁发""气化失常"，把抽象的运气格局落到"民病、五疫"与可操作的刺法，是七篇在瘟疫学方向上的专门展开与补遗。
- **阅读价值**：想理解"古人何以把瘟疫归为运气失调"并寻找具体防疫思路，遗篇是最直接的文献；其"刺法"也补了七篇少谈"治法"之缺，但须以文献与观念史眼光读之。

## 板块0 · 学习路径和建议

遗篇篇幅不长却义理跳跃，最忌逐句抠字、亦忌全盘当作方技宝典。下面给出一条由"病机"入"刺法"、再由"遗篇"回"七篇"的阅读路线，并附前置基础与读法纪律，帮助初学者不迷路。

---

### 0_1 学习路径

#### 0_1_1 阅读顺序

第1步，先读《本病论》——它偏重"病"的来路，先看清"气交失序→民病/五疫"这一总链条，把"为什么会有疫"立在运气框架上。第2步，再读《刺法论》——它在"病"之后补"刺"的门道，给出五俞刺、避毒气等具体操作，是把理论转为应对的篇章。第3步，把两篇与七篇大论的"胜复郁发""迁正退位"对照，确认遗篇是哪一段机制的细化，体系才真正合拢。

#### 0_1_2 前置基础

「1」七篇大论的"气化失常、胜复郁发、司天在泉"框架是必读前提，否则遗篇中的"不迁正、不退位"无从落脚；若尚未通七篇，宜先以入门读本建立干支化运气的基本概念，再回来读遗篇方能顺畅。
「2」基本针灸常识（俞穴、补泻之意）无需深究，能看懂"刺某藏之俞以调其气"的文意即可；所有实操部分一律交由合格中医师，本文不教针法，也不建议自行施针。

#### 0_1_3 重点条目

阅读前先记住四个锚点，后文推演都绕不开它们。其一，"五疫"：因五运乖违而起的木火土金水五类疫疠，是遗篇的中心病种。其二，"气交"：天地上下之气不交则病，是"民病"的总发生机制。其三，"刚柔失守"与"升降不前"：运气交接失时失位，是郁而化疫的两类关键情态。其四，"刺法"：刺五脏之俞以调气、避毒气以自保，属古人防病方技，仅供文献理解。

---

### 0_2 使用建议与边界声明

#### 0_2_1 读法纪律

遗篇的"刺五俞、避毒气"是古代方技与观念，今人防疫与诊疗依靠现代医学与公共卫生，读此篇宜作"古人疫病观文献"与"运气学说专题补遗"来读。切勿当作可自操作的手册，更不可以此替代就医；凡涉及针刺，必须由合格医师施行，本文不构成任何医疗或预防建议。

#### 0_2_2 边界声明

运气可以算，结论却只是倾向。两条边界先立住：

- **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉都可逐字复核，但它对具体年份气候与疫病的"预测"属传统经验范畴，现代统计验证结果并不一致，只能当倾向假设，须用当年实际气象物候校正。
- **不可替代诊疗**：凡涉用药、针刺与防疫措施，一律以正规医疗与公共卫生指引为准；本册的"某气主某病"皆传统主张，只作学习与对照。

## 板块1 · 作者、年代与版本源流

遗篇最令人困惑的，是它"既在《素问》之中、又不在《素问》之中"的身份。这一板块梳理其"亡而复出"的文献轨迹、年代判定与版本选择，帮助读者把遗篇放在正确的史料位置上。

### 1_1 遗篇性质
"遗篇"之名，源于唐代王冰整理《素问》时称原书八十一篇中有数篇散亡，其中即包括《刺法论》与《本病论》，故后世称此二篇为"素问遗篇"或"亡篇"。今传文本并非王冰原本所录，而是后人据残文与运气学说补辑重出，因此它在性质上属于"依托《素问》框架的晚出专论"，而非与七篇同时成篇的先秦两汉旧文。读时须把"遗篇所论之理"与"遗篇成文之时代"分开看待，才不会在年代问题上纠缠不清。

### 1_2 成书年代
传统认为遗篇补入于宋代，其文字风格、术语习惯与七篇大论有明显差异：七篇偏重系统推演与格局铺陈，遗篇则更多方技口吻、禁咒意味与"三年化疫"之类的占验式表达。结合运气学说在宋代被立为太医局考试科目、相关专书层出的背景，遗篇很可能是那一阶段运气学"向下延伸到疫病预防"的产物。确定其绝对年代并无必要，把握"晚出、依托、专题化"三点即可。

### 1_3 版本流传与取用
遗篇多附于《素问》传本之后单独成卷，也有《素问遗篇》专本与丛书附刻流传。取用时以含遗篇的通行《素问》整理本为准，并注意不同版本在《刺法论》《本病论》文字详略上的差异。由于遗篇本就"补入"性质，校读时更宜留意其与前七篇术语是否严丝合缝——不吻合处恰是它作为"补遗"而非"正本"的证据，不必强行统一，反而可借此体会运气学说内部的层累过程。

## 板块2 · 核心主旨与内容梳理

把两篇合读，会发现它们是一体两面：《本病论》讲"疫从何来"，《刺法论》讲"疫如何防"，合起来构成运气学说里少见的"病机—治法"闭环。本板块按"本病→刺法→刚柔失守→与七篇衔接"四层梳理其主干。

### 2_1 《本病论》：气交失序与民病
《本病论》的核心是定义"本病"——并非个人调养失当所致，而是"气交之间，运气乖违"所生的大众之病，亦即古人语境中的"疫"。它反复强调天地上下之气当交而交、当迁而迁；一旦"不迁正、不退位""上下不交"，气便郁滞不行，进而在人群中表现为成片发病。原文所述把群体性疾患的源头直接挂到运气交接的失序上，这是遗篇区别于临床杂病论的独特视角，也是它最值得今人研读的"疫病观念史"价值。

### 2_2 《刺法论》：五疫之刺与避让毒气
《刺法论》承接"病"而来，给出可操作的应对：一是"刺五藏之俞"以调其气，针对木火土金水五疫各有所刺；二是"避其毒气"，留下"正气存内，邪不可干，避其毒气，天牝从来，复得其往"的著名文段，主张从口鼻（天牝）一道防住疠气。它把"运气致病"翻转成"运气防病"，是从理论到方技的关键一步，也补上了七篇大论几乎不谈"具体治法"的空白。

### 2_3 刚柔失守与三年化疫
两篇皆重"刚柔失守"：岁运之干（刚）与司天在泉之纪（柔）未能相应相守，便埋下郁气。原文所述，此类失守往往"三年化疫"——即当年运气失守，郁气蓄而不发，至第三年方骤然成疫。这把七篇"郁极而发"的抽象机制，具体化为可逐年推求的疫病时间窗，是遗篇最具辨识度的创说，也是它把"年度运气"与"跨年疫病"连起来的关键。

### 2_4 与七篇"胜复郁发"的衔接
遗篇所论的"疫"，可视为七篇"郁发"在人群层面的极端表现：某气久郁，发则为变，落于人便成疠。把"升降不前""迁正退位"挂回七篇的"气化失常"链条，遗篇就不再是孤立的方技残卷，而是七篇在瘟疫方向上的细化与补遗。同时其"刺法"部分偏方技传承，不必强求与推演严丝合缝，将其定位为"专题补遗"最为稳妥。

## 板块3 · 关键概念与术语体系

遗篇术语虽少，却个个是理解全篇的锁钥。本板块把五疫、气交、刚柔失守、升降不前、本病、刺法等核心词逐一拆开，建立一套可检索的概念表，便于后续推演与笔记。

### 3_1 五疫
五疫指因五运乖违而起的五类疫疠：木疫、火疫、土疫、金疫、水疫，各与一运相应。原文所述，五疫之气多从口鼻（天牝）而入，具有"相染"的群体特征，故治法上强调刺相应藏俞以泄其郁、并避其毒气。五疫是遗篇的中心病种，也是它"运气—瘟疫"交叉定位的落脚点，读懂五疫便读懂了遗篇大半。

### 3_2 气交
"气交"指天地上下之气的交接运行，是《素问》运气诸篇共有的核心意象。遗篇特别突出"气交失序"——上下不交、当迁不迁，则气化不行、郁而为民病。可以说，"气交"是遗篇一切病机的空间总框，"民病"则是其时间结果，二者一静一动，撑起全篇的因果骨架。

### 3_3 刚柔失守
"刚"约指岁运之干（阳刚之运），"柔"约指司天在泉之纪（阴柔之位）；二者当相守相应而失其配合，即为刚柔失守。原文所述，失守之年运气根基动摇，郁气潜伏，常演为"三年化疫"。它是遗篇把"年度运气"与"跨年疫病"连起来的关键概念，也是推演时第一个要判定的环节。

### 3_4 升降不前
"升"指气当升于上（如司天之气的升迁），"降"指气当降于下（如在泉之气的退位）；升降受阻、当位不至，便是升降不前。它与刚柔失守互为表里：失守是"根基错位"，不前是"运行受阻"，二者共同造成气郁化疫。遗篇对此有细致的各气"不迁正、不退位"分论，是气交失序的两种具体表现形态。

### 3_5 本病与刺法
"本病"谓非人自致、由气交失序所致的群体性疾病，与"客气客气客病"相对，强调病根在天时而非人事。"刺法"则是针对本病与五疫的应对方技：刺五脏之俞以调其气、择时远避以拒毒气。二者一病一治，构成遗篇"知病—防病"的主线，也最能体现它作为"运气防疫专论"的独有价值。

## 板块4 · 推演演示（含 ASCII 图）

遗篇的推演并不需要复杂排盘，它的核心是一张"运气失序→郁→疫"的因果图。下面用文字与 ASCII 示意，把五疫、气交、升降不前、三年化疫四条链路画清楚，读者可据此自绘笔记图。

### 4_1 气交—疫关联链
最精简的总链是"运郁/不承 + 气不交 → 气交失序 → 民病/五疫"。其含义是：当某一岁运被抑（不承）又与相应客气失交，天地气化便失序，郁气不得疏泄，进而在人群中化为疫疠。这条链可视为遗篇全部推演的"母图"。

```
        五运不承 + 六气不交
               │
               ▼
         气交失序（上下不交）
               │
               ▼
         气机郁滞不行
               │
               ▼
         民病 · 五疫（相染）
```

### 4_2 五疫—五行对应示意
五疫各系于一运，推演时先定当年岁运与失守之运，再对应其疫。下方示意把五运与五疫一一挂接，并标出疠气从口鼻而入、相染于人群的路径。

```
        五运乖违（刚柔失守 / 不承）
   ┌─────┬─────┬─────┬─────┬─────┐
   木    火    土    金    水   （五运）
   │     │     │     │     │
 木疫  火疫  土疫  金疫  水疫  （五疫）
   └─── 疠气从口鼻（天牝）入，民病相染 ───┘
```

### 4_3 升降不前与三年化疫
升降不前是"运行受阻"，三年化疫是"失守蓄发"，二者联成遗篇最具特色的跨年推演。下图把"正常—失序—蓄发"三态并列，可直观看到气交如何由和转乱、由乱转疫。

```
正常：  司天(上) ═交═ 在泉(下)   → 气交和，民不病
失序：  司天(上) ╳不交╳ 在泉(下) → 升降不前，气郁为疫
              ↑
   刚柔失守（根基错位）→ 郁气潜伏 → 至三年 → 化疫暴发
```

### 4_4 推演要点小结
传统认为，遗篇推演的关键在于"先判失守、再定时窗、后定何疫"：当年岁运与司天在泉不相应为失守，失守后留心第三年的化疫可能，再据失守之运判定木火土金水哪一疫当先。此链可与七篇"郁发"互证，但须记住它属古人参考模型，非确定性预言，现代验证结果不一，不可机械套用。

## 板块5 · 与七篇及他书的承启异同

遗篇不是凭空而来，也非孤立方技。把它放进"七篇大论—遗篇—后世运气专书"的谱系里，才能看清它上承什么、补了什么、又与哪些书同中有异。本板块做三层比较。

### 5_1 上承七篇大论
遗篇直接承接七篇的"气化失常、胜复郁发、司天在泉、迁正退位"，是其在疫病专题上的展开。七篇给出格局与机制，遗篇把这些机制落实为"五疫"病种与"刺法"应对；尤其"郁发"在七篇是气候与物候的突变，在遗篇则明确化为人群疠气。可以说，遗篇是七篇理论"临床化、防疫化"的一次尝试，二者是框架与专题的关系，而非对立。

### 5_2 与《医学穷源集》的异同
明代《医学穷源集》以大司天论注解医案，重在"逐年病源"与个体病机的运气归因。遗篇则聚焦"气交失序之疫"——一种突发、群体、相染的疾患，二者虽都谈运气致病的层面，但一在个体/时令倾向、一在群体疫疠，病因观不在同一尺度，读时不可混为一谈，否则容易把"逐年体质倾向"误读成"瘟疫暴发预言"。

### 5_3 与后世方法论书的边界
清代《运气商》《运气辩》等专辨运气推演的适用边界，提醒勿机械套用。遗篇本身方技色彩浓、断言多，正需要这类"纠偏书"作伴读，以免把"刺五俞、避毒气"误读成可照搬的防疫规程。理想读法是以遗篇看古人的疫病想象，以方法论书看其限度，二者互补方能得其平。

## 板块6 · 案例佐证

下面以虚构人物"阿岚"的一段学习经历，演示如何把遗篇的"五疫/刺法"思路用于读文献与现代反思。请记住，故事仅为教学示例，其中的刺法思路不可用于实际自我操作。

### 6_1 阿岚的疫病读书笔记（虚构教学案例，不对应真实人物）
情境：阿岚在某年冬春之交注意到本地呼吸道疾患明显增多，翻阅运气旧籍时读到《本病论》"气交不交，民乃病"一句，便想验证"运气失序"与"群体发病"能否对应。问题：她初步查得当年岁运似有"不承"、又逢某气"不发"，与遗篇"郁则发为疠"的说法仿佛暗合，一时兴奋，几乎要把遗篇的"刺肝俞、避毒气"当成实用的防病方案记进笔记。用遗篇思路：师傅提醒她，遗篇的价值在于提供了"把群体性疾病挂回天时气化"的思考框架——先判气交是否失序、失守之运属哪一脏、对应木火土金水哪一疫，这套"病机归类"的脉络是可取的；但其中具体的针刺与避毒之法，属于古代方技与特定历史条件下的观念，不能在今天当作操作指南。结果：阿岚把遗篇重新定位为"古人疫病观文献与运气补遗"，在笔记里加注"古法参照，今用现代医学与公共卫生"，并只保留"气交失序→五疫归类"的推演练习。反思：本案例说明，遗篇最值得取的不是某条刺法，而是它"从运气格局解释瘟疫为何群发"的视角；凡涉及针刺，务必交由合格中医师操作，本文与案例均不构成任何医疗或预防建议。

## 板块7 · 笔记方法与多场景记录

遗篇内容短而跳跃，最怕读后即忘或读死。下面给出四种可落地的笔记场景，把遗篇挂回七篇、区分古今、标清层次，使这份材料真正进入你的知识库。

### 7_1 挂链笔记场景
读遗篇每出现一处"病/疫"论述，就把它挂回七篇"胜复郁发、迁正退位"的链条，并在页边标注"细化/新增/存疑"三档。例如"三年化疫"可标为"七篇郁发之跨年细化"，"刺五俞"可标为"遗篇新增方技"。如此遗篇不再是散句，而成了七篇脉络上的注释，日后温习一目了然。

### 7_2 古今对照场景
专开一页记录"古法刺避"与"今人防疫"的异同：左侧摘遗篇的避毒气、刺俞思路，右侧记现代公共卫生的隔离、疫苗、消毒逻辑。对照的目的不是比高下，而是防止把古代方技误当作现代手段，守住"文献—现实"的边界，避免误用古人方技。

### 7_3 文献分层场景
在笔记扉页标明"七篇源"与"遗篇补"的边界：七篇是框架正本，遗篇是依托补入的专题。凡遇术语不一致处，先判它属于哪一层，再决定是否纳入主推演体系，避免把补遗之语混入七篇原框架造成混乱，也便于向他人说明材料来源的可信层级。

### 7_4 观念史场景
把遗篇放入"古人对瘟疫的解释史"框架：从"气交失序"到"五疫相染"，看古人如何在缺乏微生物知识的条件下，用运气模型替群体疫病的"为何群发、何时群发"给出答案。这一视角能让遗篇脱离"灵不灵"的争论，回到它作为医学思想史料的价值，读来更从容。

## 板块9 · 现代意义、研究与延伸阅读

遗篇虽为古代方技，但其"群体病与天时失序相关"的思路，与现代生态—传染病学的某些取向可对话。本板块谈现代视角、阅读边界，并给出延伸书目。

### 9_1 现代视角
把"群体性疾病"与"环境/气候失序"相关联，与当代"新发传染病—生态失衡—气候异常"的探讨有遥相呼应之处；其"正气存内，邪不可干"也常被引申为"人群抵抗力与暴露控制"的古典表达。但必须说明，遗篇的具体刺法与避毒仪式属历史方技，现代防疫以流行病学与公共卫生为准，二者不可混同，古人框架只能作为思想史与方法论上的参照。

### 9_2 边界与提醒
遗篇涉及刺法与疫病，本文仅作古代文献与观念记录。传统认为的"三年化疫""五疫相染"属古人的参考模型，现代统计学验证结果不一，切勿机械套用或据以预测疫情。凡针刺类操作，必须由合格中医师施行；本文不构成任何医疗、诊断或预防建议，读者若有健康疑虑应咨询专业医师。

### 9_3 延伸阅读
上接《素问·运气七篇大论》（胜复郁发、迁正退位之正本）；平行可参《医学穷源集》（逐年病源与医案运气归因）；收尾宜读《运气商》《运气辩》（方法论边界与纠偏）。三层次连读，可由"框架—补遗—限度"完整把握运气学说对待瘟疫的思路，避免只取一端而失其全。
