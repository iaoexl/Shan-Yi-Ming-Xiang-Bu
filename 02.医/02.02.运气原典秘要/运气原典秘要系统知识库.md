# 运气原典秘要系统知识库

## README · 导览

> 本库以《素问》运气七篇大论为总根，以《太始天元册》残文为哲学底座，以《刺法论》《本病论》两遗篇为疫病专补，将三书打散重组为一套"可推演、可对照、可溯源"的运气学主题知识地图。它不逐本罗列，而按"总纲—基础—五运—六气—格局—病机—遗篇—推演—边界"的脉络组织，供研究者与临床参考者按主题检索、按路径进阶。
>
> 运气学的核心承诺是：以天干统五运、以地支统六气，把每年的气候、物候、病候纳入一套六十年可循环的推演框架。它是一套古人关于"天时—人气"相关性的模型化尝试，其价值在思想史与方法，不在确定预测。

### README_1 本知识库是什么

- 性质：中医运气学（五运六气）原典文献的专题整理，定位为"传统医学参考模型"的学习与研究资料，而非诊疗手册。
- 主源：《刺法论》与《本病论》（素问遗篇）、《太始天元册》、《素问·运气七篇大论》三本读书笔记及其同名书籍底本。
- 辅证：抽取《五运六气系统知识库》《中医系统知识库》中与"运气原典秘要"直接相关的段落交叉印证，不作全文照搬。
- 组织逻辑：以主题板块替代"逐本罗列"。例如"天干化五运"这一知识点在三书中分见，本库统一收归"干支与运气基础"板块，注明其分别源自七篇与遗篇。

### README_4 心法/核心方法

1. 以"气"为本：五运阴阳皆气化之流，不是给气候贴标签，而是认为气候本就是气化运行——这是运气敢以干支推全年气化的本体论底气。
2. 常变合参：主运主气是"常"（固定基准），客运客气是"变"（当年异常）；判一年须常变对照，单看一层必偏。
3. 倾向而非定律：岁运、司天在泉是可复核的规则，但其对气候与疫病的"预测"属传统经验范畴，只作概率性倾向，须以当年实际气象物候与个体辨证校正。

### README_5 易被忽略的前提

1. 七篇晚出、自成体系：运气七篇虽托名黄帝，实非与《素问》主体同期成篇，带有汉魏以后术数色彩；它既是《内经》家族成员，又可单独抽离发展为"运气之学"。
2. 佚书与遗篇皆非完帙：《太始天元册》仅存《素问》引文百余字，所有"宇宙论全貌"皆属后世有限重构；《刺法论》《本病论》为宋人补辑依托之"遗篇"，读时须把"所论之理"与"成文之时代"分开。
3. 运气只占"因时"一维：三因制宜中，运气对应"因时"，须与"因地"（方土）、"因人"（体质脉证）合参，舍脉证而执运气即失其本。

> 本库是通往《素问》运气原典的一张地图，而非地图所绘的疆域本身；读通七篇，方能知后世每一部运气书在整体系统中的位置。

## 板块0 · 学习路径和建议

> 运气七篇卷帙浩繁、术语密集，遗篇义理跳跃，天元册又仅余残影。初学者最易陷入"逐字训诂而不得其要"或"凭想象补亡书"的两端。本板块给出由总到分、由框架到细则的路线，并立住两条边界。

### 0_1 学习路径（分阶段）

第1阶段，先立总纲：读《天元纪大论》与《太始天元册》引文，拿到"五六相合"的坐标轴与"气本体论"底座，明白为什么气候可用五运阴阳统摄。

第2阶段，备齐零件：读《五运行大论》（五运、客运、五气经天）与《六微旨大论》（六气、气交、升降出入），建立"运"与"气"两套零件库。

第3阶段，学算五运：读《气交变大论》《五常政大论》，掌握太过、不及、平气三纪及灾眚方位、地域修正。

第4阶段，学算六气：以年支推司天在泉、布客气六步，再与《六元正纪大论》逐年表对照，练"客主加临"。

第5阶段，落到病机：读《至真要大论》病机十九条与淫胜治法，并把遗篇《本病论》《刺法论》当作"疫疠专补"收口。

第6阶段，推演校验：拿任意年干支手算一遍，与原书逐年表对一遍，错处即回炉重读的环节。

### 0_2 使用建议与边界声明

#### 0_2_1 使用建议

- 先框架后细则：未搭骨架前不急于背逐年表；先能闭眼排出"天干化运""地支司天"两套口诀，再进逐年推演。
- 佚书严分引/推：读《太始天元册》必须把"引文"（加引号、标篇目）与"推断"（标"推"）两栏隔离，凡无引文直接支撑的环节一律不写入主旨。
- 遗篇定位为"文献"：把《刺法论》的刺五俞、避毒气视为古人疫病观的方技记录，不作可自操作的手册；针刺必须经合格中医师施行。
- 始终以"倾向"归档：所有"某运易致某病"的表述，笔记中加"参考模型"标注，避免把相关性误读成因果。

#### 0_2_2 边界声明

本知识库为中医运气学文献与文化整理，不构成现代医学诊断、治疗或用药建议；运气推演与养生须在合格中医师指导下参考，切勿据此自行诊断、用药或施针；急重症请及时就医。

运气可以算，结论却只是倾向。两条边界先立住：

- **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉都可逐字复核，但它对具体年份气候与疫病的"预测"属传统经验范畴，现代统计验证结果并不一致，只能当倾向假设，须用当年实际气象物候校正。
- **不可替代诊疗**：凡涉用药、针刺与防疫措施，一律以正规医疗与公共卫生指引为准；本册的"某气主某病"皆传统主张，只作学习与对照。

> 立即可做动作：取一张纸，默写"甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火"，并标出阳干（太过）/阴干（不及），作为入门第一份随身卡。

## 板块1 · 运气学总纲、宇宙论根基与文献源流

> 运气学不是凭空算法，而是"气化宇宙论"的应用分支。本板块先确立七篇为总根，再以《太始天元册》残文为其哲学底座，最后理清成书年代与版本取用，帮助读者把三书放进正确史料位置。

### 1_1 运气学的总定位与七篇大论

《素问》"运气七篇大论"含《天元纪大论》《五运行大论》《六微旨大论》《气交变大论》《五常政大论》《六元正纪大论》《至真要大论》七篇，约当《素问》卷十九至卷二十二，由唐代王冰编次析出。它是五运六气理论的源头与标准文本，被后世尊为"运气之学"的总说明书。

七篇的内在逻辑是层层递进的：**天元纪**立"五六相合"之总纲；**五运行**与**六微旨**分别备齐"五运零件"与"六气零件"；**气交变**与**五常政**专论五运的常变与地域修正；**六元正纪**把零件组装成六十年逐年总表；**至真要**把逐年气候偏性翻译成病机与方药的临床语言。其回路为：

```text
框架(天元纪) → 零件(五运行·六微旨) → 五运常变(气交变·五常政)
            → 纪年总表(六元正纪) → 治则方药(至真要)
            = 天干地支 → 岁运客气 → 气候偏性 → 脏腑病候 → 治法方药
```

七篇所引《太始天元册》文，把运气提升到"天文—历法—气化"相统一的层面，是整套学说得以成立的哲学底座。凡后世运气书（玄珠密语、运气易览、圣济总录、医学穷源集等）的术语与算法，几乎都从这里取用或发挥；读通七篇，再回头看任何一部运气书，都能迅速定位它在整体系统中的位置。

> 自检问题：能否用一句话说明"七篇为什么能被后世不断展开为各种运气专著"？

### 1_2 宇宙论根基：太始天元册的气本体论

《太始天元册》是一部早佚的古天文之书，不以医书名世，今仅存《素问·天元纪大论》所引零星文字，最著名的一段为：

> 原典："太虚寥廓，肇基化元，万物资始，五运终天，布气真灵，总统坤元，九星悬朗，七曜周旋，曰阴曰阳，曰柔曰刚，幽显既位，寒暑弛张，生生化化，品物咸章。"

白话释义：宇宙本始于太虚之气，太虚肇建化育之本元，万物由此资生，五运终而复始运行于天；真灵布气、统摄地元，九星悬朗、七曜周旋，阴阳刚柔各得其位，寒暑弛张有序，生生不息而万物彰明。其核心主张是一条宇宙生成链——**太虚（本始之气）→ 化元（化育本元）→ 五运阴阳（天地之道）→ 岁气·万物（含人形）**。

这条链等于宣布"气"是唯一本体，形质、动静、寒暑皆是其显化。七篇借其口吻说"五运阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始"，把五运阴阳抬到"道"的高度——它不只是推算工具，而是宇宙运行的根本节律。运气七篇之所以敢以干支推演全年气化，底气正来自这种"五运阴阳即天道"的本体论自信。

读此佚书有一条铁律：**严格区分"引文"与"推断"，绝不把推断当原典**。原典只说得出百余字，便只认百余字；多出来的体系，必须老老实实标"推"。据引文可立之说极为有限：气本体、五运阴阳为道、天地动静二分，大致如此。凡企图把本书补成一部完整宇宙论的尝试，都难免"以意逆志"之失。

> 立即可做动作：把上面生成链画成一张图，只填有引文支撑的环节，补接处标"推"，体会"百余字足以撑起一座哲学序言"。

### 1_3 文献源流、版本与历史脉络

- **成书与补入**：七篇托名黄帝、岐伯问答，实为战国至汉魏间陆续形成、经后人整理的文本。唐代王冰注《素问》时将其编入，并明确说七篇"辞理秘密，难粗论述"。王冰同时附《刺法论》《本病论》两遗篇，后世普遍把这一事件视为运气学说正式确立的标志。
- **晚出色彩**：学界一般认为七篇成篇晚于《素问》主体，受汉代浑天说、谶纬气化思想影响，"五六相合"的历法化表述带有明显秦汉以后术数色彩；这恰说明它是古人长期熔天文、历法、物候、医理于一炉的集大成，是理论成熟而非草创。
- **版本取用**：今本以王冰次注、林亿等校正的《重广补注黄帝内经素问》为通行底本；宋以后张介宾《类经》、高世栻《素问直解》各有发挥。推演练习宜备带"六元正纪"逐年表的注本，以便随时校验。
- **遗篇的补辑**：《刺法论》《本病论》在王冰时已称亡缺，今传文本一般认为宋代方才补入或重辑，行文带较浓方技与禁咒色彩，属"依托《素问》框架的晚出专论"。读时把"遗篇所论之理"与"遗篇成文之时代"分开，其术语与前七篇不吻合处，正可借此体会运气学说内部的层累过程。
- **后世流变**：北宋太医局列运气为考试科目，官修《圣济总录》以六十年运气图置全书首卷；金元刘完素以"亢害承制"阐发火热病机；明汪机《运气易览》图表化入门；王肯堂《医学穷源集》立"大司天"通代注解；清《运气商》《运气辩》起而纠偏。主旋律是"既应用、又反省"。

> 自检问题：为什么说"七篇读通，其余各书只是顺流而下、各取一枝"？试举一部后世运气书，说明它展开的是七篇的哪一侧。

## 板块2 · 干支与运气基础：天干化五运、地支化六气

> 正式推演"运"与"气"之前，必须先备齐两套算具——天干与地支。它们既是纪年符号，也是把"某一年"翻译成"某种气化属性"的接口：天干通往五运（岁运），地支通往六气（客气与司天在泉）。本板块讲透阴阳配对规则与两张核心口诀。

### 2_1 天干地支与阴阳配对

干支是整套推演的输入变量，必须能随手排出六十甲子表。其阴阳判定规则如下：

- 天干阴阳：阳干为甲、丙、戊、庚、壬；阴干为乙、丁、己、辛、癸。
- 地支阴阳：阳支为子、寅、辰、午、申、戌；阴支为丑、卯、巳、未、酉、亥。
- 记忆整句口诀："甲丙戊庚壬阳，乙丁己辛癸阴；子寅辰午申戌阳，丑卯巳未酉亥阴。"把天干、地支各自的阴阳各记成一组，再套用"奇偶同配"的配对法则，就能对任意组合做合法性检验。

这套阴阳判定是后面"太过、不及"与"司天在泉"的共同前置功夫：阳干主太过、阴干主不及；阳支、阴支则参与客气与间气的顺逆判定。

### 2_2 天干化五运（岁运推导）

岁运（中运、大运）统管全年气候基调，由年干按"天干化五运"推出。这是全书最基础的输入规则，必须滚瓜烂熟：

```text
天干化五运：
  甲己 → 土     乙庚 → 金
  丙辛 → 水     丁壬 → 木
  戊癸 → 火
阳干(太过)：甲 丙 戊 庚 壬
阴干(不及)：乙 丁 己 辛 癸
太过称"太"（太角·太徵·太宫·太商·太羽），
不及称"少"（少角·少徵·少宫·少商·少羽）。
例：甲子年，年干甲(阳)化土 → 太宫（土运太过），统全年湿土偏盛之基调。
```

核心要点：岁运之"太过/不及"由天干阴阳决定（阳干太过、阴干不及）；若受司天之气克制或扶助，则可转归平气，气候相对平和。

### 2_3 地支化六气与司天在泉（六气推导）

六气（风、热/君火、火/相火、湿、燥、寒）的客气由年支开启，并标出"司天（上半年主令，固定压在客气三之气）、在泉（下半年主令，固定压在客气终之气）、左右间气"的上下左右空间关系：

```text
地支化气（司天在泉的根）：
  子午 → 少阴君火司天，阳明燥金在泉
  丑未 → 太阴湿土司天，太阳寒水在泉
  寅申 → 少阳相火司天，厥阴风木在泉
  卯酉 → 阳明燥金司天，少阴君火在泉
  辰戌 → 太阳寒水司天，太阴湿土在泉
  巳亥 → 厥阴风木司天，少阳相火在泉
规律：在泉 = 司天之对面（三阴对三阳，按子午→巳亥六组固定配对）。
例：甲子年支"子" → 少阴君火司天，统上半年；阳明燥金在泉，统下半年。
```

读这张盘的方法是：先定司天压在三之气，再定在泉在与之相对的终气侧，四间气补齐其余四步。初学最常见的错，是先算客气、后补司天，结果六步全乱——务必先司天后客气。

> 立即可做动作：取任意年份（如2024甲辰、2025乙巳），按2_2、2_3各推一次岁运与司天在泉，并标出阳干/阴干、太过/不及。

## 板块3 · 五运体系：岁运·主运·客运与三纪

> 五运指木火土金水五种气化在"运"层面的运行，是"年尺度"的气候动态模型。本板块厘清岁运、主运、客运三个层次，以及太过、不及、平气三纪，并接通五运与五藏的虚实相应。

### 3_1 五运的层次：岁运、主运、客运

- **岁运（中运、大运）**：统管全年基调，由年干按"天干化五运"推出，决定这一年"大气候"属哪一行。
- **主运**：一年五步固定递变之"常"，体现木火土金水依次主时的常规气候流转，不受年干影响。
- **客运**：每年在固定主运之外轮转的动态之运，反映当年异常增减之"变"，随岁运而迁。

"常中有变"是五运模型的精髓：主运给出基准轴，客运叠加其上显出当年偏性。如《五运行大论》所言"气相得则和，不相得则病"，为后来客主加临判定埋下伏笔。

### 3_2 太过、不及、平气三纪

岁运盛衰分三态：

1. **太过**：阳干所主（太角、太徵、太宫、太商、太羽），该行气化偏盛。
2. **不及**：阴干所主（少角、少徵、少宫、少商、少羽），该行气化偏衰。
3. **平气**：太过被司天所克、或不及被司天所助，转归平和，灾病较轻。

《气交变大论》用"德、化、政、令、灾、变"六种表现描述每一运的正常与失常；《五常政大论》把每运分为平气、太过、不及三类常态（即"三纪"），补足前篇只分两态的粗略，并补入"地域高下"修正——同一岁运，高山与平原、东方与西方实际气候并不雷同，提醒模型须与地理结合，不可刻舟求剑。

### 3_3 五运与五藏相应（运藏虚实）

五运分别落到肝、心、脾、肺、肾五藏：木运应肝、火运应心、土运应脾、金运应肺、水运应肾。岁运太过则本藏气实、不及则本藏气虚，且"太过者本藏实而乘其所胜，不及者本藏虚而所不胜乘之"。例如：

```text
岁运   太过(本藏实)        不及(本藏虚)
木     肝实风盛、脾受克     肝虚、燥金乘之
火     心实热盛、肺受克     心虚、寒水乘之
土     脾实湿盛、肾受克     脾虚、风木乘之
金     肺实燥盛、肝受克     肺虚、火热乘之
水     肾实寒盛、心受克     肾虚、湿土乘之
```

这套"运偏则藏虚实随之"的说法，临床味明显比单纯框架推演更浓，是把"运"通向"方"的环节（《五常政大论》提出"气之上者抑之、下者举之"的补泻随运思路）。

> 自检问题：以"土运太过"为例，说出本藏虚实、所胜受克之脏，以及《五常政》提示的地域修正意义。

## 板块4 · 六气体系：主气·客气·司天在泉·标本中气

> 六气指风、热（君火）、火（相火）、湿、燥、寒六种气化，是"半年/六步"的气化模型。本板块拿下主气六步之"常"、客气六步与司天在泉之"变"，以及标本中气的从化关系。

### 4_1 主气六步（常）

主气一年六步固定运行，体现"春温夏热长夏湿秋燥冬寒"之常，起点永远锁在大寒后的厥阴风木，顺序与三阴三阳相生一致：

```text
        初气    二气    三气    四气    五气    六气
主气：  风木    君火    相火    湿土    燥金    寒水
        (大寒)  (春分)  (小满)  (大暑)  (秋分)  (小雪起)
```

主气是"常"的参照轴，客气、司天在泉都要叠加在这条基准线上读"偏了多少、移到哪步"。

### 4_2 客气六步与司天在泉定位

客气随年支轮转，反映当年异常。其排布以"司天定三气、在泉定终气"为锚：

```text
        初气      二气      三气      四气      五气      六气
客气：  (在泉左间)(在泉)   (司天左间)(司天)   (司天右间)(在泉右间)
判定：  客主相得与否 → 气候顺逆
        （客气六步以司天为三之气、在泉为终之气，向上下逆推布列）
```

例如甲子年：三之气司天君火 + 主气相火 → 客主同气相得，夏火偏盛；终之气在泉燥金 + 主气寒水 → 燥寒相临，冬燥偏显。司天在泉定出后，该年上下半年的气化主轴便清晰，间气则用于细化各步偏性。

### 4_3 标本中气与从化

六气各有"本、标、中气"的从化关系，是解释六气为何会"从本、从标、从中"而表现出不同病性的关键术语。简言之：

- **本**：指六气自身的气化属性（风化、热化、火化、湿化、燥化、寒化）。
- **标**：指其所属的三阴三阳之位。
- **中气**：与本气互为表里的中见之气的气化。

例如少阳之上，火气治之，中见厥阴；阳明之上，燥气治之，中见太阴。明白标本中气，才能理解同一"火"在不同从化下既可显为热盛、亦可显为寒象的复杂病性，也为"病机十九条"的归属提供理论依据。

> 立即可做动作：画一张"主气六步 + 甲子年客气六步"对照图，逐气步标注客主"相得/不相得"。

## 板块5 · 客主加临与运气相合格局

> 把"运"（板块3）与"气"（板块4）合参，是推演落到一年气候—病候倾向的关键一步。本板块讲客主加临的相得与否、运气相合的特殊格局，并补入《至真要大论》的南政北政与脉不应之律。

### 5_1 客主加临的相得与否

客主加临指把"客气"叠加到"主气"之上，逐气步比较二者相得或不相得，以判定当年气候是顺是逆、何处易生冲突：

- **相得**：客主同气或相生（如木客加风主、火客加君主），气候和缓。
- **不相得**：客主相克（如燥金客加君火主），气候乖戾、疾病易作。

其判定结果须与岁运、司天在泉合参，方能对一年的气候—病候倾向得出较稳判断，单看一层容易偏颇。

### 5_2 天符、岁会、太乙天符、同天符、同岁会、平气

五运与六气合参，会形成若干特殊格局，用于判断一年气化是偏盛、专一还是平和：

```text
格局        判定条件（原文所述）                气化意义
天符        岁运之干与司天之支五行同          天气与岁运相符，气化偏盛
岁会        岁运与岁支（年支）五行同          运气与岁支相符，气化专一
太乙天符    天符且岁会（运、司天、岁支皆同）   气化最盛，原文述其致病力强
同天符      阳年（太过）岁运与在泉五行同      运气与在泉相符
同岁会      阴年（不及）岁运与在泉五行同      运气与在泉相符
平气        太过被司天所克，或不及被司天所助  气化平和，灾病较轻
用法：先定岁运五行、司天/在泉五行、岁支五行，再逐格比对，得当年所属格局。
```

传统认为天符、岁会、太乙天符气化较盛、致病力较强，须格外留意；平气则灾病较轻。这些格局的判别，是"运"与"气"合参后的高阶读出。

### 5_3 南政北政与脉不应（补《至真要大论》脉应气）

《至真要大论》另立"南政北政"之律，把运气接到脉诊的"手感"上，是七篇中"运—气—脉"相参的关键一节：

- **南政**：岁运为甲己土运之年（土居中央，面南行令），其气认"司天"。
- **北政**：其余乙庚金、丙辛水、丁壬木、戊癸火之年，其气认"在泉"。

原典述其脉"不应"（沉细伏、似不应指）之部位随司天/在泉之三阴而异：

> 原典："北政之岁，少阴在泉，则寸口不应；厥阴在泉，则右不应；太阴在泉，则左不应。南政之岁，少阴司天，则寸口不应；厥阴司天，则右不应；太阴司天，则左不应。诸不应者，反其诊则见矣。"

白话释义：北政之年以在泉定不应之位（少阴在泉则寸口不应，厥阴在泉则右寸不应，太阴在泉则左寸不应）；南政之年以司天定不应之位（少阴司天则寸口不应，厥阴司天则右寸不应，太阴司天则左寸不应）；"不应"之脉，翻转诊法（如覆手、易位）则可见其真象。更细一层，司天统上半年气化、多应于寸部，在泉统下半年气化、多应于尺部，把时间（上下半年）与空间（寸尺部位）叠进脉诊，使运气有了逐年、逐季的"手感"对照。读此须始终以"倾向"而非"必然"对待，且脉诊终须合参证、体、地，不可单凭运气断脉。

> 自检问题：甲己土运之年属南政还是北政？其"寸口不应"出现在司天为哪一气时？

## 板块6 · 气化机制与病机治则

> 运气不只是排盘，更要解释"气如何失衡、病如何生出、该怎样治"。本板块串起气交升降（六微旨）、胜复郁发（气交变·五常政）、病机十九条（至真要）与司天在泉淫胜治法，形成从天道回落人道的桥梁。

### 6_1 气化、气交与升降出入（六微旨）

《六微旨大论》定义六气及其标本中气关系，并强调"气化"是气候与生命变化的根本动力。它提出"升降出入"四字与"气交"概念：

> 原典："升降出入，无器不有。""气交之分，人气从之。"

白话释义：任何形体（器）都离不开气的升、降、出、入四类基本运动；天地之气交会于人与万物居处之间（气交之分），人直接受此交会之气左右。这是理解一切岁气作用于人体的理论枢纽——不是孤立谈天、也不是孤立谈人，而是把人放在"天地气交"这个动态场中去理解健康与疾病。

### 6_2 胜复郁发（气交变·五常政）

"胜"为某气偏盛而乘克他气，"复"为受克之气起来报复，"郁"为气被抑而不得发，"发"为郁极而突发变异。这是运气解释"气如何失衡"的核心机制：

- 某运太过则胜其所胜，所不胜来复；某运不及则所胜妄行、所不胜乘之。
- 气被抑而久郁，至一定时机"郁发"，表现为气候突变与物候异象。
- 《六元正纪》兼论"气化有常、有变、有郁发"，把胜复郁发的动态机制嵌入逐年框架，使静态年表具备预测气候突变与疫病起伏的弹性。

这一机制在人群层面的极端表现，就是遗篇所论的疫疠（见板块7）。

### 6_3 病机十九条（至真要大论）

病机十九条把症状归到五脏与六气，是运气推演落到临床辨证的接口。它分"五脏病机"与"六气病机"：

- 五脏病机示例："诸风掉眩皆属于肝、诸寒收引皆属于肾、诸气膹郁皆属于肺、诸湿肿满皆属于脾、诸热瞀瘛皆属于火（心）。"
- 六气病机示例："诸痛痒疮皆属于心、诸痿喘呕皆属于上、诸厥固泄皆属于下、诸痉项强皆属于湿、诸暴强直皆属于风、诸病水液澄澈清冷皆属于寒。"
- 属火、属热者尤多："诸禁鼓慄如丧神守皆属于火、诸逆冲上皆属于火、诸躁狂越皆属于火、诸病胕肿疼酸惊骇皆属于火；诸胀腹大皆属于热、诸病有声鼓之如鼓皆属于热、诸转反戾水液浑浊皆属于热、诸呕吐酸暴注下迫皆属于热。"可见火热的辨识在临证中份量极重。

掌握十九条，等于拿到一张"症状→归属"的速查表，遇症先定其脏其气，再回当年岁气看是否相印证，是运气落地的第一步。

### 6_4 司天在泉淫胜治法与气味配伍

《至真要大论》讲司天在泉淫胜时的治法，据六气之性给出寒热温凉反佐的配伍思路，使推演真正收口于"该怎么治"：

> 原典示例："风淫所胜，平以辛凉""热淫所胜，平以咸寒"。

白话释义：风气淫胜（如风木司天太过），以辛凉之品平之；热气淫胜，以咸寒之品平之。其余诸气各有对应平治之味，并据标本中气定"从本、从标、从中"的用药取向。《圣济总录》等后世方书即把"运＋气→病机倾向→选方"的链条落成逐年方册（如土运偏盛之年多佐苦燥以祛湿，木运不及之年多辛甘以助木），但须警惕"按年查方"的机械套用——真正可取的态度是借其方味规律反观临床、佐以辨证。

> 立即可做动作：取"皮肤干燥、干咳少痰"一条，用病机十九条归入"燥金（肺）"，再回当年岁气看是否相印证，养成"先定位、后归因"的习惯。

## 板块7 · 遗篇专论：五疫、三年化疫与气交失序

> 遗篇《刺法论》《本病论》是七篇在瘟疫方向上的专门补遗。它把"胜复郁发"抽象机制落到"五疫"病种与"气交失序"的群体发病观上，并给出刺法的古代方技。本板块按"性质—本病—刺法—失守—谱系"梳理。

### 7_1 遗篇性质与成书

"遗篇"之名，源于王冰整理《素问》时称原书数篇散亡，其中即包括《刺法论》《本病论》。今传文本并非王冰原本所录，而是后人据残文与运气学说补辑重出，性质上属"依托《素问》框架的晚出专论"，而非与七篇同时成篇的先秦旧文。其文字风格、术语习惯与七篇有明显差异：七篇偏重系统推演，遗篇更多方技口吻、禁咒意味与"三年化疫"式占验表达，很可能是宋代运气学"向下延伸到疫病预防"的产物。读时把"遗篇所论之理"与"遗篇成文之时代"分开，方不失其史料位置。

### 7_2 本病论：气交失序与民病

《本病论》的核心是定义"本病"——并非个人调养失当所致，而是"气交之间，运气乖违"所生的大众之病，亦即古人语境中的"疫"。原典反复强调天地上下之气当交而交、当迁而迁；一旦"不迁正、不退位""上下不交"，气便郁滞不行，进而在人群中表现为成片发病：

> 原典："气交失易位，气交乃变，变易非常，即四失序，万化不安，变民病也。"

白话释义：气交的位置发生错易，气化随之变异，变异超出常度，便是"四失序"，万物生化不安，转而为民众之病。这是遗篇区别于临床杂病论的独特视角，也是它最值得今人研读的"疫病观念史"价值。

### 7_3 刺法论：五疫之刺与避毒气

《刺法论》承接"病"而来，给出可操作的应对：一是"刺五藏之俞"以调其气，针对木火土金水五疫各有所刺；二是"避其毒气"。原典留下著名文段：

> 原典："正气存内，邪不可干，避其毒气，天牝从来，复得其往。"

白话释义：体内正气充实，则邪气难以侵犯；并须避开疠毒之气，疠气多从口鼻（天牝）一道侵入，防住这道门户，邪气来而复去、不得停留。它把"运气致病"翻转成"运气防病"，补上了七篇大论几乎不谈"具体治法"的空白。须强调：其中刺法与避毒仪式属古代方技与特定历史条件下的观念，不能在今天当作操作指南；凡涉及针刺，必须由合格中医师施行。

### 7_4 刚柔失守、升降不前与三年化疫

遗篇最具辨识度的创说，是"刚柔失守"与"三年化疫"：

- **刚柔失守**：岁运之干（刚）与司天在泉之纪（柔）未能相应相守，运气根基动摇，郁气潜伏。原典："刚柔二干，失守其位，使天运之气皆虚乎？……天地迭移，三年化疫。"
- **升降不前**：气当升于上（司天升迁）或降于下（在泉退位）而受阻，当位不至。它与刚柔失守互为表里——失守是"根基错位"，不前是"运行受阻"，共同造成气郁化疫。
- **三年化疫**：此类失守往往当年不发，郁气蓄而不发，至第三年方骤然成疫。这把七篇"郁极而发"的抽象机制，具体化为可逐年推求的疫病时间窗，把"年度运气"与"跨年疫病"连了起来。

其因果总链可浓缩为：

```text
        五运不承 + 六气不交
               │
               ▼
         气交失序（上下不交）
               │
               ▼
         气机郁滞不行
               │
               ▼
         民病 · 五疫（相染）
```

五疫各系于一运：木疫、火疫、土疫、水疫、金疫，疠气多从口鼻（天牝）而入，具有"相染"的群体特征。原典："五疫之至，皆相染易，无问大小，病状相似。"推演关键在于"先判失守、再定时窗、后定何疫"：当年岁运与司天在泉不相应为失守，失守后留心第三年的化疫可能，再据失守之运判定木火土金水哪一疫当先。

### 7_5 遗篇在运气谱系中的位置

遗篇直接承接七篇的"气化失常、胜复郁发、司天在泉、迁正退位"，是其在疫病专题上的展开；二者是框架与专题的关系，而非对立。它与《医学穷源集》（逐年病源、个体病机归因）尺度不同——一在群体疫疠、一在个体时令倾向，读时不可混为一谈，否则易把"逐年体质倾向"误读成"瘟疫暴发预言"。遗篇方技色彩浓、断言多，正需《运气商》《运气辩》一类纠偏书作伴读，以见其限度。理想读法是以遗篇看古人的疫病想象，以方法书看其边界，二者互补方得其平。

> 立即可做动作：在笔记扉页标"七篇源 / 遗篇补"边界，凡遇遗篇术语与七篇不一致处，先判其属于哪一层，再决定是否纳入主推演体系。

## 板块8 · 原典推演演示与排盘自测

> 运气学的精髓在于"可算"——给定某一年干支，就能推出岁运、司天在泉与客主加临，进而得到气候与病候倾向。本板块给出总链、甲子年示范、五疫推演图与自测题，读者可拿任意年份照此手推。

### 8_1 推演总链（由年干支到气候病候）

```text
输入：年干支
  ├─ 年干 → 天干化五运 → 岁运(太过/不及/平气)
  └─ 年支 → 地支化六气 → 司天(三气)·在泉(终气)·间气
            ↓
  布客气六步，叠加主气六步 → 客主加临(相得/不相得)
            ↓
  合参岁运 + 司天在泉 + 客主加临 + 格局(天符/岁会/平气…)
            ↓
  出趋势判断：该年气化偏在哪、易留意哪类病证
  （须标注"参考模型、须结合辨证与地域"，不得写成确定性断言）
```

### 8_2 甲子年手算示范

```text
第1步 岁运：年干"甲" → 甲己化土，甲为阳干 → 太宫（土运太过），全年湿土偏盛。
第2步 六气：年支"子" → 子午少阴君火司天 → 在泉：阳明燥金（统下半年）。
第3步 客主加临：
        初气    二气    三气    四气    五气    六气
   主气 风木    君火    相火    湿土    燥金    寒水
   客气 燥金    寒水    风木    君火    湿土    相火
   三之气司天君火 + 主气相火 → 同气相得，夏火偏盛；
   终之气在泉燥金 + 主气寒水 → 燥寒相临，冬燥偏显。
第4步 格局：岁运土，司天君火，岁支子水，三者五行不同 → 非天符/岁会，为常岁。
结论：土太过 + 君火司天 → 湿气偏盛、火气司上，传统认为易见湿与热上蒸之候。
验证：与《六元正纪》"甲子"条原文比对，若岁运、司天在泉、客主加临一致，则算法已掌握。
```

### 8_3 五疫—三年化疫推演图（遗篇）

```text

失序：  司天(上) ╳不交╳ 在泉(下) → 升降不前，气郁为疫
              ↑
   刚柔失守（根基错位）→ 郁气潜伏 → 至三年 → 化疫暴发

   ┌─────┬─────┬─────┬─────┬─────┐
   木    火    土    金    水   （五运）

 木疫  火疫  土疫  金疫  水疫  （五疫）
   └─── 疠气从口鼻（天牝）入，民病相染 ───┘
```

## 板块9 · 阅读方法、边界声明与延伸研究

> 运气宜"读一遍、算一遍、对一遍"。本板块给出多场景笔记法、误读警示、现代研究视角与延伸书目，帮助把厚书读薄、把算法读熟，并始终守住"模型非定律"的底线。

### 9_1 笔记与多场景记录法

- **通读批注**：每篇标题下用一句话写"本篇解决什么问题"（如《天元纪》解决"五六为何相合"），比逐字抄原文高效；把"天干化运""地支司天"公式抄成随身卡，遇推算即抽卡核验。
- **推演练习**：拿具体年份手算，写在页边，再与《六元正纪》原文逐年表对照，错处即薄弱点；建"逐年推演表"（年干支、岁运、司天在泉、客主加临、所属格局五栏），连续推满六十年印象更深。
- **临床/体感对照**：把病机十九条做成"症状→归属"速查卡，遇症即查其脏其气，再回当年岁气印证；把自己或家人同年体感与"逐年病源"对照，记"倾向吻合/不符"并附注干扰项（地域、饮食、体质），形成可回头检视的体感档案。
- **佚书双栏**：读《太始天元册》必分"引文"（加引号、标篇目）与"推断"（标"推"）两栏隔离，使实料与重构一眼可分。
- **古今对照**：专页记录遗篇"古法刺避"与"今人防疫"异同，防止把古代方技误当现代手段。

### 9_2 边界声明与常见误读

本知识库为中医运气学文献与文化整理，不构成现代医学诊断、治疗或用药建议；运气推演与养生须在合格中医师指导下参考，切勿据此自行诊断、用药或施针；急重症请及时就医。

常见误读警示：

1. 把"太过不及"误读成吉凶断语——它只是气化偏盛偏衰的"运行态"，须始终以参考模型定位。
2. 把"某运易致某病之倾向"读成"某运必生某病"——后者是典型误读；遗篇"三年化疫"也可能被读成确定预言，其实属古人参考模型，非确定性疫病预报。
3. 把遗篇刺法、避毒仪式当作现代防疫法——属历史方技，现代防疫以流行病学与公共卫生为准。
4. 舍脉证而执运气——运气只占"因时"一维，须与"因地""因人"合参，方能落到辨证论治。

### 9_3 现代研究视角

近几十年有研究者从"气候统计学"角度回测运气格局与逐年气象、疫病的关系，结论多倾向"弱相关、非决定性"，即岁气给出的是概率性倾向而非必然结果。也有从"生物节律""时间医学"角度解读气化的学者，把六步、五运视作人体顺应自然周期的节律框架，尚属探索阶段。疫病建模方面，研究者常以历年运气格局（岁运太过不及、司天在泉、胜复郁发）回溯呼吸道、消化道传染病高发年份，作为公共卫生的历史参考维度之一。明代《医学穷源集》的"大司天"观则把六十年格局放大为更长时段的气运底图（传统以三元一百八十年为一套），用以解释某些病证在某一历史阶段格外多见——它提供"势"，当年运气提供"机"，二者合参方能断"证"，但仍须以脉证体质为实据，不可拿"大司天"三字直接断人。

### 9_4 延伸阅读书目

- 上接原典：《素问·运气七篇大论》（以王冰次注、林亿校正《重广补注黄帝内经素问》为底，配张介宾《类经》运气诸篇互参）、《太始天元册》（据《天元纪大论》引文及先秦两汉宇宙论文献《易传》《淮南子》互证）。
- 推演与图谱：《玄珠密语》（推演原理）、《运气易览》（图表上手）、《圣济总录·运气卷》（逐年方）、《医学穷源集》（逐年病源与大司天）。
- 方法纠偏：《运气商》《运气辩》（批判性边界，主张运气是"概然而非必然"的群体倾向，是"大略"而非"定数"）。
- 研究向：可关注"大司天"理论与时间医学、气象医学的交叉文献，但读时仍须守住"模型非定律"的底线。
