## 板块0 · 学习路径和建议

> 本书为清代唐宗海（字容川，1846—1897，四川彭县人）所著，成书于光绪十年（1884），凡八卷。作者因父、妻相继为血证所苦，遍览方书而自悟，终成此书。它第一次把"出血性疾病"当作一个**独立的系统学科**来建构：有生理、有病机、有治法次第、有分部位证治、有兼见证、有方解——是真正意义上的"血证学"。
>
> 本文不逐篇复述，而是**拆出骨架、提炼可操作规则、补入后世拓展**，重点回答三个问题：这本书真正"新"在哪里？四步法在具体出血场景中怎么走？哪些结论可以直接落到临床与生活化调理上？

### 0_1 学习路径

#### 0_1_1 这本书在体系里的位置

专科类。治血四步法（止血—消瘀—宁血—补血）的源头，"离经之血即为瘀"一句改写了整个血证治法。读法：先把四步的次序记死，再看每一步的禁忌与转折条件；次序颠倒比用错药更常见。

#### 0_1_2 与全库其他书的衔接顺序

1. 医学三字经、医学源流论——建立医学史与范式认知
2. 素问、灵枢选读——理论根基（藏象、经络、运气）
3. 神农本草经 + 药性赋 + 汤头歌诀——药性与方剂口诀
4. 伤寒论、金匮要略——辨证论治的实战主干
5. 温热论、温病条辨——补上温病一支
6. 景岳全书、血证论、类证治裁——各家学说与专科深入

### 0_2 使用建议与边界声明

#### 0_2_1 使用建议

- 四步次序记死：止血—消瘀—宁血—补血；临床最常见的错不是用错药，是次序颠倒。
- 每一步的禁忌与「何时转入下一步」的条件单独列一张表，那是全书最实用的部分。
- 「离经之血即为瘀」当总纲，遇血证先问一句「瘀在何处」，再谈补泻。
- 与《金匮》血痹虚劳篇对读，看唐宗海如何承接仲景。

本册是文献研读与学习笔记，不构成诊疗建议。读这本书时，有两条边界要守住：

专科内容的安全窗最窄：孕产哺育、婴幼儿、高龄体弱、急症重症，一律优先就医，不以本册内容自行处理。针刺、艾灸、放血、正骨等操作只在执业人员手中进行，自学只做识别与禁忌判断。

凡属急症重症、孕产哺育、婴幼儿与高龄体弱，或涉及有毒药物与十八反十九畏组合，一律先就医，不以本册内容自行处理。

## 板块1 · 为什么这本书值得反复读：三个底层突破

读懂《血证论》，先要抓住它比前人"多出那一块"。否则很容易把它误读成一本"止血方汇编"。

### 1_1 突破一：第一次把"血证"建成完整体系

此前医书论血，散见于伤寒、杂病、妇科之中，多为零星条目。唐容川则把一切与血相关的病——**血上干（吐、咳、衄）、血外渗（汗血、血箭、刀伤）、血下泄（便血、尿血、崩漏）、血中瘀（瘀血、蓄血、经闭）、失血兼证（痨、嗽、发热、怔忡）**——收拢在同一套生理—病机—治法逻辑下。卷一立总纲，卷二至卷五按"血的去向"分证，卷六专论兼见诸证，卷七、卷八详解方剂。

**实操启示**：面对任何出血或瘀血症，先判断它属于"向上奔迫 / 向外渗漏 / 向下走泄 / 内里停瘀"哪一类，再定治法方向。这个"定位先于定性"的思路，比一上来辨寒热虚实更优先。

### 1_2 突破二：把"水火气血"打通，提出"治血必治气、治血先治火"

> **原文核心句**：_人之一身，不外阴阳，而阴阳二字，即是水火，水火二字，即是气血……水即化气，火即化血。气与水，本属一家，治气即是治水；血与火原一家，知此乃可与言调血矣。_

他的推理链非常清晰：

- **气结则血凝，气虚则血脱，气迫则血走**——气的三种失常，对应血的三种病变；
- **气盛即为火盛，火升故血升，火降即血降**——所以"泻火即是止血"；
- 治气的关键在**脾胃**（后天气血生化之源），治火的落脚点常在**阳明胃腑**。

**这是全书最可落地的一条总纲**：上消化道出血、咳血、鼻衄，只要见"气火上冲"之势（面赤、心烦、脉数有力），核心动作永远是**降气、降胃、降火**；而不是堆砌止血炭药。

### 1_3 突破三：创立"脾阴学说"，打破了"补脾只补脾阳"的千年偏见

李东垣之后，医家重脾胃者多只知温补脾阳。唐容川用一个著名比喻扳正了这个偏：

> _"譬如釜中煮饭，釜底无火固不熟，釜中无水亦不熟也。"_

- 脾阳虚 → 水谷不化（釜底无火）→ 经典用四君子、理中辈；
- **脾阴虚 → 水谷仍不化（釜中无水）**→ 当以润燥、益血、滋脾阴，如麦冬养荣汤、甲己化土汤、四君子加黄精山药玉竹。

他甚至给出一个颠覆性的比例判断：**当补阳者十之二三，当补阴者十之八九**（《用药宜忌论》）。这对后世"阴虚内热型出血"的诊治影响极大——今天见慢性失血、口干、脉细数、大便干结者，思路多从此出。

```plain
   （急）     （标）    （防变）  （防复）   （固本）

```

### 2_2 横向：辨证三轴（任何一步都要同时考量）

| 轴 | 关键问题 | 实操抓手 |
| --- | --- | --- |
| **脏腑轴** | 病在何脏？ | 来路辨肺/肝，归宿在胃/冲脉，归根在脾肾 |
| **气血轴** | 气的状态？ | 结、虚、迫——决定用理气、补气还是降气 |
| **水火轴** | 火盛还是阳虚？ | 实火泻火，虚火滋阴，阳虚温摄 |

**"离经之血便是瘀血"**——这是横向轴里最反常识、也最实用的一句。世人误以为只有血块、紫黑色才算瘀，唐容川明确指出：_血初离经，清血也、鲜血也，然既是离经之血，虽清血鲜血亦是瘀血。_ 一经离脉，便与好血"睽绝不合"，还会**阻新血之化机**。所以"凡血证，总以去瘀为要"，且"清、凝、鲜、黑，总以祛瘀为先"。

**落地规则**：凡有出血史（哪怕只是一次鼻衄、经期血块多、跌打青紫久不退），一律要追问：有没有留瘀？舌下络脉是否迂曲、舌面有无瘀点、局部是否刺痛固定、肌肤是否甲错？有其一，即应在主方中加活血之品。

## 板块3 · 治血四步详解（核心章节，含原文、白话与实操）

> 原文蓝本为卷二《吐血》篇开头那段纲领性文字：_"惟以止血为第一要法……以消瘀为第二法……以宁血为第三法……以补虚为收功之法。四者乃通治血证之大纲。"_

### 3_1 第一步：止血 —— "存得一分血，便保得一分命"

#### 3_1_1 原文精要

> _"此时血之原委，不暇究治，惟以止血为第一要法。止之使不溢出，则存得一分血，便保得一分命。"_
>
> _"其法独取阳明……阳明之气，下行为顺……急调其胃，使气顺吐止，则血不致奔脱矣。"_

#### 3_1_2 关键病机辨析：来路不同，治法不同

唐氏对吐血来源有极精到的解剖级描述，这是实操中最容易被忽略的"定位法"：

| 出血来路 | 伴随征象 | 治主何脏 | 核心思路 |
| --- | --- | --- | --- |
| **由背脊 → 膈间 → 入胃**（重者有"辟辟弹指、漉漉有声"） | 胸背必痛 | **治肺为主** | 肺为华盖，位在背与胸膈 |
| **由两胁肋 → 油膜 → 小肠 → 逆入胃**（重则潮鸣有声） | 腰胁多痛 | **治肝为主** | 肝为统血之脏，位在胁下 |
| 无论何路，最终"吐出" | —— | **必责之于胃** | 冲为血海，其脉丽于阳明，治阳明即治冲 |

**实操金律**：上逆出血的止血，**本质是"降"**——降肺气、顺胃气、纳肾气，气下则血下。

#### 3_1_3 分型用药（止血阶段的四条路径）

| 类型 | 识别要点 | 代表方/药 | 加减要点 |
| --- | --- | --- | --- |
| **气实火旺**（占六七成） | 血色鲜红、心烦、脉数有力、便秘 | **泻心汤**（大黄、黄连、黄芩） | 血多加童便、茅根；喘满加杏仁、厚朴；血虚加生地、当归 |
| **血热妄行** | 发热、口渴、舌红绛 | **犀角地黄汤**（今多以水牛角代犀角） | 凉血止血主方 |
| **收敛止血**（轻证） | 出血量大或需炭药收涩 | **十灰散**、白及、三七 | "红见黑即止"之意，炭药炒黑存性 |
| **虚脱（气随血脱）** | 喘促昏愦、神气不续、六脉细微散数 | **独参汤**（大补元气固脱） | 危脱之证，非血药所治 |
| **阳虚失摄**（十中一二） | 手足清冷、便溏遗溺、脉微迟、面色惨白 | **甘草干姜汤** | "阳不摄阴，以阳和而阴血内守" |

**最容易踩的坑**：把"吐血=虚证"当前提。唐氏特别强调，初吐时**邪气最盛，正虽虚而邪则实**，"不去其邪，愈伤其正，虚者益虚，实者愈实"。泻心汤"实则泻胃"，大黄一味"能推陈致新，降气即以降血"——今人多不敢用，他叹曰"惜哉"。

#### 3_1_4 拓展干货「1」：止血按"出血部位"定方（参考现代应用）

- **上部出血（咳血、鼻衄、脑出血倾向）**：降气凉血为主，泻心汤、十灰散、桑白皮/白茅根/侧柏叶；
- **下部出血（便血、尿血、崩漏）**：兼顾脾统血、肾固摄，黄土汤、归脾汤、补中益气汤；
- **慢性小量出血（紫癜、皮下瘀点）**：见"血热"用犀角地黄汤思路，见"气虚不摄"用归脾汤——现代临床已把这套逻辑用于特发性血小板减少性紫癜（ITP）的分型治疗，以"滋阴止血方"为基方，止血→消瘀→宁血→补血四步走完，可减少激素依赖。

### 3_2 第二步：消瘀 —— "瘀血不去，新血断无生理"

#### 3_2_1 原文精要

> _"血止之后，其离经而未吐出者，是为瘀血……或壅而成热，或变而为痨，或结瘕，或刺痛，日久变证，未可预料，必亟为消除，以免后来诸患。"_
>
> _"凡吐衄，无论清、凝、鲜、黑，总以去瘀为先。"_

#### 3_2_2 为什么"止血"和"消瘀"几乎要同步？

因为**止血药本身就会造成新的瘀滞**（收敛、炭类、收涩之品留滞），加上离经之血本已成瘀。若不清除：「1」 阻碍新血化生；「2」 瘀久化热，再度迫血 → **反复出血**。这正是"止血—再出血"死循环的根源。

#### 3_2_3 瘀血的"隐藏信号"（读原文要会的诊断功夫）

| 信号 | 原文依据 |
| --- | --- |
| 刺痛、痛处固定（痛则不通） | 瘀血堵塞气之往来 |
| 口渴（"血渴"） | 气不得通，不能载水津上升 |
| 发热恶寒如疟 | 瘀血在腠理，半表半里，荣卫不和 |
| 肌肤甲错、骨蒸痨热 | 瘀血被气火煎熬，成"干血痨" |
| 结为症瘕（聚散/常聚不散） | 气与血胶结而成 |
| **瘀血攻心**：心痛、头晕、神昏 | 危急之候，无论产妇、吐衄家皆是危证 |

#### 3_2_4 消瘀四法 + 实操选方

| 路径 | 适用 | 代表方 | 关键提醒 |
| --- | --- | --- | --- |
| **轻活血** | 瘀滞轻、正气不足 | 当归尾、丹参、三七、花蕊石散 | 化瘀兼止血，三七为首选 |
| **行气化瘀** | 兼气滞（胀痛、情绪相关） | 血府逐瘀汤、香附、郁金、枳壳 | "治血必调气" |
| **破血逐瘀** | 瘀结重、症瘕干血 | 大黄䗪虫丸、抵当汤、三棱莪术 | 中病即止，不可久服 |
| **利水消瘀** | 水血互结（水肿兼瘀） | 桂枝茯苓丸、泽兰、益母草 | "血不利则为水" |

**落地组合建议**（安全区间，需在医师指导下调整）：

- 轻证通用：**三七粉 + 丹参 + 当归尾**，化瘀不伤正；
- 伴气滞：**血府逐瘀汤**思路（桃红四物 + 四逆散结构）；
- 伴热：**犀角地黄汤 + 活血药**，凉血兼化瘀。

#### 3_2_5 拓展干货「2」：现代视角下的"去瘀生新"

现代研究把"瘀血"理解为涵盖血流变异常、微循环障碍、血管内皮病变的综合状态。活血化瘀药的"生新"机制已被部分阐明：改善血液流变性、抑制血栓形成、**促进血管新生**。三七、丹参这类"活血止血双向调节"药，正是唐容川"止血不忘消瘀"思想的现代注脚。

**生活化落地**：

- 三七粉：每日 1~3g，温水冲服，适合有明确出血史、术后、跌打后的**防瘀留**阶段（孕妇、经期禁用）；
- 丹参/当归食疗：炖汤少量加入，适合气血偏瘀的亚健康调理；
- 关键原则：**有出血倾向时只用"活血止血"类（三七、蒲黄），绝不用破血药**。

---

### 3_3 第三步：宁血 —— "宁气即是宁血，防复是关键"

#### 3_3_1 原文精要

> _"止吐消瘀之后，又恐血再潮动，则须用药安之，故以宁血为第三法。"_
>
> _"血之所以不安者，皆由气之不安故也，宁气即是宁血。"_

这一步最容易被临床忽略，却是**决定"会不会再出血"的分水岭**。血之所以不安，根子在**气不平**——而气不平的源头在**肺、肝、胃**三处：

| 气不平之源 | 表现 | 宁法 | 代表方 |
| --- | --- | --- | --- |
| **肺气上逆** | 咳喘、鼻衄倾向 | 清肺降气 | 泻白散、杏仁、桑白皮 |
| **胃气上逆** | 呕恶、吐血反复 | 和胃降逆 | 半夏、竹茹、旋覆代赭思路 |
| **肝气上逆** | 怒则出血、胁胀痛 | 疏肝宁血 | 逍遥散、丹栀逍遥散 |
| **火热内扰** | 烦、渴、舌红 | 清热凉血 | 四生丸、茜根散、玉女煎 |
| **阴虚火旺** | 反复衄血、午后热 | 滋阴降火 | 茜根散、六味/左归思路 |

**宁血实操清单**：

1. **调情绪**：怒则气上，直接诱发再出血——这是"治肝"的生活化落地；
2. **控饮食**：酒、煎炒、浓味生热——原文专条提到白虎汤加茵陈、炒栀、大黄、藕节；
3. **防外感**：血家外感忌发汗（见下一节"用药宜忌"），外感是最常见复发诱因；
4. **固脏腑**：宁血本质是"把肺、肝、胃、心各自归位"，需按脏辨证收尾。

#### 3_3_2 拓展干货「3」：宁血的"脏腑收尾"具体方（原文卷二补虚篇前段）

唐氏论宁血与补虚衔接处，给了明确的脏腑归宿方：

- **宁肺**：生脉散代茶，加阿胶、麦冬补肺阴；辛字润肺膏（羊肺、杏仁、柿霜、真酥、白蜜）——_"肺为华盖……未有吐血而不伤肺气者也，故初吐必治肺，已止尤先要补肺"_；
- **宁肝**：逍遥散（血虚肝郁）、六味/一贯煎思路（肝阴不足）；
- **宁心**：清心降火，血虚者归脾汤思路；
- **宁肾**：安肾气即安冲气，冲脉为血海之根——六味、肾气丸、麦味地黄汤酌用。

### 3_4 第四步：补血（补虚）—— "补虚为收功之法，但要讲规矩"

#### 3_4_1 原文精要

> _"邪之所凑，其正必虚……去血既多，阴无有不虚者矣。阴虚则阳无所附，久且阳随而亡，故又以补虚为收功之法。"_

补血最容易"好心办坏事"。所以唐氏的补法有**严格的先后顺序和比例纪律**：

#### 3_4_2 「1」 补的前提：邪尽才补

> _"邪气未尽而补之，是关门逐贼；瘀血未除而补之，是助贼为殃。"_

**实操红线**：出血停止后**至少 1 周内**，不要单用人参、黄芪、肉桂、附子之类纯补阳药——容易助火复冲、再度出血。阿胶、熟地等滋腻之品必配砂仁、陈皮，**防碍脾**。

#### 3_4_3 「2」 补的比例（原文原话，极具实操价值）

| 维度 | 比例 | 含义 |
| --- | --- | --- |
| 补脾 : 补肾 | 三四 : 五六 | **以补肾为本**（肾为冲脉之根、精血之源） |
| 补阳 : 补阴 | 二三 : 八九 | **以滋阴为主** |

#### 3_4_4 「3」 补血分型落地

| 证型 | 识别 | 代表方 | 要点 |
| --- | --- | --- | --- |
| **气血两虚** | 乏力、心悸、面色苍白 | **归脾汤**、圣愈汤 | 补气以生血 |
| **肝肾阴虚** | 口干、潮热、腰酸 | 六味地黄丸、左归丸 | 填精养血 |
| **脾阴虚** | 思虑劳倦、饮食不健、怔忡 | 麦冬养荣汤、归脾汤加减 | 唐氏特色，润燥滋脾 |
| **脾肾阳虚** | 四肢清冷、自汗、脉沉弱 | 正元丹、人参养荣汤、右归丸 | 占比最少，慎之又慎 |

#### 3_4_5 「4」 补血的"脾胃护法"（贯穿始终）

> _"脾为后天之本，气血化生之源……补脾必须，注意避免滋腻过度碍脾。"_

无论用哪一张补方，**都要留一味醒脾药**（砂仁、陈皮、枳壳、莱菔汁）。这是全书补血能"补得进去"的关键技巧。

## 板块4 · 用药宜忌：一张"红绿灯表"（卷一《用药宜忌论》）

这一篇是全书的"用药安全门"，也是**网络教程里被反复拆讲的高价值干货**。核心是：汗、吐、攻、和本为治杂病四大法，但失血之证，**宜忌大不相同**。

### 4_1 汗、吐、下、和、补 五色灯

| 法 | 信号灯 | 原文金句 | 实操规则 |
| --- | --- | --- | --- |
| **汗** |  禁区 | _"衄家不可汗，亡阴故也……吐血更甚，水血两伤，其身枯骨。"_ | 表证只宜"和散"，配敛阴（白芍、麦冬、五味子），**禁麻、桂、羌、独** |
| **吐** |  终身禁 | _"血家最忌是动气……即瘥后复有杂证，亦不得轻用吐药。"_ | 痰涎壅肺改用**降气化痰**：苏子、杏仁、瓜蒌皮 |
| **下** |  有条件可用 | _"下之正是救阴，攻下即所以补阴也。"_ | 必须同时满足：「1」 里实热结（便秘/黑便、腹满拒按）「2」 舌红苔黄厚 「3」 脉滑数有力。**便溏、脉弱、正虚不支者禁下**，改清润降利 |
| **和** |  首选（第一良法） | _"表则和其肺气，里则和其肝气，而尤照顾脾肾之气。"_ | 补阴和阳、损阳和阴、逐瘀和血、泻水和气，补泻兼施、寒热互用 |
| **补** |  邪尽才用 | _"瘀血未除而补之，是助贼为殃。"_ | 先清后补，先脾肾分途，阳药轻、阴药重 |

### 4_2 下法的"使用条件"速记（最易误用，单列）

**可用（急下存阴）**：大便燥结或色黑如羊屎 + 腹满拒按 + 舌红苔黄厚/焦黑 + 脉滑数有力 + 出血色鲜红紫、伴烦躁口渴。

- 轻证：**生大黄（后下）+ 枳实 + 玄参**（增水行舟）
- 重证：**大承气汤**，中病即止，"得下止服"
- 正虚：**新加黄龙汤**思路（承气 + 人参、当归、玄参扶正攻下）

**绝对禁用**：便溏、脉弱、舌淡白——哪怕十日不便，也只能**增液汤润下**。

### 4_3 "和法"的四个临床场景（拓展自网络教程整理）

和法是"血证第一良法"，也是小柴胡汤在书中出现 60 余次的原因。唐容川称小柴胡汤为"达表和里、升清降浊之活剂"：

| 场景 | 配伍变化 |
| --- | --- |
| 半表半里 + 出血（血家外感） | 小柴胡去半夏，加丹皮、白芍、侧柏叶 |
| 肝郁犯胃吐血 | 四逆散 + 左金丸 + 白及、乌贼骨 |
| 瘀血内停 | 血府逐瘀汤，中病减量，防过用伤正 |
| 水湿壅滞 | 五苓散 + 丹参、益母草（利水不伤阴） |

**一句记忆口诀**：_衄吐忌麻桂，和散加黑栀；出血见火结，急下可救阴；补前先问邪，阳轻阴重行。_

## 板块5 · 理论骨架：支撑四步法的三根支柱

要把四步法用活，必须理解它背后的三根理论支柱。

### 5_1 支柱一：脏腑病机 —— "治血必分脏腑"

唐氏把血证按脏腑归位，最有临床价值的是这几条：

- **心**：君主之官，主生血。"血虚则怔忡，有瘀血亦怔忡，火扰其血则懊憹"——**同一个"心慌"，三种病机**，不辨证就补，越补越乱；
- **肝**：统血之脏，下注血海。"木郁为火则血不和，火发为怒则血横决"——**治血先治肝**，怒则出血的源头在此；
- **脾**：统血之脏，"脾阳不足则不能统血，脾阴虚又不能滋生血脉"——双向统血观，唐氏独创；
- **肺**："肺为华盖，内主制节"，肺气不降则血上溢——上出血必治肺；
- **肾 / 冲脉**：冲为血海，其脉丽于阳明，"安肾气即是安冲气，冲气安而血海静"——**治血归根于肾**。

**落地**：任何出血案，先画一张"心—肝—脾—肺—肾 + 冲脉"的定位图，哪个脏失衡最重，就作为收功阶段的补养重点。

### 5_2 支柱二：气、火、血的动态关系

```plain
气盛 → 化火 → 火迫血妄行 → 出血
气结 → 血凝 → 瘀血
气虚 → 血脱 → 气随血脱（危证）

```

对应治法：

- 气盛/火旺 → **泻火降气**（泻心汤）——"治火即是治血"
- 气结 → **理气活血**（血府逐瘀、小柴胡）
- 气虚 → **补气固脱**（独参汤、归脾汤）

### 5_3 支柱三：男女异同与"升降"思维

> _"女子有月信，上遂无髭须；男子有髭须，下遂无月信。所主不同，升降各异。"_

唐氏用"气血升降"解释男女生理差异：女子血降为月信，男子气升生髭须。**这一升降思维直接落到妇科血证**——经、带、崩、产诸病，核心都在"血能否按时下行、归于血海"。崩漏用固冲涩血、经闭用活血通经，本质都是恢复"血归血海"的常道。

## 板块6 · 现代拓展：四步法如何迁移到今天的疾病谱

网络上的现代应用研究，大多把唐容川的四步法当作**可验证的临床框架**。以下为可参考的迁移方向：

### 6_1 具体疾病应用举例

| 现代疾病 | 四步法对应 | 参考方案 |
| --- | --- | --- |
| **上消化道出血** | 止血（降胃） | 泻心汤（大黄黄连黄芩）为主，现代已制成中成药 |
| **支气管扩张/肺结核咳血** | 止血（清肺降气） | 犀角地黄汤、十灰散 + 抗感染 |
| **特发性血小板减少性紫癜（ITP）** | 全程四步走 | 自创"滋阴止血方"（生地/熟地、山药、山茱萸、仙鹤草、地稔、小蓟、连翘、荆芥穗、甘草）为基方，随症加减，可改善血小板计数、减少激素依赖 |
| **心脑血管疾病（脑梗、冠心病）** | 消瘀/宁血（活血通络） | 活血化瘀改善血液流变、微循环、血流动力学 |
| **心衰血瘀证** | 消瘀 + 利水 | "血不利则为水"——益气活血 / 温阳活血 / 化痰活血三法，配真武汤、苓桂术甘汤 |
| **妇科崩漏、经闭** | 止血 + 宁血 + 补血 | 固冲涩血与活血通经交替，归根于冲任、肾 |

### 6_2 "去瘀生新"的现代机制（理论拓展）

- 三七：止血活性（三七素）+ 活血成分（三七皂苷），实现**止血不留瘀**；
- 丹参：改善血液流变性、抗血栓、促进血管新生；
- 整体思路与"瘀血 = 血流变异常 + 微循环障碍 + 内皮病变"的现代认识高度吻合。

### 6_3 皮肤科的意外延伸（参考网络教程拓展）

"久病入络致瘀"理论被广泛应用于痤疮、黄褐斑等——_"有斑必有瘀，无瘀不成斑"_。即使无明显血瘀证候，久治不愈者也可酌加丹参、当归尾。**这是四步法"消瘀"思想向外科的溢出价值**。

## 板块7 · 实操总纲：四步法流程图 + 一张速查卡

### 7_1 临床决策流程

```plain
【接诊任何出血/瘀血症】
        │
        ▼
「1」 定位：上干 / 外渗 / 下泄 / 内瘀？
        │
        ▼
「2」 辨势：气实火旺？还是气虚阳脱？（决定用泻心还是独参）
        │
        ├─ 急则治标：止血（降气、降胃、降火）
        │       └─ 留瘀 → 同步轻活血（三七/丹参）
        │
        ▼ 血止后
「3」 消瘀：舌/络脉/刺痛/甲错 → 有瘀即祛（活血→破血→逐瘀分级）
        │
        ▼
「4」 宁血：调肺/肝/胃/心，降气清热，防外感、控情绪、节饮食
        │
        ▼ 邪尽后
「5」 补血：先肾后脾，阴八九、阳二三，必配醒脾药
        │
        ▼
「6」 全程守：忌汗、忌吐；下法看条件；以和法为第一良法

```

### 7_2 六条"不可违背"的硬规则

1. **凡出血，先降气**——降肺气、顺胃气、纳肾气，气下则血下；
2. **凡出血史，必问留瘀**——离经之血即是瘀；
3. **初吐多实，勿误补**——"正虽虚而邪则实"，泻心汤敢用；
4. **忌汗、忌吐**——终身纪律；
5. **下法看"里实热结 + 正气可支"两个条件**——否则改用润下；
6. **补在最后、补阴为主、必护脾胃**——"关门逐贼"是补血第一大忌。

### 7_3 生活化落地清单（非医疗建议，仅作养生参考）

| 场景 | 可做 | 忌做 |
| --- | --- | --- |
| 鼻衄/少量上出血后 | 凉开水、静卧低头、白茅根煮水 | 仰头、热敷、饮酒辛辣 |
| 经期血块多/产后 | 益母草、丹参少量炖汤（遵医嘱） | 经期用三七活血、寒凉久坐 |
| 慢性失血恢复期 | 莲子、山药、银耳（脾阴）、枸杞（肝肾） | 阿胶熟地堆砌、盲目人参黄芪 |
| 防复发（宁血） | 控怒、规律作息、淡饮食、防感冒 | 熬夜、情绪激动、煎炒浓味、过量饮酒 |
| 术后/跌打后 | 三七粉小剂量，配陈皮砂仁 | 破血药、大汗、剧烈活动 |

## 板块10 · 案例拆解：治血四步，次序颠倒

（虚构教学案例，不对应真实人物）一位咳血患者，家属先用了大量补血之品，血未止而胸闷、发热。

唐容川的四步是止血—消瘀—宁血—补血，次序本身就是治法：血未止而先补，是给正在外溢的血加压；瘀未去而先补，是"闭门留寇"。四步之中，前三步都在"去"，最后一步才"补"，补是收功，不是开局。

**落点**：治血的次序比选药更关键。该止的时候补，是把火往屋里引。
