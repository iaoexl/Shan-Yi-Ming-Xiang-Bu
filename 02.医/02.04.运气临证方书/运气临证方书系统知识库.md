# 运气临证方书系统知识库

## README · 导览

> 本知识库以《医学穷源集》《圣济总录·运气卷》《素问玄机原病式》三部读书笔记为主源，参照五运六气系统知识库交叉印证，将运气学说"落到临床、落到方剂、落到具体病证"的一脉文献打散重组为主题板块。它不教人排盘算运，而教人理解：古人如何把逐年气化偏性，转译为"易罹何病、宜用何方、当循何机"的临证实用模型。三书各擅其长——一给图、一给方、一给案，本库把它们还原为同一套"因时制宜"思维的三种面貌。
> 运气之学，贵在"参考"二字。本库所有内容定位为中医文献与文化整理，所列运气倾向、方剂、治法均须由合格中医师临证辨证后方可论治，切勿据以自行配方服药。

### README_1 书目与范围速览

- **《医学穷源集》**：传统归明代王肯堂，属"运气医案"一脉。以六十年甲子逐年之岁运、司天在泉、胜复郁发为经，以门诊医案为纬，主张"病虽百端，其源可穷于当年运气"，并引入"大司天"长周期气化观注解历代病证。重心在"解释一桩桩具体的病"。
- **《圣济总录·运气卷》**：北宋朝廷敕修方书之首卷运气门类，属"运气方"一脉。以《素问》运气七篇为纲，按六十甲子逐年给出岁运、司天在泉、客主加临并直接对接成方，是运气学说首次系统编入国家方书大成的代表，相当于一部"运气年历配药手册"。
- **《素问玄机原病式》**：金元刘完素（刘河间）撰，属"病机发挥"一脉。不重算岁排气，而把七篇"天气模型"转化为"天气致病的病机模型"，以"六气皆从火化""五志过极皆热"为枢纽，以"亢害承制"为根基，建立寒凉清热的辨治体系，为温病学派远源。
- **三者关系**：七篇给"理"、纪用给"法"、圣济给"方"、穷源给"案"、原病式给"机"。本库不逐本罗列，而按"总论—推算—病机—方书—病源—边界—读法"的主题重组。

### README_4 心法·核心方法

- **第1条 把"偏性"当趋势，不把"运"当判决**：岁运司天算得准的是规则，算不准的是当年实际气候与个体是否应验；一切运气结论先标"倾向"，再论可否取法。
- **第2条 永远拆出中间病机，不许跳步**：无论"运—病"还是"气—方"，都须还原为"运／气 → 病机 → 症状／方味"三段，略去病机一环即易滑向武断。
- **第3条 以辨证为本、以运能为参**：运气是"因时制宜"的辅助维度，不是凌驾医理的公式；方、机、案皆须经四诊合参、合格医师决断。

### README_5 易被忽略的前提

- **前提一 三书体例不同，读法不可混同**：圣济是"方册"宜查表对照，穷源是"医案"宜析推理链，原病式是"发挥"宜与病机十九条逐句对勘；把发挥当原文、把方册当通论，是两类常见误读。
- **前提二 官修标准化是"理想模型"**：圣济同运之年方味趋向一致，是朝廷制度化的产物，会削平地域、气候、个体差异；查用时须以当年实际气象物候与脉证校正。
- **前提三 大司天只是把尺度拉长**：它不改变逐年推演规则，只多一个长周期背景；拿"大司天"三字直接断人，恰是其最易滑向的决定论陷阱。

## 板块0 · 学习路径和建议

本板块替读者理清"怎么读才不偏"。运气临证书最怕两种误读：一是把逐年病源、运气方当作宿命铁律，二是跳过医案与病机只背格局。下面给出一条由表及里、由案返理的稳妥路径，并标出前置基础与读法纪律。

### 0_1 学习路径（分阶段）

#### 阅读顺序

第1步，先读板块1总论与板块2推算骨架，看清三书如何共享"岁运—司天在泉—客主加临"这一套底层语法，这是读懂任何一本的前提。第2步，选一本切入：圣济看"运—气—方"对照、穷源看"运—机—症—治"医案、原病式看"十九条—化火"发挥，各挑三五条细读其推理链。第3步，把每一条"运气→病/方"的推断拆成"运／气 → 病机 → 症状／方味"三段，检验有无跳步，这才是把书读活的功夫。第4步，回到板块6边界与板块7自测，用"倾向标注"与"反例收藏"巩固审慎读法。

#### 前置基础

「1」运气七篇基本算法：天干化五运、地支化六气、司天在泉、主客加临、胜复郁发（详见七篇笔记），本库默认读者已略知。
「2」基础中医病名与脏腑证候常识，否则"脾湿困""燥金伤肺"等病机无从体会，医案只剩故事。
「3」基本药性常识（寒热温凉四气、辛甘酸苦咸五味）与方剂君臣佐使概念，否则读不出"方随运味"的设计意图。

#### 重点条目

三书真正的共用主线只有一条：把"气化偏性"转译为"临床应当留意的方向"。圣济转成"方味"、穷源转成"病源"、原病式转成"病机"，落点各异而枢纽同归。抓住这条主线，便不会被"某年必某病""某方治某运"的表层说法带偏。

### 0_2 使用建议与边界声明

#### 读法纪律

务必区分"某运易致某病之倾向"与"某运必生某病"——后者是典型误读。古人立论原是示人以偏盛偏衰之趋势，并非逐人注定。三书宜作"相关性素材"与"思维训练本"来读，每遇一条先问"倾向是否吻合、已验还是未验"，再论可否取法，切忌见运即断、执一而遗万。

#### 边界声明

本知识库为中医运气学文献与文化整理，不构成现代医学诊断、治疗或用药建议；所列方剂、用药须在合格中医师指导下使用，切勿自行配方服药；急重症请及时就医。

补充两条具体边界：

- **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉都可逐字复核，但它对具体年份气候与疫病的"预测"属传统经验范畴，现代统计验证结果并不一致，只能当倾向假设，须用当年实际气象物候校正。
- **不可替代诊疗**：凡涉用药、针刺与防疫措施，一律以正规医疗与公共卫生指引为准；本库的"某气主某病""某年宜某方"皆传统主张，只作学习与对照。

## 板块1 · 运气临证方书总论

本板块界定"运气临证方书"的范畴，并把三部书放进同一谱系中定位。看清它们"上承什么、各擅什么、互补在哪"，才能用得准、不重叠、不迷信。

### 1_1 何谓"运气临证方书"

运气之学原本重在"推岁运、断气候、测病源"三层。所谓"临证方书"，是把这三层进一步落成临床可用的形态：或给方（圣济）、或给案（穷源）、或给机（原病式）。它不是又一部讲推演的运气书，而是把运气从"可推"推进到"可用"的一脉文献。其共同前提是：承认某年某气偏盛，会在群体与个体层面形成可资留意的病机倾向，并据此提示用方或辨治方向。

### 1_2 三书谱系：图·方·案互补

运气学文献有"一图一方一案"的三角分工：

- **图**：以《运气易览》条理清晰的图表助人入门，解决"怎么算、怎么看格局"。
- **方**：以《圣济总录·运气卷》逐年运气方，解决"此年气化如此，故宜用此方此味"。
- **案**：以《医学穷源集》逐年病源与医案，解决"眼前这桩病，如何放回当年运气去解释"。

原病式虽不在三角之内，却补足最关键的一环——**机**：它不排年运，而把六气如何化为病机、如何决定治则讲透。四者合参，运气临证的全貌方显：图明其法、方备其用、案示其验、机通其理。

### 1_3 官修、发挥、医案三脉的源流与价值

- **官修一脉（圣济）**：北宋朝廷以运气取士、官修方书，使运气从道门秘传升格为"国家医学知识基础设施"。其价值在"集成与规范"，局限在过度标准化易掩个体差异。
- **发挥一脉（原病式）**：金元刘完素借七篇与十九条，把运气"天气模型"翻成"病机模型"，是运气落地治病的标志事件，下启寒凉派与温病学派；其锐在立论，弊在偏寒凉，须自带审慎。
- **医案一脉（穷源）**：明清"临证验证"风气下，医家不再满足于讲推演，而用逐年运气解释门诊病种并附案，使运气从书斋走向诊室；其独擅处在引入"大司天"长周期，最易滑向决定论，须配以商辩之书纠偏。

三者皆上承《素问》运气七篇，尤其《至真要大论》病机十九条与"亢害承制"一段，是共通的根脉。

### 1_4 立即可做动作

取今年干支，依七篇算法自推岁运（太过／不及）与司天在泉，再翻板块4对照表看圣济取向、翻板块5看穷源病源，体会"同一组运／气，三书各给出方、案、机三种读法"。自检问题：我此刻是在"查规律"还是在"断必然"？

## 板块2 · 运气推算骨架与方证推演逻辑

本板块把三书共享的底层语法讲清，并把"运—气—方—证"的推导链落成可操作的推演。不懂这一节，读任何一本都会卡在"它凭什么这么断"。

### 2_1 推算基础：岁运、司天在泉、客主加临、胜复郁发

- **岁运（中运）**：由年干定，天干化五运（甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火），分太过、不及、平气。岁运主一年气化之"常"。
- **司天在泉**：由年支定，地支化六气（子午少阴君火、丑未太阴湿土、寅申少阳相火、卯酉阳明燥金、辰戌太阳寒水、巳亥厥阴风木）。司天主上半年、在泉主下半年，定客气之"位"。
- **客主加临**：客气（随年支流转）加临于主气（年年固定之六步）之上，刻画正常递变之外的异常扰动，解释"同运不同年、方味仍有细别"。
- **胜复郁发**：气偏盛则胜，胜极则复，郁极则发，是气机失衡与自我调节的动力学描述，也是原病式"郁滞化火"的思想底土。

### 2_2 运—气—方—证 推导链

三书的推导同归一链，只是落点不同：

```
岁运(太过/不及) + 司天在泉 + 客主加临
        │
        ▼
本年气化偏性 → 本病机倾向（参《至真要》病机十九条）
        │
        ├─→ 圣济：落为 主方 + 药味（君臣佐使）   → "方"
        ├─→ 穷源：落为 易病清单 + 医案验证       → "案"
        └─→ 原病式：落为 病机演化（是否化火）    → "机"
```

关键在中间"病机倾向"一环：如"土运太过、太阴在泉"先化为"脾湿困中州"之机，再分别导向苦温燥湿之方、身重泄泻之案、或湿郁化热之机。略去病机直接说"某年必某病"，便是跳步。

### 2_3 推演 ASCII 结构图

```
逐年方册/病源条目结构：
〔年干支〕
   ├─ 岁运(太过 / 不及 / 平气)        ← 天干定
   ├─ 司天在泉(六气)                  ← 地支定
   ├─ 客主加临(异常扰动)              ← 客气加临主气
   ├─ 本年气化偏性 → 本病机倾向
   └─ 主方/病源/病机（运气对接临床）

逐年查法：
取 生年/病年干支
   → 查 岁运 + 司天在泉 + 客主加临
   → 参 大司天长周期背景（穷源专属）
   → 得 "易病"清单 或 "主方取向"
   → 对照 实际病历/体质 → 标 [倾向符 / 已验 / 未验]
```

读任何一年都应按此顺序自推一遍，再与书中结论核对，方能把"查表"变成真正的推演训练。

### 2_4 立即可做动作

取六个代表性年份（如甲子土太过、丙寅水太过、丁卯木不及、戊辰火太过、己巳土不及、庚午金太过），自推岁运司天与病机倾向，填一张"运／气／病机"三栏卡。自检问题：我推的"泻／补"方向，是否符合"太过泻其胜、不及补其虚"的传统立法？

## 板块3 · 病机十九条与火热论

本板块拆解《素问玄机原病式》的核心贡献。刘完素不重算岁排气，而把七篇"天气模型"转化为"天气致病的病机模型"，是运气从推演走向治病的关键节点。读此书不必先会排甲子，要会的只是看"眼前这个证，是不是已经化火"。

### 3_1 六气皆从火化

"六气皆从火化"是全书第一命题：风、湿、燥、寒诸气在病机演变中多可转归为热，强调"变"而非"恒"。须注意刘氏说的是"多从"而非"尽从"——化火的前提是气机郁滞、无从疏泄；若表气尚通、津液未伤，则未必化火，故不可机械套用。这一命题把医生注意力从"辨初感何气"引向"察是否已化火"，是读本书最该建立的动态眼光。

白话释义：外邪初感未必即热，然一经郁滞便生热化火，故临证所见热证十常八九，治当以清热为要。它不是武断口号，而是"以热为归宿"的动力学收束。

### 3_2 五志过极皆热

"五志过极皆为热甚"把怒、喜、悲、恐、思五种情志走到极端时，气皆郁结而内生热，首次把心理应激纳入运气病机体系。它补足了"六气"之外的"人气"致病一环：天气可化火，人心过极亦可化火，二者在"郁而生热"上殊途同归。对今人尤有启发——长期情志不舒、气机壅滞者，每见内热之象，正是古代"心身同病"观念的早期表达。

### 3_3 亢害承制

"亢害承制"出自七篇，意为气亢盛至极反生其制，是刘氏解释"寒可化热、燥可生风"的根本机理。它说明病机不是静态归类，而是动态博弈：某气过亢便物极而反，表面病象与深层病性可能相反（如寒极似热），这正是"皆从火化"能成立的理论前提。读任一"已化火"之断，都要回问一句"亢在何处、制从何来"。

白话释义：六气本平，亢则为害；寒极似热、燥极生风，皆因亢逆太过、物极而反，故表面寒象深处可能藏着热机。

### 3_4 治法取向：辛凉解表·寒凉清里

对应"火热"病机，刘氏主张外感表证用辛凉透达、里热用寒凉清泻，旗帜鲜明反对当时滥用辛温燥热（沿《和剂局方》之弊）。其代表思路（如双解散、凉膈散一类的配伍雏形）讲究"表里双解、给邪出路"。这一取向深刻改写金元以降治法谱系，后世温病学派"在卫汗之、到气清气"的清热存阴路线，皆可在此找到运气病机的远源。

### 3_5 病机十九条的"同改加"对照法

本书所有发挥都挂在《至真要大论》病机十九条之上，是阅读全书的"坐标轴"。以"诸湿肿满，皆属于脾"为例：

```
十九条原意：  诸湿肿满，皆属于脾        （脾失健运，水湿停聚）
刘氏发挥：    湿郁不化 → 多从热化 → 治当清化，非徒健脾
对照结论：    刘氏在"脾"之外补了"郁→热"一环，治法由温燥转向清化
```

读法上须逐条标"同／改／加"：底本重"属脾"之常，刘氏重"湿郁化热"之变，同一句话底本与发挥义并不全等。切忌把刘氏个人创见误当成七篇本意。

### 3_6 病机转化链（ASCII）

```
风(木) ─┐
湿(土) ─┼──→ 气机郁滞 ──→ 化火(热甚) ──→ 伤阴 · 动风 · 闭窍
燥(金) ─┤                          ↑
寒(水) ─┘              五志过极(怒喜悲恐思)亦归此
        （亢害承制：亢极则物极而反，寒极似热、燥极生风）
```

### 3_7 立即可做动作

取一条你熟悉的外感证候，标其初起属性（风／湿／燥／寒），自问是否出现"郁滞／入里／过极"；若有，则推"气机壅结→化火→伤阴"；若无（如舌润脉缓、表气尚通），则判"未化"。自检问题：我能说出本条"化火"的触发条件吗？

## 板块4 · 逐年运气方举隅

本板块以《圣济总录·运气卷》示范"方随运味"的运气方数据库读法。本书并非通论医理之书，而是一部以年为单位编排的"方册"，重心在"看方味如何随运变"，不当通论精读，宜作对照检索。

### 4_1 圣济运气卷的"运气方数据库"性质

卷首运气总论基本复述七篇框架（岁运、司天在泉、客主加临、胜复郁发），目的极明确——为"用方"立据，而非另立新说。其后按六十甲子逐年给出：岁运、司天在泉、客主加临，再列出对应该年的方剂与药味，整部书可视为一部"运气年历配药手册"。编制者试图让行医者"按年查方"，把复杂气化推演压缩为一目了然的检索条目。

### 4_2 方随运味：气味配伍逻辑

书中方剂的寒热温凉、辛甘酸苦，明显随当年运气偏性调整，把早期"司天定味"思路落成具体成方，形成"运—气—味—方"回路。传统立法可概括为"运太过泻其胜、运不及补其虚、司天在泉再作微调"。例如土运偏盛之年多佐苦燥以祛湿，木运不及之年多辛甘以助木。需强调：这种对应是古人基于气化推演的配伍偏好，属文献与历史层面的范式，并非现代药理学结论。

### 4_3 官修标准化：便利与风险

作为国家方书，本书带有明显"标准化"特征——同岁运之年方味趋向一致，是朝廷试图把运气"规范成制度"的痕迹，带来可复制、可教学之利，也带来削平地域、气候、个体差异之险。其局限恰来自优势：过度依赖"按年查方"易导向机械套用，忽略辨证论治根本。真正可取的态度是借其方味规律反观临床、佐以辨证，而非以其条目取代医师决断。

### 4_4 运—方对照样例表

```
年份   岁运      司天      在泉       主方取向(传统立法)      主味倾向
甲子   土太过    少阴君火  阳明燥金   苦温燥湿·佐清上         苦·燥·微寒
丙寅   水太过    少阳相火  厥阴风木   辛温散寒·防寒热错杂     辛·温
丁卯   木不及    阳明燥金  少阴君火   辛甘助木·佐酸敛         辛·甘·酸
戊辰   火太过    太阳寒水  太阴湿土   咸寒泻火·慎温补         咸·寒
己巳   土不及    厥阴风木  少阳相火   甘温补脾·佐疏风         甘·温
庚午   金太过    少阴君火  阳明燥金   辛凉泻金·护肺阴         辛·凉
```

说明：上表依"天干化五运、地支化六气"推出岁运与司天在泉，再据传统立法写方味取向。如甲子阳土太过、湿盛，取苦温燥湿并佐清上；丁卯阴木不及、金乘木衰，故辛甘助木而佐酸敛。同运不同司天之年（如甲子与己巳皆土运），一泻一补、气味翻转，正见"运定主次、司天微调"。

### 4_5 立即可做动作

仿上表抽六至十个年份，列成"运／气／主方／主味"四栏横向比较，优先覆盖十干各运的太过与不及。自检问题：同运之年方味是否趋同？同运不同司天之年方味是否写出微调差异？

## 板块5 · 逐年病源与大司天

本板块以《医学穷源集》示范"以案证运、以运释案"的临证笔记读法。它最重"解释一桩桩具体的病"，并引入"大司天"长周期观，从"逐年手册"升格为"通代医案注解"。

### 5_1 穷源与逐年病源表

"穷源"者，穷病之源也——把一病之根本溯回当年运气之偏性，追问"此证何以发于此时、此人、此地"。"逐年病源表"是全书骨架：把六十年每一甲子的岁运、司天在泉、间气胜负，转译成"本年易犯何病、何藏受邪"的清单，相当于一份运气致病风险的"年历"。读者据此逐岁查阅，先得其气候与病机的"常势"，再回看附案，便明古人立条用意。

### 5_2 附案：运→机→症→治 思维

在逐年病源条下，每（或每类）运气年均附以医案，演示"见此病→断此运→用此治"全程。其最大价值不在方本身，而在摊开推理：如何从运气断到病机，又如何从病机落到治法。读案宜把重点放在"为什么这么断、为什么这么治"，而非只抄方药。读懂附案，才算接住本书"实战"定位。

### 5_3 大司天：长周期气化底图

区别于一般逐年运气书，穷源引入"大司天"观，把六十年甲子格局放大、叠为更长时段（传统以三元一百八十年为一套）的整体气运背景。它如同一层"大气候底图"，用以解释为何某些病证在某一历史阶段格外多见。每一长周期各有主导气化，某代之所以多某类病证，可由大背景与当年小运气合参而得。这是本书最具辨识度的贡献，也是《易览》之图、《圣济》之方都未及展开的一层。

### 5_4 大司天与逐年叠加（ASCII）

```
长周期(大司天):  ──[土运主令段]────────────[火运主令段]──
                    │(底图·大气运背景)
逐年小运气: 自甲子、乙丑、丙寅起，循六十甲子逐年轮转，至癸亥而复始
                    │叠加
                    ▼
        本年实际气化 = 大司天底图 + 当年岁运司天
                    │
                    ▼
        穷源断病: 在此大背景下, 今年偏性为何 → 易发何证
```

传统认为：大司天提供"势"，当年运气提供"机"，二者会合方能断"证"；读图宜先纵后横，先认大背景，再查小运气，最后落到症状与治法。但须记：大司天只是把尺度拉长，不改变逐年规则，更不"注定"某代某人多某病。

### 5_5 立即可做动作

把自己或家人出生年代入逐年病源表，分设"书言"与"实际"两栏对照，标"倾向符／不符／存疑"。自检问题：我所标的是"倾向"还是"必"？是否补写了"运偏→病机→症状"完整三段链？

## 板块6 · 临床运用边界与纠偏方法

本板块把"运气不可机械套用"的共识落成可操作的方法。三书各自最易滑向的误区不同（圣济机械套方、穷源决定论、原病式偏寒凉），纠偏的总方法却是同一套"分层划界"。

### 6_1 边界声明（决定论防范）

运气可以算，结论却只是倾向。两条铁律先立住：其一，算得准的是规则（干支、岁运、司天在泉可逐字复核），算不准的是当年实际气候与疫病（属传统经验，现代统计不一致，只当倾向假设，须以实际气象物候校正）；其二，不可替代诊疗，凡涉用药、针刺、防疫，一律以正规医疗与公共卫生指引为准。本书所有"某气主某病""某年宜某方"皆传统主张，只作学习与对照。

### 6_2 商辩派：分层划界

明清《运气商》《运气辩》等纠偏之书的总方法，是"分层划界"：把运气内容拆为可信与不可信两堆，而非整体接受或整体推翻。原文所述把"气候大势、年际倾向"放入可信堆，把"个体之病、必发之断"放入不可执堆，实据永远压在最底。这条线画在"群体、年际"与"个体、当下"之间，也画在"气候"与"诊断"之间。全书千言，终归一"界"字——有界，运气方为良药；无界，运气反成迷药。

### 6_3 三种常见误读与防范

1. **把"易致"读成"必生"**：防范办法是每条结论标"倾向"而非"必"，并附"已验／未验／存疑"三档。
2. **把"发挥"误当"原文"**：原病式之"改、加"须与病机十九条逐句对勘，避免把刘氏创见当成七篇本意。
3. **把"方册"当"通治模板"**：圣济运气方只描述"某年宜某类方味"的大方向，须回四诊合参、合格医师辨证，绝不可越辨证直接套用。

### 6_4 立即可做动作

翻出你此前任何一条运气判断，检查它是否落入了上述三类误区之一，并补写"可信堆／不可执堆"的归属。自检问题：我的结论，压在"实据"上了吗？还是压在了"据说"上？

## 板块7 · 研读方法·笔记模板·自测

本板块把"怎么把书读进自己的本子"讲透。运气笔记最忌空抄条文，下面给出可落地的记录场景与自测工具，便于不同目的者各取所需。所有自测均限于思维训练，不涉及任何诊疗断言。

### 7_1 对照卡与填表法

动手做一张自己的"运—气—方／案／机"对照卡，比单纯浏览成倍增效。准备甲子轮转表（或干支推运小抄）与一套空白表格，遇某年先自推岁运司天，再翻书核对本书主方或病源，习惯后再与同辑逐年表、运气易览互校，既能验讹也能体会不同文献的取舍差异。

### 7_2 多场景笔记模板

- **年代对照场景**：把自与家人出生／发病年代入逐年病源表，分"书言""实际"两栏，知古人所言是趋势还是已验。
- **三段链拆解场景**：每读一案/一方，强制拆成"运／气→病机→症／味"三行，略去中间病机者自补一句参《至真要》的推导，练"不跳步"习惯。
- **倾向标注场景**：所有结论标"倾向"而非"必"，附"已验／未验／存疑"三档，从根本阻止过度推断。
- **反例收藏场景**：专辟一页收"同运异病""同病异运"实例（如同运反燥咳），作为反绝对化的弹药；反例比正例更能护住读法清醒。
- **条文对照场景（原病式专属）**：左列十九条原文、右列刘氏发挥、中栏标"同／改／加"，使每一条创变一目了然。
- **条件清单场景（原病式专属）**：建"化火条件清单"（郁滞、入里、过极、伤阴、闭窍），每添一条标"源自第几条／何病式"，使清单自带出处。

### 7_3 自测题与验收标准

「1」请用三句话说明"穷源"与"逐年病源"的关系：前者是方法（溯病于运），后者是该方法的年历式清单，一为针法、一为图谱。
「2」把"土运太过"拆成运→机→症三段链，并说明大司天背景如何与之叠加影响趋势强弱。
「3」取木运太过与木运不及各一年，比较主方取向与药味差异，并说明气化理由（运太过泻其胜、不及补其虚）。
「4」为何《原病式》说"多从火化"而非"必从火化"？请举出至少两个"不化"的条件。

验收标准：能写出完整三段链、主动标倾向档、并举一反例者，方算读通；凡一见运便断必病、略去病机者，须回板块2与板块5重读。传统认为，运气之学的功夫全在"慎断"二字。

### 7_4 进阶阅读路径

上接《素问》运气七篇（总根）与早期运气方书《元和纪用经》（"司天定味"先声）；平行《运气易览》（图最清）与《医学穷源集》（案最实）；欲看边界与争鸣，读《运气商》《运气辩》补足"用之之慎"；想深究长周期，沿"大司天"一脉参后世三元气化论病候之说。若重治法落地，可顺刘氏《宣明论方》《素问病机气宜保命集》看"火热论"如何同时落在病机与方剂两端。
