# 《素问玄机原病式》读书笔记

## README · 导览

### README_1 书目速览

- **书目信息**：金元时期刘完素（后世称刘河间）撰，原为一卷本。它是把运气学说的"病机"与"六气"直接落为临床病机学的里程碑式著作，被后世尊为"寒凉派"之祖，也是温病学派"清热"一脉的重要源头。
- **成书背景**：宋金之际，医界多循《太平惠民和剂局方》辛温燥热之法，刘完素借《素问》运气七篇与病机十九条，力倡"六气皆从火化""五志过极皆为热甚"，在战乱疾疫多发的临床环境中开出一条"迅捷清解"的革新路径。
- **核心主旨**：将《至真要大论》病机十九条，按"风、热、湿、燥、寒诸气皆能化火"的逻辑重新发挥，建立以"热"为枢纽的病机分类与治则体系，并把"亢害承制"作为病机转化的根本机理。
- **与五运六气关系**：本书不重"算岁运、排客气"，而把七篇给出的"天气模型"转化为"天气致病的病机模型"，是运气从推演走向治病的关键转化节点；素材来源主要为《素问》运气诸篇与病机十九条。
- **阅读价值**：读懂它，方能理解金元以降"寒凉派"的立论根基，也才能看懂明清温病学派"卫气营血、清热存阴"思路的运气渊源；更是理解"同一运气，为何有人化火、有人不化"的一把钥匙。

## 板块0 · 学习路径和建议

本板块为初次接触本书的读者梳理一条由浅入深、由总纲到条文的阅读路线，并说明读此书时最易踩的"把发挥当原文"的坑。建议先把下面四节当作一份"使用说明书"，再进入正文的病机发挥。

---

### 0_1 学习路径

#### 0_1_1 阅读顺序

第1步，先读篇首"五运主病"与"六气为病"两部分总纲，牢牢抓住"诸气皆能化火"这条主线，这是全书的总开关。

第2步，逐条阅读"风、热、湿、燥、寒"各病式下的"病机→症状→治法"三联动，并与《至真要大论》病机十九条逐句对照，弄清刘氏在哪些地方"同其文、改其义、补其环"。

第3步，研读其"宜寒凉、忌辛温"的用药取向，理解它与当时《和剂局方》辛燥时风的根本对抗点，体会为何要"解表用辛凉、清里用寒凉"。

第4步，回读书前的自序与"亢害承制"一段，明白刘氏并非凭空立论，而是以七篇"亢则害，承乃制"为哲学根基，把病机十九条重新编排为一套"动态转化"的学说。

#### 0_1_2 前置基础

「1」《至真要大论》病机十九条（见同辑七篇笔记）。本书所有发挥都挂在这十九条的坐标轴上，不熟十九条就无从判断刘氏改了什么。

「2」基本药性常识（寒热温凉四气、辛甘酸苦咸五味）。否则读"辛凉""苦寒"会只停留在名词，读不出其针对"化火"病机的设计意图。

「3」运气七篇的"胜、复、郁、发"概念。刘氏的"郁滞而后化火"正是"郁气"思想的临床翻版，有了这层底，才能看懂转化链上的"郁滞"一环。

#### 0_1_3 重点条目

"六气皆从火化"是全书第一要义：风、湿、燥、寒在病机演变中遇郁滞皆可转归为热，这是把纷杂外感统一到"热"之一端的激进收束。

"五志过极皆为热甚"把情志过极纳入病机：怒喜悲恐思五种情志走到极端，气皆郁结而生热，是古代"心身同病"观念的亮点，也把运气框架从"天气"扩到了"人气"。

主火、主热的方剂取向（如双解散、凉膈思路的雏形）是治则落点：刘氏不只在理论上说"热"，更在设计"辛凉透表、寒凉清里"的具体方药路径，这是它区别于纯推演类运气书的地方。

### 0_2 使用建议与边界声明

#### 0_2_1 读法纪律

本书是"发挥"而非"原文"，读时务必左手病机十九条、右手刘氏注，逐条标出"同、改、加"，避免把刘氏的个人创见误当成七篇本意。

传统认为刘氏之说"偏于寒凉"，原文所述又确以"热"为枢纽，故读时须同时警惕两种误读：一是把"多从火化"读成"必从火化"，二是把"宜凉"读成"概用凉"。

建议每读一条，都在页边自问三句：本条底本是第几条？刘氏补了哪一环？这一环的条件是什么？能答清，才算读通。

#### 0_2_2 边界声明

运气可以算，结论却只是倾向。两条边界先立住：

- **算得准的是规则，算不准的是气候**：年干支、岁运、司天在泉都可逐字复核，但它对具体年份气候与疫病的"预测"属传统经验范畴，现代统计验证结果并不一致，只能当倾向假设，须用当年实际气象物候校正。
- **不可替代诊疗**：凡涉用药、针刺与防疫措施，一律以正规医疗与公共卫生指引为准；本册的"某气主某病"皆传统主张，只作学习与对照。

## 板块1 · 作者、年代与版本源流

本板块交代本书的"人、时、本"三件事，帮助读者把一部病机书放回它所产生的医史现场，理解为何寒凉之法会在那个年代破土而出。

### 1_1 作者刘完素

刘完素，后世尊称刘河间，金元时期河北河间一带医家，倡"火热论"，主张治病多从清热泻火着眼。

他与张从正、李杲、朱震亨并称为"金元四大家"（习惯排序为刘、张、李、朱），其中刘氏被推为"寒凉派"开山，张从正攻邪、李杲补土、朱震亨滋阴，四家共同打破了宋以来拘守成方的格局。

原文所述其学术以《素问》为宗，尤重运气七篇与病机十九条，故其书虽短，却上接经典、下开宗派，在医史上有枢纽地位。

### 1_2 成书年代

本书约成于十二世纪前后的金代，正值北方战乱、疾疫多发的时段，临床对"起效迅捷、直折热势"的治法需求迫切。

传统认为，当时医界沿《和剂局方》多用辛温香燥，遇外感热病每因燥药助热而反剧，这种"方不对机"的现实矛盾，正是催生刘氏革新的直接土壤。

从医史脉络看，寒凉派的诞生并非偶然：它是运气学说被长期用于"推年运、断气候"之后，第一次被大规模、成系统地"转译"为临床病机与治则，是运气落地治病的标志性事件。

### 1_3 版本流传

传世有《素问玄机原病式》单行本，亦收入《河间六书》《医统正脉》等丛书系统，现代则有多种校注本可供研读。

研读以有校勘的丛书本或现代点校本为稳妥，阅读时宜注意与《宣明论方》《素问病机气宜保命集》等刘氏他书互参，因其"火热论"在诸书中互为表里、各有侧重。

需要提醒的是，不同传本在分卷、条文归属上略有出入，凡遇异文，应回到"病机十九条"底本判断刘氏原意，不宜以某一传本的讹误为据。

## 板块2 · 核心主旨与内容梳理

本板块是全书的"骨架图"。以下各节不重复运气通用基础，而是紧扣本书独有贡献：它如何把十九条重讲一遍、如何列病式、如何定治则、如何定位运气。

### 2_1 病机十九条的"火热"再诠释

刘完素不另立一套病机，而是把《至真要大论》十九条中属风、湿、燥、寒的条目，逐条论证其在演变中"多从火化"，这是对七篇病机说的激进收束。

原文所述其思路是：外邪初感未必即热，然一经"郁滞"便生热化火，故临证所见热证十常八九，治当以清热为要。

这一再诠释的价值，在于把原本分散的"分类学"条文，编织成一条"以热为归宿"的动力学线索，使医生面对复杂证候时先找"热"、再辨"郁"。

### 2_2 五运主病与六气为病

书中首列"五运主病"与"六气为病"两类总纲，把运气框架下的致病因素，落到具体的"病式"（如热类、火类、风类、湿类等），每式各附症状与治则。

"五运主病"偏于从五行气化立论（如诸风掉眩、诸痛痒疮各有所属），"六气为病"则按风、热、湿、燥、寒分述，二者纵横交织，构成一张可检索的病机网。

这种"总纲加病式"的编排，使抽象的运气六气变成了桌面上可对照的"症状—病机—治法"三栏表，是运气临床化最实在的一步。

### 2_3 治法取向：辛凉解表、寒凉清里

对应"火热"病机，刘氏主张外感表证用辛凉透达、里热用寒凉清泻，旗帜鲜明地反对当时滥用辛温燥热。

原文所述其代表思路（如双解散、凉膈散一类的配伍雏形）讲究"表里双解、给邪出路"，既不纵容表寒久郁化火，也不因清里而冰伏表邪。

这一取向深刻改写了金元以降的治法谱系：后世温病学派"在卫汗之、到气清气"的清热存阴路线，皆可在此找到运气病机的源头。

### 2_4 与运气的关系定位

本书不重"算运"，重"运气所生之病机"，可理解为七篇给"天气模型"、本书给"天气致病的病机模型"，是运气从推演走向治病的关键一环。

传统认为运气之用有三层：推岁运、断气候、测病源；刘氏取第三层并加以临床化，使运气不再是"某年某气"的预言，而是"某气致病当如何辨治"的方法。

也正因如此，读本书不必先会排甲子、算司天在泉；它要你会的，是看"眼前这个证，是不是已经化火"。

### 2_5 以"亢害承制"为理论根基

常被忽略但极关键的一点是：刘氏全书的哲学底座来自七篇"亢则害，承乃制"——气亢盛到极点，反会生出制约它的变化，而"化火"正是这种亢逆之一象。

原文所述其逻辑为：六气本平，亢则为害；寒极似热、燥极生风，皆因亢逆太过、物极而反，故表面寒象深处可能藏着热机，这正是"皆从火化"的深层依据。

把这一条补进对本书的理解，才不至于把"六气皆从火化"读成一句武断口号，而能看出它是"亢害承制"在病机层面的具体展开。

## 板块3 · 关键概念与术语体系

本板块把书中反复出现的核心术语逐一拆解，作为后续推演与笔记的"词表"。每个术语都尽量说清其边界与条件，避免望文生义。

### 3_1 六气皆从火化

"六气皆从火化"是全书第一命题，意为风、湿、燥、寒诸气在病机演变中多可转归为热，强调"变"而非"恒"。

须注意原文所述是"多从"而非"尽从"：化火的前提是气机郁滞、无从疏泄，若表气尚通、津液未伤，则未必化火，故不可机械套用。

这一术语把医生的注意力从"辨初感何气"引向"察是否已化火"，是读本书时最该建立的动态眼光。

### 3_2 五志过极皆热

"五志过极皆为热甚"把怒、喜、悲、恐、思五种情志走到极端时，气皆郁结而内生热，首次把心理应激纳入运气病机体系。

它补足了"六气"之外的"人气"致病一环：天气可化火，人心过极亦可化火，二者在"郁而生热"上殊途同归。

传统认为这一条对今人尤有启发——长期情志不舒、气机壅滞者，每见内热之象，这正是古代"心身同病"观念的早期表达。

### 3_3 辛凉清里

"辛凉清里"是治则总括：解表用辛凉以透达，清里用寒凉以泻火，整体对抗辛温燥热之偏。

它并非"见热就下"，而是讲究分层——表未全入则辛凉透之，里已化火则寒凉清之，表里同病则双解并行。

理解此术语，要扣住"郁"字：辛凉是为了给郁闭的表邪开一条凉透之路，寒凉是为了把已成之热直折下来，二者都服务于"散热存阴"。

### 3_4 病机十九条（发挥底本）

本书所有发挥都挂在《至真要大论》病机十九条之上，是阅读全书的"坐标轴"，不熟此轴便无法判断刘氏改了什么。

十九条中"诸风掉眩皆属于肝""诸湿肿满皆属于脾"等，到刘氏笔下往往被补入"郁→热"一环，故同一句话，底本与发挥义并不全等。

建议把十九条抄成左栏、刘氏发挥抄成右栏对照阅读，这是打开本书最稳的入手方式。

### 3_5 亢害承制

"亢害承制"出自七篇，意为气亢盛至极反生其制，是刘氏解释"寒可化热、燥可生风"的根本机理。

它说明病机不是静态归类，而是动态博弈：某气过亢便物极而反，表面病象与深层病性可能相反（如寒极似热），这正是"皆从火化"能成立的理论前提。

把此概念列为术语，是为了提醒读者：本书论"化"、不论"恒"，凡见"已化火"之断，都要回问一句"亢在何处、制从何来"。

## 板块4 · 推演演示（含 ASCII 图）

本板块用三幅 ASCII 图演示本书的核心推演：诸气如何化火、病机十九条如何被改、五志如何归热。图后附解读，便于直接用于笔记。

### 4_1 病机转化链

下图演示风、湿、燥、寒四气在"郁滞"条件下皆向火（热）转化的共同路径，并标出五志过极同样汇入此链：

```
风(木) ─┐
湿(土) ─┼──→ 气机郁滞 ──→ 化火(热甚) ──→ 伤阴 · 动风 · 闭窍
燥(金) ─┤                          ↑
寒(水) ─┘              五志过极(怒喜悲恐思)亦归此
        （亢害承制：亢极则物极而反，寒极似热、燥极生风）
```

解读：四气初感未必即热，关键在"郁滞"一环；一旦气机壅而不通，便化火生热，进而伤阴、动风。五志过极因气结亦走同一条路。

### 4_2 条文对照演示

下图以"诸湿肿满，皆属于脾"为例，演示刘氏如何在底本之外补入"郁→热"一环：

```
十九条原意：  诸湿肿满，皆属于脾        （脾失健运，水湿停聚）
刘氏发挥：    湿郁不化 → 多从热化 → 治当清化，非徒健脾
对照结论：    刘氏在"脾"之外补了"郁→热"一环，治法由温燥转向清化
```

解读：底本重"属脾"之常，刘氏重"湿郁化热"之变；同一条文，一静一动，正是本书"发挥"的典型写法。

### 4_3 五志过极归热链

下图单独演示情志致病如何汇入火热，便于与天气化火对照理解：

```
怒(肝)→气上    喜(心)→气缓
悲(肺)→气消    恐(肾)→气下
思(脾)→气结  ──→ 气机郁结 ──→ 五志过极皆热甚
```

解读：五志分属五脏、走向各异，但极端处皆令气结不行，结久则化热，与四气郁滞化火同理，证明"火热"既可来自天气、亦可来自人气。

## 板块5 · 与七篇及他书的承启异同

本板块把本书放进运气学说的谱系中定位：它上承什么、下启什么、与同类书有何异同。所有"源头""奠基"类判断均标以"传统认为/原文所述"。

### 5_1 上承七篇

传统认为本书直接以《至真要大论》病机十九条为底本、以"亢害承制"为哲理，是七篇"病机"部分的临床展开与深化。

它不是另起炉灶，而是把七篇中早已埋下的"气有余便是火""亢则害承乃制"等种子，培育成一套可操作的辨治程序。

因此读本书前若未读七篇，会觉得其论断突兀；读过七篇再回看，方知每一"化火"之断皆有运气根脉。

### 5_2 下启温病与河间学派

传统认为其"火热""辛凉"思路下启明清温病学派：吴又可、叶天士一脉"清热存阴、卫气营血"的基调，皆可在本书找到运气病机的远源。

同时它奠定了"河间学派"一脉，金元以降凡主清热泻火、表里双解者，多奉刘氏为宗，双解散、凉膈思路亦流传为常用范式。

原文所述其价值更在"思路"而非"某方"：它教后人面对外感热病先想"是否已化火"，这一警觉比具体方药影响更久。

### 5_3 异同要点

七篇病机偏"分类学"——把证候归到某气某脏；刘氏偏"动力学"——强调病机如何演变、由何而化，这是二者最本质的方法论分野。

与《医学穷源集》"逐年病源、大司天论案"不同，本书不重"年运"而重"机变"，即不追问"今年属何运"，而追问"此证是否已化火"。

与《运气商》《运气辩》等后世纠偏之书相比，刘氏偏于立论之"锐"，后书偏于用之"慎"；读本书时应自带一分审慎，方不悖运气"为参考模型、勿机械套用"的共识。

## 板块6 · 案例佐证

> （虚构教学案例，不对应真实人物）

本板块用一则完整的教学小故事，演示如何把"火热论 / 六气皆从火化"用于实际辨证。故事按"情境—问题—用本书方法—结果—反思"展开，仅说明读法，不作任何医疗建议。

情境：阿岚是北方某镇药铺的年轻学徒，某年冬春之交，镇上连日外感发热的人多了起来。她也染了病，初起恶寒、头痛、周身酸楚，自以为受了风寒，便照镇上旧法喝了碗辛温姜汤发汗。

问题：三日后非但热不退，反而身热增高、咽痛红肿、目睛微赤、心烦口渴，大便三日未行，舌红苔薄黄而干。镇中一位老医仍按"外感风寒"旧例，欲再投辛温发散重剂，阿岚心中起疑：为何越温越重？

用本书方法：阿岚翻出《原病式》，先对"六气皆从火化"一条细想——寒邪初感虽属水，然入里郁滞、不得疏泄，便多从火化。她再查病机十九条："诸热瞀瘛皆属于火""诸胀腹大皆属于热""诸燥狂越皆属于火"，逐条比对自身热、赤、便难、心烦之象，判断此已非单纯风寒，乃寒邪入里、郁而化火之候。依书中"辛凉解表、寒凉清里"取向，她把思路从"温散"改为"辛凉透表、微清其里"，并记下"表未全入、里热初成，宜给邪出路，不可冰伏"。

结果：按辛凉清解的思路调护数日，阿岚自记"身热渐缓、咽痛减轻、大便得行、心烦转平"，体会到"先辨已化火与否"确是读本书的要害。她把这次经过写成一则笔记，标题便是"寒未必寒，问郁滞"。

反思：事后师傅点评：你这次用对了"多从火化"的警觉，但也要记牢刘氏说的是"多从"而非"必从"。后来阿岚又遇一位湿重身困、舌淡苔腻之人，师傅提醒："湿亦能化热，却须有郁滞之象；此人舌润脉缓，是湿未化热，若照搬清凉便误。"阿岚遂在笔记补一行："六气皆从火化，是有条件的转化，条件是郁滞；无郁则不化，临证必合舌脉。"此故事说明：本书教的是"病机转化的警觉"与"条件意识"，不是死守某方、见寒便温或见症便凉。

## 板块7 · 笔记方法与多场景记录

本板块给出四类可直接套用的笔记模板，帮助把本书"动态病机"的思维固化成可检索、可复述的个人知识。每种场景都强调"留下条件"，避免空记结论。

### 7_1 条文对照场景

左列《至真要》病机十九条原文，右列刘氏发挥，中间再加一栏标"同 / 改 / 加"，使每一条的创变一目了然。

例如"诸湿肿满皆属于脾"：同栏写"均责之脾"，改栏写"由温燥转清化"，加栏写"补郁→热一环"，三栏齐备才算读透。

长此以往，十九条会变成一张"刘氏改易地图"，日后遇湿证先查此条，便知何时该健脾、何时该清化。

### 7_2 病机转化图场景

在笔记中临摹板块4的三幅 ASCII 转化链，并在每一"跳"旁注明触发条件：风→火需"郁"，湿→火需"滞"，寒→火需"入里郁极"，五志→火需"过极"。

图旁宜留空白处，每遇一真实或书中的化火案例，就记一句"某证，因某条件而化火"，把抽象链变成自己的病例库。

这类图的妙处在"反例"：凡遇"初感寒却未化火"的情形，也记一笔"无郁滞，故未化"，以此守住"多从而非必从"的边界。

### 7_3 治则速查场景

单开一页，按"病式 → 宜凉 / 宜清 / 宜双解"列成速查表，如风火用辛凉、里热用苦寒、表里同病用双解。

每格旁注"忌辛温燥热"的对应情形，使"该用什么"与"不该用什么"成对出现，防止只记正面而漏了禁忌。

遇症即查，查后回书核对底本，渐能把刘氏的治法取向内化为条件反射式的辨治直觉。

### 7_4 辨析输出场景

试着向人讲清"为什么湿会化热""为什么寒极似热"，讲不通处必是"郁滞"条件没说清，立刻回查板块3、板块4补漏。

输出是最好的检核：能用自己的话把"亢害承制—郁滞—化火"一串讲顺，才说明已越过"背名词"阶段，进入"用模型"阶段。

建议每读一卷，便写一段三百字以内的"今日一得"，强迫自己把术语翻译成人话，这是把书读薄的关键习惯。

### 7_5 条件清单场景

专门建一页"化火条件清单"：郁滞、入里、过极、伤阴、闭窍，凡书中提及的化火前提都归档于此。

每添一条，顺手标"源自第几条 / 出自何病式"，使清单自带出处，避免把个人推演混入刘氏原意。

这张清单日后就是自测与临证的"红绿灯"：条件不全，不轻易断"已化火"。

## 板块8 · 实用验证与自测

本板块提供一套可操作的自我检验流程与三道自测题，用来确认是否真读懂了"动态病机"而非仅记住口号。所有验证均定位为传统医学参考模型的练习。

### 8_1 病机转化自测

下面流程可对任意一外感证候做"是否化火"的推演自测，框定在传统病机模型内使用：

```
第1步  取一外感病例，标其初起属性(风 / 湿 / 燥 / 寒)
第2步  问：是否出现"郁滞 / 入里 / 过极"？  → 是则进入第3步
第3步  推：气机壅结 → 化火(热甚) → 伤阴 / 动风
第4步  核对书中该病式是否归入"热类 / 火类"
第5步  结论：符合"多从火化" / 仍为原气(未化，条件不全)
```

提示：若条件不全（如无郁滞、舌润脉缓），应判"未化"，这正是守住"多从而非必从"的实操训练。

### 8_2 自测题

「1」请用自己的话说明"六气皆从火化"的含义，并列举至少两个"不化"的条件（如未郁滞、津液未伤）。

「2」刘氏与《至真要大论》在"湿"的病机上主要不同在哪？提示：底本重"属脾"，刘氏补"郁→热"一环。

「3」"五志过极皆热"对今日理解"情志—内热"关系有何启示？请结合一条生活观察作答。

「4」试以"亢害承制"解释"寒极似热"：为何表面寒象深处可能藏着热机？（进阶题）

### 8_3 验收标准

能不看书答出"化火四条件"且举例，算"入门"；能在一条条文上标清"同改加"并讲出机理，算"读通"；能向他人讲顺"亢害承制—郁滞—化火"全链，算"内化"。

凡卡在某一档，回对应板块重读即可，不必通篇返工——本书结构本就支持按缺口定点回查。

## 板块9 · 现代意义、研究与延伸阅读

本板块把这部八百年前的病机书，对接到今天的阅读与研究方向，并明确其边界：它是传统医学的参考模型，不是诊疗依据。

### 9_1 现代视角

现代医学中"炎症—发热"一类概念，与古代"火热"在表象上有一定可比性，但二者理论体系不同，不可简单等同，更不宜以化验指标反推运气。

本书真正可取的现代价值，在于其"动态病机"思维：不把证候当静态标签，而追问"它正往哪转化、条件是什么"，这种建模方式对今天的辨证训练仍有启发。

传统认为刘氏"偏于寒凉"的立论，在今天更宜读作一种"纠偏"——它针对的是当时辛温燥热之弊，而非放之四海皆准的定法，这一语境意识同样适用于读任何古籍。

### 9_2 边界与提醒

本书所及治法仅为古代文献记录，今人若身体不适，务必就医，本文及本笔记不作任何医疗建议。

运气学说与本书病机发挥，均属传统医学的参考模型，宜作"因时制宜"的辅助维度，不可机械套用、以运代医。

凡把"六气皆从火化"当绝对定律、或据本书自行立方者，皆已偏离刘氏"多从""有条件"的本意，阅读时须自带审慎。

### 9_3 延伸阅读

向上承接：《素问·运气七篇大论》（尤重《至真要大论》病机十九条与"亢害承制"一段），是本书全部发挥的底本与根基。

平行对读：《医学穷源集》以"大司天"论医案，可对照体会"重年运"与"重机变"两种运气用法之别。

向下续看：《运气商》《运气辩》等明清纠偏之书，专论运气不可刻板套用，正好补足刘氏"立论之锐"后的"用之之慎"。

同派互参：刘氏本人的《宣明论方》《素问病机气宜保命集》，可与本书互为表里，看"火热论"如何同时落在病机与方剂两端。
