## 板块1 · 开场：为什么这本小册子值得再读一遍

《药性赋》旧题金元时期作品，作者不详，历来列为中医"四小经典"之一。它的做法很朴素：把约 248 味常用中药按**寒、热、温、平**四性编成韵文，四言六言，对仗押韵，朗朗上口。全赋分四章，各章药数传统口径为**寒性 66 种、热性 60 种、温性 54 种、平性 68 种**。

但请注意一件事：**这本书不是"用药说明书"，而是一张索引地图**。赋文只告诉你"这味药最擅长干什么"，几乎不写剂量、禁忌、炮制和真伪优劣。所以正确的打开方式是：以赋为纲搭骨架，再以本草专著（现代《中药学》教材、《中华本草》）填血肉。

> **一句话定位**：药性是中医"理法方药"链条里最靠前的一环。辨证辨到最后，总要落到"用什么药"——这一落点，全在药性里。

## 板块2 · 先立框架：四性、五味与升降浮沉

读赋之前，先把三个坐标搞清楚。否则赋文背得再熟，也是一堆散装词条。

### 2_1 四性：寒与凉一家，温与热一伙

| 类别 | 阴阳属性 | 核心治则 | 典型药 |
| --- | --- | --- | --- |
| 寒凉 | 属阴 | **热者寒之**——清热、泻火、解毒、凉血、滋阴 | 石膏、黄连、犀角（水牛角代） |
| 温热 | 属阳 | **寒者热之**——散寒、温里、助阳、回阳 | 附子、干姜、肉桂 |
| 平 | 界限不显 | 作用缓和，可作长期调补与方中"底盘" | 甘草、茯苓、人参 |

判定标准只有一个：**用药后的反应 + 所治证候的寒热**。能消除热证的，就是寒凉药；能消除寒证的，就是温热药。"平性"不是没药性，而是寒热倾向不鲜明、偏性小，适合久服和打底。

### 2_2 五味：决定"干什么"，比四性更具体

赋文讲四性、不讲五味，但五味才是落到功效上的关键：

- **辛**：发散、行气、行血 → 麻黄、桂枝、川芎
- **甘**：补益、和中、缓急 → 甘草、熟地、党参
- **酸（涩）**：收敛、固涩 → 乌梅、龙骨、牡蛎、赤石脂
- **苦**：清泄、燥湿、降泄 → 黄连、大黄、栀子
- **咸**：软坚散结、泻下 → 芒硝、海藻、昆布
- **淡**（附）：渗湿利水 → 茯苓、猪苓、泽泻

**实操口诀**：看到功效词就能反推味。"散结"多半咸（海藻、昆布、芒硝），"收涩止泻"多半酸（乌梅、赤石脂），"通便"苦或咸。这条规律在赋文里反复印证。

### 2_3 升降浮沉：赋文藏得最深、最值钱的一层

《药性赋》看似只讲寒热，其实**通篇都在暗写升降浮沉**——只是没点破。而这一层，恰恰是"同是清热、为什么选 A 不选 B"的真正答案。

**四条判断法则（务必背熟）**：

| 维度 | 升浮（向上、向外） | 沉降（向下、向内） |
| --- | --- | --- |
| 四气 | 温、热 | 寒、凉 |
| 五味 | 辛、甘、淡 | 苦、酸、咸 |
| 部位质地 | 花、叶、质轻 | 子、实、质重 |
| 代表 | 麻黄、升麻、黄芪 | 大黄、芒硝、苏子、枳实 |

**赋文中的升降证据链**（这是本书最精彩的部分，原文不直接说，全靠对读）：

- **"宽中下气，枳壳缓而枳实速也"** → 同株植物，实（幼果）沉降力强、壳（近成熟）力缓。部位定升降。
- **"疗肌解表，干葛先而柴胡次之"** → 葛根升津透表、止渴为先；柴胡和解退热、疏肝次之。次序即趋向。
- **"旋覆花明目治头风，而消痰嗽壅"** + 俗语"诸花皆升，旋覆独降"→ 旋覆花是降气止呕、消痰降逆的代表。花本当升，它偏降，所以格外要记。
- **"桔梗下气，利胸膈而治咽喉"** → 桔梗为"诸药之舟楫"，载药上行，开宣肺气。
- **"升麻消风热肿毒，发散疮痍"** 而补中益气汤里升麻、柴胡**升举阳气** → 同一味药兼具"清热解毒"与"升阳"两面。
- **"常山理痰结而治温疟，葶苈泻肺喘而通水气"** → 常山涌吐痰涎（升浮），葶苈泻肺逐水（沉降），二者常被后人编成"常山葶苈"对子，一升一降。

> **落地方法**：给每味药打两个标签——`[性]` 和 `[向]`。比如薄荷 = `{辛凉 | 升浮}`，大黄 = `{苦寒 | 沉降}`。两个月后你会发现，选药不再靠"好像记得"，而是靠"病位在上用升浮、病势上逆用沉降"。

## 板块3 · 逐章拆解：四性之偏，即是治病之用

赋文的每一章都以一句总纲起头，这句总纲比后面 60 多味药都重要——**它是这一章的"使用说明书"**。

### 3_1 寒性药：六十六种，专治"热者寒之"> **总纲**：_诸药赋性，此类最寒。_（凡能消除热证的皆属寒凉）

**开篇五句即全章纲领**，值得逐字拆：

| 原文 | 白话 | 归经要点 | 现代对应 / 提醒 |
| --- | --- | --- | --- |
| 犀角解乎心热 | 清心经热毒、凉血 | 心经 | 犀角已禁用，**水牛角替代**，清心凉血、泻火解毒 |
| 羚羊清乎肺肝 | 清肝肺火热、息风止痉 | 肝（兼肺） | 高热惊厥、惊风抽搐、目赤肿痛 |
| 泽泻利水通淋而补阴不足 | 利水渗湿，又防滋阴碍湿 | 肾、膀胱 | "补阴不足"是**制约滋阴药之弊**，非补阴主药 |
| 海藻散瘿破气而治疝何难 | 软坚散结、消瘿瘤疝气 | 肝、胃、肾 | **咸味软坚**的典型 |
| 菊花能明目而清头风 | 疏风清热、平肝明目 | 肺、肝 | 注意：赋文此处偏**清热平肝**，与温性章菊花用法不同 |

**记忆锚**：_心火找犀角（水牛角），肝火肺火找羚羊_。同是"角"，犀牛沉静属阴、镇心降火；羚羊迅捷善走、清肝息风——这是用"取象"理解药性的活例子。

**全章功效聚类**（把 66 味自己归成 7 组，才是真会背）：

1. **清热泻火**：石膏、知母、栀子、黄芩、黄连、黄柏（"三黄"分经：芩泻肺、连泻心、柏泻肾/相火）
2. **清热凉血**：生地、赤芍、牡丹皮、犀角（水牛角）、地骨皮
3. **清热解毒**：金银花类、连翘、射干、山豆根、贯众、升麻
4. **清热燥湿**：黄连、黄柏、苦参、白鲜皮
5. **滋阴清热（退虚热）**：天冬、麦冬、生地、玄参、地骨皮、知母
6. **利水渗湿通淋**：泽泻、车前子、滑石、瞿麦、石韦、茵陈
7. **泻下与攻逐**：大黄、芒硝、牵牛子、葶苈子

**最容易踩坑的三个"对子"**（赋文专门用对比句教你区分）：

- **枳实 vs 枳壳**：实速壳缓，部位定强弱
- **葛根 vs 柴胡**：葛根先、柴胡次；葛根治阳明（项背、口渴），柴胡治少阳（寒热往来、胁痛）
- **熟地 vs 生地、白芍 vs 赤芍**：
    - 熟地补血疗虚损，生地凉血医眼疮 → **制与不制，一补一清**
    - 赤芍破血疗腹痛，白芍补虚生新血 → **赤泻白芍**，同根异用

>  **现代替换清单**（赋文里不能直接照抄的）：犀角→水牛角；虎骨→已禁用，改用狗脊、牛膝、杜仲等壮筋骨药；麝香→人工麝香或冰片、苏合香替代；马兜铃→含马兜铃酸，现代严格限制；轻粉（腻粉）→有毒慎用。

### 3_2 热性药：六十种，"回阳救逆"的主力战场

> **总纲**：_药有温热，又当审详。_

这一章的特点是**"救"字当头**——附子、干姜、肉桂、吴茱萸、川乌，全是寒证、虚证、厥逆证的救命药，同时也是**全书毒性最集中**的一章。

**核心药链**（掌握这几条，热性章就通了）：

**「1」 回阳救逆第一梯队：附子—干姜—肉桂**

| 药 | 赋文定位 | 关键用法 |
| --- | --- | --- |
| 附子 | "疗虚寒翻胃，壮元阳之力" | 回阳救逆第一品；**须久煎减毒**；不同炮制差别极大（生附、制附、附片） |
| 干姜 | "暖中" | 温中焦、回阳通脉；配附子为"附子无姜不热" |
| 肉桂 | "行血而疗心痛，止汗如神" | 补火助阳、引火归元；**官桂畏赤石脂** |

**「2」 温里散寒梯队**：吴茱萸（"疗心腹之冷气"）、高良姜（"止心气痛之攻冲"）、荜茇、荜澄茄、川椒、胡椒、丁香（"快脾胃而止吐逆"）、沉香（"下气补肾，定霍乱之心疼"）、橘皮（陈皮，"开胃去痰，导壅滞之逆气"）。

**「3」 温经与祛风湿**：川乌（"破积，有消痰治风痹之功"）、天雄、独活（"疗诸风，不论久新"）、威灵仙、五加皮、狗脊。

**必须牢记的配伍红线**（全部出自本章）：

- **乌头反半夏**（"附子疗虚寒"↔ 半夏燥湿化痰，药性相激）——十八反核心条目之一
- **川乌、草乌畏犀角**
- **巴豆畏牵牛**；巴豆"利痰水，能破积热"，峻下，与牵牛同用为大忌

> **核心警示**：附子用得对是回阳救逆第一品，用得偏便是杀人之毒。炮制、剂量、久煎、配伍，任何一环都**不能凭赋文判断**——必须查本草专著与师承经验。

### 3_3 温性药：五十四种，最常用的"日常处方层"> **总纲**：_温药总括，医家素谙。_（温药是医家最熟、用得最多的层）

这一章和"热性章"的分界要搞清楚：**温性偏于"调补+理气+祛风湿"，热性偏于"救逆+大辛大热"**。温药安全得多，是处方的主体。

**四大板块**：

**（1）补气健脾**——人参、黄芪、白术、山药、甘草、茯苓、薏苡仁、白扁豆、大枣、神曲、麦芽、谷芽
**（2）补血活血**——当归、熟地、白芍、川芎（"治头疼之要药"）、桃仁、红花、丹参、蒲黄
**（3）理气化痰**——陈皮、半夏、木香、香附、枳实、厚朴、砂仁、豆蔻
**（4）祛风湿、强筋骨、止咳**——防风、羌活、独活、白芷、细辛、苍术、防己、杜仲、续断、菟丝子、紫菀、款冬花、杏仁

**本章是"药对思维"的训练场**（背药不如背对）：

| 药对 | 机制 | 出处逻辑 |
| --- | --- | --- |
| 黄芪 + 陈皮 | 补气防壅滞 | 补而不滞 |
| 熟地 + 砂仁 | 滋阴防滋腻 | 补而不滞 |
| 半夏 + 陈皮 | 燥湿 + 理气 | 治痰先理气，气顺痰自消 |
| 防风 + 黄芪 + 白术 | 玉屏风散，益气固表 | 补中有散 |

**赋文中藏在角落的配伍指示**（这些比单味功效更值钱）：

- _"散肾冷、助脾胃，须荜澄茄；疗心痛、破积聚，用蓬莪术"_ → **"须""用"是君臣佐使的提示**
- _"缩砂止吐泻安胎，化酒食之剂"_ → 砂仁既能安胎又能化酒食，一药两向
- _"麻黄表汗以疗咳逆"_（热性章）+ _"疗肌解表，干葛先而柴胡次之"_（寒性章）→ 麻黄在温、发表在寒，**同一药因配伍归经不同，章节归属有异，不可死扣**

### 3_4 平性药：六十八种，"和事佬"才是方子的底盘

> **总纲**：_详论药性，平和惟在。_

平性药是最容易被低估的一章。它不"猛"，但**几乎所有方子都有它的影子**——补气、养血、安神、收涩、利水，全靠它们打底。

**四类主力**：

1. **补气养血**：人参、甘草、大枣、紫河车、阿胶、当归
2. **利水渗湿**：茯苓（"补虚劳，多在心脾"）、赤茯苓（"破结血，独利水道"）、猪苓、木通、商陆
3. **安神收涩**：茯神、远志、酸枣仁、柏子仁、龙骨、牡蛎、金樱子、桑螵蛸、乌梅
4. **理气消食、祛风湿**：青皮、陈皮、木香、神曲、麦芽、砂仁、天麻、牛膝

**平性章的"对比黄金句"**（赋文特意成对出现，正是为了让你区分）：

- **赤茯苓 vs 白茯苓**：赤者入血分、破结利水；白者入气分、健脾补中 → **同株异部，一利一补**
- **鳖甲 vs 龟甲**：鳖甲"治劳疟，兼破症瘕"（偏软坚散结、退热）；龟甲"坚筋骨，更疗崩疾"（偏滋阴潜阳、益肾） → 同属介类，一散一补
- **茯神 vs 茯苓**：茯神宁心益智、主惊悸；茯苓健脾利湿 → 茯神即茯苓抱木部分，"抱木者安神"> **核心洞察**：方剂里真正"不出错"的底盘，几乎全是平性药。**学好平性药 = 学会组方的骨架**，再往骨架上挂寒药、热药，方子才有层次。

**七情**：单行、相须、相使、相畏、相杀、相恶、相反。其中前五种可用，后两种（**相恶、相反**）属禁忌。

诸参辛芍叛藜芦（**藜芦反人参、沙参、丹参、玄参、苦参、细辛、芍药**）。

**十九畏**：

> 硫黄畏朴硝，水银畏砒霜，狼毒畏密陀僧，巴豆畏牵牛，丁香畏郁金，川乌草乌畏犀角，牙硝畏三棱，官桂畏赤石脂，人参畏五灵脂。

### 4_4 古病名 → 现代病症对照表

赋文用金元时期的病名，直接照字面理解会跑偏。整理如下：

| 赋文病名 | 对应现代概念 |
| --- | --- |
| 痨瘵 / 劳疟 / 劳嗽 | 肺结核、慢性消耗性疾病 |
| 翻胃 / 反胃 | 幽门梗阻、胃食管反流、胃癌晚期 |
| 崩漏 | 功能性子宫出血、异常子宫出血 |
| 肠风 / 痔痢 | 便血、痔疮、痢疾 |
| 五淋 | 泌尿系感染、结石 |
| 症瘕 / 积聚 | 腹腔肿瘤、肝脾肿大、囊肿 |

> **用法**：读赋文时把病名实时翻译成现代概念，记忆锚点立刻从"古文"变成"症状画面"，回想速度翻倍。

### 4_5 从"药性"到"方剂"：四步走的通路

```plain
辨出寒热（理法）
   ↓ 选择药性（寒者热之 / 热者寒之）
选定某一性的药群
   ↓ 据病位定升降（上→升浮，下→沉降，逆→降，陷→升）
确定趋向
   ↓ 据功效聚类 + 七情配伍
组织药对 → 成方（君臣佐使）

```

**示例**：辨证为"风寒束表、肺气不宣"→ 选温热解表药（麻黄、桂枝，辛温升浮）→ 配杏仁降气（一宣一降）→ 麻黄汤。全过程只用了"四性 + 升降 + 药对"三条。

### 5_3 三个反遗忘技巧

**「1」 场景绑定法（国医大师王永钧经验）**
把功效绑到具体症状画面：记"麻黄"，就绑定"风寒感冒、发热、无汗、身痛、麻黄发汗解表散寒"。**给知识安上锚点，才不会"背了用不上"**。

**「2」 三分背诵、七分对照**
对照三样东西：**药店实物**（摸质地、闻气味、尝滋味）、**方剂**（《汤头歌诀》）、**脉象**（《濒湖脉学》）。"认药不认嘴，认嘴不认手"——没亲手摸过、亲口尝过，永远是别人的药。

**「3」 滚动复盘 + 错字卡**
每天 15 分钟回顾；每周一次全文通读；**错字漏字超 5 个即不合格**（全赋约 2500 字，含标点约 2822 字）。

### 5_4 避坑清单（读赋最常见的六个误区）

1.  **把赋当处方** →  赋是索引，剂量/禁忌必查本草
2.  **死抠章节归属**（同一药不同版本分章不一） →  抓住"性 + 功效"即可
3.  **照搬珍稀/毒性药**（犀角、虎骨、麝香、马兜铃、轻粉） →  用现代替代品并遵法规
4.  **忽视升降浮沉** →  这是赋文最隐藏的价值，务必显式标注
5.  **只背不对照方** →  背一首赋文，拆三首方子，效率最高
6.  **忽略炮制和用法差异** →  生熟、汤丸、久煎、先下后下，赋文一概未载，须另学

## 板块6 · 结语：赋是地图，不是疆土

《药性赋》最了不起的地方，是用两千多字给近 250 味药建了一张**可检索、可背诵、可推导**的索引。但它始终是"地图"——真正的能力在于：

> **见寒热 → 知四性 → 辨病位 → 定升降 → 组药对 → 成方**。

六步走完，赋文才从"顺口的句子"变成"手里的工具"。接下来最自然的延伸，是《汤头歌诀》（学成方结构）与《神农本草经》《本草纲目》（补单味细节）。读赋千遍，不如**亲手组一个方、亲手识一味药**。

## 板块9 · 案例拆解：四性背得熟，升降却用反

（虚构教学案例，不对应真实人物）一位患者气逆咳喘，自学者见"麻黄"性温散寒，便用于虚喘，服后心悸、汗出、喘更甚。

四性是横坐标，升降浮沉是纵坐标。麻黄辛温而升散，用于寒邪闭表之实喘；虚喘气 already 不纳，再用升散，是逆其势。药性赋把四性串成韵语，纵坐标却要靠本草与方书补，只背赋文，等于只学了半张地图。

**落点**：选药先问"往哪个方向走"，再问"寒热温凉"。方向错，性味对也没用。
