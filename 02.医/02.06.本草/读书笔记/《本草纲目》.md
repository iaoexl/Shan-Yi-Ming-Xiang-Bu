### 0_1 学习路径

#### 0_1_1 这本书在体系里的位置

方药类。药物的博物志，五十二卷、一千八百余种，任何人都不可能通读。读法：序例读理论（四气五味、七情和合），谷菜果部读日常，毒药部只作文献；其余当反查工具，按病证找药，别从头啃。

1. 医学三字经、医学源流论——建立医学史与范式认知

3. 神农本草经 + 药性赋 + 汤头歌诀——药性与方剂口诀
4. 伤寒论、金匮要略——辨证论治的实战主干
5. 温热论、温病条辨——补上温病一支
6. 景岳全书、血证论、类证治裁——各家学说与专科深入

#### 0_2_1 使用建议

#### 0_2_2 边界声明

本册是文献研读与学习笔记，不构成诊疗建议。读这本书时，有两条边界要守住：

方中剂量一律保留原书古制，不作现代克数换算——经方剂量考证口径相差可达数倍，照某一系数抓药是自学最危险的动作。有毒药物（附子、乌头、朱砂、雄黄、马钱子、巴豆等）与十八反十九畏涉及的组合，只作文献阅读，实操交执业医师。

## 板块1 · 先破题：这不是一本「药方大全」

多数人翻开《本草纲目》，期待的是一本按病索方的速查手册。翻了几卷就会失望——满纸的「释名」「集解」「正误」，药方反而埋在每条药物的末尾。

这不是书的缺陷，而是阅读姿势错了。

李时珍给自己定的任务是「考释性理，实吾儒格物之学」。他要解决的，是宋明以来本草知识的三大病：**舛（错）、谬（误）、遗漏**。药材名字混乱，一物多名、多名一物；性味记载互相打架；民间经验口口相传，无人系统整理。他的书因此天然分成两条线：

- **「是何物」之线**：辨明药材的真伪、形态、产地、采收（卷五至卷五十二，占全书九成篇幅）；
- **「如何用」之线**：药性理论与临证指南（卷一至卷四，序例与「百病主治药」）。

现代读者若想从书中「拿得走东西」，关键不是背诵某一首偏方，而是掌握这两条线背后的**方法论**：**先辨清对象，再匹配用法**。这在信息爆炸、养生谣言横行的今天，比任何单方都更值钱。

### 1_1 一个阅读策略

| 你的目标 | 建议主攻章节 | 读法 |
| --- | --- | --- |
| 学养生食疗 | 卷一序例 + 谷、菜、果、木部 | 通读「粥」「茶」「果实」条 |
| 学药性思维 | 卷一「脏腑虚实标本用药式」「升降浮沉」 | 精读 + 对照日常食材 |
| 了解成书精神 | 王世贞原序 + 李时珍自序 | 速读，建立整体感 |
| 临证参考 | 卷三、卷四「百病主治药」 | 按症状反向检索 |
| 博物与文化 | 水、火、土、金石、服器部 | 泛读，当明代百科全书看 |

### 2_2 三层结构：总论 → 临床索引 → 药物各论

**第一层：序例（卷一、卷二）**
相当于全书总论。一面回顾历代本草 41 种，一面系统整理药性理论——气味阴阳、五味宜忌、标本阴阳、升降浮沉、补泻、引经报使、各类用药禁忌。金元诸家（张元素、李东垣、张子和、王好古）之论，多汇于此。

**第二层：百病主治药（卷三、卷四）**
沿用《证类本草》「诸病通用药」旧例，以**113 种病证为纲**，罗列主治药名及功效，再于病证下按草、菜、果、木等分列小纲。这一层是临证手册，思路是「从病找药」，与各论的「从药找病」正好互补。

**第三层：药物各论（卷五至卷五十二）**
以部为纲、以类为目，16 部 60 类。每药先标正名，下列 8 个项目（释名、集解、辨疑/正误、修治、气味、主治、发明、附方），所谓「标名为纲，列事为目」。

### 2_3 「以纲挈目」四字，是全书最被低估的创新

「纲目」二字不是修饰词，而是**体例革命**。此前所有本草书都按「上、中、下三品」分类——这是价值判断（可久服 vs 有毒），不是认知分类。李时珍把它彻底废掉，改成：

> **「不分三品，惟逐各部；物以类从，目随纲举。」**

这八个字包含三层方法论，至今通用：

1. **「物以类从」——按事物本来面目归类**，而非按道德评判分层；
2. **「以部为纲」——先建大框架**，16 部相当于 16 个一级目录；
3. **「以类为目」——再逐层细分**，部下有类（60 类），类下有族（隐而未显，实际已按科属排列）。

做学问、整理资料、甚至管理个人知识库，都可套用这套「先立纲、再分目」的框架。

## 板块3 · 分类逻辑：一部暗含「进化论」的 16 部

### 3_1 部的完整结构

| 界别 | 部 | 下属类别举例 |
| --- | --- | --- |
| **无机物界** | 水部、火部、土部、金石部 | 天水、地水；金、玉、石、卤石 |
| **植物界** | 草部、谷部、菜部、果部、木部、服器部 | 草部分为山草、芳草、隰草、毒草、蔓草等 11 类 |
| **动物界** | 虫部、鳞部、介部、禽部、兽部 | 禽部分为水禽、原禽、林禽、山禽 |
| **终结** | 人部 | — |

李时珍自己说明排序理由：

> 「首以水火，次以土，水火为万物之先，土为万物母也。次之以金石，从土也。次之以草、谷、菜、果、木，从微至巨也。次之以虫、鳞、介、禽、兽，终之以人，从贱至贵也。」

「从微至巨」「从贱至贵」——从无机到有机，从低等生物到高等动物，再到人。**这一序列与 19 世纪达尔文的生物进化思想不谋而合**，比林奈的植物分类法早了一百余年。达尔文在《动物和植物在家养下的变异》中多次引用《本草纲目》关于鸡的品种、金鱼等记载，称其为「中国古代的百科全书」。

### 3_2 分类里藏着的三个现代启示

1. **「服器部」排在木部之后**——因其多以竹、木、棉为原料。这是按「物质来源」而非「用途」归类，体现**追根溯源**的思维；
2. **植物部分按形态细分**（山草、芳草、水草、石草……）——已暗含按生境、科属划分的现代植物学思想，为后世植物分类学开了先河；
3. **「人部」终结全书**——不是迷信，而是把人放回自然序列的最高点，完成「万物—人」的闭环。

### 3_3 类的细分，是一张可复用的分类模板

以「草部」为例，10 个细目几乎覆盖了草本植物的全部生态位：山草、芳草、隰草、毒草、蔓草、水草、石草、苔类、杂草、有名未用。这种「**先分大类、再按生态/形态细分**」的模板，可直接用于任何知识体系的结构化整理。

## 板块4 · 单味药的「八项信息标准」：最实用的知识框架

这是全书**最值得提取到现代生活中使用的思维工具**。李时珍为每一味药设立标准化条目，相当于今天的「药物数据卡」：

| 条目 | 回答的问题 | 现代对应 |
| --- | --- | --- |
| **释名** | 古今别名、命名由来 | 统一命名，避免混淆 |
| **集解** | 产地、形态、生长环境、最佳采收 | 溯源与鉴定 |
| **辨疑 / 正误** | 前人记载哪里错了 | 批判性校验 |
| **修治** | 如何炮制加工 | 工艺标准 |
| **气味** | 四气五味、有毒无毒 | 药性指标 |
| **主治** | 对应病症 | 功效清单 |
| **发明** | 名家心得、药理解读 | 理论与经验 |
| **附方** | 以该药为主的实际方剂 | 应用案例 |

**这套「八项标准」的本质，是强制每次认知都走完一个闭环**：是什么 → 从哪来 → 有没有错 → 怎么处理 → 有什么用 → 怎么用。做任何专业判断（选品、投资、用人），都可以照抄这个模板。

### 4_1 实操：用「八项标准」整理你的厨房食材

不必等生病才翻开书。把家中常用食材做成一张「本草卡片」，方法完全同构：

- **释名**：生姜别名「地辛」「百辣云」；红枣即「大枣」
- **集解**：产地、品种、何时采收最佳
- **辨疑**：别把「山药」当「土豆」（古人确实混淆过薯蓣类）
- **修治**：姜要不要去皮？枣要不要去核？
- **气味**：生姜辛温；红枣甘温
- **主治**：姜温中止呕；枣补中益气
- **发明**：历代名家怎么说
- **附方**：姜枣同用，是桂枝汤的基础结构

做完 20 张卡片，你对「药食同源」的理解会远超 90% 的人——因为**你掌握的是方法，不是知识点**。

## 板块5 · 药性理论：读懂「四气五味」才算入门

序例卷一集中了全书的药性理论。这是《本草纲目》最难但最值得啃的部分，因为它是**所有具体用法的「底层代码」**。

### 5_1 四气：用药物的偏性，纠正人体的偏性

四气即寒、热、温、凉（平性归于温和凉之间）。核心原则只有一句：

> **「疗寒以热药，疗热以寒药。」**（《素问》引文，本书重申）

- 能消除寒证的 → 热性/温性药（如干姜、附子）
- 能消除热证的 → 寒性/凉性药（如黄连、石膏）

**实操转换**：不确定食材是寒是热时，用它**对身体的「感觉」反推**——

- 吃完觉得暖、出汗、燥 → 偏温热（姜、羊肉、花椒）
- 吃完觉得凉、清爽、通便 → 偏寒凉（梨、绿豆、菊花）

对应到日常饮食：冬天手脚冰凉、容易腹泻的人，多用温热食材；夏天长痘、便秘、口苦的人，多用清凉食材。**方向搞反，等于火上浇油。**

### 5_2 五味：味道本身就是功效说明书

| 味 | 核心作用 | 代表 | 现代直觉验证 |
| --- | --- | --- | --- |
| **辛** | 散、行（发散、行气、行血） | 姜、葱、薄荷、花椒 | 吃辣发汗、通气 |
| **甘** | 补、缓、和（补益、缓急、调和） | 甘草、红枣、蜂蜜 | 糖能缓解疲劳、调味 |
| **酸** | 收、涩（收敛、固涩） | 乌梅、山楂、五味子 | 酸味生津、收敛 |
| **苦** | 泻、燥（清热、燥湿、泻下） | 黄连、苦瓜、黄芩 | 苦能降火、通便 |
| **咸** | 软、润（软坚散结、润下） | 海藻、海带、芒硝 | 海带软坚、咸味通便 |

> 「辛散、酸收、甘缓、苦坚、咸软。」——《黄帝内经》

**关键洞察**：「味」分两层。**自然之味**（口尝的酸甜苦辣）与**临床之味**（功效上的酸苦甘辛咸）常常一致，但**不必然一致**。典型如海螵蛸（乌贼骨）：成分是碳酸钙，口尝一点不咸，但因其有收敛作用，药性归「咸」。李时珍在书中订正了钩藤、败酱等多味药物的性味——**不能只信舌头，要信功效**。

### 5_3 一个被忽略的精密结构：五脏与五味的对应矩阵

这是卷一里最「实操」的一张表，可直接用来做日常饮食决策：

| 五脏 | 所宜（补） | 所禁（伤） | 五色对应 |
| --- | --- | --- | --- |
| 肝 | 酸（麻、犬、李、韭） | 辛 | 青 |
| 心 | 苦（麦、羊、杏、薤） | 咸 | 赤 |
| 脾 | 甘（粳、牛、枣、葵） | 酸 | 黄 |
| 肺 | 辛（黄黍、鸡、桃、葱） | 苦 | 白 |
| 肾 | 咸（大豆、豕、栗、藿） | 甘 | 黑 |

李时珍在「五禁」下点明：

> 「肝病禁辛，宜食甘；心病禁咸，宜食酸；脾病禁酸，宜食咸；肺病禁苦，宜食辛；肾病禁甘，宜食辛。」

再叠加**四季调整**：

> 孙思邈曰：**春宜省酸增甘以养脾，夏宜省苦增辛以养肺，秋宜省辛增酸以养肝，冬宜省咸增苦以养心。**

#### 5_3_1  落地示例：四季饮食调整清单

| 季节 | 原则 | 具体动作 |
| --- | --- | --- |
| 春季 | 省酸增甘，养脾气 | 少吃醋、酸味收敛物；多吃小米、红枣、山药 |
| 夏季 | 省苦增辛，养肺气 | 苦瓜、苦丁茶减量；适当加点姜、葱、花椒 |
| 秋季 | 省辛增酸，养肝木 | 姜、辣椒减量；多吃山楂、乌梅、酸味水果 |
| 冬季 | 省咸增苦，养心火 | 腌菜、重盐减量；适当吃些苦瓜、莲子心 |

 这是**方向性指南**，不是精确食谱。核心是「**因时调偏**」——哪个季节容易出问题的脏腑，提前用饮食给它减负。

### 5_4 用药的「剂量红线」：任何现代读者都该记住的一段话

> 「大毒治病，十去其六；常毒治病，十去其七；小毒治病，十去其八；无毒治病，十去其九。谷、肉、果、菜，食养尽之，无使过之，伤其正也。」

**翻译**：用猛药，病好六成就该停；用普通药，好七八成就停；用温和药，好九成就停。剩下的靠饮食调养收尾。**永远不要追求「彻底清零」，过犹不及会伤正气。**

这句话对现代人的意义在于：**任何保健品、补品、甚至运动计划，都应遵循「中病即止」的节奏**，而不是一路加到极限。

## 板块6 · 原文精读：10 段值得抄下来的话

> 本节只做「译文 + 解读 + 现代转译」，拒绝堆砌原文。

### 6_1 方法论类

**「1」「医者贵在格物。」**
解读：医学的根本在于**穷究事物的真实面目**。这句话是全书的「题眼」。李时珍花 27 年做野外考察、解剖穿山甲、亲尝曼陀罗，都是为了「格物」。
_现代转译_：面对任何健康信息，先追问「证据在哪、对象是否搞错」，比记住结论更重要。

**「2」「凡药之所用，皆以攻邪，非以养正。」**（序例·用药宜忌）
解读：药物的作用是**驱除病邪，不是养护正气**。养生靠饮食起居，治病才靠药物。
_现代转译_：别把药当保健品天天吃。「有病病受之，无病身受之」——无病服药，药性反伤正气。

**「3」「是药三分毒，有病病受之，无病身受之。」**（序例·用药总论）
解读：所有药材都带偏性。生病时药物专攻病灶；无病随意服，偏性就伤身。
_现代转译_：补品也分偏性，六味地黄丸再「平和」也不是人人可吃。

### 6_2 诊断与辨证类

**「4」「人身不过表里，气血不过虚实。」**（张子和汗吐下三法条下）
解读：人的身体不外乎表里，气血不外乎虚实。**四个字就能框住所有辨证**。
_现代转译_：判断身体状况，先问——是表层还是深层？是不足还是过盛？方向对了，手段才不会错。

**「5」「缓则治其本，急则治其标。」**（标本阴阳）
解读：慢性病治根源，急症先处理表象。这是**优先级思维**。
_现代转译_：长期失眠先调作息和情绪（本），偶尔熬夜后用褪黑素应急（标）。

**「6」「夫众病积聚，皆起于虚也，虚生百病。」**（陈藏器诸虚用药凡例）
解读：多数疾病的积累，都起于「虚」。**正气存内，邪不可干**。
_现代转译_：与其囤积各种「特效方」，不如先把睡眠、饮食、情绪这三件「补正」的事做好。

### 6_3 情志与健康类

**「7」「怒则气逆，喜则气散，悲则气消，恐则气下，惊则气乱，劳则气耗，思则气结，炅则气泄，寒则气收。」**（诸气）
解读：九种情志/环境变化，对应九种气机紊乱。**情绪本身就是病理变量**。
_现代转译_：长期焦虑（气结）、暴怒（气逆）、恐惧（气下）都会直接致病。调情志不是「心灵鸡汤」，是最硬核的预防医学。

**「8」「心静则药灵，心躁则药滞。」**（服药例）
解读：内心安定，药效通达；内心焦躁，药效凝滞。
_现代转译_：服药、调理期间的情绪状态，直接影响效果。这是被现代医学逐渐证实的「心身效应」。

### 6_4 饮食与生命观类

**「9」「饮食者，人之命脉也。」**
解读：饮食是人的生命线。**药食同源的根基在此**。
_现代转译_：把「今天吃什么」当成和「今天吃什么药」同等重要的决策。

**「10」「安谷则昌，绝谷则亡。水去则营散，谷消则卫亡，神无所居。」**（六腑六脏用药气味补泻）
解读：五谷之气安定就昌盛，断绝就灭亡。水没了营气散，谷气没了卫气亡，神就无处安住。
_现代转译_：再忙也要规律进食。**「营卫」相当于今天的营养供给与免疫防御**，源头都在饮食。

## 板块7 · 可落地的实操模块

> 以下内容均取材于原书卷一、卷二十五（粥）、菜部、果部、草部等章节，**仅作健康生活方式参考，不构成医疗建议**。涉及具体病症请就诊正规医疗机构。

### 7_1 全书最值得抄走的实操：44 种药粥

《本草纲目》卷二十五「谷部·粥」条，李时珍用近千字系统整理了 44 种粥方。他的核心论点是：

> 「每日起食粥一大碗，空腹胃虚，谷气便作，所补不细，又极柔腻，与肠胃相得，最为饮食之妙诀。」

并引苏轼的话：**「夜饥甚，吴子野劝食白粥，云能推陈致新、利膈益胃，粥既快美，粥后一觉，妙不可言。」**

粥之所以被全书单列，是因为它完美体现了「**食养尽之**」的理念——**用食物完成最后那「十之一二」的恢复**，而不是一路用药。

```plain
1. 主粮（粳米）淘净，按 1:8 加水，大火煮沸
2. 转小火慢熬 20–30 分钟至「米开粥稠」
3. 配料（切细/磨粉）在粥将成时加入，再煮 5–10 分钟
4. 晨起空腹温食，效果最佳
```

#### 7_1_3  三条使用边界（原书精神 + 现代补充）

1. **粥是调养，不是治疗**：书中明言「诸谷作粥……以备参考」，定位是日常食养；
2. **糖尿病者慎用甜粥**：红枣粥、枸杞粥、酥蜜粥等含糖量高，需控量或换方；
3. **不宜久放**：李时珍特别强调粥「厚曰饘，薄曰酏」，现煮现吃，避免变质。

1. **姜 + 枣**：生姜温散、红枣甘补，「一散一补」构成桂枝汤的基础结构。日常煮水喝，是温和的「调和脾胃」方。
2. **山药 + 排骨 / 红枣 + 枸杞**：前者健脾，后者气血双补。**搭配逻辑是「一主一辅」，不是越多越好**——这正是「君臣佐使」在厨房里的降维应用。

## 板块8 · 批判性阅读：这本书哪里「不能信」

一份有质量的读书笔记，必须包括**对书的批判**。李时珍的伟大在于「敢于纠错」，我们今天更应以同样精神对待他。

### 8_1 他纠正了前人什么（值得学习的态度）

| 错误 | 李时珍的纠正 |
| --- | --- |
| 穿山甲用鳞片诱蚁 | 实为「用舌捕食蚁」——他亲自解剖观察 |
| 葳蕤与女萎混为同物 | 辨为二物 |
| 天南星与虎掌混为同物 | 辨为二物 |
| 百合与卷丹品种混淆 | 澄清品种 |
| 五倍子误认为果实 | 实为虫瘿（蚜虫寄生形成） |
| 薯蓣（山药）误列入草部 | 后人所正 |

他的方法极朴素：**野外考察 + 解剖实物 + 走访民间**（农夫、渔户、药农、匠人）。这正是「格物」二字的具体化。

### 8_2 我们今天要纠正他什么

1. **「人部」与服食丹石**：人部记载了人乳、人尿、人血等，带有时代局限；对「服食丹石成仙」虽多有批判，但部分矿物药（朱砂、雄黄、铅丹）的毒性认知不足；
2. **「古镜」「孝子衫」之类**：已明确非药用物品，本书多标注存疑态度——**这种「存疑」本身就值得尊重**；
3. **植物药 1195 种、动物药 340 种、矿物药 357 种**的分类无误，但**具体功效的因果解释**（如「以形补形」）多属经验归纳，缺乏现代药理学验证；
4. **含重金属方剂**：朱砂安神丸、雄黄类方等，**现代医学明确禁用或慎用**，切勿自行套用。

> **结论**：学他的**思维方法**（辨疑、实证、分类、辨证），参考他的**食疗与生活智慧**，慎用他的**具体矿物方与峻烈方**。

| 1590 年（万历庚寅） | 王世贞作序，盛赞「博而不繁，详而有要」 |
| 1593 年 | 李时珍去世 |
| 1596 年 | 金陵胡承龙初刻本刊行，长子李建中助刊 |

### 9_2 王世贞序里三个值得记住的评价

> 「每药标正名为纲，附释名为目，正始也；次以集解、辨疑、正误，详其土产形状也；次以气味、主治、附方，著其体用也。」

这是对全书结构的精准概括——**正名 → 考实 → 致用**。

> 「如入金谷之园，种色夺目；如登龙君之宫，宝藏悉陈；如对冰壶玉鉴，毛发可指数也。」

这是对信息呈现的赞美——**丰富而不杂乱，透明而可核验**。

> 「博而不繁，详而有要，综核究竟，直窥渊海。兹岂仅以医书觏哉？实性理之精微，格物之通典，帝王之秘箓，臣民之重宝也。」

这是全书最高定位：**不只是医书，而是「格物」的通典**。

### 9_3 三个跨越时代的启示

1. **「三易其稿」的耐心**：27 年反复修订，今天的「快速迭代」文化下，这种深度几乎绝迹。但真正经得起时间的东西，都需要这种投入；
2. **「渔猎群书，搜罗百氏」的广度**：引书 717 种，许多失传古籍靠此书留存。启示：做研究要**穷尽既有材料，再谈创新**；
3. **「敢奋编摩之志，僭纂述之权」的勇气**：明知要推翻《神农本草经》以来的三品体系，仍敢于重构。启示：**尊重权威，但不被权威绑架**。

## 板块10 · 总结：这本书真正能给你的东西

读完一整遍（哪怕只读序例 + 粥条 + 44 粥表），能带走的不该是「几首偏方」，而应是**四层能力**：

### 10_1 第一层：一个分类框架

「以纲挈目、物以类从」——任何复杂领域，先立纲、再分目，比一头扎进细节高效十倍。

### 10_2 第二层：一套认知闭环

「释名 → 集解 → 辨疑 → 修治 → 气味 → 主治 → 发明 → 附方」的八项标准——**先辨清对象，再匹配用法**，杜绝「还没搞懂就急着用」的本能错误。

### 10_3 第三层：几条生活原则

- **「疗寒以热，疗热以寒」**——先判断方向，再行动
- **「是药三分毒」**——补品也有偏性，勿滥用
- **「中病即止」**——好转六七八九成就停，剩下的靠食养
- **「春省酸增甘、夏省苦增辛、秋省辛增酸、冬省咸增苦」**——用饮食节律替身体减负
- **「药补不如食补」**——把精力放在每天吃什么上

### 10_4 第四层：一种治学态度

实地考察、亲尝亲试、敢纠前人、存疑留白。**「医者贵在格物」——对任何信息，穷究真实，而非盲从权威。**

## 板块12 · 案例拆解：单味久服的「养生」陷阱

（虚构教学案例，不对应真实人物）一位读者见书中某药"久服轻身延年"，便单味长期服用，半年后出现口干、便结、心烦。

《本草纲目》的体例是先列性味归经、再列主治、最后附方——它的用法预设是"配伍中的一味"，不是"单独长期服用的保健品"。凡"久服"之说，多出自古代养生语境，且多指上品平和的谷菜之属；把有偏性的药当日常饮，是以药代食。

**落点**：读本草先读性味，再读主治。有偏性者只入方，不入日常。
