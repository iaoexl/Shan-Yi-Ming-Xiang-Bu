底板类。六经辨证是全库的临床主干——后面所有辨证坐标系（八纲、脏腑、卫气营血、三焦）最终都要挂回这六层切面上。读法：第一遍只抓六经框架与方证对应，把"什么证用什么方"读成条件反射；第二遍再攻救误与传变。条文可以后补，框架不能缺。

1. 医学三字经、医学源流论——建立医学史与范式认知

4. 伤寒论、金匮要略——辨证论治的实战主干
5. 温热论、温病条辨——补上温病一支

## 板块1 · 先建立地图：六经不是六个病，是六个"切面"

很多人初读《伤寒论》最大的误解，是把"六经"理解为六条经络上的巡诊路线。这是致命的起点偏差。

张仲景借用了《内经》的"六经"之名，却赋予了全新的内涵——**六经是人体由外到内、由浅入深切出的六个圈层，每一层是一种"气化状态"，而非一个固定器官。**

试着这样想象人体：

| 切面 | 层级 | 性质 | 关键词 |
| --- | --- | --- | --- |
| 太阳 | 最表层·藩篱 | 阳·表 | 营卫不和、正邪交争于表 |
| 阳明 | 里热·腑实 | 阳·里 | 燥、实、津伤 |
| 少阳 | 半表半里·枢纽 | 阳·枢 | 气机郁滞、枢机不利 |
| 太阴 | 中焦·脾胃 | 阴·表（三阴之始） | 湿、脾阳虚、寒湿 |
| 少阴 | 根基层·心肾 | 阴·里 | 阳气衰微/阴虚火旺 |
| 厥阴 | 最深·阴阳交争 | 阴·枢 | 寒热错杂、风从内生 |

**核心洞见：每一经不是一个症状，而是一整片"圈层的气化状态"。** 比如单看太阳一个切面，就有表实（麻黄汤）、表虚（桂枝汤）、表郁兼热（麻杏石甘汤）、水停（五苓散）、瘀血（桃核承气汤）——一个切面里藏着一个完整方阵。这是后面所有实战推演的骨架。

## 板块2 · 底层公理：四条线先刻进脑子

无论条文多么繁杂，所有条文最终都落在四根柱子上。做题前先在脑子里拉好这个坐标系：

### 2_1 阴阳为纲——先分阴阳，再谈别的

这是最高维度的分类。**三阳病多阳证（实、热），三阴病多阴证（虚、寒）**，但这只是粗分，更精细的分法藏在每条里。

### 2_2 表里为界——病在哪一层

一秒钟定位：**有汗还是无汗？** 有汗→太阳表虚（桂枝汤证）；无汗而喘→太阳表实（麻黄汤证）；胸胁满→少阳；腹满便秘→阳明；腹满吐利→太阴；四肢厥冷脉微→少阴。

### 2_3 寒热为性——是热还是寒

口渴大汗脉洪大→热；口不渴舌淡脉弱→寒。

### 2_4 虚实为势——正邪谁占上风

三阳正盛邪实，易治；三阴正虚邪陷，难治。**三阴病的本质不是"病更重"，而是"根基更虚"**——同样的便秘，阳明是热盛津伤的燥结，少阴是"下利清谷"的虚寒，治法截然相反。

> **实操口诀（背这个，比背条文有用）：**
>
> + 恶寒发热 + 汗出 → 营卫不和 → 桂枝汤
> + 恶寒发热 + 无汗 → 表闭寒郁 → 麻黄汤
> + 口渴 + 大汗 + 脉洪 → 热盛津伤 → 白虎汤
> + 口苦咽干目眩 → 枢机不利 → 小柴胡汤

## 板块3 · 太阳病：营卫的微观拆解（最容易上手的一章）

太阳病的全部病机，根源只有一个词——**营卫失调**。把这个理搞透，太阳篇就通了。

### 3_1 营与卫的本质（颠覆刻板认知）

- **营**行于脉中，属阴，主"疏"、主释放，禀肝血疏泄之性。
- **卫**行于脉外，属阳，主"密"、主固摄，禀肺气收敛之性。
- 正常状态：营疏卫密，一疏一密、一收一泄，维持气机出入平衡。

### 3_2 风邪与寒邪的不同进门方式

这是太阳篇最该拿捏的 distinction：

**风邪伤人（桂枝汤证）：** 风性疏泄，侵袭时卫气自动密固抗邪 → 卫闭需营气供能 → 若供能不及，营郁在前、卫闭在后 → **邪热内生、寒气外束** → 发热、汗出、恶风、脉缓。

**寒邪伤人（麻黄汤证）：** 寒性凝敛，直接损伤营气疏泄之性 → 营伤无力供养卫气 → 卫气失其固密 → 寒邪内生。→ 恶寒、无汗、体痛、脉浮紧、肌肤起粟。

> **一句话区分：桂枝汤治"营郁"，麻黄汤开"卫闭"。** 病机方向完全相反，这也是为什么桂枝汤要芍药清营热、麻黄汤要麻黄开卫散寒。

### 3_3 救误思路（这一节最值钱）

太阳病误治变证是全书最密集的区域，但救逆有规律可循：

- **过汗伤阳**（漏汗不止、恶风、四肢拘急）→ 桂枝加附子汤，扶阳固表。
- **表证未解误下**→ 若气上冲胸，仍用桂枝汤；若胸阳受损（脉促胸满）→ 桂枝去芍药汤。
- **火逆**（误用火法）→ 烦躁谵语，需清热或回阳救逆。

救误的总纲就八个字：**观其脉证，知犯何逆，随证治之。**

## 板块4 · 少阳病：和解思想的原型

少阳是六经里最"反直觉"的一经——它既不发汗（汗之则谵语），也不吐下（吐下则悸而惊），唯一的正法是**和解**。

### 4_1 抓主证的弹性

小柴胡汤证的核心不是"七个症状全出现"，而是抓住**"往来寒热、胸胁苦满"**这组主证即可（《伤寒论》第101条精神）。临床中很多病人的少阳证根本不典型，但只要见到胸胁胀满、或见或不见的寒热交替感，就可以考虑和解思路。

### 4_2 一个被忽略的关联

少阳病的"呕不欲食"，本质不是胃病，而是**少阳郁滞→阻碍阳明降路→胃气不降**。所以各类呕逆，表象在胃，根源多在少阳。这直接印证了三阳气机"以降为顺"的规律——太阳、少阳气机一堵，阳明就降不下去。

## 板块5 · 表里同病：临床最高频的难题

这是 hardest 也最实用的部分。患者往往表里都有问题，先治哪边？

### 5_1 铁律一：三阳病 → 先表后里

核心原则：只要太阳表证未解，无论里证多急，一律**先解表，禁攻下**。

- 第44条："太阳病，外证未解，不可下也，下之为逆。"
- 三阳的次第是：**太阳（表）→ 少阳（半表半里）→ 阳明（里）**，依次推进，不可跳跃。

### 5_2 铁律二：三阴病 → 先里后表

三阴以里虚寒为本，治当温扶阳气，**忌汗、吐、下、苦寒攻伐**。

- 第277条："自利不渴者，属太阴，以其脏有寒故也，当温之。"
- 第323条："少阴病脉沉者，急温之。"

### 5_3 关键判断表（直接照此执行）

| 症状信号 | 判断 | 处理 |
| --- | --- | --- |
| 下利清谷 + 脉沉 + 四肢厥冷 | 里虚寒危象 | **先救里**，四逆汤；里阳恢复、二便正常后再解表，桂枝汤 |
| 发热头痛 + 脉反沉 | 表证兼里虚 | 先四逆汤救里 |
| 下利腹胀满 + 身疼痛 | 里虚为主 | 先温里（四逆汤），后攻表（桂枝汤） |

> 经典原文（第91条）就是这条原则的总纲，建议原文抄写三遍：**"伤寒，医下之，续得下利清谷不止，身疼痛者，急当救里；后身疼痛，清便自调者，急当救表。救里宜四逆汤；救表宜桂枝汤。"**

### 5_4 表里同病的第三选项：表里同治

当表里证的病机关系密切、里证不是大虚大实时，可以一手抓：**大青龙汤**（外散表寒、内清郁热）、**小青龙汤**（外散表寒、内化水饮）、**五苓散**（外疏表邪、内利膀胱蓄水）。这是"实人伤寒发其汗，虚人伤寒建其中"的灵活补充。

## 板块6 · 三阴病群像：从"虚"里读出方向

三阴病最怕的两个坑：**一是把阴虚当阳虚治，二是把少阳误判为少阴。**

### 6_1 少阴的"分水岭"——寒化 vs 热化

少阴核心病机是**水火不济**，但走向完全两叉：

- **寒化**（最常见）：四肢厥冷、下利清谷、脉微细 → 回阳救逆 → **四逆汤**。
- **热化**（较少见但致命）：心烦不得卧、咽干、舌红少苔 → 滋阴降火 → **黄连阿胶汤**。

> 关键：脉沉紧 = 少阴虚寒（核心辨证点）；脉沉细数 = 少阴热化。**脉沉是少阴的门票，但脉沉之后的寒热方向决定用哪张方。**

### 6_2 厥阴的复杂性

厥阴是六经最后阶段，病机最复杂——**上风火交加、下寒湿凝滞，寒热虚实错杂**。代表方乌梅丸（清上温下、安蛔止痛）是寒热并用思维的巅峰体现。

### 6_3 太阴的"湿"字诀

太阴病核心关键字是**"湿"**。纯太阴独立病证临床少见，多依附于少阴、厥阴存在。抓住"湿"字，就能读懂大半三阴传变——太阴湿气不化、脾土失常，才会进一步传入少阴、厥阴。

## 板块7 · 经方使用实操：剂量、煎煮、服法，半个疗效在手上

经方之所以"效如桴鼓"，一半在辨证精准，一半在**煎服规范**。很多人辨证对了，煎服错了，效果打折扣。

### 7_1 剂量：比例 > 绝对值

这是经方应用的铁律。**微调剂量绝不能打乱君臣佐使的比例**，一旦比例错乱，方义彻底改变。

- 两套换算标准：重症急救参考东汉原量（1两≈15.6g，一剂分2-3次温服）；日常调理用现代常量（1两≈3-5g）。
- **急重症、体质壮实者**可用原方逻辑减量分服；**轻症、老人儿童**一律轻量，中病即止。

### 7_2 煎煮：顺序即药效

| 操作 | 代表方剂 | 目的 |
| --- | --- | --- |
| 麻黄先煎去上沫 | 麻黄汤、大青龙汤 | 去沫减负，防心烦 |
| 先煮枳朴，后下大黄芒硝 | 大承气汤 | 行气散满在前，荡实润燥在后 |
| 石膏同煎（不入先煎） | 白虎汤 | 米熟汤成，保存清气 |
| 阿胶烊化 / 大黄后下 | 黄连阿胶汤、承气类 | 保护有效成分 |

### 7_3 服法：观察反应，中病即止

桂枝汤的服法堪称模板，值得逐字体悟：

1. 咬咀（碎成小块，充分析出）；
2. 微火久煎；
3. 服已须臾，**啜热稀粥**以助药力、温覆 → 目的不是"补药"，是"助胃气以资汗源"；
4. **汗出即停，不必尽剂**——防大汗亡阳、伤津耗气；
5. 若病证仍在，"小促其间"，半日令三服尽 → 不一次性服完，给身体反应空间；
6. 列出饮食禁忌：禁生冷、黏滑、肉面、五辛、酒酪、臭恶。

> 其他服法也各有匠心：大黄黄连泻心汤用麻沸汤"浸之须臾，绞去滓"（急煎法）；四逆汤类急煎用于急症；十枣汤"平旦服"（晨服法）。**服药后要"周时观之"**——约一小时观察反应，再决定是否需要更服。

## 板块8 · 传变不是直线： Three 条铁则 + 一个隐藏主线

### 8_1 传变三铁则

**铁则一：正气不虚，邪不可传。** 第5条"伤寒一日，太阳受之，脉若静者为不传；颇欲吐、若躁烦、脉数急者为传也。"——脉象安静，正气稳住，病停在太阳；脉象急数、恶心烦躁，正气扛不住了，邪气才向内传入。

**铁则二：正气虚于何处，邪气便传向何处。** 常规循经传是太阳→少阳→阳明→太阴→少阴→厥阴（由表到里、阳入阴、实转虚），但临床远非如此整洁：有**直中**（寒邪长驱直入，一来就少阴）、有**合病**（两经同时发病）、有**并病**（一经未罢又一经起）。

**铁则三：天人相应，顺势则解，逆势则危。** 仲景在每经篇末给了"欲解时"——太阳从巳至未上（阳气最旺时辰），体表的阳气借天时振奋，便有自愈之机。若某经欲解时病反加重，提示正气已失守。

### 8_2 隐藏主线：脾胃这条生命线

翻遍全书，处处都在**护胃气**：

- 桂枝汤服后啜粥 → 助胃气以资汗源；
- 阳明急下 → 存胃阴；
- 太阴理中汤 → 直接救胃阳；
- 所有攻邪方（麻黄、承气、柴胡）→ 中病即止，不可过剂。

**三阳以祛邪为先、扶正为辅；三阴以扶正为先、祛邪为辅。** 这个主次关系分清了，表里同病、阴阳错杂的难题就有一把钥匙。

## 板块9 · 从"条文背诵者"到"辨证思考者"的跃迁清单

读完此书最大的自我检验标准，是看自己是否完成了从"记方证"到"推病机"的跃迁。给自己列一份自查清单：

- [ ] 看到病人，第一反应不是"这是什么病"，而是**"病位在哪一经？病机是什么状态？"**
- [ ] 能脱离症状清单，**只抓1-3个主症就锁定六经**，而不是等所有症状集齐。
- [ ] 遇到表里同病，能脱口而出**先表还是先里**的判断逻辑，而不是纠结。
- [ ] 用方时**先守比例，再谈加减**，明白"方义变了疗效就变了"。
- [ ] 煎服法不再视为"杂项"，而是**和辨证一样重要的疗效保障**。
- [ ] 遇到不典型的复合证，能**分清正邪、气机的主次关系**，而非被表象牵着走。

> 仲景留给我们最珍贵的，不是269首方的记忆，而是一种思维方式——**"观其脉证，知犯何逆，随证治之"**。不执一方、不泥一法，以患者真实证候为依据，灵活变通、精准施治。中医之妙，不在药繁，而在辨证精准；不在求奇，而在守正求真。

## 板块10 · 案例拆解：表里同病，先救哪一头

（虚构教学案例，不对应真实人物）一位老人发热恶寒、无汗身痛，同时下利清谷、手足发凉。家属先按"止泻"处理，用了收涩药，泻虽暂缓，人却更加萎顿。

按六经的次序，这是表证未解而里阳已虚。三阳病先表后里，三阴病先里后表；此例下利清谷、四肢厥冷已属里虚寒，当先温里，待里阳回复、二便自调，再解表。收涩止泻把邪关在里，正是"见泻止泻"的典型错法。

**落点**：表里同病的第一问不是"哪个症状重"，而是"正气的根有没有动摇"。根动则先救里。
