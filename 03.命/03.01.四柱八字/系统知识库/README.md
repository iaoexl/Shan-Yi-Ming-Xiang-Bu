# 四柱八字系统知识库 · 总纲

> **一句话定位**：这是一套把"八个字"讲成人话的成体系教材——从认字、排盘、判旺衰、定格局、取用神，一路走到能独立写出一份完整命例解读报告。
>
> **适用对象**：零基础入门者，以及学过但体系散乱、需要重建框架的人。
>
> **使用方式**：先读本文件建立全局地图，再从「板块0」顺着编号往下走；也可以按板块独立取用——每个板块都自带入口导语、实操工具与通关验收清单。

#### 一个完整的例子：从八个字到一句话

> 这一节用一个压缩的案例，把十二步流程走一遍，让你对"最终成品"有个直观印象。**真实报告要比这个详细得多（每步都要写推导过程），此处只展示骨架。**

**第1步 采集信息**：某男，公历 1987 年 3 月 20 日 10 时 15 分生于杭州（东经约 120°）。

**第2步 真太阳时校正**：杭州经度约 120°，时差极小，无需明显校正，仍为巳时。

**第3步 排四柱**：查万年历得 丁卯年、癸卯月、戊辰日、丁巳时；按年干丁（阴干）+ 男命 → 阴男，逆排大运。

**第4步 判旺衰**：戊土日主生于卯月（春木当令，木克土）→ **失令**；日支辰为戊土本气根 → **得地**；天干两丁火为印星、卯月木旺生火 → **得生**；无比劫 → 不得助。综合判定：**偏弱**（不是极弱，因为有本气根与双印）。

**第5步 定格局**：月支卯，本气乙木；天干不透乙，透癸水（正财）与丁火（正印）。按定格规则，月令本气不透 → 退看中气余气，仍不透 → **不成正格**，转为看全局气势：木旺、火相，印星有力。

**第6步 判成败与层次**：不成格则按扶抑 + 病药论。命局木旺（官杀）攻身，病在官杀太旺。

**第7步 取用神**：病为官杀旺 → 药为印星化杀生身（印星已有力且透干）。调候上，卯月不寒不燥，无需优先调候。**最终用神 = 火（印星），喜神 = 土（比劫），忌神 = 木（官杀）。**

**第8步 标四神**：用 = 火，喜 = 土，忌 = 木，仇 = 水（水生木）。

**第9步 查神煞**：日干戊，天乙贵人在丑未；文昌在申；禄神在巳（时支见巳 → 禄在时柱，晚年有稳定收入）。桃花：年支卯，亥卯未见子为桃花。

**第10步 排大运**：丁为阴干、男命 → 阴男 → 逆排。从月柱癸卯往前推，依次是：壬寅、辛丑、庚子、己亥、戊戌、丁酉、丙申、乙未，共八步（每步十年）。起运岁数需按 9_2 的算法，查出生日距上一个节气的天数换算确定。

**第11步 分项分析**：事业宜靠学识与资质立足（印星为用），适合文化、教育、公职、医疗方向（火土类象）；压力型环境对他消耗大，宜"化压力为资历"而非硬扛。

**第12步 输出报告**：

```plain
"你的命局属于'身偏弱、官杀偏旺、印星有力'的结构。
 简单说：你不是靠硬扛的人，而是靠'把压力转化成资历'的人——
 学历、证书、专业口碑、长辈贵人是你的主要依仗。

 行业上适合文化、教育、公职、医疗方向（用神为火土）。
 发力期在火土旺的大运与流年（需按具体大运排定）。
 需要提醒的是：木旺之年压力会明显加重，那几年宜守不宜攻，
 重要决策尽量避开农历一、二月。"
```

> **注意这最后一段断语的三个特点**：**一是给出了"你是什么类型的人"而不是"你会发生什么"**；**二是把五行翻译成了具体行业**；**三是给了可执行的动作（避开哪几个月）**。这三条是判断一份报告是否合格的最低标准。

#### 开始之前的两句话

> **第一句**：八字是理解"结构"的工具，不是预测"注定"的判决。好的分析，让人更清楚自己能做什么，而不是更焦虑自己会遭遇什么。
>
> **第二句**：看懂和能复述之间隔着一道坎，跨越它成本最低的方式是——**合上文档，把图和表默画一遍**。画不出来的地方，就是你真正的盲点。

#### 实战论命七步法（十二步的精简版）

前面「八字分析十二步流程」给出的是完整版十二步，用于正式出报告。日常快速看盘可用这个精简版：

```plain
第一步：排四柱 → 确定日主（以日干为"我"）
第二步：标五行 → 每柱标五行 + 阴阳 + 藏干
第三步：定旺衰 → 得令(40~50%) + 得地(30%) + 得生(15%) + 得助(10%)
第四步：排十神 → 以日主为中心，标出全部十神

```

#### 使用公约（读之前请先接受这四条）

##### 1. 术语口径统一

本知识库内部凡是遇到流派分歧处，一律**先声明口径、再统一使用**，中途不换：

| 分歧点 | 本库采用 | 另一派常见口径 |
| --- | --- | --- |
| 女命父亲 | 偏财 | 正财 |
| 女命母亲 | 正印 | 偏印 |
| 大运顺逆的判定干 | 年干 | 日干（部分派别） |
| 子时日柱分界 | 23:00 分界（主流） | 0:00 分界（少数派） |
| 三会 vs 三合谁更强 | 三会成立时最猛，但以"紧贴+得令"终裁 | 部分派别以三合为先 |

**自测与练习时按本库口径作答；实战中若两派结论冲突，以"星宫同看 + 实际经历校验"为准。**

> **为什么这张表必须存在**：命理里大量分歧不是"谁对谁错"，而是"口径不同"。真正致命的不是选了某一派，而是**同一份分析里前后换口径**——前面按年干定顺逆、后面按日干取用，出来的结论会自相矛盾，而且极难自查。所以读完这张表后只有一条纪律：**选一套，贯彻到底，并在结论里注明用的是哪一套。**
>
> **最容易踩的三处**：第1处——大运顺逆（年干 vs 日干），年干与日干阴阳不同时，两套结果完全镜像；第2处——女命父母星（正印为母 vs 偏印为母），直接影响六亲断语；第3处——子时日柱分界（23:00 vs 0:00），出生在 23 点前后的人会整柱不同。

##### 2. 断语分层

任何分析都要区分三档，不许全部说成"必然"：

```plain
确定：原局明现 + 大运支持 + 流年触发
倾向：原局有此结构，但时机未到
可能：仅单一信号，需其他条件配合
```

##### 3. 健康类只给提醒，不给诊断

```plain
✗ "你肝不好，要注意肝病。"
✓ "命局木气偏旺，容易在压力大、情绪压抑时出状况。
   建议规律作息、少熬夜、适度运动，体检按常规做即可。"
```

八字看健康是**先天体质倾向提示**，不能替代医学诊断。

##### 4. 负面信息必须配解法

```plain
✗ "你劫财旺，冲动鲁莽又挥霍，容易破财。"
✓ "你的行动力很强，但大额决策前最好给自己设一个
   24 小时的冷静期，重要合作一律走书面合同。"
```
