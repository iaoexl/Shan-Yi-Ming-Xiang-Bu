### README_1 这套知识库是什么

**它教你怎么把一张星盘，读成一个具体的人。**

本库采用现代心理占星立场。星盘描述模式、潜能与功课，不预言具体事件；"可能""倾向"不得说成"注定"。健康、医疗、法律、重大财务决策一律以专业人士意见为准（详见板块 6 · 表达伦理与验证体系）。

| 关键词 | 含义 |
| --- | --- |
| **可推导** | 每句解读能拆回行星 / 星座 / 宫位 / 相位 / 状态 |
| **可验证** | 每阶段有检验标准与准确率记录 |
| **能落地** | 给实操动作、笔记模板与话术示范 |

### README_3 三个贯穿全库的方法

#### 五要素公式

> **星是谁，座是样，宫是场，相是账，态是有没有力量。**

| 要素 | 回答 |
| --- | --- |
| **行星** | 什么能量在运作（who） |
| **星座** | 以什么方式表现（how） |
| **宫位** | 在哪个生活领域发生（where） |
| **相位** | 彼此怎么作用 |
| **状态** | 这颗星有没有力量、表达顺不顺 |

任何一句解盘都能拆回这五个词；拆不回去就是空转。状态评估见板块 2，拆解示范见板块 10_16，三条贯穿原则见板块 10_13。

#### 记录—验证—修正

```plain
解盘 → 记笔记 → 找当事人验证 → 标出对错 → 分析错在哪 → 更新规则
```

模板与准确率统计见板块 6_12、6_15。三个贯穿人物（小林、阿May、老陈）的案例见板块 6_21 - 6_23。

### README_9 技法示例：从背表到解盘，中间隔着什么

> **说明** ：教学示意案例，用于演示推理链条，非真实个案记录。

**问题**：他能背出所有符号，却写不出一句完整解读。

**推演**：学习分五阶段——认符号、学规则、串链条、做验证、建体系。他停在第二阶段；阶段三（把符号组成一句话）与阶段四（记录预判与反馈）都还没开始。

**结论**：从"记得住"到"解得出"，缺的是成句训练与反馈记录，不是更多书。对应动作：板块 10_16 的六个台阶 + 板块 6_33 的 90 天练习表。
