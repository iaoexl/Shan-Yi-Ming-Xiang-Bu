## 板块1 · 人格结构日月升与十大行星

### 1_1 三者分工对照

大多数人对星座的全部认知是"太阳星座"。这是学星盘要翻过去的第一道墙。

#### 核心对照表

| 项目 | 太阳星座 | 月亮星座 | 上升星座（ASC） |
| --- | --- | --- | --- |
| 回答的问题 | 我要成为谁 | 我需要什么才安心 | 我怎么走进这个世界 |
| 人格层级 | 核心意志 / 人生主线 | 情绪本能 / 潜意识 | 外壳气场 / 应对模式 |
| 决定条件 | 阳历生日即可查 | 需要出生日期 + 大致时辰 | 需要 **精确到分钟的时间 + 出生地** |
| 换座速度 | 约 30 天一换 | 约 2.5 天一换 | 约 2 小时一换 |
| 主导场景 | 职场决策、公开表现、人生规划 | 亲密关系、独处、压力应激 | 初见、面试、陌生环境、第一印象 |
| 核心诉求 | 实现价值、获得认可、守住尊严 | 情绪安稳、被理解、有安全感 | 适应环境、建立边界、塑造气场 |
| 常见短板 | 固执要强、好面子、目的性强 | 敏感内耗、情绪化、容易心软 | 防御心重、习惯性"演"、不够松弛 |
| 一句话 | 我要活成的样子 | 我卸下防备的样子 | 别人第一眼看到的样子 |

**记忆锚点：**

+ **太阳 = 你想活成的样子** （主动、外显、要努力才能长出来）
+ **月亮 = 你卸下防备的样子** （被动、私密、不用装就自动流露）
+ **上升 = 别人第一眼看到的你** （本能、自动、你自己往往意识不到）

**口诀：日是要成为，月是怕什么，升是像什么。**

#### 三者的"获取难度"排序

| 层级 | 需要什么 | 难度 | 意义 |
| --- | --- | --- | --- |
| 太阳星座 | 阳历生日 | ★ | 人人都有，但只是 1/3 |
| 月亮星座 | 出生日期 + 大致时辰（±2 小时内） | ★★ | 月亮 2.5 天换座，所以只需大致时间 |
| 上升星座 | **精确到分钟的时间 + 出生地** | ★★★★★ | 上升 2 小时换座，时间错了就全错 |

**踩坑预警：** 很多人在不知道出生时间的情况下，用 App 随便填个时间排盘，然后照着那个"上升"对号入座。 **这是学星盘最大的自欺。** 时间不准，上升与宫位全部不可信；但 **太阳与月亮的位置、以及行星之间的相位，仍然可用** （因为相位不依赖出生时间）。

### 1_2 一个饭局看懂三者同时运作

**第一幕 · 上升天蝎启动（进门到落座的前 5 分钟）**
**第二幕 · 太阳狮子接手（饭局中段）**
**第三幕 · 月亮双鱼收尾（回家后）**

### 1_3 太阳落十二星座 · 一句话速查

**使用频率最高的表之一。每句都是"这个人靠什么活出自己"。**

| --- | --- | --- | --- |
| ♈ 白羊 | 我要先动 | 靠行动确认自己存在 | 三分钟热度、只顾开头 |
| ♉ 金牛 | 我要攒住 | 靠积累与感官确认自己 | 抗拒变动、固执 |
| ♊ 双子 | 我要知道 | 靠信息与连接确认自己 | 浅、散、停不下来 |
| ♋ 巨蟹 | 我要护住 | 靠照顾与被需要确认自己 | 情绪绑架、过度防御 |
| ♌ 狮子 | 我要发光 | 靠被看见与创造确认自己 | 要面子、怕被忽视 |
| ♍ 处女 | 我要修好它 | 靠有用与精确确认自己 | 挑剔、焦虑、钻细节 |
| ♎ 天秤 | 我们要平衡 | 靠关系与协调确认自己 | 不敢说不、依赖他人评价 |
| ♏ 天蝎 | 我要全部 | 靠深度与掌控确认自己 | 记仇、试探、不信任 |
| ♐ 射手 | 我要意义 | 靠信念与探索确认自己 | 好高骛远、说教、逃承诺 |
| ♑ 摩羯 | 我要做成 | 靠成就与结构确认自己 | 自我压榨、冷硬、怕失败 |
| ♒ 水瓶 | 我要不同 | 靠独特与理念确认自己 | 疏离、为反而反 |
| ♓ 双鱼 | 我融进去 | 靠共情与想象确认自己 | 边界消失、逃避、上瘾 |

**进阶干货：太阳是"要活出来的"，不是"天生的"。**
这是理解太阳最关键的一点。太阳星座描述的是 **你要成为的样子** ——它需要努力才能长出来。一个 20 岁的狮子，可能还完全没有"发光"的自觉；一个 50 岁的狮子，才真正活成了太阳狮子的样子。
**所以：不要拿太阳星座去"判断"一个年轻人，要用它去"指引"。**

| ♐ 射手 | 自由、有意义、能走 | 讲大道理、想逃、规划远方 | 给空间与意义，别用情绪拴住 |

**记忆锚点：想知道一个人真实的样子，看月亮；想知道他压力下会变成什么样，也看月亮。**

### 1_5 上升落十二星座 · 一句话速查

**每句都是"陌生人第一眼会怎么描述我"。**

| 上升落座 | 第一印象 | 身体/气质特征倾向 | 与人打交道的默认姿态 |
| --- | --- | --- | --- |
| ♈ 白羊 | 直接、有冲劲、不好惹 | 动作快、轮廓利落、易有小伤疤 | 先出手再想，喜欢干脆 |
| ♉ 金牛 | 稳、慢、可靠、不好推动 | 体态结实、声音低、节奏慢 | 慢慢来，先观察再信任 |
| ♊ 双子 | 机灵、话多、年轻感 | 手势多、眼神活、显得比实际年轻 | 用聊天破冰，什么都聊一点 |
| ♋ 巨蟹 | 温、软、有距离感 | 圆润、眼神柔和、防御性姿态 | 先保护自己，熟了才靠近 |
| ♌ 狮子 | 有存在感、大方、像主角 | 姿态挺、气场外放、爱打扮 | 主动热情，希望被看见 |
| ♍ 处女 | 干净、细致、有点紧绷 | 整洁、表情克制、动作精准 | 先观察细节，不轻易表态 |
| ♎ 天秤 | 优雅、好相处、有分寸 | 五官协调、笑容得体、讲究 | 先和气，能不冲突就不冲突 |
| ♏ 天蝎 | 有深度、神秘、不好看透 | 眼神沉、存在感强、话少 | 先试探，确认安全才交心 |
| ♐ 射手 | 开朗、大方、像见过世面 | 动作大、笑声响、气息外放 | 自来熟，喜欢打开局面 |
| ♑ 摩羯 | 稳重、严肃、有距离 | 骨架明显、表情少、显成熟 | 先公事公办，慢热 |
| ♒ 水瓶 | 特别、疏离、不好归类 | 气质独特、风格自成一派 | 友善但保持距离，不黏 |
| ♓ 双鱼 | 柔和、朦胧、好接近 | 眼神迷蒙、边界感弱、易显疲惫 | 随和、配合，不太拒绝 |

**进阶干货：上升是"滤镜"，不是"伪装"。**
很多人以为上升是"装出来的"，其实不是。上升是你在陌生环境里 **自动启动的应对模式** ——它曾经保护过你，所以成了本能。
它也不是一成不变的：随着你安全感的提升，上升的"防御性"会降低，你会更自然地展现出太阳与月亮的部分。 **这就是为什么熟了以后，人会"变样"。**

### 1_6 为什么"我不像我的星座"

**踩坑预警：** "我一点也不像我的星座"，通常有五个原因，按出现频率排序：

#### 五大原因

| 排名 | 原因 | 说明 | 怎么确认 |
| --- | --- | --- | --- |
| **1** | **上升或月亮盖过了太阳** | 尤其当上升/月亮与太阳的元素不同时 | 对比三者的描述，看哪个最像 |
| **2** | **太阳没有与个人行星形成紧密相位** | 能量"孤立"，表现不明显 | 看太阳与日月水金火有没有 ≤6° 的相位 |
| **3** | **太阳落在果宫（3、6、9、12 宫）** | 声音天然偏小 | 看太阳落在第几宫 |
| **4** | **太阳被土星、冥王星等压制** | 合相或硬相位，早期不敢活出太阳 | 看太阳有没有被土/冥/海刑冲合 |
| **5** | **太阳弱陷** | 如太阳天秤、太阳水瓶，需要用不习惯的方式运作 | 查庙旺弱陷表（板块 2） |

#### 逐条详解

**原因 1：上升或月亮盖过太阳（最常见）**

**原因 2：太阳没有紧密相位**
**原因 3：太阳落果宫**
**原因 4：太阳被压制**
#### 一个自查清单

**实操动作：** 如果你觉得自己"不像太阳星座"，依次检查这五条：

```plain
□ 1. 我的上升/月亮是哪个星座？它们的描述是不是更像我？
□ 2. 我的太阳与日月水金火有没有 ≤6° 的相位？
□ 3. 我的太阳落在第几宫？是 3、6、9、12 吗？
□ 4. 我的太阳有没有被土星/冥王/海王刑冲合？
□ 5. 我的太阳是弱陷吗？（天秤、水瓶为陷；宝瓶、天秤需特别注意）

```

勾选越多，太阳被"稀释"得越厉害。 **但这不是坏事** ——它只意味着你的自我意识需要更长时间、更刻意地长出来。

### 1_7 古典与现代的看盘顺序之争

**进阶干货：这是很多教程不会告诉你的关键分歧。**

#### 两套顺序

| 对比项 | 古典占星 | 现代心理占星 |
| --- | --- | --- |
| **顺序** | 先看上升 → 次看月亮 → 最后参考太阳 | 从太阳（自我意识）讲起 |
| **理由** | 上升决定整张盘的宫位结构，是"命盘的地基"；月亮主身体、情绪、早年环境，祸福权重大；太阳更多是"社会性自我" | 目标是自我实现，所以从"我是谁"讲起 |
| **典型问题** | "会发生什么" | "这对我意味着什么" |

#### 为什么古典先看上升

古典体系的逻辑非常实际：

1. **上升决定宫位结构** → 没有上升，整个盘都立不起来；
2. **上升的守护星（命主星）是全盘最重要的单颗星** → 它决定"你这一生的故事由谁执笔"；
3. **月亮主身体、情绪、早年环境** → 在判断终身格局、健康、早年家庭运时权重极高；
4. **太阳是"社会性自我"** → 重要，但不是地基。

#### 实操建议

**口诀：古典看盘先看升，现代看盘先说日。两条路都成立，但别混着用还自相矛盾。**

| 场景 | 建议顺序 |
| --- | --- |
| 判断终身格局、健康、早年家庭 | 古典顺序：上升 → 月亮 → 太阳 |
| 做心理陪伴、自我探索 | 现代顺序：太阳 → 月亮 → 上升 |
| **稳妥做法** | 先讲上升与命主星（定地基），再讲日月（定人格），把太阳放在"人生主线"的位置上 |

### 1_8 三件套的实操写法

**实操动作：** 用这个句式造一个句子——

> "我表面看起来像 ___（上升），其实我想要的是 ___（太阳），而让我真正安心的是 ___（月亮）。"

**注意：这个句子里的三个空，不应该用星座名填，而应该用"具体的样子"填。**

| 错误填法（空洞） | 正确填法（具体） |
| --- | --- |
| "我看起来像处女座，我想要双子座，让我安心的是摩羯座" | "我看起来（上升处女）克制、细致、不太表态；其实我想要（太阳双子）的是保持好奇、什么都懂一点、不被单一身份绑住；而让我真正安心（月亮摩羯）的是把事情做成、有成果可以交代" |

#### 进阶写法：加入"张力"

在上面的句子后面，加一句 **张力描述** ：

> "所以我的内在张力是：___ 和 ___ 之间总是打架。"

"你需要的不是'收心'，而是 **给好奇心一个可以交付的形式** ——比如把'广泛涉猎'变成'每月产出一篇文章'，这样双子的好奇和摩羯的成就感就能同时被满足。"
**进阶干货：好的三件套描述，最后一定要落到"怎么办"。**
描述性格是入门券， **真正的价值在于指出那条"能同时满足两个需求"的路** 。这是解盘从"算命"走向"有用"的分界线。

### 1_9 技法示例：为什么我不像我的星座

> **说明** ：以下为 **教学示意案例** ，用于演示本节技法的推理链条，非真实个案记录。

**配置**

示意配置：太阳射手（落 3 宫）、月亮天蝎（落 2 宫）、上升巨蟹。

**推演**

本节的三层分工在这里正好用上：

+ **太阳** 回答"我这一生要成为什么"——他要的是意义与视野（射手）；
+ **月亮** 回答"我需要什么才安心"——他要的是深度、掌控与独处（天蝎）；
+ **上升** 回答"别人第一眼看到什么"——他给人的第一印象是温和、有距离感（巨蟹）。

三者并不矛盾，而是 **分工不同** 。他的"宅"是月亮天蝎的需求，他的"乐观"是太阳射手的方向。

**复盘**

"不像自己的星座"最常见的成因就是 **只看太阳、不看月亮与上升** 。三层一旦分开描述，抱怨通常会立刻消失。

### 1_10 三档分类：先分清"个人的"和"一代人的"

行星是演员，星座是它的表演方式，宫位是它登场的舞台。先分清"这是哪股能量"，再谈别的。

**记忆锚点：行星分三档，档位决定它影响的是"我个人"还是"我这一代人"。**

| 档位 | 行星 | 运行周期 | 影响层级 | 关键词 |
| --- | --- | --- | --- | --- |
| **个人行星** | 太阳、月亮、水星、金星、火星 | 月亮 28 天 ～ 火星约 2 年 | 个人性格、日常行为 | "我这个人" |
| **社会行星** | 木星、土星 | 约 12 年 / 约 29.5 年 | 与社会的关系、人生阶段 | "我这代怎么立足" |
| **世代行星** | 天王星、海王星、冥王星 | 84 / 165 / 248 年 | 整个世代的底层代码 | "我们这代人的集体命运" |

#### 为什么这个分类很重要

**踩坑预警：三王星在一张个人盘里单独落座的意义很弱。**
同一个月出生的几百万人都有冥王星天蝎。 **三王星只有在以下三种情况下才真正"个人化"：**

| # | 条件 | 说明 |
| --- | --- | --- |
| 1 | 与个人行星（日月水金火）形成 **紧密相位** （尤其 3° 以内） | 这是最常见也最重要的一种 |
| 2 | 落在 **四轴** 或角宫（尤其合轴） | 让世代能量落到个人生活里 |
| 3 | 成为某宫的 **宫主星** | 例如上升天蝎，冥王星就是命主星 |

### 1_15 行星逆行与速度

**逆行的通用解读法**

**进阶干货：逆行不是行星真的倒着走，而是地球与它相对运动造成的视觉逆行。**

| 面向 | 顺行 | 逆行 |
| --- | --- | --- |
| 能量方向 | 向外释放、直接 | 向内加工、回旋 |
| 显现方式 | 即时、外显 | 延迟、需要反复打磨 |
| 时间感 | 顺势而为 | 慢热、需要自己想通 |
| 常见气质 | "我做了再说" | "我想通了才做" |

**记忆锚点：顺行向外给，逆行向内磨。逆行不是缺陷，是加工深度。**

#### 逐星逆行速查

| 行星 | 本命逆行的常见表现 |
| --- | --- |
| ☿ 水逆 | 思维方式与主流不同步；需要更长时间形成表达；内心戏丰富 |
| ♀ 金逆 | 爱与价值判断内转；需要反复确认"我到底喜欢什么"；对关系更谨慎 |
| ♂ 火逆 | 愤怒内转；容易生闷气、事后才意识到生气；行动需要酝酿，不适合被催促 |
| ♃ 木逆 | 信念内转；不轻信权威，要自己想通才信；信仰是自建的 |
| ♄ 土逆 | 内在权威建立得晚；需要自己定义规则，而非接受外界规则 |
| 三王星逆行 | 一年中约 5 个月在逆行，本命盘中约 40% 的人是三王星逆行， **影响远小于个人行星逆行** |

**踩坑预警：三王星逆行几乎不值得单独解读。** 因为逆行占比太高（约 40%），它不是"异常"，而是"常态的一半"。 **只有个人行星（水金火木土）的逆行才具有明显的个体差异意义。**

#### 行星速度（Swift / Slow）

**深水区：这是古典占星的小技法，但很好用。**

行星运行速度接近其最大速度时称"快"（swift），接近留（station）时称"慢"（slow）。

| 状态 | 含义 |
| --- | --- |
| **快速行星** | 能量活跃、外显、表现力强、来得快去得也快 |
| **慢速行星** | 能量凝练、内敛、在该行星主管的事务上更持久、更深刻 |

**在行运判断中尤其重要：**

+ **慢速的行运行星停留时间长，影响更持久** ；
+ **留（stationary）的行星是能量最强的时刻** ，往往是事件爆发点。

**进阶干货（一个立即可用的技巧）：** 当你在做流年判断时，先去看那颗行运行星是不是在 **逆行或留** 。

+ 顺行快速经过 → 影响像一阵风，来了就走；
+ **逆行来回三次** → 会形成"三重过境"，第一次是预告，最后一次是定案， **这件事会被反复处理** 。

### 1_17 行星的"提问句式"

**进阶干货：把十个行星变成十个问题，你就有了随时可用的提问工具。**

| 行星 | 提问句式 | 用途 |
| --- | --- | --- |
| ☉ 太阳 | "我到底想要成为什么样的人？" | 找人生主线 |
| ☽ 月亮 | "什么能让我真正安心？" | 找情绪出口 |
| ☿ 水星 | "我是怎么想事情的？" | 找沟通与学习风格 |
| ♀ 金星 | "我觉得什么有价值？我怎么表达爱？" | 找关系与金钱模式 |
| ♂ 火星 | "我怎么行动？我怎么生气？" | 找行动力与冲突模式 |
| ♃ 木星 | "我相信什么？我的运气在哪？" | 找机会与信念 |
| ♄ 土星 | "我在怕什么？我的功课是什么？" | 找需要长期经营的地方 |
| ♅ 天王星 | "我在哪里需要自由？" | 找需要打破的结构 |
| ♆ 海王星 | "我在哪里消融边界？" | 找灵感与风险点 |
| ♇ 冥王星 | "我在哪里会被彻底改变？" | 找深层动力与执念 |

**实操动作：** 拿这十个问题，逐个问自己，并把答案写下来。写完你会发现—— **这十个答案合起来，就是一份相当完整的自我描述。** 而它们全部来自你自己的星盘。

### 1_18 技法示例：金星不是管爱情，是管「值不值」

**配置**

示意：金星摩羯，落 2 宫，与土星合相。

**推演**

本节对十大行星的角色分工在这里是关键：

+ 金星的首要含义是 **价值判断与取舍标准** ——"我认为什么值得"；
+ 落在摩羯、与土星合 → 她的价值判断偏审慎、讲实际、慢热；
+ 落 2 宫 → 这套标准直接作用于"我拥有的资源"与"自我价值感"。

至于感情，金星只描述 **她在关系里被什么吸引、用什么方式表达好感** ，并不直接等于"感情好不好"。

**复盘**

把一颗行星简化成一个生活领域（金星=爱情、火星=暴力、土星=倒霉），是符号学习的第一阶段，也是必须尽快跨过的一关。 **行星是动词，不是名词** 。
