## 板块2 · 力量评估状态相位与格局

### 2_1 庙旺弱陷：行星的"四档状态"

同样是金星，落在金牛和落在天蝎，能量质量完全不同。这一套打分系统叫 **尊贵（Dignity）** ，是古典占星最实用的工具之一。

**行星先天尊贵表（古典体系）——必须背下来**

| 行星 | 庙（入庙 Rulership） | 旺（擢升 Exaltation） | 弱（陷落 Detriment） | 陷（衰弱 Fall） |
| --- | --- | --- | --- | --- |
| ☉ 太阳 | 狮子 | 白羊（19°） | 水瓶 | 天秤 |
| ☽ 月亮 | 巨蟹 | 金牛（3°） | 摩羯 | 天蝎 |
| ☿ 水星 | 双子、处女 | 处女（15°） | 射手、双鱼 | 双鱼 |
| ♀ 金星 | 金牛、天秤 | 双鱼（27°） | 天蝎、白羊 | 处女 |
| ♂ 火星 | 白羊、天蝎 | 摩羯（28°） | 天秤、金牛 | 巨蟹 |
| ♃ 木星 | 射手、双鱼 | 巨蟹（15°） | 双子、处女 | 摩羯 |
| ♄ 土星 | 摩羯、水瓶 | 天秤（21°） | 巨蟹、狮子 | 白羊 |

#### 四档的含义

**记忆锚点：**

+ **庙（Rulership）** = 回自己家，能量最自在、最有力
+ **旺（Exaltation）** = 做客上座，被格外礼遇，能量偏高但有"过头的风险"
+ **弱（Detriment）** = 到了对头家，能量别扭，需要用不习惯的方式运作
+ **陷（Fall）** = 掉坑里，能量最难受，需要刻意经营才出得来

**踩坑预警：弱陷 ≠ 坏。**
它描述的是 **运作难度** ，不是结果好坏。土星落陷（白羊）的人可能一辈子在学"如何既冲得动、又有章法"；一旦学会，这种人反而比天生土星庙旺的人更有意识的掌控力。

**口诀：庙旺是天赋，弱陷是功课。**

#### 擢升度数的用法

**进阶干货：擢升不只到星座，还精确到度数。**
例如太阳擢升在 **白羊 19°** 、月亮擢升在 **金牛 3°** 、木星擢升在 **巨蟹 15°** 。

**行星落在自己的擢升度数附近（±2° 内），能量会被额外强化** ，类似"坐在主位的主位上"。这是一个很精细但很准的加分项。

### 2_2 尊贵打分制

**进阶干货：把尊贵量化，是古典占星优于现代占星的地方——它可比较、可排序。**

#### 分值表

| 项目 | 分值 |
| --- | --- |
| 入庙（Domicile） | **+5** |
| 擢升（Exaltation） | **+4** |
| 三分主星（Triplicity） | **+3** |
| 界（Term / Bound） | **+2** |
| 面（Face / Decan） | **+1** |
| 陷落（Detriment） | **−5** |
| 衰弱（Fall） | **−4** |
| 外来的（Peregrine，无任何尊贵） | **0** |

#### 怎么用

**给盘里每颗行星打分，找出分数最高和最低的：**

| 结果 | 意义 |
| --- | --- |
| **最高分的行星** | 你最有力的工具，是"可以用一辈子的武器" |
| **最低分的行星** | 你最费劲的课题，是"必须刻意经营才拿得到的东西" |

**实操动作：** 给自己的日、月、水、金、火各打一个基础分（庙 +5、旺 +4、平常 0、弱 −5、陷 −4）。有余力再算三分、界、面。

**找出分数最低的那颗——它通常就是你人生最费劲、也最值得投入的课题。**

| 行星 | 落座 | 状态 | 分 |
| --- | --- | --- | --- |
| 太阳 | 狮子 | 入庙 | **+5** |
| 月亮 | 双鱼 | 平常（三分主星 +3） | +3 |
| 水星 | 处女 | **入庙 +5，擢升 +4** （双重） | **+9** |
| 金星 | 巨蟹 | 平常 | 0 |
| 火星 | 天秤 | **陷落** | **−5** |
| 木星 | 天蝎 | 平常 | 0 |
| 土星 | 双子 | 平常 | 0 |

**解读：**

+ **水星 +9** （处女入庙 + 擢升）→ 她的分析、表达、细节处理能力是她最锋利的武器。 **她做编辑工作，以"一眼看出错别字"闻名。**
+ **火星 −5** （天秤陷落）→ 她的行动力与自我主张是最大的课题。 **她的真实困境是：明明有想法，但要开口争取时总会犹豫、会绕、会先考虑别人。**
+ **太阳 +5** （狮子入庙）→ 她的自我表达是自在的，这救了她—— **她虽然不敢"争"（火星陷），但她敢"发光"（太阳庙）。**

**给她的建议** ：不要硬逼自己变成"敢冲的人"（那不是她的配置），而是 **用她最强的水星（分析、精准）来为火星开路** ——比如把要说的话先写下来、用数据和逻辑支撑自己的主张。 **用长板补短板，而不是硬啃短板。**

#### 两套界表与混用禁忌

**踩坑预警：存在"埃及界"与"托勒密界"两个版本，两者在部分星座的边界度数上不同。**
（例如天秤座：埃及界为土星 0-6 / 水星 6-14；另有版本作土星 0-6 / 水星 6-11 / 木星 11-19 / 金星 19-26 / 火星 26-30。）

**规则只有一条：选定一套，从头用到尾，不要混用。**

+ 古典/希腊占星通常用 **埃及界**
+ 中世纪传统常用 **托勒密界**

#### 界的古典用法（背景知识）

**进阶干货：** 古典文献中，各行星所掌管的界度数总和为 360°，被用作"寿数"的参考（土星 57、木星 79、火星 66、金星 82、水星 76；日月另有 120 与 108 的说法）。

**这是古代 longevity 判断的一部分，现代实践中强烈不建议用于预测寿命。** 但作为理解"界"在传统体系中分量的背景知识，很值得知道—— **界在古代的地位，远高于今天。**

### 2_4 面（Decans）与三分主星

**面（Faces / Decans）**

**深水区：每个星座切成三个 10° 段，按"迦勒底顺序"轮流分配，落在自己面内的行星 +1 分（最弱的一档尊贵）。**

迦勒底顺序： **土星 → 木星 → 火星 → 太阳 → 金星 → 水星 → 月亮** （由慢到快），从白羊第一面（火星）开始循环。

#### 三分主星（Triplicity）

**深水区：每个元素组有三颗主管星——昼主（日生盘用）、夜主（夜生盘用）、参与者（两者共用）。落在自己三分主星内的行星 +3 分。**

**三分主星表（多罗特乌斯系统）**

**记忆锚点：三分主星是唯一需要区分"日生盘/夜生盘"的先天尊贵。** 这也是为什么古典占星排盘第一步就是判断日生夜生。

### 2_5 日生盘与夜生盘（Sect）

**深水区：这是古典占星的地基，也是三分主星、法达推运等技法的前置条件。**

#### 判断方法

**出生时太阳在地平线之上 → 日生盘（Diurnal）；在地平线之下 → 夜生盘（Nocturnal）。**

**在盘图上看：** 太阳落在第 7-12 宫为日生盘；落在第 1-6 宫为夜生盘。

#### 派别表

| 派别 | 行星 | 特点 |
| --- | --- | --- |
| **昼间派（Diurnal）** | 太阳、木星、土星 | 日生盘中这些星"更符合本性"，力量更顺 |
| **夜间派（Nocturnal）** | 月亮、金星、火星 | 夜生盘中这些行星更顺 |
| **中立** | 水星 | 随其东出/西入、与其他行星的关系而定 |

**记忆锚点：日生盘里，土木日三颗星是你的"本命助力"；夜生盘里，月金火三颗星更得力。**

**踩坑预警：** 火星传统上归夜间派，这点常让人意外。
原因是古典体系中白天派（日木土）提供的是"秩序与稳定"，而夜间派（月金火）提供的是"变动与激情"—— **火星的躁动在夜间（阴性能量主导时）反而更合拍。**

### 2_6 偶然尊贵：行星的"处境分"

先天尊贵回答"这颗行星本身状态好不好"， **偶然尊贵（Accidental Dignity）** 回答"它在这张盘里处境顺不顺"。

#### 六大偶然因素

| 因素 | 影响 |
| --- | --- |
| **「1」 宫位强弱** | 角宫（1/4/7/10）> 续宫（2/5/8/11）> 果宫（3/6/9/12） |
| **「2」 喜乐宫** | 落在自己的喜乐宫会格外自在（见板块 0_23） |
| **「3」 派别（Sect）** | 符合日生/夜生派别的行星更顺（见 2_5） |
| **「4」 灼燃 / 核心** | 距太阳太近被遮蔽；在核心则被强化（见 2_7） |
| **「5」 东出 / 西入** | 东出更主动外显，西入更内省审慎（见 2_7） |
| **「6」 速度** | 快速行星活跃，慢速行星凝练（见板块 1_15） |

#### 宫位强弱速查

| 类型 | 宫位 | 能量强度 | 比喻 |
| --- | --- | --- | --- |
| **角宫** | 1、4、7、10 | 高 | 承重墙 |
| **续宫** | 2、5、8、11 | 中 | 储藏室 |
| **果宫** | 3、6、9、12 | 低 | 走廊与书房 |

**记忆锚点：行星落角宫 = 这件事在你人生里"很响"；落果宫 = 存在但声音小，需要你主动去找它。**

**进阶干货：偶然尊贵有时比先天尊贵更重要。**
一颗状态很差（入陷）但落在角宫的行星，可能比一颗入庙但躲在 12 宫的行星 **表现得更明显** 。
**先天尊贵决定"质量"，偶然尊贵决定"音量"。** 两者都要看。

### 2_7 灼燃、核心与东出西入

**行星与太阳的距离**

**深水区：行星与太阳的距离，是古典占星判断行星"有没有话语权"的关键指标。**

| 状态 | 与太阳的距离 | 含义 |
| --- | --- | --- |
| **核心 Cazimi** | 0°-0°17′（约 17 分内） | 行星"坐在太阳的心脏里"，被极大强化——这是 **吉相** ，不是凶相 |
| **灼燃 Combustion** | 0°17′-8°30′（约 8.5° 内） | 行星被太阳的光芒淹没，能量被遮蔽、被消耗、难以自主 |
| **在日光束下 Under the Beams** | 8°30′-17° | 行星被削弱，但比灼燃轻 |
| **摆脱光束** | > 17° | 正常 |

**踩坑预警：很多软件只标 Combustion，不区分 Cazimi。**
如果你的水星离太阳只有 0.2°，那不是"水星被烧掉"，而是 **水星极度强化** ——这两者的解读天差地别。 **务必核对度数。**

#### 灼燃的实操读法

**进阶干货：**

+ 灼燃的行星能量 **没有消失** ，而是"被太阳吞掉了"——它表现得更隐蔽、更不由自主、更容易被权威（太阳=父亲/上司/主流）压制；

| 行星灼燃 | 常见表现 |
| --- | --- |
| ☿ 水星灼燃 | 自己的想法容易被主流话语淹没，需要刻意练习"说出自己的话" |
| ♀ 金星灼燃 | 在爱里容易失去自我，价值感依赖他人认可 |
| ♂ 火星灼燃 | 愤怒被压住或爆发得毫无预兆 |

#### 东出与西入

**深水区：内行星（水金火）相对太阳的位置。**

| 状态 | 定义 | 表现 |
| --- | --- | --- |
| **东出（Oriental）** | 行星在太阳之前升起（黄道度数上"在前"） | 能量更早、更主动、更外显 |
| **西入（Occidental）** | 行星在太阳之后升起 | 能量更晚熟、更内省、更审慎 |

**实操含义：** 东出的内行星表现更直接、更有主见；西入的内行星更依赖关系与反馈来定义自己。

### 2_8 接纳、互容与守护链

**进阶干货：这是网络教程里很少讲清、但一说就懂、且极实用的三件事。**

#### 接纳（Reception）

**定义：** A 星落在 B 星守护的星座，且 A 与 B 成相位 → B "接待"了 A，愿意动用自己的资源帮 A。

**关键价值：即使是刑相或冲相，只要存在接纳，结果的破坏性会大幅降低** ——因为对方"认这个亲戚"。

#### 互容（Mutual Reception）

**定义：** A 落在 B 守护的星座，B 也落在 A 守护的星座 → 两星互相撑腰，形成强力的双向支持。

**举例：** 金星在白羊（火星的地盘）、火星在金牛（金星的地盘）→ **金火互容** 。
即便它们成刑相，也比普通刑相好办得多—— **因为双方有来有往、能互相兜底。**

#### 互容的三种层级

| 层级 | 条件 | 强度 |
| --- | --- | --- |
| 完全互容 | 互相落在对方 **入庙** 的星座 | 最强 |
| 擢升互容 | 互相落在对方 **擢升** 的星座 | 很强 |
| 混合互容 | 一颗落在对方入庙、另一颗落在对方擢升 | 强 |

**口诀：先看庙旺定强弱，再看接纳看帮不帮忙。**

#### 守护链与最终定位星（Dispositor Tree）

**进阶干货：这是一个能快速抓住全盘"权力结构"的工具。**

**做法：**

1. 对每颗行星，找出它所在星座的守护星；
2. 顺着链条往上追，直到某颗行星 **所在星座的守护星就是它自己** —— 那颗星叫 **最终定位星（Final Dispositor）** ；
3. 或者，链条进入循环 —— 那说明这是一个 **互容群体** ，能量在这些行星之间循环。

**读法：**

+ **最终定位星** = 这张盘的"最终裁决者"。整张盘的议题，最终都会归到它落的星座、宫位与状态上；
+ **不是每张盘都有最终定位星** （很多盘会形成互容循环）；
+ 若某颗星是最多行星的定位星，它就是"幕后老板"，即使它本身不强。

**实操动作：** 拿你的盘画一棵守护链树。看看有没有最终定位星—— **如果有，它是谁、落在哪宫？那个人/那件事，就是你人生的"总开关"。**

### 2_9 技法示例：陷落的行星不是没有，是使错了劲

> **说明** ：以下为 **教学示意案例** ，用于演示本节技法的推理链条，非真实个案记录。

**配置**

示意：水星双鱼，落 3 宫，与海王有宽相位。

**推演**

本节对"庙旺弱陷"的用法要点是： **状态描述的是运作方式与顺畅度，不是有无** 。

+ 水星在双鱼 → 思维以意象、感受、联想为主，不走线性逻辑；
+ "陷"意味着 **这一档运作起来更费力、更不被环境奖赏** ；
+ 但它的产出形态是独特的——擅长隐喻、图像、整体把握，短于逐条论证。

**复盘**

"陷"常被读成"缺陷"，这既不准确也有害。准确的表述是： **这一档的出厂设置与环境主流不匹配，因此需要额外的转换成本** 。指出转换成本，比贴"你不擅长"的标签有用得多。

### 2_10 五大主相位

单颗行星是单词，相位是动词。没有相位，盘上的十颗行星就是十个互不相干的词；有了相位，它们才开始说话。

| 相位 | 角度 | 符号 | 性质 | 动态 | 关键词 | 生活比喻 |
| --- | --- | --- | --- | --- | --- | --- |
| **合相** Conjunction | 0° | ☌ | 中性偏强 | 融合、叠加、浓度最高 | "捆在一起" | 两个部门合并办公 |
| **六合** Sextile | 60° | ⚹ | 吉 | 机会、可开发的天赋 | "给你梯子" | 有人给你递了个机会 |
| **刑相** Square | 90° | □ | 挑战 | 摩擦、压力、必须处理 | "逼你长本事" | 两个部门抢同一笔预算 |
| **拱相** Trine | 120° | △ | 吉 | 顺畅、天生就会 | "顺水推舟" | 配合多年，闭着眼都对 |
| **冲相** Opposition | 180° | ☍ | 张力 | 对立、拉扯、投射 | "照镜子" | 你讨厌的对方身上那个特质 |

#### 三个核心理解

**记忆锚点：**

+ **合相是"放大镜"** —— 它不辨好坏，只把两颗星的能量拧成一股，是好是坏看行星本身；
+ **刑与冲是"发动机"** —— 不舒服，但产出最大；真正"一事无成"的盘，往往不是刑冲多，而是 **什么硬相位都没有** ；
+ **拱与六合是"天赋券"** —— 舒服，但因为太顺，容易闲置浪费。

**口诀：合相加浓，拱六送糖，刑冲给压力也给你力量。**

#### 一个关键提醒：刑冲不是"坏"

**踩坑预警：这是新手最需要扭转的观念。**

| 误解 | 正解 |
| --- | --- |
| "刑冲多 = 命不好" | 刑冲提供 **驱动力** 。很多成就高的人盘上都有密集的硬相位 |
| "拱合多 = 命好" | 拱合提供 **顺畅** ，但也提供 **惰性** 。全吉相位的人常常"什么都不缺，但什么都不做" |
| "我要避开刑相位" | 刑相位是你要处理的课题，不是要躲开的灾祸 |

真正难解的盘，不是刑冲多的盘，而是 **没有任何紧张感、因而也没有任何动力的盘** 。

### 2_11 次要相位与梅花相

**次要相位总表**

| 相位 | 角度 | 性质 | 含义 | 强度 |
| --- | --- | --- | --- | --- |
| 半六合 Semi-sextile | 30° | 微吉 | 轻微的调适需求，相邻但不完全合 | 弱 |
| 半刑 Semi-square | 45° | 微凶 | 持续的烦躁、小摩擦 | 中弱 |
| 五分相 Quintile | 72° | 中性偏吉 | 创造力、独特性、天赋的精细表达 | 中 |
| 倍五分相 Bi-quintile | 144° | 中性偏吉 | 同上，更精微的创造天赋 | 中 |
| 补八分相 Sesquiquadrate | 135° | 微凶 | 需要调整的慢性压力 | 中弱 |
| **梅花相 Quincunx / Inconjunct** | 150° | 不调和 | 两者无法同时照顾，只能来回调整 | **中强，值得一学** |

#### 梅花相（150°）详解

**进阶干货：150° 的两颗行星"看不见彼此"——它们的元素与模态都不兼容。**

这带来的不是正面冲突，而是 **慢性的不适感** ：你必须在这两件事之间反复切换，哪边都放不下，哪边都做不彻底。

| 常见表现 | 例子 |
| --- | --- |
| 健康上的慢性小毛病 | 反复发作但查不出原因的不适 |
| 工作中反复的"两头兼顾" | 两个任务都无法全力投入 |
| 关系中"说不清哪里不对" | 不吵架，但长期别扭 |

**破解方式：承认它无法被一劳永逸地解决，只能持续微调——这本身就是答案。**

这就是梅花相的正确答案—— **不是解决，是安排。**

### 2_12 容许度（Orb）全表

容许度 = 允许偏离精确角度的误差范围。超过容许度，相位不成立。

#### 本命盘常用容许度

**本命盘常用容许度参考表**

| 相位 | 角度 | 常用容许度 | 说明 |
| --- | --- | --- | --- |
| 合相 | 0° | 8°（有用到 10-12°） | 日月等发光体可放宽 |
| 冲相 | 180° | 8° | 张力型主相位 |
| 拱相 | 120° | 7-8° | 顺畅型主相位 |
| 刑相 | 90° | 7-8° | 挑战型主相位 |
| 六合 | 60° | 4-6° | 比主相位要紧 |
| 梅花相 | 150° | 2-3° | 次要相位 |
| 半六合 | 30° | 2-3° | 次要相位 |
| 半刑 | 45° | 2° | 次要相位 |
| 补八分相 | 135° | 2° | 次要相位 |
| 五分相 | 72° | 2° | 微相位 |
| 平行/反平行（赤纬） | — | 1° | 见板块 3_14 |

#### 不同盘种的容许度差异（重要）

**这张表比上一张更常用**

| 盘种 | 容许度 | 为什么 |
| --- | --- | --- |
| **本命盘** | 主相位 6-8° | 描述的是长期性格结构，可以宽松 |
| **行运盘 Transit** | 约 1-3°（常用 2-3°） | 表示时机，必须收紧 |
| **次限推运 Secondary Progression** | 约 1° | 行星移动极慢 |
| **太阳弧 Solar Arc** | 约 1° | 用于事件定位 |
| **合盘 Synastry** | 约 3-5°（日月可略宽） | 关系影响 |
| **组合盘 Composite** | 约 2.5° | 合成盘的特性 |
| **平行/反平行** | 1°（行运可收紧到 0.5°） | 赤纬变化快 |

#### 按行星分配容许度（发光体最宽）

**进阶干货：容许度不只按"相位类型"分，也按"参与的行星"分。这是很多教程漏掉的一层。**

**核心原理：越重要的星，容许度越宽。**
太阳与月亮是两颗"发光体"，是盘上最重要的星—— **所以它们的相位容许度最大** 。
世代行星（天海冥）影响力世代化、个人性最弱—— **所以容许度最窄** 。

**现代心理占星通用标准（按行星）**

| 行星类别 | 行星 | 容许度 |
| --- | --- | --- |
| **发光体（最宽）** | 太阳、月亮 | **8°-10°** |
| **个人行星** | 水星、金星、火星 | 6°-8° |
| **社会行星** | 木星、土星 | 5°-7° |
| **世代行星（最窄）** | 天王星、海王星、冥王星 | 3°-5° |
| **关键虚点** | 上升 ASC、天顶 MC | 约 8°（与日月相近） |

**记忆锚点：日月的相位可以"宽一点算"，三王星的相位必须"紧一点才算"。**
**同一个 10° 的合相：太阳-土星仍然有力；火星-木星基本可以忽略了。**

#### 古典的"光锥"规则（进阶）

**深水区：古典占星用"行星光锥"（orb of light）理论来定容许度，规则与现代不同。**

**基本原理：** 每颗行星被认为有一个影响力的"光锥"，其半径通常是该行星自身最大容许度的一半。
**相位是否成立，取决于两颗行星的光锥是否相交。**

**古典各星最大容许度**

| 行星 | 最大容许度 |
| --- | --- |
| 太阳 | 15° |
| 月亮 | 12° |
| 木星、土星 | 9° |
| 火星 | 8° |
| 水星、金星 | 7° |
| 天王、海王、冥王、关键虚点 | 5° |

**口诀（古典最核心的一条）：慢行星遵从快行星。**

**当两颗行星形成相位时，实际使用的容许度，完全由运行速度更快的那颗决定。**

**举例：**

> 土星（容许度 9°）与月亮（容许度 12°）将要形成对冲相。

**由于月亮跑得远快于土星，只允许用月亮的容许度（12°）来判断。**
**反之则不成立** ——不能用土星的 9° 去卡月亮。

**进阶干货：为什么古典"理论容许度更宽"，实际却更严格？**
因为古典还有一层门槛： **相位必须"在星座上成立"或满足光锥相交** 。
理论数字虽大，判定条件却多—— **所以古典的相位筛选，实际比现代更严。**

#### 容许度三原则

**踩坑预警：**

| # | 原则 | 说明 |
| --- | --- | --- |
| **1** | **容许度不是国际标准** | 各派略有出入（有资料给出合冲 8°、刑拱 7°、六合 6°；也有统一 8°、六合 4° 的做法）。 **新手直接用排盘软件默认值，不要自己乱调** |
| **2** | **越接近 0°，相位越强** | 同样一个刑相，误差 0.5° 和 7° 完全不是一个量级。解盘时 **先读误差最小的那几个** |
| **3** | **次要相位用更小的容许度** | 通常 2°，否则一张盘会冒出几十个"相位"，全是噪音 |

#### 关于"边缘相位"

**踩坑预警：如果两颗星正好卡在容许度的边界上，算不算？**

**答：算一个"弱化版"的相位。**

| 情况 | 处理 |
| --- | --- |
| 相位在容许度边缘 | **它存在，但影响力轻微** ——权重低于更紧的相位 |
| 完全忽略宽相位 | 错误 不推荐。它们是真的，只是表达更轻 |
| 把宽相位和 0.5° 的相位同等对待 | 错误 更错。这会毁掉你的优先级判断 |

**记忆锚点：宽相位是"耳语"，紧相位是"喊话"。两者都听得见，但你先回应哪个，没有悬念。**

**进阶干货：容许度的"实用排序法"**
不要纠结于"到底该用 7° 还是 8°"。真正有用的做法是—— **把盘上所有相位按误差从小到大排序，然后只解前 5-8 个。**
误差最小的那几个，无论用什么容许度标准，都是主旋律。 **这才是容许度这个概念的真正用途：帮你筛选，不是帮你划线。**

### 2_13 入相位与出相位（Applying / Separating）

**进阶干货：这是新手最容易忽略、但在推运中极关键的一个判断。**

#### 定义

| 类型 | 定义 | 能量状态 |
| --- | --- | --- |
| **入相位（Applying）** | 运行较快的行星正朝精确成相的角度靠近 | 能量 **正在增强** ，事情正在逼近 |
| **出相位（Separating）** | 行星刚过精确点、正在离开 | 能量 **正在衰减** ，事情已过高峰、正在被消化 |

**判断法：** 看两颗星中运行较快的那颗，它在星盘上的位置正朝精确角度靠近，就是入相位。

**口诀：入相主未来，出相主过去。**

#### 三种场景的读法

| 场景 | 入相位的读法 | 出相位的读法 |
| --- | --- | --- |
| **本命盘** | 这个议题会越来越明显，是"要做的事" | 这个议题来自过去，是"已内化的部分" |
| **行运** | 事件正在路上 | 事件高峰已过，正在收尾 |
| **合盘** | 两人关系在加深 | 这段联结的强度在沉淀 |

### 2_14 相位的优先级

**踩坑预警：新手最典型的失败是"相位全解一遍"。** 一张盘可能有 30 个相位，全讲等于没讲。

#### 优先级排序表

**解盘时按此顺序讲**

| 优先级 | 类型 | 理由 |
| --- | --- | --- |
| 1 | **误差 ≤ 1° 的任何相位** | 音量最大，是主旋律 |
| 2 | **涉及发光体（日月）的相位** | 日月是盘的两大支柱 |
| 3 | **涉及命主星/上升的相位** | 命主星决定全盘走向 |
| 4 | **构成格局的相位** （T 三角、大三角等） | 格局高于单相位 |
| 5 | **内行星之间的紧密相位** | 影响日常行为 |
| 6 | 外行星相位 | 影响长期与世代层面 |
| 7 | 其余 | 可略 |

#### "主旋律清单"练习

**实操动作：** 在你的盘里，把所有误差在 3° 以内的相位列出来（不管吉凶）。

**这就是你星盘的"主旋律清单"。通常只有 5-8 个——解盘时优先讲这些，其余一律降权。**

>
>
>
> + 情绪极深且带执念（月冥冲 0.4°）
> + 思维严谨可靠（水拱土 0.9°）
> + 自我意识有模糊感，需要警惕自我欺骗（日刑海 1.2°）
> + 爱与行动能配合（金六合火 1.8°）
> + 外表开朗大方，冲淡了天蝎的疏离（木合 ASC 0.8°）
> + 行动与扩张互相拉扯，容易过度（火刑木 2.6°）
>
> **这就是"挑重点"的实际效果** ：从 27 条信息，压缩成 6 句能记住的话。

| # | 相位 | 误差 | 性质 |
| --- | --- | --- | --- |
| 1 | 月亮 ♓ 冲 冥王 ♍ | 0.4° | 硬 |
| 2 | 水星 ♍ 拱 土星 ♑ | 0.9° | 吉 |
| 3 | 太阳 ♌ 刑 海王 ♏ | 1.2° | 硬 |
| 4 | 金星 ♋ 六合 火星 ♉ | 1.8° | 吉 |
| 5 | 木星 ♏ 合 ASC | 0.8° | 强化 |

### 2_15 相位的"三层读法"

**进阶干货：任何一个相位，都可以从三层来读。掌握这个，你的解读会立刻立体起来。**

| 层 | 问题 | 例子（以"金火刑相"为例） |
| --- | --- | --- |
| **机制层** | 这两颗星的能量怎么互相作用？ | 爱（金）与行动/欲望（火）互相冲突——想要的太多、追得太急、或者喜欢的人恰恰惹你生气 |
| **表现层** | 这在生活里长什么样？ | 恋爱来得快去得快；容易被"有挑战性"的人吸引；争吵即调情 |
| **出路层** | 这个张力怎么用？ | 把"追逐的刺激"与"爱的深度"分开：允许自己慢下来，把冲劲用在共同做事上，而不是用在征服上 |

**踩坑预警：绝大多数新手只讲前两层（机制 + 表现），而最有价值的是第三层（出路）。**
"你金火刑相，所以感情容易起冲突"——这只是描述，甚至是重复对方已知的事。
"你可以把冲劲用在共同做事上，而不是用在征服上"—— **这才是解盘的价值。**

#### 五大相位的"出路模板"

| 相位 | 常见困境 | 出路方向 |
| --- | --- | --- |
| **合相** | 两股能量混在一起，分不清哪个是哪个 | **学会分辨** ：什么时候该用 A，什么时候该用 B |
| **六合** | 有机会但没开发 | **主动去用** ：它是需要你伸手去拿的梯子 |
| **刑相** | 两股能量互相打架，内耗 | **建立流程** ：给两股能量分配不同的时间/场景，而不是让它们同时抢方向盘 |
| **拱相** | 太顺，容易闲置或理所当然 | **主动挑战** ：给自己设定超出舒适区的目标，别浪费这份天赋 |
| **冲相** | 在两端之间摇摆，或投射到别人身上 | **收回投射** ：承认那是自己的一部分，然后找中间点 |

### 2_16 相位的"音量"判断：一张实用量表

**深水区：把相位强度量化，是提升解读准确度的一个有效方法。**

| 因素 | 加分 | 说明 |
| --- | --- | --- |
| 误差 ≤ 1° | +++ | 音量最大 |
| 误差 1-3° | ++ | 明确的主旋律 |
| 误差 3-6° | + | 有影响，但可讲可不讲 |
| 误差 > 6° | — | 通常略过 |
| 涉及日月 | + | 支柱行星 |
| 涉及命主星 | + | 全盘执笔人 |
| 合轴（任一方） | ++ | 被放大 |
| 构成格局 | +++ | 格局高于单相位 |
| 是入相位 | + | 正在发生 |
| 有接纳/互容 | ++ | 破坏性大幅降低 |

**用法：** 给每个相位打分，只讲总分 ≥ 4 的。

### 2_17 技法示例：刑相位不是判决，是待做的功

**配置**

示意：太阳狮子（10 宫）刑土星天蝎（1 宫），容许度 3°。

**推演**

本节对相位的定位： **相位描述的是两股力量之间的关系形态，不是事件结果** 。

+ 太阳（我要发光、被看见）与土星（限制、延迟、要求达标）成刑 → 两股力量互相拉扯；
+ "刑"意味着 **摩擦** ，摩擦会产生热量，也会产生阻力；
+ 落宫给出战场：10 宫（事业与公众形象）× 1 宫（自我与身体）→ 冲突集中在"我想被认可"与"我总觉得自己不够格"之间。

**复盘**

把"刑"直接翻译成"凶"，是把 **动力学** 误读成了 **判决** 。相位给的是"这两股力量怎么互动"，吉凶取决于这股摩擦被导向哪里。

### 2_18 六大格局速查

单看相位是看单词，看格局是看句子。格局一出现，它的重要性 **高于** 其中任何单个相位。

| 格局 | 构成 | 含义 | 核心读法 | 破解之道 |
| --- | --- | --- | --- | --- |
| **星群 Stellium** | 3 颗（严格说 4 颗）以上行星聚在同一星座或同一宫 | 能量高度集中的焦点领域 | 这是你生命的"主战场" | 成也在它、累也在它；要主动管理，不要被动承受 |
| **T 三角 T-Square** | 两星对冲，双双刑第三星（顶点星） | 巨大压力集中在顶点星上 | **顶点星是出口，也是成就点** | 看"空腿"（顶点正对面的星座/宫位）缺什么，那就是解药 |
| **大十字 Grand Cross** | 两组对冲 + 四个刑相（四星成十字） | 四股力量互相拉扯，持续高压 | 按基本/固定/变动分类看 | 能整合者成就极高；需要长期的内在协调 |
| **大三角 Grand Trine** | 三星两两成拱相，同元素 | 极强的天赋闭环 | 风险是 **太顺而懒** | 看有没有相位戳进来"打破"它，那颗星就是激活点 |
| **风筝 Kite** | 大三角 + 第四星与其中一星对冲、与另两星六合 | 天赋有明确出口 | 那颗第四星是"把手" | 把手星是天赋落地的落点，也是业力课题所在 |
| **上帝之指 Yod** | 两星六合，双双与第三星成梅花相（150°） | 带有宿命感的特殊任务 | 顶点星是必须持续调整的压力点 | 常见于有特殊使命感的盘 |

**记忆锚点：T 三角看顶点，大三角看缺口，风筝看把手，Yod 看顶点，星群看主战场。**

### 2_19 T 三角详解

**A 与 B 对冲（180°），C 同时与 A、B 成刑相（90°）。C 是顶点星（apex）。**

```plain
        C（顶点星）
        │
    刑  │  刑
        │
   A ───┴─── B
      对冲

```

#### 三步读法

| 步骤 | 看什么 | 说明 |
| --- | --- | --- |
| **第 1 步** | **顶点星 C** | 所有压力最终都汇聚到它身上。它是你的"爆发点"，也是你的"成就点" |
| **第 2 步** | **底边 A-B 对冲** | 这是一组内在对立，是你反复经验的拉扯 |
| **第 3 步** | **空腿（Empty Leg）** | C 正对面（180°）的那个星座与宫位是空的——它代表"缺失的能力"，也正是解药所在 |

#### 空腿法则

**进阶干货：这是 T 三角解读中最实用的一条。**

**举例：** 顶点星在白羊第 3 宫，那么空腿就是天秤第 9 宫。
这个人处理压力的方式，不是硬扛（白羊），而是去发展 **天秤第 9 宫** 的能力—— **学习协商、寻找更宏观的视角、在关系与信念中找到平衡** 。

>
> + **底边** ：月亮（摩羯、第 5 宫）对冲 海王星（巨蟹、第 11 宫）
> + **顶点** ：水星（双子、第 9 宫），同时刑月亮与海王
>

他的真实体验：脑子里永远在打架——一边是月亮摩羯要求"要有成果、要靠谱"（第 5 宫的创造表达），一边是海王双鱼要求"要模糊、要感受、要放下标准"（第 11 宫的社群与理想）。 **而夹在中间的，是他的思考与表达。**

>
> **第 3 步 · 空腿** ：顶点星在双子第 9 宫 → 空腿在 **射手第 3 宫** 。

射手第 3 宫的能力是： **形成自己的信念体系、用宏观视角统合碎片信息、把"我学到的"变成"我相信的"。**

"你处理这个内在拉扯的方式，不是让一边赢（那是不可能的），而是 **发展射手第 3 宫的能力** ——
把你的严格标准（摩羯）和你的感受力（双鱼） **整合进一套你自己的信念系统里** 。
换句话说： **别试图同时满足两个标准，而是建立一个更高的标准，让它同时容纳两者。** "

### 2_20 大三角的陷阱

**踩坑预警：大三角不是"好运认证"。** 它给的是流畅，但流畅的东西容易被浪费。

#### 三大问题

| 问题 | 说明 |
| --- | --- |
| **选择困难** | 三个人生领域互相配合得太好，当事人不知道该选哪个 |
| **缺乏驱动力** | 因为什么都不费力，没有"非做不可"的压力 |
| **封闭回路** | 外界刺激进不来，容易在自己的舒适区里打转 |

#### 破解方式

**寻找盘中有没有行星与大三角中的某颗形成硬相位（刑/冲）** ，那颗星就是"打破循环的钥匙"，也是这个人真正被推着成长的地方。

### 2_21 大十字与星群

**大十字的分类**

| 类型 | 组成星座 | 表现 |
| --- | --- | --- |
| **基本宫大十字** | 白羊、巨蟹、天秤、摩羯 | 强烈的开创欲，想掌控人生各方面，但常顾此失彼、内耗严重 |
| **固定宫大十字** | 金牛、狮子、天蝎、水瓶 | 极其固执坚毅，认定方向不为所动，但缺乏变通、易画地为牢 |
| **变动宫大十字** | 双子、处女、射手、双鱼 | 适应性强但一生奔波变动，缺乏根基，像"命带多个驿马" |

**进阶干货：大十字极其罕见。**
如果你的盘上有大十字，不必恐慌——它意味着你天生要在四个方向之间做整合。 **能整合的人，成就的深度非同寻常。**

#### 星群（Stellium）

**定义：** 3 颗以上行星聚在同一星座或同一宫（严格定义要求 4 颗以上）。

**四步读法：**

| 步骤 | 看什么 |
| --- | --- |
| 1 | 看星群落在 **哪个星座** → 这股能量以什么方式运作 |
| 2 | 看星群落在 **哪个宫** → 这是哪个生活领域 |
| 3 | 找出星群中 **度数最小** 的那颗（领头星）→ 它是这个星群的"发言人" |
| 4 | 看星群中央的 **太阳** （如果太阳在其中）→ 太阳会被强化 |

**踩坑预警：星群所在的宫位是"主战场"，但也意味着其他宫位相对薄弱。**
星群第 10 宫的人，事业极强但家庭领域可能长期被忽视—— **这不是命，是需要提醒自己平衡的地方。**

### 2_22 七种盘型：星盘的"轮廓"

**进阶干货：这是 Marc Edmund Jones 在 1941 年《Guide to Horoscope Interpretation》中提出的分类法，后来被 Dane Rudhyar 纳入人本主义占星体系。** 它是"看盘先看轮廓"的工具。

**前提：只用十大行星（日 → 冥），不含四轴、凯龙、南北交。** 因为原始定义就是这么定的。

#### 七种盘型速查表

| 盘型 | 定义 | 核心比喻 | 人生课题 |
| --- | --- | --- | --- |
| **捆束型 Bundle** | 所有行星集中在约 120°（约 4 个星座）内 | 激光，不是灯泡 | 极度专注；要主动向外扩展，避免盲区 |
| **碗型 Bowl** | 所有行星在约 180°（半个盘）内 | 半个碗是满的，另半个在召唤 | 从"拥有"走向"追寻"；空的那半球就是你的追寻方向 |
| **提桶型 Bucket** | 碗型 + 一颗孤星在对面（把手） | 所有能量从一个点流出 | 把手星是你的扩音器，是全盘的出口 |
| **火车头型 Locomotive** | 行星占约 240°，留一段约 120° 的空白 | 你是引擎 | 顺着行进方向推进；领头星是你的驱动力 |
| **跷跷板型 See-saw** | 行星分成两组，大致对冲，中间有两个 ≥60° 的空档 | 你在两个世界之间 | 学会权衡对立观点，而不是二选一 |
| **散落型 Splash** | 行星均匀散布，覆盖 8 个以上星座 | 你包罗万象 | 兴趣广但要主动选择深度 |
| **扩展型 Splay** | 不规则聚集成三个以上簇，不符合任何对称模式 | 你就是模式本身 | 高度个人化，不该被归类 |

#### 五分钟判断自己的盘型

**实操动作：**

1. 只看十大行星（日月水金火木土天海冥），忽略四轴与一切小行星；
2. 找出 **两颗相邻行星之间最大的那段空隙** ；
3. 按空隙大小与分布范围对号入座：

| 观察结果 | 盘型 |
| --- | --- |
| 所有行星挤在约 1/3 圈内 | 捆束型 |
| 行星占约半个盘，另一半全空 | 碗型 |
| 碗型 + 对面一颗孤星 | 提桶型 |
| 行星占约 2/3 圈，留一段约 120° 空白 | 火车头型 |
| 分成两组对冲，中间两个空档 | 跷跷板型 |
| 散布在 8-10 个星座上 | 散落型 |
| 不规则成簇，不符合以上任何一条 | 扩展型 |

#### 三种盘型的深度用法

**第1步 碗型：关键在空的那半球**

| 情形 | 含义 |
| --- | --- |
| 碗在 **南半球** （7-12 宫，星盘上半部） | 能量天然向外、向公共生活倾斜 |
| 碗在 **北半球** （1-6 宫，星盘下半部） | 能量向内，重视个人发展与私密经验 |

碗型人常有"总觉得少了点什么"的感觉—— **那正是空半球在召唤。**

**第2步 提桶型：关键在把手星**

把手星无论落在哪个星座、哪个宫，都是整盘能量的 **压力阀与出口** 。

| 把手星 | 成事方式 |
| --- | --- |
| 土星当把手 | 通过纪律与结构成事 |
| 金星当把手 | 通过关系、美感、价值成事 |
| 火星当把手 | 通过行动与开创成事 |
| 水星当把手 | 通过沟通、信息、分析成事 |

**第3步 火车头型：关键在领头星**

领头星 = 顺时针方向上，紧接在空白区之后的那颗行星。
它像"第二个命主星"，是驱动整列的引擎。
**火车头人通常自认"自己推着自己走"，但驱动的质量完全取决于领头星是谁。**

#### 盘型的三个边界问题

**踩坑预警：**

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | **盘型之间常有重叠** | "主要是碗型、带提桶倾向"是完全正常的判断 |
| 2 | **是否把凯龙、南北交、四轴算进去，会改变结果** | 原始定义不含它们；如果你要加，就对每张盘都统一加上，保持可比性 |
| 3 | **盘型只基于行星在黄道上的位置，与宫位制无关** | 换宫位制，盘型不变 |

**记忆锚点：盘型是"第一印象"，是看细节之前的轮廓。它不覆盖具体配置，只提供背景色。**

### 2_23 空相位行星与 Singleton

**空相位行星（Unaspected Planet）**

**进阶干货：这是网络教程极少提、但解释力很强的一个配置。**

**定义：** 某颗行星与本命盘中任何其他行星都没有形成主要相位（有的定义允许与四轴成相）。

**两种读法：**

| 读法 | 含义 | 适用 |
| --- | --- | --- |
| **"自由"的读法** | 这颗行星不受任何牵制，能量纯粹、独立、不受干扰——它是你的"纯能量源" | 落角宫 + 状态好 |
| **"孤立"的读法** | 这颗行星无法与其他心理功能对话，容易"自说自话"——它要么被过度使用，要么完全被忽略 | 落果宫 + 状态差 |

#### Singleton（唯一的那个）

**进阶干货：与空相位互补的一个概念，非常好用。**

**定义：** 盘里某个属性 **只有唯一一颗** 行星具备——这颗星就成了全盘的"压力出口"，重要性被放大。

| Singleton 类型 | 含义 |
| --- | --- |
| **唯一的元素星** | 唯一的火象/土象/风象/水象行星 → 该元素相关的所有事都压在它身上 |
| **唯一的模态星** | 唯一的基本/固定/变动行星 → 该节奏是你唯一的调节手段 |
| **唯一的半球星** | 某半球只有它一颗 → 那个方向的人生议题全部由它承担 |
| **唯一的阴阳星** | 唯一的阳性/阴性行星 |
| **唯一的逆行星** | 逆行的议题集中在它身上 |

**记忆锚点：Singleton 是"独苗"——独苗承压，也独苗出彩。** 给这颗星的资源多一点关注，回报会很明显。

### 2_24 格局与盘型的解读顺序

**记忆锚点：一次完整的"结构解读"，应该按这个顺序走：**

```plain
第 1 步  盘型      → 能量的整体轮廓（背景色）
第 2 步  星群      → 主战场在哪
第 3 步  格局      → 句式的核心（T三角看顶点，大三角看缺口…）
第 4 步  空相位/Singleton → 异常配置（独苗承压）
第 5 步  最后才回到单个行星的落座落宫

```

**踩坑预警：很多人一上来就一颗一颗讲行星，讲到第三颗就乱了。**
正确做法是 **先定结构，再看细节** 。结构定了，细节会自动归位。

**实操动作：** 打开你的盘，按上面五步，给自己的盘写一段"结构描述"（不超过 200 字）。

### 2_25 技法示例：大三角的舒适区，比 T 三角更难处理

**配置**

示意：大三角落在火象星座，涉及 5 宫、9 宫、1 宫；同时全盘无硬相位。

**推演**

本节对两类格局的处理不同：

+ **T 三角** 是张力结构，有明确的"空腿"（缺口）指向行动方向；
+ **大三角** 是闭环结构，能量在三角内部顺畅循环， **但正因为顺畅，缺少外部出口** 。

本例的问题恰在于此：火象大三角给了充沛的自发性与运气，却没有硬相位提供"非做不可"的压力点。结果是能量自我消化，不转化为产出。

**复盘**

格局判断必须区分 **张力型** 与 **闭环型** 。T 三角的问题是"太紧"，解法是"补空腿"；大三角的问题是"太顺"，解法是"主动加压"。用反了，都会失灵。
