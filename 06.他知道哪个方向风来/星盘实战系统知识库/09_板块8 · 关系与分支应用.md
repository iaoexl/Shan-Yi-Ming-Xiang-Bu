## 板块8 · 关系与分支应用

### 8_1 合盘：两个人的星图

> **本命盘看一个人，合盘看两个人。**

本板块回答："我们之间发生了什么？为什么这么来电？为什么这么拧巴？"

### 8_2 合盘三件套

**三种盘的区别**

| 盘种 | 做法 | 看什么 | 适合回答 | 新手建议 |
| --- | --- | --- | --- | --- |
| **比较盘 Synastry** | 两张盘叠看互相的相位与落宫 | 吸引与摩擦的具体来源 | "我们为什么这么来电 / 这么拧巴" | **先学这个** |
| **组合盘 Composite** | 取两人行星的 **中点** 合成"第三张盘" | 这段关系本身的性格与命运 | "我们这段关系是个什么东西" | 第二步 |
| **时空盘 Davison** | 取两人 **出生时间地点的中点** 合成盘 | 关系的演进与现实走向 | "这段关系会往哪去" | 第三步 |

**记忆锚点：比较盘看"你对我做了什么"，组合盘看"我们加在一起是什么"，时空盘看"我们会走到哪"。**

#### 三种盘的用法分工

| 场景 | 用哪个 |
| --- | --- |
| 刚认识，想了解彼此的化学反应 | 比较盘 |
| 已在一起，想理解这段关系的本质 | 组合盘 |
| 想看这段关系的长期走向 | 组合盘 + 时空盘 |
| 想看婚姻的可能性 | 比较盘（7 宫与土星）+ 组合盘（日月中点） |
| 想看合拍度 | 比较盘的日月升互换 + 金火 |

#### 三种盘的适用阶段与观察重点

**这张表解决"我现在该看哪一张"的问题**

| 盘种 | **适用阶段** | **重点观察** | 比喻 |
| --- | --- | --- | --- |
| **比较盘 Synastry** | 关系建立初期、暧昧或热恋阶段 | 太阳、月亮、金星、火星与上升之间的相位；尤其金火（吸引）、日月（相契）、月月（情绪安全感） | 把两种食材放在一起，尝它们 **原本的味道** 是相融还是相冲 |
| **组合盘 Composite** | 已在一起的伴侣、夫妻、长期事业合伙人 | **土星的落点与相位** （责任与稳定度）、太阳与月亮、第 4 宫（家庭）、第 7 宫（婚姻） | 两种食材混合搅拌， **烤成一个全新的蛋糕** |
| **时空盘 Davison** | 想看关系的长期演进与现实走向 | 四轴、推运（尤其次限与太阳弧）、土星与外行星的过境 | 这个蛋糕 **随着时间会变成什么样** |

**进阶干货：为什么组合盘要看土星？**
比较盘里的土星常被误解为"分手信号"，但在 **组合盘** 里，土星的含义完全不同——
**组合盘中的土星代表"这段关系本身的稳定结构"** 。
土星落在组合盘的重要位置（尤其合轴或与日月成相），往往说明 **这段关系需要、也经得起长期经营** 。

**踩坑预警：不要用比较盘回答"我们合不合适"，用组合盘回答。**

+ **比较盘** 说的是"你们之间的化学反应"——它解释吸引与摩擦， **但不回答关系的质量** ；
+ **组合盘** 才是"这段关系作为一个实体"的盘—— **婚姻与长期合伙，主要看它。**

**记忆锚点：初期看比较盘（有没有火花），长期看组合盘（有没有结构），走向看时空盘（会走到哪）。**

#### 别漏掉"伴侣点"（进阶补充）

**进阶干货：合盘里最容易被忽略、却最准的一条线索，是** 日月中点（Sun/Moon Midpoint） **——它被称为"伴侣点"。**

**为什么它比普通相位更"准"：**
它把一个人的"自我意志（太阳）"与"情感需求（月亮）"压缩成了一个点。
**别人的行星落在这里，是同时打到你的自尊与你的感受** ——所以那种"这个人很合我"的感觉会特别强。

| 别人的行星落在你的日月中点 | 体验 |
| --- | --- |
| **金星 / 上升** | 强烈的契合感，即使常规相位不多 |
| **土星** | 这段关系要求你认真，且影响你的自我整合 |
| **海王** | 强烈的理想化，也可能边界模糊 |
| **双向** （互相落在对方的中点） | 双方都觉得"就是这个人" |

**注意：中点激活强度 = 关系的重要性，不等于关系的质量。**
很多深刻但痛苦的关系，中点激活得极强。

**完整读法见板块 3_16（中点与 90 度盘）。**

### 8_3 合盘的前提

**踩坑预警：合盘最重要的前提是——两个人的出生时间都要准。**

| 情况 | 可用性 |
| --- | --- |
| 一方时间不准 | **比较盘的宫位落入部分不可信** （相位部分仍可用，因为相位不依赖时间） |
| 任一方时间不准 | **组合盘与时空盘高度依赖双方时间，不要用** |
| 时间都准 | 全部可用 |

完整伦理边界见 8_9「合盘伦理」。

### 8_4 行星落入对方十二宫

**这是比较盘最直观也最好用的一张表。**
读法："我的行星落入对方的第 N 宫，我在这段关系里对他产生了 ___ 的影响。"

| 落入对方宫位 | 影响 |
| --- | --- |
| **1 宫** | 强烈"看见彼此"的感觉；我会影响他的自我认同，他觉得在我面前"更像自己"或"更不像自己" |
| **2 宫** | 我影响他的价值感与金钱观；可能带来资源，也可能让他觉得"被估价" |
| **3 宫** | 我们很能聊；我激发他的表达欲，沟通是这段关系的入口 |
| **4 宫** | 我触动他的家庭与根源；关系有"家"的感觉，也可能唤起旧家庭议题 |
| **5 宫** | 恋爱感、玩得来、有火花；我激发他的快乐与创造力 |
| **6 宫** | 我影响他的日常与健康；关系可能在日常琐事中展开（同事/服务场景） |
| **7 宫** | **天然的伴侣感** ；我让他想要承诺，这是最强的"关系宫"落入 |
| **8 宫** | 深度纠缠、强烈吸引、transformative；也可能抓得太紧、边界模糊 |
| **9 宫** | 我拓展他的视野；关系带有"一起成长/一起远行"的质地 |
| **10 宫** | 我影响他的事业与公众形象；关系可能被"看见"，也可能介入他的社会角色 |
| **11 宫** | 我们是朋友也是伴侣；我带他进入新的社群，关系有自由感 |
| **12 宫** | 宿命感、说不清的牵扯、无条件的接纳；也可能是看不清、易被蒙蔽 |

### 8_5 行星之间的互相位

**本节及以下表格中的“日、月、水、金、火、木、土”均为** 行星缩写 **，与四元素（火象、土象、风象、水象）无关。**

**这是比较盘的第二张核心表**

| 配置 | 常见感受 | 备注 |
| --- | --- | --- |
| **日月互换** （我的太阳星座 = 你的月亮星座，反之亦然） | 极强的熟悉感与互补 | 最经典的"天生一对"信号之一 |
| **日-日 合/拱** | 核心价值观相近，容易互相理解 | 同元素更明显 |
| **月-月 合/拱** | 情绪上"住得惯"，生活习惯合拍 | **长期关系最重要的相位之一** |
| **月-月 刑/冲** | 安全感来源冲突，生活习惯摩擦 | 需要大量磨合，但也可互补 |
| **金-火 相位** （任一方向） | 经典的两性吸引 | 合相最强，刑冲则火花与冲突并存 |
| **金-金 相位** | 审美与爱的语言相近 | 拱合舒服，刑冲则爱的方式不同 |
| **火-火 相位** | 行动节奏一致（拱合）或互相较劲（刑冲） | 留意谁先让步 |
| **水-水 相位** | 沟通顺畅（拱合）或鸡同鸭讲（刑冲） | **日常相处的关键** |
| **日-月 相位** （我的太阳对他的月亮） | 我照亮他的情感需求 | 单向的滋养感 |
| **金星-土星 相位** | 稳定与承诺，也可能感到冷淡或被限制 | 关键看双方成熟度 |
| **火星-土星 相位** | 一方的行动被另一方压制，或一起做成大事 | 常见的"互补型"配置 |
| **木星触及对方个人行星** | 被触碰的一方感到被鼓励、被扩展 | 最讨喜的相位之一 |
| **土星触及对方个人行星** | 被触碰的一方感到压力，也感到可靠 | **双刃剑** |
| **天王触及对方个人行星** | 强烈的兴奋与不稳定 | 刺激但难持久 |
| **海王触及对方个人行星** | 浪漫、理想化、灵性联结 | 需警惕看不清 |
| **冥王触及对方个人行星** | 宿命感、深度改变、权力议题 | 强度最大，也最容易越界 |
| **凯龙触及对方个人行星** | 一方触发另一方的旧伤，也有疗愈可能 | 需要极大的善意 |
| **南北交触及对方行星** | 强烈的宿命感与"业力"色彩 | 未必舒服，但很难断开 |
| **Vertex 触及对方行星** | "命中注定"的相遇感 | 强度大，常出现在重要关系的开端 |

### 8_6 比较盘解读六步法

| 步骤 | 看什么 | 为什么 |
| --- | --- | --- |
| **1** | **双方行星落入对方 1、7、5、8 宫的情况** | 决定"有没有火花"与"有没有伴侣感" |
| **2** | **月亮的互动** （月月相位、月亮落入对方宫位） | 决定"住不住得惯"，是长期关系的关键 |
| **3** | **金火互动** | 决定吸引力与性化学 |
| **4** | **土星触及** | 决定这段关系的稳定性与压力点 |
| **5** | **外行星触及** | 决定这段关系的深度与宿命感 |
| **6** | **日月升互换与轴线互动** | 决定"熟悉感"与"互补性" |

#### 六个常见误区

**踩坑预警：**

| 误区 | 正解 |
| --- | --- |
| "刑冲太多 = 不合适" | 一个全吉相位的合盘，往往因太舒服而缺乏成长动力 |
| "没有相位 = 没有关系" | 可能是"彼此独立、互不干扰"，未必是坏事 |
| "土星相位 = 这段关系会分手" | 土星带来承诺与责任， **很多长久婚姻都有强土星配置** |
| "冥王相位 = 宿命注定" | 冥王带来强度与改变，能否承受取决于成熟度 |
| "8 宫落入 = 危险关系" | 8 宫的深度是亲密关系的一部分，不是危险信号 |
| "12 宫落入 = 对方在骗我" | 12 宫代表无条件的接纳与看不见的部分，不等于欺骗 |

**进阶干货：看合盘先看"轴点互换"。**
如果一方的行星落在另一方的四轴（尤其 ASC、MC）附近，这段关系的"存在感"会非常强—— **不管吉凶，对方都会深刻地改变你。**
**这比数相位更能快速判断一段关系的分量。**

但因为有前面那些强力的正面配置做底， **吵完能和好，而且关系在吵完之后反而更深** 。

### 8_7 组合盘（Composite Chart）

**做法与禁忌**

**做法：** 取两人每颗行星的 **中点** （黄道经度上的中点），合成一张全新的盘。

**踩坑预警（中点陷阱）：** 当两颗行星相距超过 180° 时，"中点"有两个（近端与远端）。
不同软件处理方式不同，有的取近端，有的取远端（取较长弧的中点）。
**若两张盘结果差异很大，先确认软件的中点算法。**

#### 解读要点

| 看什么 | 含义 |
| --- | --- |
| **组合盘 ASC** | 这段关系"呈现给外界的样子"；外人怎么看你们 |
| **组合盘太阳** | 这段关系的 **核心身份** ——"我们是谁" |
| **组合盘月亮** | 这段关系的 **情绪核心** ——"我们在一起的感觉" |
| **组合盘金星** | 这段关系的爱意表达方式 |
| **组合盘火星** | 这段关系的行动方式与冲突模式 |
| **组合盘土星** | 这段关系的责任、限制与"必须经营的部分" |
| **组合盘 MC** | 这段关系在社会上的样子（例如是否公开、是否被祝福） |
| **组合盘中的格局** | 这段关系的整体结构（大三角=顺畅；T三角=有张力但成长快） |
| **组合盘 7 宫** | 这段关系如何面对"外部世界" |
| **组合盘 8 宫 / 12 宫重的行星** | 深度纠缠、隐秘性、或需要留白的议题 |

**记忆锚点：组合盘的太阳是"我们是谁"，月亮是"我们在一起是什么感觉"。这两颗最重要。**

#### 组合盘太阳落十二宫

| 太阳落宫 | 这段关系的身份 |
| --- | --- |
| **1 宫** | 关系是"两个独立个体的联合"，重视各自的存在感 |
| **2 宫** | 关系建立在共同的价值与资源上 |
| **3 宫** | 关系是"一起说话、一起学习" |
| **4 宫** | 关系是"一个家"；重视归属与私密 |
| **5 宫** | 关系是"一起玩、一起创造"；有恋爱感 |
| **6 宫** | 关系是"一起做事、一起服务"；日常感强 |
| **7 宫** | **关系本身就是核心** ；重视承诺与对等 |
| **8 宫** | 关系是"深度交织"；强度大，涉及转化 |
| **9 宫** | 关系是"一起成长、一起看世界" |
| **10 宫** | 关系是"一起被看见"；有共同的社会目标 |
| **11 宫** | 关系是"一起做点什么"；朋友+理想伙伴 |
| **12 宫** | 关系是"隐秘的、灵性的"；需要独处空间 |

### 8_8 时空盘（Davison）与关系推运

**时空盘 vs 组合盘**

| 项目 | 组合盘 | 时空盘 |
| --- | --- | --- |
| 算法 | 行星取中点 | 时间地点取中点 |
| 性质 | 更"关系本体论" | 更"关系事件论" |
| 擅长 | 这段关系是什么 | 这段关系会经历什么 |
| 推运 | 可做组合盘推运 | 可做时空盘推运 |

**进阶干货：两个盘可以互补使用。**
常见做法是：用 **组合盘** 看本质，用 **时空盘** 看发展；或者只选一种，但固定下来保持连贯。

#### 关系推运

**深水区：**

| 技法 | 用法 |
| --- | --- |
| **组合盘次限** | 看这段关系的心理发展阶段 |
| **组合盘太阳弧** | 看关系中的重大事件（结婚、分手、危机） |
| **组合盘太阳返照** | 看"这段关系的一年"（从关系成立日起算） |
| **比较盘流年** | 看行运行星如何同时触动两个人的盘 |

**踩坑预警：** 关系推运需要双方时间都准确，而且 **不要用它来预言分手或离婚** 。
合理的用法是提示"这段时期关系会进入某个阶段，需要留意什么"。

### 8_9 关系特殊点、四类型与伦理

**宿命点（Vertex）在合盘中**

**进阶干货：这是合盘里"命中注定感"的主要来源之一。**

| 配置 | 感受 |
| --- | --- |
| 对方行星合我的 Vertex | "这个人像是注定要出现的"；相遇带有失控感 |
| 对方 ASC/DSC 合我的 Vertex | 强烈的相遇感，关系改变你的人生方向 |
| 双方 Vertex 互有行星 | 双向的宿命感 |

**踩坑预警：Vertex 带来的是"强度"，不是"幸福"。**
强烈的宿命感可能是深刻的爱，也可能是深刻的纠缠—— **它不保证关系的品质。**

#### 南北交在合盘中

| 配置 | 含义 |
| --- | --- |
| 对方行星合我的 **北交** | 这个人推动我成长；关系有"指向未来"的质感 |
| 对方行星合我的 **南交** | 强烈的熟悉感（像前世认识）；可能舒适但也可能停滞 |
| **双方南北交互换** （我的北交=你的南交） | 极强的"业力"感；成长与惯性同时存在 |
| 对方行星合我的南北交轴线 | 这段关系会牵动我的人生方向 |

**记忆锚点：北交关系"推着你走"，南交关系"拉着你不放"。**
**最好的状态是：既有南交的熟悉，又有北交的牵引。**

#### 土星在合盘中的双重角色

**进阶干货：土星是合盘里最被误解的行星。**

| 土星的角色 | 表现 |
| --- | --- |
| **稳定剂（正向）** | 带来承诺、责任、可靠性；这段关系经得起时间 |
| **压力源（负向）** | 带来束缚、冷淡、评判、"我在这段关系里不能做自己" |

**判断标准：** 看土星触及的是哪颗行星、双方其他配置如何。

| 土星触及 | 常见表现 |
| --- | --- |
| **月亮** | 一方在情感上感到被限制（较难） |
| **金星** | 爱意表达受限，但也意味着这份爱是认真的 |
| **太阳** | 一方觉得被压制，但也可能获得支持性的结构 |
| **在 7 宫** | 关系的承诺议题被放大 |

**关键提醒：** 很多长久婚姻的合盘里都有强土星。 **土星不是"分手信号"，它是"这段关系需要认真经营"的信号。**

#### 四种常见关系类型

**一张实用的总结表**

| 类型 | 特征 | 优势 | 风险 |
| --- | --- | --- | --- |
| **镜像型** （日月升互换、对宫吸引） | 互补、彼此是对方的另一半 | 强烈的完整感 | 容易互相投射，看不清自己 |
| **同类型** （同元素行星多、日-日/月-月拱合） | 天然懂、相处舒服 | 低摩擦、高默契 | 缺乏成长张力，易一起停滞 |
| **师徒型** （土星/木星触及多） | 一方给予结构或扩展 | 有成长性、关系有功能 | 权力不对等、依赖 |
| **业力型** （冥王/南北交/8宫/12宫重） | 强度极大、宿命感强 | 深刻、transformative | 边界模糊、纠缠、难以善终 |

#### 合盘伦理

| 原则 | 说明 |
| --- | --- |
| **双方知情同意** | 解合盘须双方知情，不背着一方解读 |
| **不评判第三方** | 不解读"他到底爱不爱我"这类涉及他人自由意志的问题 |
| **不下关系判决** | 不说"你们注定分手"，只说"这段关系里有 ___ 的课题" |
| **不介入决定** | 不替对方决定是否结婚、分手、生子 |
| **保护隐私** | 合盘涉及两个人的出生数据，须妥善保管 |

#### 合盘的答法示范

"我不会替你们判断'合不合适'，因为那是你们的事。但我可以告诉你 **这段关系的质地，以及你们需要一起面对的课题** ：
你们的关系 **不是'轻松'型的，是'有分量'型的** 。
它的价值不在于舒服，而在于 **它会推动你们两个人都成长** 。

### 8_10 技法示例：比较盘说吸引，组合盘说这段关系本身

> **说明** ：以下为 **教学示意案例** ，用于演示本节技法的推理链条，非真实个案记录。

**配置**

示意：
+ **比较盘** ：A 的金星合 B 的火星（吸引力强），但 A 的火星刑 B 的土星（相处中摩擦与压制感）；
+ **组合盘** ：太阳与土星合相，月亮落 8 宫。

**推演**

本节三种盘的分工在这里是分水岭：

+ **比较盘** 回答"我们之间发生什么"——吸引力（金火）与摩擦（火土）并存；
+ **组合盘** 回答"这段关系作为一个独立实体是什么样子"——日土合意味着这段关系本身的基调是 **严肃、需要经营、有现实压力** ；
+ 只看比较盘会得出"有火花"，只看组合盘会得出"很辛苦"，两者合起来才是完整判断。

**复盘**

合盘最常见的失误是 **只做比较盘** 。吸引强度与关系质量是两件事，前者看比较盘，后者看组合盘。另需注意伦理前提： **合盘需要双方的出生数据，且解读须同时对两人负责** 。

### 8_12 古典与现代的核心差异

**对照表**

| 维度 | 古典占星 | 现代心理占星 |
| --- | --- | --- |
| 哲学根基 | 自然哲学、宇宙秩序 | 心理学、人本主义 |
| 核心目标 | 判断吉凶、预测事件 | 自我理解、人格成长 |
| 视角 | 客观、外在（"会发生什么"） | 主观、内在（"我为什么会这样"） |
| 守护星 | 古典七曜 | 七曜 + 三王星 |
| 核心技法 | 宫主星飞星、尊贵打分、阿拉伯点、推运时限 | 相位心理分析、格局、心理动力 |
| 吉凶判断 | 明确区分吉星凶星 | 不做吉凶判断，强调"中性" |
| 关键词 | 命主星、飞星、接纳、界、时主星 | 原型、整合、成长、阴影 |

**记忆锚点：古典占星回答"会发生什么"，现代占星回答"这对我意味着什么"。**
**两者不冲突，是同一件事的两个切面。**

#### 该学哪一套？

| 你的目标 | 建议 |
| --- | --- |
| 想做事件预测与应期判断 | 古典 |
| 想做心理陪伴与成长咨询 | 现代 |
| **想两个都做** | **先精通一套，再学另一套** （不要同时学，会互相干扰） |

**进阶干货：一个稳妥的整合方式**
**用古典做骨架，用现代做血肉。**

+ 用古典技法确定 **结构** （命主星、宫主星飞星、尊贵强弱、时限）；
+ 用现代技法填充 **意义** （相位的心理动力、原型的表达、成长方向）。

这样既有古典的"准"，又有现代的"深"。

### 8_13 古典解盘主流程

```plain
1. 判断日生盘 / 夜生盘（sect）
2. 找命主星（上升守护星）→ 看其状态与落宫
3. 给每颗行星打先天尊贵分（庙旺三分界/面，弱陷）
4. 评估偶然尊贵（宫位、喜乐、灼燃、速度、东出西入）
5. 检查接纳与互容关系
6. 逐宫看宫主星飞星（事件链条）
7. 看阿拉伯点（尤其福点）
8. 用时主星技法（法达、小限）判断时间

```

**逐步说明**

| 步骤 | 关键动作 | 为什么 |
| --- | --- | --- |
| **1** | 太阳在 7-12 宫 = 日生；1-6 宫 = 夜生 | 决定派别与三分主星 |
| **2** | 上升星座的守护星 = 命主星 | 全盘执笔人 |
| **3** | 庙+5、旺+4、三分+3、界+2、面+1、弱−5、陷−4 | 找出最强与最弱的行星 |
| **4** | 角宫/续宫/果宫、喜乐宫、灼燃、速度 | 判断"音量"与"处境" |
| **5** | 接纳、互容 | 判断"有没有人帮忙" |
| **6** | 逐宫追宫主星落宫 | 判断"事件往哪走" |
| **7** | 福点为主，其他点按需 | 判断"满足感在哪" |
| **8** | 法达 + 小限 | 判断"什么时候" |

**踩坑预警：古典流程里，第 1 步（sect）经常被跳过——但它是后面所有步骤的前置条件。**
日生夜生判错，三分主星、sect 派别、法达顺序全会错。

### 8_14 时主星技法（Time Lord Techniques）

**深水区：古典占星用"时间主星"体系来划分人生阶段，这是现代占星所没有的。**

#### 五种技法

| 技法 | 层级 | 尺度 | 说明 |
| --- | --- | --- | --- |
| **法达 Firdaria** | 主 | 大限（数年）+ 小限（1-2 年） | 见板块 7_12 |
| **小限 Profections** | 主 | 年、月 | 见板块 7_13 |
| **黄道释放 Zodiacal Releasing** | 主 | L1-L4 层层细分 | 见板块 7_14 |
| **主限 Primary Directions** | 辅助 | 年 | 见板块 7_15 |
| **界主星（Bound Lord）** | 辅助 | 依度数而定 | 行星推进到不同界时，时主星切换 |

#### 时主星的正确用法：叠加

**进阶干货：用时主星的正确姿势是"叠加"，而不是单用。**

"今年的大背景是 **扩张期** （木星大限），而今年的具体执笔者是 **金星** （金星小限）——
所以今年木星的'扩张'，是通过 **金星的方式** （感情、金钱、美感、关系）来兑现的。
所以这个'通过关系来扩张'的过程， **会伴随压力与责任** （土星）。

### 8_15 古典的"吉凶"概念

**踩坑预警：古典的"吉星/凶星"不是道德判断。**

#### 分类

| 分类 | 行星 | 含义 |
| --- | --- | --- |
| **大吉星** | 木星 | 扩张、机会、保护 |
| **小吉星** | 金星 | 和谐、愉悦、吸引 |
| **大凶星** | 土星 | 限制、损失、延迟 |
| **小凶星** | 火星 | 切割、冲突、损伤 |
| **中性** | 水星、太阳、月亮 | 依状态与相位而定 |

#### "凶"的真实含义

古典体系里，凶星带来的是 **困难、延迟、损失** —— **但这些恰恰是"事情会发生"的必要条件。**

**进阶干货：这是一句值得记住的话——**

> **没有凶星的盘，往往是没有事件的盘。**

真正凶的是" **状态极差的吉星** "（例如木星落陷又受克），而不是" **状态良好的凶星** "（例如土星入庙于摩羯）。

#### 吉凶判断的三层修正

| 修正层 | 内容 |
| --- | --- |
| **第 1 层：先天性质** | 吉星/凶星（木金 vs 土火） |
| **第 2 层：状态** | 庙旺则吉性增强、凶性减弱；弱陷则相反 |
| **第 3 层：偶然尊贵** | 角宫、喜乐、sect 符合 → 增强；灼燃、果宫 → 减弱 |

→ 这颗土星 **极其有力** ，带来的是：事业上的长期成就、可靠的权威地位、经得起时间的结构。 **这是"大器晚成"的经典配置。**
→ 这颗木星 **虚有其表** ，带来的可能是：虚假的乐观、被夸大的机会、投入没有回报的领域。
这就是为什么古典占星要花那么大力气去给行星打分—— **因为"状态"比"性质"更重要。**

### 8_16 七曜的自然征象（古典的"人事对应表"）

**深水区：古典占星为每颗行星配了一套"自然征象"——它天生管哪些人、哪些事、哪些物。**
这套对应关系是古典判断的词典： **当你问"这件事归谁管"，答案就在这张表里。**

#### 七曜自然征象表

**这是古典占星最实用的一张词典表**

例如问官司：看 7 宫（对手）+ 木星（法官）+ 水星（文书）。
例如问遗产：看 8 宫 + 土星（土星管遗产与老年）。
**现代占星几乎不用这套，但在卜卦与择日里，它是主力工具。**

#### 行星的"昼夜派别"与"阴阳"

| --- | --- |
| **昼间派（日生盘得力）** | 太阳、木星、土星 |
| **夜间派（夜生盘得力）** | 月亮、金星、火星 |

这就是为什么"状态"可以修正"性质"—— **派别相合，本身就是一种修正。**

### 8_17 古典宫位观：吉宫、凶宫与喜乐宫

**深水区：古典对十二宫有一套"好坏"的排序，这在现代占星里是不讲的。**

#### 角宫 / 续宫 / 果宫的力量差

| 类型 | 宫位 | 力量 | 含义 |
| --- | --- | --- | --- |
| **角宫（Cardinal）** | 1、4、7、10 | **最强** | 事情"显化"、看得见结果 |
| **续宫（Succedent）** | 2、5、8、11 | 中等 | 支持角宫、积累资源 |
| **果宫（Cadent）** | 3、6、9、12 | **最弱** | 事情"游离"、难以把握 |

**进阶干货：同一颗行星，落角宫与落果宫，表现力差距极大。**
这就是板块 2_6 里"偶然尊贵"的核心—— **行星落在角宫，音量最大；落在果宫，声音发不出去。**

#### 古典的"凶宫"

**踩坑预警：古典把 6、8、12 宫称为"凶宫"，但这绝不是"这三个宫位完蛋了"。**

| 宫 | 古典看法 | 现代正解 |
| --- | --- | --- |
| **6 宫** | 疾病、奴役、劳苦 | 日常、工作、健康、服务 |
| **8 宫** | 死亡、他人之财、恐惧 | 深层交换、蜕变、共有资源 |
| **12 宫** | 隐秘之敌、囚禁、自我毁灭 | 潜意识、灵性、幕后、独处 |

**记忆锚点：古典说"凶"，说的是"这个领域的体验不舒服"，不是"这个领域没价值"。**
事实上， **12 宫在古典里同时是"土星的喜乐宫"** ——土星在这里反而得力（土星喜乐 12 宫）。

#### 行星喜乐宫（Joys）回顾与应用

| 行星 | 喜乐宫 | 为什么 |
| --- | --- | --- |
| ☿ 水星 | **1 宫** | 心智与身份同在 |
| ☽ 月亮 | **3 宫** | 月亮主变动，3 宫是短途与消息 |
| ♀ 金星 | **5 宫** | 金星主快乐，5 宫是愉悦 |
| ♂ 火星 | **6 宫** | 火星主劳作与切割，6 宫是工作与健康 |
| ☉ 太阳 | **9 宫** | 太阳主崇高，9 宫是信念与远方 |
| ♃ 木星 | **11 宫** | 木星主增益，11 宫是贵人与社群 |
| ♄ 土星 | **12 宫** | 土星主孤寂与隐匿，12 宫是隐藏 |

**进阶干货：喜乐宫是一个"隐藏加分项"。**
当你要判断"这颗星状态好不好"，而尊贵分打出来差不多时， **喜乐宫可以作为决胜依据** 。
例如：火星落 6 宫，尊贵分不高，但它在自己的喜乐宫—— **它会比同分数的其他位置更能发挥作用。**

#### 古典与现代的关键分歧点

| 议题 | 古典 | 现代 |
| --- | --- | --- |
| **8 宫** | 死亡、他人钱财 | 深度关系、性、心理蜕变、共有资源 |
| **12 宫** | 隐秘之敌、束缚、损失 | 潜意识、灵性、疗愈、幕后工作 |
| **6 宫** | 疾病与奴役 | 日常作息、服务、身心健康 |
| **5 宫** | 子女、享乐 | 创造力、恋爱、自我表达 |
| **凶星** | 明确区分吉凶 | 不判吉凶，只谈"功课" |
| **宫主星** | 事件链条的核心工具 | 参考之一，非必需 |

**口诀：古典看"会发生什么"，现代看"这对我意味着什么"。两把尺子，量的是同一块布。**

| # | 建议 |
| --- | --- |
| **1** | **先把本命盘读熟，再学古典。** 古典技法是工具，本命解读能力才是地基 |
| **2** | **古典技法要"成套使用"** ，不要东取一件西取一件（例如只学界不学三分，会得出矛盾结论） |
| **3** | **古典与现代可以共用一套盘** ，但 **不要在同一句话里混用两套逻辑** （例如用三王星做宫主星链条，又用古典打分） |

### 8_19 古典占星的现代价值

**进阶干货：为什么今天还要学古典？三个不可替代的价值。**

| 价值 | 说明 |
| --- | --- |
| **「1」 可量化** | 古典的尊贵打分制让"哪颗星最强"变成可比较、可排序的问题——现代占星缺乏这种工具 |
| **「2」 可预测** | 古典的时主星体系（法达、小限、黄道释放）提供了清晰的时间框架 |
| **「3」 可验证** | 古典技法大多有明确的规则与判据，说错了能查出来是哪里错了 |

**但古典也有它的局限** ：它对"内在体验"的描述远不如现代占星细腻。
**所以最好的状态是：用古典定结构与时机，用现代定意义与方向。**

### 8_20 技法示例：同一颗土星，古典说凶，现代说功课

**配置**

示意：土星合月亮，落 4 宫；土星为夜生盘（sect）中的吉星候选。

**推演**

本节对古典与现代差异的要点是： **两套体系的判据不同，结论也不同，但都自洽** 。

+ **古典口径** ：土星为"大凶星"，主阻滞、恐惧、匮乏；与月亮合 → 情绪与家庭领域的现实压力。古典会进一步看 **sect（昼夜区分）** 与 **尊贵** 来调节强弱，并非一律判凶；
+ **现代口径** ：土星是"边界与责任"，与月亮合 → 情绪表达有压抑倾向，需要通过建立结构与边界来发展；
+ 两者的 **共同点** 是：这一配置确实带来压力感； **差异** 在于古典给出"轻重与时机"，现代给出"意义与功课"。

**复盘**

混用两套口径是常见错误——用古典的"凶"配上现代的"注定"，会得出既吓人又无用的结论。 **选一套口径，全程不改** ；若要对照，就把差异明确讲出来，让听者自己判断。

### 8_21 分支二：卜卦与择日

**卜卦（Horary）** 回答一个具体问题； **择日（Electional）** 挑一个好时机。
它们和本命盘的最大区别是： **本命盘看"你是什么样"，卜卦择日看"这件事会怎样/什么时候做最好"。**

### 8_22 卜卦占星（Horary）基础

**什么是卜卦**

**定义：** 在提问的 **那一刻、那个地点** 画一张盘，用这张盘来回答那个具体问题。

**记忆锚点：卜卦盘不是"提问者的盘"，而是"这个问题的盘"。**
问题的"生日"，就是它被认真提出的那一瞬间。

**典型问题：**

+ 我丢的东西找得到吗？在哪？
+ 这笔生意能成吗？
+ 这份工作我应该去吗？
+ 他/她对我有意思吗？
+ 这个房子该不该买？

**踩坑预警：卜卦不是"算命的替代品"。**
它有严格的适用条件，也有明确的"不能回答"的边界（见 7_33）。

#### 五条基本规则

| # | 规则 | 说明 |
| --- | --- | --- |
| **1** | **问题必须明确** | "我该不该换工作"可以，"我的人生怎么办"不行 |
| **2** | **提问者必须有真实关切** | 随便问问、替别人问、拿来测试的，一律不作数 |
| **3** | **以"问题进入提问者脑海并被认真对待"的那一刻为准** | 不是你开口问占星师的时间，是你自己真正起念的时间 |
| **4** | **同一问题不重复问** | 问一次就得答案；不满意再问一次，第二张盘无效 |
| **5** | **盘要"可读"才作数** | 见下文的"严谨性检查" |

#### 卜卦盘的严谨性检查（Radicality）

**深水区：古典卜卦有一套"这张盘能不能用"的检查机制，学名 Radicality。**

| 检查项 | 含义 | 不通过时 |
| --- | --- | --- |
| **上升度数** | 上升落在 0-3°（问题太早，还没成形）或 27-30°（问题太晚，已经定局） | 不宜判断 |
| **土星落 1 宫** | 传统认为"占星师的判断会出错"，或提问者未坦白 | 谨慎，或请对方补充信息 |
| **月亮空亡** | 传统认为"事情不会有结果" | 倾向"维持现状" |
| **上升守护星状态极差且无解救** | 事情缺乏推动力 | 倾向"不成" |

**进阶干货：不要把这些检查当成"拒绝回答的借口"。**
现代实践中，更常见的做法是：把这些当作 **对答案的修正提示** ——
例如月亮空亡，不是说"不能回答"，而是提示"这件事大概率不会有实质性进展"。

#### 卜卦解盘的四要素

| 要素 | 对应 | 说明 |
| --- | --- | --- |
| **「1」 提问者的征象星** | **上升的守护星（命主星）** | 永远是第 1 宫主，代表"你" |
| **「2」 问题的征象星** | 按问题归属的宫位找宫主星 | 例如问工作 → 看第 10 宫主 |
| **「3」 月亮** | 事情的 **共同征象星 / 推动者** | 月亮代表"事情的走向"与"事情的经过" |
| **「4」 两者之间的相位** | 判断成不成 | 见下文 |

**口诀：一宫主是我，那宫主是事，月亮推着走，相位定成败。**

#### 常见问题的宫位归属

**卜卦盘用的是"本命宫位体系"，但含义按问题转化**

| 问题类型 | 看哪个宫 | 征象星 |
| --- | --- | --- |
| 我（提问者） | 第 1 宫 | 1 宫主 |
| 金钱、失物（我的财产） | 第 2 宫 | 2 宫主 |
| 兄弟姐妹、邻居 | 第 3 宫 | 3 宫主 |
| 房屋、土地、父亲、结局 | 第 4 宫 | 4 宫主 |
| 恋爱、子女、投机 | 第 5 宫 | 5 宫主 |
| 健康、雇员、宠物 | 第 6 宫 | 6 宫主 |
| 配偶、合伙人、对手、诉讼对方 | 第 7 宫 | 7 宫主 |
| 他人钱财、遗产、死亡议题 | 第 8 宫 | 8 宫主 |
| 远行、学业、法律、宗教 | 第 9 宫 | 9 宫主 |
| 事业、职位、母亲、名誉 | 第 10 宫 | 10 宫主 |
| 朋友、贵人、组织 | 第 11 宫 | 11 宫主 |
| 隐秘之事、损失、束缚、医院 | 第 12 宫 | 12 宫主 |

#### 判断成败的五种信号

| 信号 | 含义 | 强度 |
| --- | --- | --- |
| **两颗征象星形成入相位的合相或拱/六合** | 事情能成 | 强（正面） |
| **两颗征象星形成入相位的刑或冲** | 事情能成，但有阻碍、有代价 | 中（成但难） |
| **征象星之间无相位（无光传递）** | 事情难成，或双方没有交集 | 弱（倾向不成） |
| **出相位** | 事情已经过去、已成定局 | 时机已过 |
| **月亮空亡** | 事情不会有实质进展 | 倾向"维持现状" |

**进阶干货（"光的传递"Translation of Light）：**
当 A 与 B 没有直接相位时，如果有一颗第三方行星 C， **既与 A 成入相位、又与 B 成入相位** （且 C 从 A 的相位"走"到 B 的相位），那么 C 就是"传递者"——事情会通过 C 所代表的人或事而促成。

> **问题** ："我投的这个岗位，能拿到 offer 吗？"（提问时间地点确切）
>
> **第 1 步 · 找征象星** ：
>
> + 提问者 = 1 宫主。上升处女 → **水星**
> + 问题（工作/职位）= 10 宫主。10 宫头双子 → **水星**
> + **两者是同一颗星** （水星）→ 强烈的"我与这件事本就一体"的信号
>
> **第 2 步 · 看月亮** ：

月亮在天蝎，落第 3 宫（沟通、文书），与木星成入相位的六合。
→ 月亮正在推动事情，而且方向是 **扩张与有利** （木星）。

> **第 3 步 · 看相位** ：

水星（双向征象）与木星成入相位的六合，误差 4°。
→ 事情能成，且带有助力。

> **第 4 步 · 应期** ：

水星与木星的精确成相需要约 4 个时间单位。因为水星在中天附近（角宫，快），判断为 **约 4 周内** 。

> **结论** ：

"能拿到。而且这次不是你去追，是对方会主动联系你（征象星同为一颗，说明你与这个岗位高度匹配）。时间大约在四周内。"

> **验证** ：三周后收到 offer。
>
> **这个案例的关键点** ： **卜卦的答案往往非常具体** 。它不回答"你的职业前景如何"，它回答"这个岗位，四周内，会给你 offer"。

#### 应期（Timing）

**深水区：卜卦最难也最有价值的部分是"什么时候"。**

**应期通用规则：**

1. 看征象星成相需要多少度；
2. 按行星速度与所在宫位类型换算时间单位。

| 要素 | 换算 |
| --- | --- |
| **角宫（1/4/7/10）** | 快（天/周级） |
| **续宫（2/5/8/11）** | 中（周/月级） |
| **果宫（3/6/9/12）** | 慢（月/年级） |
| **移动快的行星（月水金）** | 时间短 |
| **移动慢的行星（木土及三王）** | 时间长 |

**常用单位对照（以度数差为准）：**

| 度数差 | 角宫 | 续宫 | 果宫 |
| --- | --- | --- | --- |
| 1° | 约 1 天/周 | 约 1 周/月 | 约 1 月/年 |

**踩坑预警：应期是卜卦里最不可靠的一环。**
即使是资深从业者，也应期判断的准确率也远低于"成不成"的判断。
**合理做法是给出区间（"大约一到三个月"），而不是具体日期。**

### 8_23 择日占星（Electional）基础

**与卜卦的区别**

| 对比项 | 卜卦 | 择日 |
| --- | --- | --- |
| 问题 | "这件事会怎样？" | "什么时候做这件事最好？" |
| 时间 | 由问题提出时刻决定 | **由你主动挑选** |
| 目标 | 判断 | 优化 |

#### 五条核心原则

| # | 原则 | 说明 |
| --- | --- | --- |
| **1** | **先有本命盘，再有择日** | 择日不能脱离当事人。给 A 挑的好日子，对 B 可能很糟 |
| **2** | **强化该事项的宫主星与自然征象星** | 例如开业要强化 10 宫主、MC、太阳、木星 |
| **3** | **月亮是择日的灵魂** | 月亮状态决定事情的"过程顺不顺" |
| **4** | **避开该事项的"凶星"压制** | 例如婚姻避开土星压金星、手术避开火星压命主星 |
| **5** | **角宫优于果宫** | 要"响亮"的事，让关键行星落角宫 |

#### 择日六步流程

```plain
第 1 步  确定事项类型（开业？结婚？签约？手术？搬家？）
第 2 步  找出该事项的主征象星（宫主星 + 自然征象星）
第 3 步  让主征象星处在良好状态（庙旺、角宫、与吉星成相）
第 4 步  让月亮处在良好状态（不空亡、不被凶星刑冲、最好与吉星成入相位）
第 5 步  避开明显的禁忌（见下文）
第 6 步  在候选人之中挑"最好"的那个，而不是等"完美"的那个

```

**踩坑预警：择日不是找"完美的日子"。**
完美的日子不存在。择日的艺术是 **在可行的时间窗口里，挑一个相对最好的** 。

#### 月亮的择日宜忌

**月亮是择日的第一变量**

| 月亮状态 | 宜 | 忌 |
| --- | --- | --- |
| **渐盈（新月→满月）** | 开始、增长、投入、播种 | 收割、结束 |
| **渐亏（满月→新月）** | 收尾、清理、减重、结束项目 | 开启需要长期增长的事 |
| **空亡** | 休息、例行事务 | **几乎所有重要启动** |
| **与木星/金星成入相位** | 几乎所有事（吉） | — |
| **与土星成相位** | 需要长期坚持的事（如签长约、打地基） | 开业、婚礼、需要顺畅的事 |
| **与火星成相位** | 需要冲劲的事（如竞技、切割、手术） | 需要和谐的事（婚礼、谈判） |
| **与海王星成相位** | 艺术、灵性、慈善 | 签合同、财务决策、需要清晰的事 |
| **被土星/火星刑冲** | 无事为宜 | 重要启动 |

**进阶干货：一条流传很广但很实用的老规则——**

> **"不要在月亮空亡时开始任何你希望它有结果的事。"**
>
> 这条规则的实用价值极高，因为它简单、可查、且大量案例支持。 **学完就能用。**

#### 常见事项择日要点

| 事项 | 强化什么 | 避开什么 |
| --- | --- | --- |
| **结婚** | 金星（爱）、7 宫主、月亮、木星（祝福）；月亮渐盈 | 土星压金星、月亮空亡、火星刑 7 宫主、日月食当日 |
| **开业 / 创业** | 10 宫主、MC、太阳、木星、火星（行动）；月亮与木星/太阳成相 | 月亮空亡、土星压 MC、水星逆行期间启动全新业务 |
| **签约** | 水星（文书）、7 宫主（契约）、月亮状态良好 | **水星逆行** 、月亮空亡、海王星模糊征象星 |
| **手术** | 避开火星压命主星/月亮；避开月亮在该身体部位对应的星座 | 月亮在该部位星座、火星刑命主星、日月食 |
| **搬家** | 4 宫主、月亮；月亮渐盈为宜 | 月亮空亡、土星压 4 宫主 |
| **求职/面试** | 水星（表达）、10 宫主、太阳；月亮与木星成相 | 月亮空亡、水星逆行 |
| **考试/升学** | 水星（思维）、9 宫主、木星 | 水星逆行、月亮空亡 |
| **远行** | 9 宫主、月亮；月亮状态良好 | 月亮空亡、火星刑 9 宫主 |
| **生子（剖腹产择时）** | 注意 **见下方伦理说明** | — |

**踩坑预警（剖腹产择时）：**
这是一个 **高度敏感** 的议题。医疗安全永远是第一位的。
占星择时 **绝不能影响医疗决策** ，也不应在没有医生参与的情况下讨论。
**负责任的从业者会把这一点明确告知，并拒绝在不具备医疗条件的情况下提供此类服务。**

#### 水星逆行到底要不要避开

**进阶干货：这是被误解最多的一条。**

| 说法 | 正解 |
| --- | --- |
| 错误"水逆期间什么都别做" | 过度恐慌。水逆每年来 3 次，每次约 3 周，全年约 20% 的时间——不可能停摆 |
| 错误"水逆不影响我" | 也未必。水逆期确实是沟通、文书、交通、设备故障的高发期 |

**更准确的理解：**
水星逆行 = **"复查、修正、重来"的时段** 。

| 水逆期 **适合** | 水逆期 **不适合** |
| --- | --- |
| 复盘旧项目、修订文稿 | 签署全新的重要合同 |
| 找回失联的人、重修旧好 | 发布全新产品/品牌 |
| 维修、整理、归档 | 购买电子产品、签租车/购房合同 |
| 重新审视已有方案 | 做不可逆的、需要精确沟通的决定 |
| 带"re-"前缀的一切：review / revise / return / reconnect | 首次启动任何"第一次"的事 |

**口诀：水逆不是不能动，是适合"重来"不适合"新开"。**

**水逆结束后（顺行），合同重新签定，一切都顺。**
**所以最实用的建议是** ：重要合同尽量避开水逆；如果避不开， **就把"可能会改"写进预期里** ，别签完就以为定了。

### 8_24 行星时（Planetary Hours）

**深水区：一个简单、古老、可立即上手的小技法。**

#### 原理

把一天（日出到日出，或传统的日出至日落、日落至日出两段各 12 等分）分成时段，每个时段由一颗行星（古典七曜）按固定顺序轮值。

**迦勒底顺序（由慢到快）：**

```plain
土星 → 木星 → 火星 → 太阳 → 金星 → 水星 → 月亮

```

**关键规律：** 每天日出的第一个小时，由当天的"星期主星"掌管。

| 星期 | 主星 | 中文 |
| --- | --- | --- |
| 周一 | ☽ 月亮 | 月曜日 |
| 周二 | ♂ 火星 | 火曜日 |
| 周三 | ☿ 水星 | 水曜日 |
| 周四 | ♃ 木星 | 木曜日 |
| 周五 | ♀ 金星 | 金曜日 |
| 周六 | ♄ 土星 | 土曜日 |
| 周日 | ☉ 太阳 | 日曜日 |

#### 怎么用

| 行星时 | 适合做的事 |
| --- | --- |
| **太阳时** | 见权威、争取认可、重要会面、公开亮相 |
| **金星时** | 约会、表白、谈判、艺术创作、美容、购物 |
| **水星时** | 签文书、沟通、学习、发重要邮件、短途出行 |
| **月亮时** | 家庭事务、照顾他人、搬家、直觉性决定 |
| **火星时** | 启动竞争、切割、运动、处理冲突、动手术 |
| **木星时** | 申请、面试、法律事务、谈加薪、远行规划 |
| **土星时** | 长期规划、打地基、整理归档、处理麻烦事、结束旧事 |

**进阶干货：不要孤立使用行星时。**
行星时是 **临门一脚的微调工具** ，不是择日的主体。
**正确顺序是：先用月相与月亮状态挑日子 → 再用行星时挑当天的具体时段。**

### 8_25 卜卦与择日的配合

两者不是竞争关系，而是 **前后脚** ：一个回答"该不该"，一个回答"何时做"。

#### 配合顺序

| 场景 | 先用 | 再用 | 说明 |
| --- | --- | --- | --- |
| "我该做这件事吗？什么时候做？" | **卜卦** （该不该） | **择日** （什么时候） | 顺序不能颠倒——不该做的事，挑再好的日子也没意义 |
| "这件事能成吗？成了的话什么时候？" | **卜卦** （成不成 + 应期） | — | 卜卦本身可给应期 |
| "我要开业，挑个好日子" | **择日** （挑日） | **行星时** （挑时段） | 先定日期，再定当天的钟点 |

**记忆锚点：卜卦问"该不该"，择日问"何时做"，行星时定"哪个钟点"。**

#### 一个完整的工作流

**实操动作：以"我要不要签这份合同"为例。**

| 步骤 | 做什么 | 判据 |
| --- | --- | --- |
| **第 1 步** | 起卜卦盘，问"签这份合同对我有利吗？" | 看 ASC 主星与 7 宫主（对方）的关系 |
| **第 2 步** | 若结论为"可以" | 进入第 3 步 |
| **第 3 步** | 若结论为"不宜" | **到此为止** ——不要再挑日子了 |
| **第 4 步** | 择日：在本命与卜卦都不冲突的前提下，挑月亮状态好的时段 | 避开月空亡、避开月亮受严重刑克 |
| **第 5 步** | 定行星时：在该日内挑与事项性质相合的行星时 | 签约类看水星时，合作类看金星时 |

**踩坑预警：最常见的错误是先挑好日子，再问"该不该做"。**
这是把顺序搞反了—— **等于先定婚礼日期，再决定要不要结婚。**

#### 什么时候两个都不用

**进阶干货：这三种情况，卜卦和择日都帮不了你。**

| 情况 | 为什么 | 该做什么 |
| --- | --- | --- |
| **问题本身不成立** | 例如"我该不该让他回心转意"——这不是你能决定的事 | 重新提问，问"我该怎么面对" |
| **你已经决定要做了** | 只是想求个心安 | 直接做，别问 |
| **涉及专业领域** | 医疗、法律、重大财务 | **去找专业人士，不要问星盘** |

### 8_26 卜卦与择日的三条学习纪律

| # | 纪律 | 说明 |
| --- | --- | --- |
| **1** | **先把本命盘学扎实** | 卜卦与择日都建立在本命盘的语言之上。本命不熟，这两个学不会 |
| **2** | **大量记录与回验** | 每次卜卦都记下问题、盘、判断、结果，定期统计准确率 |
| **3** | **拿不准就说"这张盘读不出来"** | 这比硬给一个答案专业得多 |

### 8_27 技法示例：卜卦问失物：钥匙在哪儿

**配置**

示意：起卦时刻上升落在双子，失主主星（水星）落 3 宫，与木星成六合。

**推演**

本节卜卦占星的基本流程：

1. **确认问题可卜** ——失物类问题有明确判据（能否找回、在哪、多久），适合卜卦；
2. **取主星** ：失主由 1 宫主星代表（水星），失物由 2 宫主星代表；
3. **看两者关系** ：失主星与失物星成吉相位 → 可找回；无相位 → 难；
4. **看失物星落宫与星座** 定方位与场所：本例落 3 宫、风象 → 文书堆、车内、通讯设备附近、或离家不近的短途范围内；
5. **看有无"收拢"迹象** 判断时间。

**复盘**

卜卦与择日的共同前提是： **问题必须具体、可判** 。像"我今年运势如何"这类问题，不适合卜卦，因为它没有明确的判据。卜卦的强项恰恰在于 **回答"是/否 + 在哪 + 何时"这类封闭问题** 。

### 8_28 分支三：换地、时事与商业占星

> **前两个分支把占星用在"时间"上（推运、卜卦、择日），这一块把它用在"空间"和"集体"上。**

你会看到：同一张盘，在地球上的不同位置，会画出完全不同的能量地图。

### 8_29 换地占星（Astro_Carto_Graphy，简称 ACG）

**什么是 ACG**

**原理：** 把本命行星投影到地球表面。每颗行星在出生时刻，会在地球上有四条特殊的线—— **升起线、落下线、天顶线、天底线** 。

当你 **身处某条行星线上** （或附近），那颗行星的能量会在你的生活里被显著放大。

**记忆锚点：ACG 回答的是"我在哪里，会活出哪一颗行星"。**

#### 四条主线

| 线 | 缩写 | 行星位置 | 含义 |
| --- | --- | --- | --- |
| **升起线** | ASC 线 | 行星在该地 **升起** （地平线） | 该行星能量 **融入你的身份与气质** ，最外显 |
| **落下线** | DSC 线 | 行星在该地 **落下** | 该行星能量通过 **关系与他人** 来到你面前 |
| **天顶线** | MC 线 | 行星在该地 **过中天** | 该行星能量体现在 **事业与公众形象** 上 |
| **天底线** | IC 线 | 行星在该地 **过天底** | 该行星能量影响 **家庭、内在、私人生活** |

**进阶干货：四条线的常见排序——**

+ 想 **改变自己的状态** （性格、能量、生活方式）→ 走 **ASC 线**
+ 想 **提升事业与曝光** → 走 **MC 线**
+ 想 **遇到某类人** → 走 **DSC 线**
+ 想 **安家、疗愈、内在安定** → 走 **IC 线**

#### 行星线含义速查

**这是 ACG 最核心的一张表**

| 行星线 | 在该地可能的体验 |
| --- | --- |
| **☉ 太阳线** | 更有活力、更被看见、更容易成为焦点；自我表达顺畅 |
| **☽ 月亮线** | 情绪更敏感、更"有家的感觉"、也更易受环境影响 |
| **☿ 水星线** | 交流频繁、学习机会多、信息流通快、适合写作与教学 |
| **♀ 金星线** | 人缘好、桃花多、生活更舒适、审美与艺术机会多 |
| **♂ 火星线** | 行动力增强，但 **冲突、意外、摩擦也增加** ；适合拼搏，不适合静养 |
| **♃ 木星线** | **最受欢迎的线** ：机会、贵人、扩展、乐观、成长 |
| **♄ 土星线** | 辛苦、压力、责任重；但也是 **长期成就与深耕之地** |
| **♅ 天王星线** | 变动、刺激、意外、自由；适合创新，不适合求稳 |
| **♆ 海王星线** | 浪漫、灵性、艺术；但也可能 **方向模糊、边界不清** |
| **♇ 冥王星线** | 强度极大、深层改变、权力议题； **不是轻松之地，但可能是转化之地** |

#### 三种用法

| 用法 | 做法 | 说明 |
| --- | --- | --- |
| **「1」 选居住地 / 迁居** | 看你想要激活哪颗行星，去那条线附近 | 例如想发展事业 → 找木星 MC 线或太阳 MC 线 |
| **「2」 选旅行 / 短期出差地** | 按出行目的挑线 | 想休息 → 月亮 IC 线；想突破 → 天王线 |
| **「3」 理解"为什么我在这里不自在"** | 看你当前所在地是否压在某条凶星线上 | 例如长期待在土星 ASC 线，可能持续感到压抑 |

#### 读图的四条实操规则

**踩坑预警：**

| # | 规则 | 说明 |
| --- | --- | --- |
| **1** | **距离越近，力量越强** | 通常认为线附近约 **300-500 公里** 内影响明显；越靠近线越强 |
| **2** | **多条线叠加要合看** | 若某地同时有木星 MC 线与土星 ASC 线，要综合判断，不能只看吉的 |
| **3** | **"坏线"不等于"不能去"** | 土星线适合长期深耕；冥王线适合深度转化。 **要看你去那里做什么** |
| **4** | **ACG 不能替代现实条件** | 工作、签证、家庭、语言、成本——这些永远优先 |

"你的木星 MC 线正好穿过那里—— **木星管扩展与机会，MC 管事业与公众形象** 。

### 8_30 时事占星（Mundane Astrology）

**把国家、城市、机构、事件当作"有生日的实体"，用占星解读集体层面的趋势。**

#### 四类"实体盘"

| 类型 | 起盘时刻 | 用途 |
| --- | --- | --- |
| **国家盘（National Chart）** | 建国、独立、宪法生效、政权确立的时刻 | 看国运与集体议题 |
| **ingress 盘（Ingress Chart）** | 太阳进入 0° 白羊（春分）的时刻 | 看当年全球/区域趋势 |
| **日月食盘** | 每次食发生的时刻 | 看食后半年内的集体事件 |
| **重大事件盘** | 某事件发生的时刻 | 分析该事件的结构与后续 |

#### 常用技法

| 技法 | 说明 |
| --- | --- |
| **春分盘（Aries Ingress）** | 最经典：以当地春分时刻起盘，看当年该地区运势 |
| **摩羯/巨蟹/天秤 ingress 盘** | 四季入宫盘，看季度趋势 |
| **外行星过境国家盘四轴** | 尤其土星、冥王过国家盘的 ASC/MC，常对应结构性变革期 |
| **日月食落在国家盘的哪个宫** | 对应集体议题被触发的领域 |
| **食相发生的地理可见区** | 传统认为食的可见区域与该事件相关 |

**进阶干货：时事占星中最被验证的一条规律——**

> **土星或冥王星经过一个国家的 ASC / MC / 太阳时，往往对应制度性的压力、重构或权威更替。**
>
> 历史上多次被反复检验。这是时事占星最稳健的工具之一。

#### 时事占星 · 三条伦理边界

**踩坑预警：时事占星是最容易越界的一块。**

| # | 边界 |
| --- | --- |
| **1** | **不预言具体灾难、战争、死亡事件** |
| **2** | **不用于政治站队或煽动** |
| **3** | **承认时事占星的准确率远低于个人盘** ——它描述的是"气候"，不是"剧本" |

**记忆锚点：时事占星描述的是"集体氛围与结构性压力"，不是"会发生什么新闻"。**

"你能做的，是描述 **这段时期的集体心理气候** ——例如'土星与冥王合相期间，集体会经历结构性的压力、限制与制度性的重构'。
但你 **不能** 据此说'某月某日某地会发生 X 事件'。

### 8_34 技法示例：换地占星：不是'搬家就转运'

**配置**

示意：某条行星线（如木星线）经过国内某区域，另一条（如土星线）经过另一区域。

**推演**

本节对 ACG 的定位需要说清楚：

+ ACG 的做法是：把出生盘的行星投影到地球表面，画出各行星的 **升起、天顶、落下、天底** 四条线；
+ 某条线经过某地，通常被解释为"该行星的象征在该地更容易被感受到"；
+ **但它不是搬迁建议** ——它描述的是"不同地点强调不同的主题"，而不是"某地一定更好"；
+ 严谨的用法是 **与过运、返照盘叠加** ，看某段时间身处某地会强化什么。

**复盘**

ACG 最大的滥用是 **简化成"搬家改运"** 。可验证的部分很有限，它更适合作为"选择出差地、求学地、短期驻留"的辅助参考，而不是人生决策依据。
